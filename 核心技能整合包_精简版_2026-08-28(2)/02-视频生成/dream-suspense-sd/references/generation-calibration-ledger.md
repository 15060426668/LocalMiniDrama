# Generation Calibration Ledger

用途：把真实生成结果反向沉淀成模型配置，而不是继续添加未经验证的“万能提示词”。

## Promotion Rule

- 单次成功只保留案例，不升级为通用规则。
- 同一模型同类镜头重复成功两次，形成候选配置。
- 三次以上且跨场景稳定，才进入模型正式配置。
- 模型升级后旧配置降为历史记录，重新验证摄影机、动作、口型、转场和连续性。

## Compiler Use

用户明确目标模型时，先读取该模型已验证配置；没有实测记录时使用通用编译契约，并把判断标记为预计风险。不得用其他模型的成功经验冒充当前模型结论。
