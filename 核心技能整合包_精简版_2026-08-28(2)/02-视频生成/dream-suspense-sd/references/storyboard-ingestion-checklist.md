# Storyboard Ingestion Checklist v6

用途：在写BASE或A之前确认来源合法、完整、已批准。此清单只做摄取，不设计新镜头。

## 1. 来源资格

按优先级接受：

1. 当前对话中用户明确批准的正式分镜。
2. 用户明确指定的批准分镜文件。
3. 需要修复的既有SD文本及其批准源。

以下不能直接进入编译：方案池、对标分析、粗略想法、仅有尾帧/参考图、未确认的豆包/MJ文本、上游训练资料。来源不足时列出最小缺口，不自行补戏。

## 2. 阶段和媒介

确认：

```text
用户当前明确要求SD承接
媒介：动画 / 非动画 / 2D主体+真人底片
时长：4-30秒整段，或已批准的多段划分
入口：硬切新镜头 / 连续跟拍 / 动作匹配 / 遮挡 / 声音先行
参考权限：人物 / 场景 / 服装 / 动作 / 首帧 / 尾帧 / 音频
```

媒介继承当前项目，不因“电影感、真实光影、镜头”自动改成真人。动画项目读取 `animation-expanded-execution.md`；非动画项目读取 `sd-video-advanced-execution.md`。

## 3. 段级事实锁

从批准源提取：

```text
段落任务、类型脊柱、入口状态、退出变化、下一段债务
角色目标、信息权限、不可提前事实
人物位置、轴线、屏幕方向、物件所有权
批准台词、说话人、语言和口型窗口
参考绑定、光源、持续声床、上一段尾态
```

抽象导演目的保留在内部，只把会改变像素、运动、时序、声音因果或连续性的事实送入模型载荷。

## 4. 来源账本

为每个源镜头建立一行：

```text
源镜头号 | 源时间 | 必须事实 | 稳定/时间差量
| BASE/A归属 | 易丢锚点 | 源尾态 | 下一镜入口
```

规则：

- 稳定事实只在BASE出现一次。
- 动作、摄影机、表情、台词、环境和转场全部进入所属A拍。
- 一个事实有一个主归属；跨字段只写短因果连接。
- 每个源镜头至少映射一个A拍；每个A拍必须能追溯源镜头。
- 来源覆盖默认100%，不得因字符压力删掉批准事实。

## 5. 参考绑定

逐张记录参考的权限范围：

```text
参考1：绑定角色A身份/服装，不绑定动作和场景
参考2：绑定七味居大厅空间/光色，不绑定人物站位
参考3：绑定首帧构图和姿势
参考4：绑定目标尾帧，不改变中段剧情
```

不要用新增长相或建筑描述覆盖已绑定参考。参考未展示的背面、房间连通、遮挡后动作和道具关系仍需来自批准分镜。

内部账本可以记录资产绝对路径，用户侧模型载荷必须把它们翻译成实际上传顺序中的“参考图1/2/3”或明确的附件槽位名。模型载荷中出现盘符路径、Unix绝对路径、`file://`或临时目录即为摄取失败，因为生成模型无法据此读取本地文件。

## 6. 台词摄取

- 逐字提取台词、说话人、语言、发声时间、重音、停顿、打断和尾音。
- 潜台词和修改理由不进入SD。
- 源分镜没有批准改词时，编译器不得润色或翻译。
- 估算口型时间超载时停止并返回台词层，报告差额。
- 镜头不随发言人机械切换；继承源分镜的观看权限。

## 7. 动画执行摄取

从正式动画分镜逐拍提取：

```text
正常基准 / 当前任务 / 触发
姿势链 / 视线与呼吸 / 支点 / 路径 / 接触 / 恢复
听者、对手、NPC、道具和环境反馈
主表达引擎的进入、发展、归还和残留
摄影机与主体路径、遮挡、焦点和落点
声音、光影和媒介变化
精确尾态
```

动作只有标题、运镜没有落点、表现引擎没有归还或尾态不可继承时，返回动画/导演层，不在SD中补救。

## 8. 30秒摄取

- `4-30秒`批准段默认一个BASE、一条提示词。
- `30秒`是上限。先试读台词并标出可与对白并行的走位、视线、道具和身体动作，以“最短可执行时长”决定总长；不得先选30秒再向内填充。
- 情景喜剧和漫剧优先压缩连接动作：普通走近、转身、起身、递物、抱起连续完成，只有笑点停顿、受力后果或信息反转获得独占时间。
- 扩写的是执行维度和因果密度，不是动作耗时。更长载荷应增加摄影机、表演、物件、环境、声音和尾态的准确度，不能把角色动作写成迟缓展示。
- 内部按批准动作和自然`2-4秒`窗口映射A拍。
- `16-30秒`保留`12-18秒`附近的状态刷新，不在15秒重启。
- 前半段尾态必须进入后半段入口；检查支点、视线、道具、环境力、画面法则、摄影机和声尾。
- 只有总长超过30秒或批准源本身分段时才生成多条提示词。

## 9. 入口刷新

新段默认硬切到明确的新开场构图，不用“延续上一画面”代替：

```text
上一段尾态继续存在
-> 新镜头明确机位/景别/焦点/画面所有者
-> 第一秒发生当前段的新信息或动作
```

用户明确要求一镜到底、连续跟拍或批准转场机制时，直接从上一镜摄影机落点和主体尾态接续，不强行硬切。

## 10. 摄取通过门

- 来源已批准，当前阶段确实是SD。
- 媒介、时长、入口和参考权限明确。
- 时长通过台词试读和动作并行排程得出；参考绑定已转换为模型可见槽位，模型载荷不含本地路径。
- 所有源镜头和台词可追溯。
- 动画动作、摄影机、环境、声光和尾态已可执行。
- 16-30秒没有15秒断点。
- 没有需要下游决定的故事、台词或镜头事实。
- 交付目标是纯文本BASE+A，不是JSON。
