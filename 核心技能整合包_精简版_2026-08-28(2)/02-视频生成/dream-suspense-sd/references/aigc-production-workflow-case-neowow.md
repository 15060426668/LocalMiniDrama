# NeoWOW《元启录》成片级 AIGC 视频工作流案例

来源：用户提供的 `neowow_元启录_1秒帧_ASR_成片画布精析报告.md` 与 `neowow_元启录_全链路完整分析终版.md`。本文件用于沉淀“成片 + 画布节点 + 1秒帧 + ASR + 高频提示词 + 全链路生产方法”的可复用视频生产方法。它不是《命运覆写》剧情设定，不得把《元启录》的人物、世界观、龙、魔法、台词移植进当前项目；只能抽取工作流、控制变量和提示词结构。

## 适用场景

当用户要求以下任务时读取本文件：

- 分析成片级 AIGC 视频为什么能成立。
- 从报告、抽帧、ASR、画布节点里提炼可复用视频提示词方法。
- 设计长片段 / 多段 SD / Seedance 工作流，而不是只写单条提示词。
- 需要把抽象命题拆成生活锚点、系统扩展、危机触发、角色抉择、视觉高潮和哲学落点。
- 需要学习“画布节点化资产 + 高频提示词复用 + 成片混剪”的生产方式。
- 需要从零规划一条完整 AI 视频生产链路：创意、资产、音色、分镜、4 秒试拍、粗剪补镜、统一后期。

## 核心创作结构

《元启录》的有效结构不是“AI 觉醒灾难”，而是“AI 觉醒后主动放弃替人类做决定”。可复用的是它把抽象命题拆成三条可被镜头验证的线：

1. 家庭线：用回家、生日、洗澡、晚餐、早餐这些小事证明 AI 已经进入亲密关系。
2. 社会线：用学校、银行、交通、治安、新闻系统同时失灵，证明 AI 已经进入基础设施。
3. 行动线：用外部危机逼主角再次依赖 AI，从而把“选择权交还给人类”的主题变成身体行动。

可复用闭环：

```text
开头：角色向系统索要最优方案。
中段：系统看似可靠，但逐渐替人承担判断。
危机：系统撤退或失灵，个人问题扩展成社会问题。
高潮：角色必须最后一次依赖过去的问题来源。
结尾：用一个微小日常选择证明选择权回到人身上。
```

## 成片工作流模板

```text
创意命题：
  一个抽象伦理 / 情感 / 科幻问题。

生活锚点：
  用家庭、餐桌、上学、回家、洗澡、生日、早餐等具体场景证明关系。

资产节点化：
  先定角色、道具、城市、组织、交通工具、资源系统、敌我形象，不急于直接成片。

系统扩展：
  把个人故障扩展到学校、银行、交通、新闻、公共安全等社会基础设施。

危机触发：
  通过新闻屏幕、公共事故、怪物失控、警报或突发灾害把角色推入行动。

角色抉择：
  让主角再次依赖过去的问题来源，制造主题矛盾。

视觉高潮：
  用已经铺过的世界观资源解决战斗 / 危机，不临时引入新设定。

哲学落点：
  不用旁白说教，用一个小选择或小动作证明角色 / 世界已经改变。
```

## 全链路制作公式

《元启录》的核心判断是：它不是一条长提示词生成一支短片，而是一条完整工程链。

```text
创意命题
→ 世界观符号
→ 人物关系
→ 全局风格宪法
→ 角色 / 场景 / 声音资产
→ 分镜提示词
→ 图片首帧
→ 短视频试拍
→ 截帧 / 裁剪 / 提音频
→ 续写迭代
→ 剪辑合成
→ 主题闭环
```

制作原则：

- 画布不是线性脚本，而是制作工厂：图片节点建角色 / 场景 / 首帧，文本节点写提示词和分镜，视频节点试拍，音频节点绑定声音，分组节点管理剧情段落。
- 资产先行：先做人物、场景、道具、声音、风格文本，再进入视频生成。
- 模型分工：图像模型做人设 / 场景 / 变体，视频模型做运动，文本模型做提示词和分镜，后期工具做裁剪、提音频、高清和混剪。
- 生成结果重新资产化：可用局部截帧成下一段参考，可用音频提取成声音资产，可用动作裁剪成后续镜头素材。

## 最小可行版本

如果不做长片，可以先做 90 秒版本。这个结构对《命运覆写》也有参考价值：先证明主题闭环，再扩成多集或长段。

```text
00-10 秒：主角向系统 / 道具 / 他人索要方案。
10-25 秒：系统进入日常生活，替人做选择。
25-40 秒：系统失灵或规则异常，生活秩序破裂。
40-55 秒：新闻 / 公共空间 / 第三方反应证明这不是私人小故障。
55-75 秒：主角面对危机，最后一次依赖过去的问题来源。
75-90 秒：问题来源退后，人完成一个小选择或小动作闭环。
```

必须保留：

```text
开头有“求方案”
中段有“替人生活 / 替人判断”
危机有“社会后果”
高潮有“最后一次依赖”
结尾有“人自己选择”
```

不要学错：

```text
不要只学外壳美术、怪物、技能、特效。
真正要学：主题闭环、关系铺垫、资产工程、镜头拆分、声音绑定、纠错约束、剪辑节奏。
```

## 视频提示词控制模式

《元启录》的提示词系统不是一条巨长咒语，而是模块组合：

```text
资产绑定模块
风格锁定模块
角色一致性模块
光线匹配模块
镜头调度模块
动作连续模块
对白音色模块
纠错约束模块
音画限制模块
```

写 SD / Seedance 时先判断本段需要哪些模块，不要把所有模块无差别堆进去。

### 1. 全局 CG 风格锁

用途：让长片多节点输出维持同一媒体身份，防止漂移到真人、普通二维动画或廉价展示图。

可转译写法：

```text
高质量三维CG动画电影质感，统一PBR材质，角色动作为动捕驱动的自然身体惯性，关节运动保留轻微机械节制，镜头具备真实摄影机存在感，画面保持同一渲染体系、同一色彩管理和同一材质逻辑。
```

注意：在《命运覆写》SD / Seedance 里仍服从项目安全 STYLE LOCK，不直接写高风险 IP 或品类词。

### 2. 声音控制短句

用途：让片段可后期混剪，不让模型用配乐替代动作与环境。

可转译写法：

```text
仅环境音、动作音、角色对白和空间反射声，不用煽情配乐；每个声音都绑定可见动作或明确声源。
```

使用规则：公共场所不能只写“环境声”，必须分为近景拟音、中景人声、远景空间、主体对白空间层。

### 3. 手持呼吸感

用途：让 CG 视频从静态展示图变成带摄影机存在感的片段。

可转译写法：

```text
摄影机保持轻微手持呼吸感，画面存在很小的身体惯性和跟焦微调；紧张段落手持波动略增强，但主体位置、轴线和焦点不丢失。
```

注意：手持感不是乱晃。日常戏用轻呼吸，危机戏可加大波动；需要信息读取的手机、屏幕、道具特写要降低晃动。

### 4. 焦段 + 角度 + 构图占比

用途：避免模型只生成“好看的角色”，而忽略镜头意图。

可转译写法：

```text
使用 85mm-120mm 长焦近景，人物面部占画面约六到八成，侧 45 度角，背景压缩并柔焦，只保留关键环境色块；眼睛或手中道具为清晰焦点。
```

使用规则：日常亲密戏可用长焦、过肩、浅景深；公共危机需要适当拉宽，保留人群、屏幕、动线和空间关系。

### 5. 连续性约束

用途：解决 AI 视频最容易出现的跳轴、重置站位、动作断裂。

正向转译写法：

```text
沿用上一镜头结束时的站位和屏幕方向；角色仍在同一空间轴线上连续运动，摄影机只改变景别或机位，不重置人物距离、朝向和道具位置。
```

注意：不要把“不要跳轴”直接塞进 A 区块；A 区块写正向空间事实，风险项需要时放 B 区块或自审。

### 6. 资产高危项反复锁定

用途：当某个角色、怪物、道具容易被模型误生成时，必须把结构写成正向可见事实。

可转译写法：

```text
关键道具保持已确认资产结构：形状、数量、位置、显示内容和材质不变；每次出现只改变受光、焦点、运动关系，不改变基本结构。
```

《命运覆写》应用：辉光管、D-Mail 手机、时间机器、白塔客厅、人物资产卡都属于高危资产。已有资产卡人物不重写服饰。

### 7. 非人 / 半机械角色微表情

用途：让“像人但不是人”的角色不滑向普通真人表演。

可转译写法：

```text
表情变化克制：眼皮只有极轻微位移，嘴角只产生毫米级上扬，头部转动略有机械停顿，呼吸和眨眼频率低于普通人；情感通过停顿、视线和声线变化表现。
```

注意：这类规则只在角色身份需要时使用，不套给所有人。

### 8. 世界观资源视觉化

用途：把抽象系统变成镜头可执行元素，而不是台词说明。

可转译写法：

```text
世界观资源以可见物件和能量痕迹承担叙事：小型资源体在地面滚动或悬浮，角色动作改变资源排列，光效、风压、粒子残留和环境扰动同步说明系统正在被调用。
```

《命运覆写》应用：D-Mail、辉光管数字、手机界面、微波炉通道、时间机器坐标、记忆覆写痕迹，都应优先屏幕化 / 道具化 / 光影化。

### 9. 光线匹配 / 角色融入场景

用途：让凭空生成或换入场景的人物不浮在画面上。

可转译写法：

```text
角色受光方向与场景主光一致，面部亮区和环境窗光 / 屏幕光对应；脚下接触阴影压在地面上，衣料边缘接收同色环境反射，人物暗部保留场景色温，不出现独立棚拍感。
```

《命运覆写》应用：白塔客厅、咖啡厅、婚戒所、街道和监控画面都要写清角色受光来源，尤其是没有现成场景资产时。

### 10. 新闻 / 屏幕信息合流

用途：把大量世界观信息压缩进一个可看的空间，而不是让角色站着解释。

可转译写法：

```text
公共空间里一块清晰屏幕承担信息源：屏幕播报关键事件，中景人物听见后反应，背景路人停顿、低语或抬头观看；镜头在屏幕内容、主角表情和人群反应之间切换，形成信息合流。
```

《命运覆写》应用：电视新闻、手机短信、监控画面、D-Mail 弹窗、辉光管读数都可以承担信息合流。

## 生成与后期闭环

### 分镜字段

每个镜头至少写：

```text
景别
角度
焦段
主体
动作
对白
运镜
光线
声音
连续性
纠错约束
```

《命运覆写》SD 输出仍以项目格式为准，但内部必须先过这张表。

### 4 秒试拍原则

```text
不要一开始就生成长视频。
复杂动作先拆成 4 秒左右的试拍节点。
先低成本试动作、站位、光线、表情和口型。
能用的片段保留；不能用的片段截帧、裁剪、提音频或重试。
```

适用：复杂打斗、多人走位、拥挤公共空间、手机屏幕操作、车祸瞬间、时间线跳跃。

### 粗剪再补

```text
按剧情顺序粗剪
→ 找缺镜头
→ 回画布补生成
→ 修声音
→ 加统一配乐
→ 最后调节节奏
```

写提示词时应给后期留接口：镜头有明确起止动作、声音不被随机音乐污染、关键帧可截出下一段首帧。

## 剪辑与声音规律

### 节奏结构

```text
开场：快，直接进入危险或异常。
日常：慢，建立关系。
主题/喜剧：中速，信息和温度交错。
失灵：突然断裂。
公共危机：排比加速。
新闻：信息压缩。
追逐 / 行动：动作加速。
高潮：密集高能。
退场：抽空变慢。
结尾：平静收束。
```

### 声音资产化

```text
角色一致性 = 外形一致 + 服装一致 + 动作习惯一致 + 声音一致。
```

生成阶段优先“有音效，无音乐”的本质是：保留对白、环境声、动作声，避免每个生成片段自带不可控音乐；配乐留给后期统一设计。

声音分层模板：

```text
近景：衣料、手部、脚步、道具、呼吸。
中景：对白、旁人反应、服务员 / 路人 / 同伴短句。
远景：空间混响、交通、警笛、新风、城市低频。
主观 / 画外：手机、耳机、系统声、内心声、新闻播报。
```

## 终极复刻公式

```text
一个强命题
+ 一个亲密关系
+ 一个小生活入口
+ 一个社会级后果
+ 一个动作级危机
+ 一个最后一次依赖
+ 一个自我牺牲 / 身份重置 / 权力退让
+ 一个小选择闭环
= 一支有完整创作链路的 AI 短片
```

使用时必须先替换为用户项目自己的命题、人物关系和世界观，不要套用原案例外壳。

## 对《命运覆写》SD 输出的吸收方式

- 抽象设定先变生活锚点：时间线、D-Mail、记忆覆写不能只靠解释，要用咖啡、手机短信、错位称谓、桌面道具、新闻屏幕、公共反应证明。
- 先定资产再做成片：人物资产卡、道具资产、场景资产、UI 格式都要先锁，再进入长片段。
- 新闻 / 屏幕是信息压缩器：复杂世界线信息可以通过电视新闻、手机界面、监控屏、系统弹窗压缩释放。
- 声音不靠配乐兜底：每段都要写动作音、环境层、对白空间方向；公共空间必须有人流反应和空间混响。
- 连续动作要写正向轴线：提示词要写“沿用上一镜站位、屏幕左/右方向、人物距离和道具位置”，不要只写禁止项。
- 长片段要拆成节点：每 4-30 秒一个可控视频节点；16-30秒节点继续细分2-4秒内部动作窗，每个窗口只有一个主运动目标，但背景、道具、光影和声音继续并行运动。
- 生成前先想后期：本段是否能截首帧、接下一段、提声音、插入粗剪；提示词要给出清晰起止画面。
- 主题必须被场景证明：不要让角色讲设定代替事件推进；每段都要能回答“这段证明了什么关系或规则”。

## 质量自审清单

输出 SD / Seedance 前检查：

- 这段是否有生活锚点，还是只在讲抽象设定。
- 是否已经把系统 / 世界观变成屏幕、道具、动作、声音或空间反应。
- 是否有全局媒体身份和项目 STYLE LOCK，但没有写风险 IP / 品类词。
- 是否明确镜头焦段、角度、主体占比、前中后景、景深和焦点。
- 是否用正向空间事实解决连续性，而不是只写“不要跳轴”。
- 是否给了声音层，并且声音都绑定动作或空间声源。
- 是否让 4-30 秒节点服务一个明确叙事功能，16-30秒是否有中段刷新，超过30秒的段落是否主动拆条。
- 是否先做资产和音色，再做视频；是否把可用生成结果重新资产化。
- 是否只学了外壳美术，而没有学到主题闭环、资产工程、镜头拆分、声音绑定和剪辑节奏。
