# Animation Pure-Text Execution v6

本文件只补充动画分镜到五字段A拍的编译难点。字段定义和用户交付格式由 `../SKILL.md` 唯一拥有；完整阶段所有权见导演技能的 `animation-production-pipeline.md`。

## 1. 来源到五字段

内部先把每条动画事实映射一次：

| 正式分镜事实 | A主归属 | 不重复位置 |
|---|---|---|
| 画面所有者、景别、机位、焦点、摄影机路径和落点 | 镜头与构图 | 主体字段只写身体怎样响应镜头 |
| 意图、感知、姿势链、表情、口型、支点、接触、恢复 | 主体动作与表演 | 不在尾帧重述全过程 |
| 听者/对手/NPC、道具、环境力、次级材质、物理后果 | 关系/物件/环境反馈 | 光声字段只写触发关系 |
| 声源、光源变化、动画媒介差量、转场过程 | 声光与转场触发 | 稳定光色/声床上收BASE |
| 结束姿势、方向、物件、持续运动、声尾、残留、下一拍入口 | 尾帧与连续性 | 不另设SD锚点或连续性校验字段 |

同一事实只能有一个主归属。需要跨字段证明因果时，用短指代连接，不全文复述。

## 2. 主体预算

先删其他字段后单独阅读`主体动作与表演`：动画师仍应能按顺序完成该拍。普通拍至少可读：

```text
当前任务/正常基准
-> 可见或可听触发
-> 视线/呼吸/姿势准备
-> 一个主身体或手部动作
-> 听者/道具反馈造成的调整
-> 恢复或新支点
```

高强度动作再补完整八槽：意图、预备/支点、发力、路径、接触/阻力、峰值/过冲、恢复、尾态。不是每拍机械写八个标签，而是不能丢当前动作的关键因果。

## 3. 对话和情景喜剧

对话拍优先保护说听关系，而非面部特写：

- 口型只覆盖批准发声时间；起句前写准备，尾音后写听者或环境反应。
- 同一构图中可同时保留说者任务、听者低幅动作、第三人误读和背景入口，但每拍只有一个焦点变化。
- 包袱拍先写正常任务，再写误判/升级，最后写兑现和反应；不要直接从“大家聊天”跳到“全员爆笑”。
- 关键笑点后保留可见反应窗口；补刀继承上一人的姿势、视线或物件状态。
- 镜头不按发言人轮流切。只有听者反应、关系权力或空间行动取得观看权时才移动/切换。

## 4. 一镜到底和复合运镜

连续摄影机运动仍按自然A拍展开。每拍写：

```text
进入时摄影机位置和主体屏幕方向
-> 本拍由哪项动作/声音触发摄影机响应
-> 摄影机路径与主体路径如何同时变化
-> 前景遮挡、视差、焦点和世界锚怎样证明空间
-> 本拍摄影机落点如何成为下一拍起点
```

不要在每拍重复“镜头连续跟随”。第二拍起直接从上一落点写新差量。升、降、推、拉、摇、横移、环绕可以组合，但同一拍必须有一个主摄影机意图；另一操作只能服务路径过渡。

## 5. 表现段与画层换权

主表达引擎在段级锁一次，A拍只写当前状态变化：

```text
现实基准 -> 触发 -> 越界入口 -> 当前发展
-> 画面所有者变化 -> 主体怎样适应/抵抗
-> 归还动作 -> 现实后果和残留
```

每拍登记：当前谁拥有画面；主体必须保留哪项证据；特效允许遮挡什么和多久；何时把画面还给哪项动作/关系；末端怎样成为下一拍入口。高潮后不清空，至少留下姿势、空位、污迹、裂纹、错位物件、声尾、光痕或同形转场。

## 6. timing/spacing

- 帧法服从姿势和间距，不先堆“一拍二、抽帧、卡点”术语。
- Moving Hold保留呼吸、眼睑、线沸腾、衣发、道具、环境或听者的低幅任务。
- 高速动作可用短smear或冲击帧，但必须写进入姿势、持续、退出姿势和归模锚点。
- 慢动作只改变取得时间所有权的层；背景、声源或轻质材料可保持不同速度。
- 一拍一/二/三是试拍值，若用户未指定帧率，提示词强调动作节奏和姿势间距而非虚构精确帧号。

## 7. 16-30秒

一段只写一个BASE。前半段建立任务、第一次策略和状态；`12-18秒`附近编译批准的状态刷新；后半段继承并发展后果。中段刷新必须来自动作、关系、物件、焦点、声音、空间或画面法则，不是换一组漂亮形容词。

额外时长分配优先级：主体准备 > 听者反应 > 环境接力 > 后果 > 恢复。不能用长段权限在同一拍增加第二个主动作、第二次无关变形或第二条复杂摄影机路线。

## 8. 2D主体与真人底片

BASE分开锁：

```text
真人底片：透视、地平线、摄影机、景深、光向、颗粒、真人NPC路线、真实接触面
2D主体：参考身份、比例、线条/平涂/阴影规则、阶梯帧、允许离模范围
共享空间：支点、遮挡交换、视差、动态接触影、反射、真实物件后果
```

A拍按`底片可见差量 -> 2D主体动作 -> 遮挡/接触 -> 真人道具/NPC后果 -> 线条/帧感差量 -> 双层尾态`编译。发光描边不能代替共享空间证据。

## 9. 压缩和拆拍

可以删除：重复审美词、BASE已有事实、同义环境描述、内部动机解释、来源和审核信息。

不能删除：动作顺序、脸身同步、支点/接触、说听关系、摄影机落点、环境因果和尾态。

出现以下任一项先拆内部拍：

- 两个独立主动作或两个完整口型轨。
- 动作、接触和恢复无法在当前窗口读清。
- 复合运镜在一个窗口内有两个独立目标。
- 表现引擎需要第二次独立进入和归还。
- 尾态无法用一句准确描述。

拆拍不等于拆提示词。4-30秒仍保持一条文本，除非总时长或执行负荷满足流程中的新段条件。

## 10. 快速审读

- 关掉声音后，主体意图、动作方向和结果可读。
- 只听声音时，声源、距离、台词先后和转场方向可追踪。
- 遮住风格词后，摄影机和身体动作仍可执行。
- 每拍结尾能画成明确静帧，并可直接作为下一拍第一帧。
- 五字段没有重复抄写同一尾态或稳定背景。
- 输出是纯文本BASE+A，没有JSON和审计附件。
