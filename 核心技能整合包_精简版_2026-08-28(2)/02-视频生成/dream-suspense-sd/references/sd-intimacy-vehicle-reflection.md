# SD Intimacy, Vehicle And Reflection Execution

用途：编译双人拥抱、扶腰、接吻、车辆共乘和镜面构图。此类镜头同时涉及双人身份、身体接触、头部路径、车辆物理和反射关系，默认按高风险处理。

## Two-Person Contact Order

```text
接近路线
-> 第一接触点
-> 发起者重心和手部
-> 回应者延迟反应
-> 衣料/头发/身体压力反馈
-> 双方稳定姿态
-> 眼神或情感落点
```

每个短节拍只保留一名动作发起者。第二人先通过眼睛、肩膀、手指或呼吸回应，再完成身体动作。

## Waist Catch

```text
vehicle braking completes
-> support foot contacts ground
-> vehicle weight settles
-> free hand leaves handlebar
-> forearm reaches behind the waist
-> palm compresses fabric
-> falling center of gravity redirects toward a stable shared stance
```

中文执行锚点：车辆减速完成，支撑脚踩实地面，车架回弹一次，空闲手离开车把，前臂绕到腰后，掌心压出衣料褶皱，人物重心在两人之间稳定。

## Kiss Staging

```text
stable feet or seated base
-> gaze confirmation
-> initiator head route
-> responder delayed lean
-> hair/helmet/cloth secondary motion
-> brief lip contact
-> settled close distance
```

车辆场景先锁车轮静止、支撑脚落地和镜面振动衰减，再编译回头、前倾与亲吻。

## Reflection Geometry

镜面段必须锁：

- 镜面形状、位置和朝向。
- 镜中左右人物归属。
- 镜外可见车把、墙面或框架。
- 反射光源和强调色位置。
- 人物进入镜面的顺序。
- 尾帧镜面振动或稳定状态。

镜面亲密动作复杂度达到拆段线时，稳定覆盖采用直接侧面双人近景，保持相同头部路线、光线和情感落点。

## Vehicle Motion

- 行驶：双手握车把、双脚位于踏板、车轮接地、背景视差和衣料惯性同向。
- 减速：身体重心后移、悬挂前沉、电机声下降、支撑脚准备落地。
- 停稳：支撑脚接地、车架回弹、镜面振动衰减、衣摆和头发逐渐回落。
- 共乘：后座人物双腿与座位关系清楚，手臂环抱位置稳定，前后身体保持一条可读纵向轴线。

## Split Rule

以下组合优先拆成连续节拍：

- 减速 + 停车 + 回头 + 接吻。
- 镜面构图 + 双人接吻 + 摄影机移动。
- 扶腰 + 车辆继续移动 + 复杂背景事件。
- 双人换装/换时段 + 动作匹配 + 新摄影机路径。
