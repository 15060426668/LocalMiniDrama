# Generated Frame Sequence QA

用途：对生成视频抽出的连续帧进行技术检查，再由导演完成语义检查。

## Automated Tool

```powershell
python scripts/analyze_frame_sequence.py <frame-directory> --output <report.json>
```

自动检查：

- 画幅尺寸漂移。
- 黑帧、白帧和纯色帧。
- 极低细节帧。
- 近似重复帧。
- 突然亮度跳变。
- 突然整体色偏。
- 每帧亮度、对比度、锐度代理值和平均RGB。

## Manual Director QA

自动报告之后逐帧检查：

```text
人物身份与脸部：
手指、手掌和接触点：
服装、湿度、灰尘和身体残留：
空间方向与门窗位置：
道具所有者、朝向和位置：
主光方向与颜色归属：
镜头运动与画面落点：
VFX变化边界和残留：
上一段尾帧与下一段首帧：
```

## Repair Routing

| 症状 | 第一回修层 |
|---|---|
| 连续黑帧或曝光突跳 | 光影/色彩、实拍证据、模型执行配置 |
| 多帧近似静止 | 主动作、摄影机路径、内部信息刷新 |
| 整体色彩突然改变 | 主色板、光源状态、时间转场锚点 |
| 人物换脸或服装漂移 | 角色基准、参考图、连续性清单 |
| 道具跳位 | 所有权、手、方向、尾帧状态 |
| 空间翻转 | 屏幕方向、门窗方位、摄影机侧 |
| 接触动作融合 | 拆分发起者与回应者，减少同时运动 |
