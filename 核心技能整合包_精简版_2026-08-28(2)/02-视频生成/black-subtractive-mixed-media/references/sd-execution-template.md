# SD Execution Template

Use this file only after the mechanism has been approved as a formal storyboard. The animation route uses one `BASE LOCK` and expanded seven-field A beats for a 4-15 second segment.

## BASE LOCK

```text
媒介与身份：真人摄影底片 + 彩色手绘2D角色 + 动态黑色减法遮罩；2D角色保持可见的手绘轮廓、哑光平涂、克制赛璐璐阴影和选择性分拍。
空间与方向：真实机位、视平线、透视、前中后景、真实NPC路线、黑色遮罩来源与默认运动方向。
全局光色与质感：真人底片的白平衡、曝光、颗粒、景深和运动模糊；2D角色服从光源方向但保留彩色绘制边界；黑色边界密实，受光区有物理来源。
跨镜连续性：角色身份、服装、脚底/座面支点、道具归属、遮罩残留、投影方向和下一拍可继承的视线。
声音母版：真人环境声床、遮罩触发声、光区出现时的空间变化声，以及它们对视线、呼吸、摄影机和剪点的触发关系。
```

## A Beat

```text
第X-X秒｜源镜头号
镜头与构图：开场画面、前中后景、真实底片机位与焦点，黑色遮罩的空间位置、第一处可见光区、摄影机路径和落点。
主体动作与表演：正常任务 -> 触发 -> 视线/眼睑/呼吸变化 -> 预备与支点变化 -> 肩肘腕脊柱腰胯膝脚的动作顺序 -> 手/脚/身体路径 -> 接触或动作峰值 -> 反应与恢复。
物件/环境/物理反馈：黑色来源的运动后果，真实道具归属，遮罩前后遮挡交换，脚底/座面接触，投影、反射、衣料、头发、粒子和真人NPC延迟反应。
光影/色彩/质感：本拍发生的光区变化、黑边密度、边缘光、2D线条/填色/曝光节奏变化，真人材质的受光与色溢。
声音与声画触发：具体声源、方向与距离、进入顺序和强弱，触发的眼神、动作、焦点、光区或剪点变化。
转场：遮挡物/黑色来源/光区/声音如何覆盖当前空间，过渡中的可见形状，以及下一画面的首个空间锚点。
尾帧与连续性：角色最终支点、视线、手和道具状态，黑色边界与光区形状，投影/反射/材质残留，真人NPC状态和下一拍起始动作。
```

## Eight-Second Training Exercise

Use this only as a practice exercise, not as a universal story template:

```text
0-2秒：真人场景与两名彩色2D少女执行普通任务，脚底和真实道具接触明确。
2-3秒：一名真人路人或前景物体掠过镜头，黑色遮罩从其边缘扩张。
3-4秒：画面保留一处接触地面和一只抬起的手，周围空间进入黑色。
4-6秒：光区沿手的方向变成窄门或透视长廊，先揭露手和脸，再揭露远处真实环境。
6-7秒：真人NPC或树影从角色前方穿过，证明遮罩、底片和2D角色存在前后层级。
7-8秒：黑色边界停在一个清楚的几何落点，保留投影、衣料褶皱、风和声音残留。
```

## Compile Rules

- Keep the model payload positive and executable.
- Preserve the complete subject-action chain; split beats before compressing it.
- Keep artist, video, film, franchise, and donor-shot names outside the model payload.
- Keep audit tables, numeric sound mixing, and source provenance outside the copy-ready prompt.
- When the request is only analysis or training, return the mechanism and exercise rather than pretending an unresolved idea is an approved SD source.
