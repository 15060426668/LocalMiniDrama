# 2D 国风 PV 制作台

## 目标

把“喜欢某种 PV 画风”转换成可训练、可验收、可复用的生产系统。输出必须能落到镜头、图层、动作、声音和练习结果，不停在形容词层面。目标风格是原创江湖语境中的可迁移规律，不复制具体游戏的角色、构图、文案、标志或素材。

## 路由边界

先判断当前请求属于哪一层，只启动最小必要链路：

| 请求 | 主处理 | 本技能的职责 |
|---|---|---|
| 还没有故事、人物或冲突 | `story-framework` / `script-writing` | 只补 PV 所需的最小叙事输入 |
| 已有视频、截图或逐帧材料 | `video-story-analysis` | 先做证据化拆解，再提取可迁移规律 |
| 有场景图、平面图、立面图、资产板 | `scene-asset-decomposition` | 先建立空间母版和资产身份，再做分镜 |
| 需要镜头方案、分镜细则、连续运镜 | `director-storyboard-integrated` | 本技能提供 2D PV 风格约束和板式 |
| 已批准镜头需要动作与 timing | `animation-suspense-performance` | 细化表演、spacing、顿帧、尾状态 |
| 已批准分镜进入生成 | `dream-suspense-sd` | 只编译，不改故事、镜头和构图 |
| 要把资料重新排版、分组、做镜头/资产板 | 本技能的 `scripts/render_pv_board.py` | 生成可检查的 HTML 板 |
| 要研究镜头运动语法 | `video-shotcraft` | 只借鉴运动机制、节奏和 QA，不照搬产品皮肤 |

不要把本技能变成新的剧本库、对白库或 SD 提示词库；这些内容仍由上游和下游技能负责。

## 核心风格 DNA

将参考风格拆成五层，每层都必须写成“画面事实 + 运动机制 + 叙事功能”：

1. **人物身份层**：先用轮廓、发饰、衣纹、兵器、持物和站姿让观众认出人，再给脸部或招式特写。人物登场不是卡面静止，而是“进入空间、完成一个动作、留下关系后果”。
2. **山河与历史层**：用地图、山门、城郭、长路、卷轴和群像交代势力关系；每次拉远都要增加信息或改变人物关系，不能只换壁纸。
3. **墨、纸、印刷层**：墨渗、描线、撕页、印章、留白和纸纹只在有因果时出现，例如人物落款、门派旗号、记忆覆盖或场景切换；特效必须能进入、承担遮罩/转场、再退出。
4. **动作与时间层**：日常动作负责可信度，关键动作使用预备、爆发、顿帧、余势四段；真正的高光每 4-8 秒最多一次，不能每镜都做海报式 pose。
5. **声音与材质层**：纸、木、金属、雨、衣料和脚步给现实触感；音乐重拍才交给刀锋、印章或标题落地。可沿用 `video-shotcraft` 的因果句式 `riser -> impact -> sparkle`，但按江湖材质换音色，避免游戏音包感。

建议的江湖配比：人物关系和生活动作 50%，山河/门派/历史空间 25%，兵器和动作高光 15%，墨纸书法与材质奇观 10%。这是起始配比，不是硬模板。

## 标准工作流

### 0. 冻结练习规模

默认从 4-8 秒单镜头开始，再做 12-15 秒段落，最后才做 24-30 秒 PV。明确画幅、帧率、交付媒介、角色数量、环境数量、主要动作和声音预算。

### 1. 写一页 PV brief

只保留：一句话冲突、主角欲望、关系变化、可见道具、时代/门派信号、结尾状态、风格禁区。没有冲突和结尾状态时，不进入画风细化。

### 2. 建立 style DNA 表

把参考片拆成色彩、线条、材质、构图、角色登场、镜头运动、转场、声音八列；每列写“观察到的证据”“可迁移的机制”“江湖原创译法”“不能复制的表面”。详见 `references/style-dna.md`。

### 3. 建资产分组板

先按 `character / costume / weapon / prop / fg / mg / bg / fx / text / sound` 分组，再按镜头用途和角色关系交叉索引。每项带来源、ROI、证据状态 `O/I/U`、版本、画面层级、所属镜头和可复用范围。详见 `references/layout-asset-board.md`。

### 4. 建镜头台账

每个镜头只指定一个主动作语法：揭示、推近、绕行、发牌式散开、描线、墨渗、猛切、顿帧或归位。记录时长、画面事实、动作因果、相机、声音、尾帧和下一镜交棒。把镜头按“开场/立传/关系/冲突/群像/收束”分组，而不是按灵感顺序堆叠。

### 5. 做 2D 表演深化

沿用 `animation-suspense-performance` 的七拍链：预备、触发、加速、主动作、冲击/顿帧、余势、恢复。对每个角色写眼神、重心、手部、衣摆/兵器、呼吸和对方反应；禁止只写“帅气挥刀”“霸气转身”。

### 6. 设计声音交棒

先写动作音源，再写环境底，再写音乐重拍。声音表必须能回答“哪个动作触发、何时落地、尾音是否覆盖下一镜”。`riser -> impact -> sparkle` 只能用于真正的能量峰值，不能每镜复读。

### 7. 验收与重排

静帧检查构图和层级，连帧检查预备/爆发/恢复，整段检查信息刷新和尾状态。出现“看不懂、太满、太像卡牌轮播、人物像贴纸、墨效无因果”时，优先重排镜头和资产板，不先加特效。

## 学习顺序

按 `references/learning-ladder.md` 逐级完成，不跨级追求整片：

1. 单人物 4 秒：轮廓、道具、一次可读动作。
2. 单人物 6 秒：聚光/推近/顿帧/恢复的完整弧线。
3. 人物与兵器 8 秒：预备、爆发、余势和材质声音。
4. 两人关系 10 秒：前后景、视线、动作接力和轴线连续。
5. 门派空间 12-15 秒：地图/山门/人物进入同一空间，完成一次因果转场。
6. 群像 15 秒：三层景别、角色优先级、统一动作节拍，不做头像墙。
7. 原创江湖片段 24-30 秒：冷开场、立传、冲突峰值、收束尾帧。

每级都要留下源图、资产板、镜头台账、动作表、声音表和复盘，不以“生成出一段视频”作为唯一通过标准。

## 硬性禁区

- 不复制《三国杀》《无悔华夏》或其他作品的角色、卡面、标题、标志、原画和逐镜构图；只提炼公开可观察的运动、材质和叙事机制。
- 不把每个镜头做成角色海报，不让每个角色都正面报菜名，不让墨、粒子、镜头旋转成为无动机装饰。
- 不在没有证据时假定精确镜头、作者意图、隐藏空间或原始声音；现有视频走证据化分析。
- 不把 `video-shotcraft` 的产品截图、品牌文案和音频资产带入江湖项目；只读取其镜头卡、节奏与 QA 规则。
- 不把版式板当成最终分镜；板是决策和验收工具，批准后的正式分镜仍由 `director-storyboard-integrated` 产出。

## 交付格式

默认交付以下文件或章节：

1. `PV brief`：冲突、关系、结尾状态和限制。
2. `Style DNA`：八列机制表与原创译法。
3. `Asset board`：资产分组、证据状态、来源和镜头归属。
4. `Shot ledger`：按功能分组的镜头、时长、动作、相机、声音和尾帧。
5. `Performance sheet`：七拍动作链和角色反应。
6. `Practice ladder`：当前级别、验收结果、下一次只改一件事。
7. 可选 `PV board.html`：由 `scripts/render_pv_board.py` 生成，用于重新排版、筛选和分组检查。
