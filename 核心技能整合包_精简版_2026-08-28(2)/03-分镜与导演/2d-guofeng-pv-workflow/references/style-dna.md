# Style DNA：原创江湖的 2D 国风 PV

## 先拆机制，再谈画风

参考《三国杀》人物 PV 或《无悔华夏》式历史 PV 时，只记录屏幕上能证实的事实。不要把“高级、东方、燃、史诗”当成分析结果。每条观察写成：

`证据 -> 机制 -> 原创译法 -> 禁止复制的表面`

## 八列拆分表

| 列 | 要观察什么 | 江湖译法示例 | 验收问题 |
|---|---|---|---|
| 色彩 | 主色、强调色、明暗比例、色彩何时变化 | 墨黑/纸白做叙事底，门派用一枚低饱和识别色，冲突才升高饱和 | 不看字幕能否读出势力和能量峰值 |
| 线条 | 工笔、粗墨、轮廓断续、描线速度 | 人物身份线比背景线更稳定，兵器轨迹线只在动作发生时出现 | 线条是否服务动作和层级，而不是铺满画面 |
| 材质 | 纸、绢、木、铁、雨、尘、漆、印泥 | 纸纹作为真实媒介，刀锋用冷硬高光，山门用旧木压暗 | 材质是否能被动作或声音触发 |
| 构图 | 中轴、对角、留白、前中后景、群像层级 | 角色落在空间关系中，主角留可呼吸的负空间，群像按叙事权重排列 | 画面是否同时容纳身份、关系和行动 |
| 登场 | 先轮廓还是先道具，是否有进入空间的动作 | 先听刀鞘/脚步，再看衣摆和兵器，最后给眼神或印记 | 登场是否改变场内关系 |
| 镜头 | 推近、拉远、绕行、俯拍、猛切、顿帧、归位 | 远景先交代山门与势力，中景让人物进入，近景把动作后果钉住 | 每个镜头是否只有一个主运动语法 |
| 转场 | 墨渗、纸页、描线、印章、遮罩、匹配剪辑 | 旧地图被墨吃掉后露出新路线，兵器横划成为下镜切口 | 转场是否由前镜动作或物件因果触发 |
| 声音 | 环境底、动作音、音乐重拍、留白 | 木门、雨声、衣料、金属互相区分，重拍只给真正的落印/出刀 | 声音是否能解释画面运动而非盖住画面 |

## 两种参考气质的可迁移部分

### 人物卡面感的可迁移部分

- 轮廓先行，身份道具早于脸部说明。
- 一个标志性动作比十个姿势更能留下角色。
- 兵器、衣摆、发饰和视线要组成同一条动作线。
- 高潮可用短暂顿帧、色彩反转或线条爆发，但必须有冲击事件。

不要复制角色卡框、技能名、原画姿势、人物阵营色或原作标题排版。

### 历史地图/山河感的可迁移部分

- 用空间规模建立时间和权力感，再让人物进入这个空间。
- 地图、旗号、城郭、路网和群像要提供叙事信息，不是背景幻灯片。
- 群像先按势力和关系分层，再按脸部识别；避免头像墙。
- 拉远必须带来新信息，拉近必须落到人物选择或后果。

不要复制真实游戏的地图样式、图标、阵营布局和 UI 组件。

## 江湖原创的默认材质方案

使用四种主材质即可形成稳定基线：

1. **旧纸**：章节、地图、门派谱系、回忆覆盖。
2. **墨与印泥**：命令、落款、誓约、因果转折。
3. **木与石**：门派空间、生活动作、历史重量。
4. **铁与雨**：兵器、冲突、危险临界。

每个镜头最多引入一种新奇观材质；其余材质保持连续，才能让 2D 合成看起来像一个世界。

## 颜色与版式纪律

- 先确定一个纸/夜/室内基底，再用一个门派识别色和一个危险强调色。
- 标题、印章、地图注记和角色名共享同一套字级与对齐基线。
- 重要文字放在静止或低运动窗口，至少留出可读 hold；不要让书法特效代替信息。
- 画面内的装饰线、颗粒、飞墨和光点都要有层级，不能平均撒满。

## 不能从参考片直接推出的东西

仅凭成片通常不能确定精确镜头焦段、作者意图、原始软件、未显示的图层、真实录音链或素材版权。此类内容要标记为未知，并通过项目资料或制作方证据补足；不要写成“专业流程一定如此”。
