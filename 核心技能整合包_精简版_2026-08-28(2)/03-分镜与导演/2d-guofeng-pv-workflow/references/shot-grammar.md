# Shot Grammar：把镜头卡迁移到 2D PV

`video-shotcraft` 的库是产品宣传片语境。下面只借运动机制、帧预算、声音因果和 QA 习惯，不能直接搬运产品 UI、品牌文案、截图、音频或视觉皮肤。

## 开场与立传

| 镜头卡 | 迁移为江湖镜头 | 关键纪律 |
|---|---|---|
| `brand-ink-open` | 一笔墨线/印记建立片名或门派符号 | 墨线要承担揭示，不做无意义 Logo 动画 |
| `stroke-segment-build` | 山脉、城郭、刀锋或人物轮廓逐段描出 | 描线的终点必须交代空间或身份 |
| `crane-rise-reveal` | 从地面脚步/兵器上摇到人物与山门 | 上摇过程中信息要逐层增加，不能只换景 |
| `magician-card-flourish` | 纸页、门派册页或兵器谱翻出关键对象 | 只借错峰与翻面节奏，禁止做成卡牌轮播 |
| `spotlight-hero-card` | 聚光锁定一个主角的完整动作弧 | 至少给预备、主动作、恢复和 hold |

## 关系与空间

| 镜头卡 | 迁移为江湖镜头 | 关键纪律 |
|---|---|---|
| `graze-face-tour` | 相机沿兵器/肩线掠过，最后落到眼神 | 相机运动必须被人物/兵器的几何关系驱动 |
| `overhead-camera-moves` | 俯拍棋盘、药案、地图或庭院中的人物走位 | 俯拍不是展示素材，必须让关系更清楚 |
| `depth-layer-moves` | 前景雨帘/门框，中景人物，后景山门或火光 | 每层只承担一个深度任务，保持遮挡连续 |
| `tension-camera-moves` | 关键选择前短暂冻结并环绕人物/兵器 | 同一镜头不要叠加另一种时间操纵 |

## 动作与冲突

| 镜头卡 | 迁移为江湖镜头 | 关键纪律 |
|---|---|---|
| `impact-feedback` | 出刀、落印、碎石或门撞开的冲击帧 | 负片/集中线/色散只给全段唯一高潮 |
| `speed-ramp-freeze` | 蓄力慢、爆发快、命中顿帧、余势恢复 | 速度变化要对应身体重心和声音，不是软件滤镜 |
| `crash-zoom-punch` | 视线或兵器突然逼近，切入选择/后果 | 急推终点必须是可读的动作后果 |
| `montage-rhythm-moves` | 三个角色或三件物件按同一节拍接力 | 每一拍都要推进关系，不能只是换头像 |

| 镜头卡 | 迁移为江湖镜头 | 关键纪律 |
|---|---|---|
| `print-texture-transitions` | 墨渗覆盖旧场景，透出新地图/新空间 | 墨渗必须有落点、扩散和完全交棒三个阶段 |

## 群像与收束

| 镜头卡 | 迁移为江湖镜头 | 关键纪律 |
|---|---|---|
| `avatar-grid-radial-build-colorize` | 以势力关系放置角色，而不是头像网格 | 先空间和关系，后脸部识别；不做阵营 UI |
| `outro-group-photo-launch` | 群像定格后让片名/门派印记落地 | 结尾保留静止尾帧，给观众读完关系 |
| `paper-title-card` | 章节、地点或一句江湖命题的呼吸字卡 | 字卡是路标，不是装饰；前后要有因果 |
| `trailer-grammar-moves` | 冷开场、画面/字卡对话、猛切入冲突 | 预告片节奏要稀疏有重音，不能全程加速 |

## 推荐帧预算

以 30fps 为起点，按内容调整：

- 单主角完整动作：90-150f，包含 10-18f 预备、20-45f 主动作、4-8f 顿帧、20-40f 余势和至少 12f hold。
- 关系接力：每次信息刷新至少 12-24f；让视线和物件交棒，不要靠硬切解释关系。
- 墨渗/纸页转场：24-48f，必须看得到进入、覆盖、交棒和退场的因果。
- 冲击帧：1-4f；整段最多一个最高强度负片/色散点。
- 结尾标题或印记：至少 30f hold；声音尾巴不能把读字时间吃掉。

## 音画因果

把 `video-shotcraft` 的 `riser -> impact -> sparkle` 当作一次能量句式：

1. `riser`：动作已经开始，声音提前告诉观众能量正在聚集。
2. `impact`：兵器、落印、门撞或标题在明确帧落定。
3. `sparkle`：余韵、墨点、纸屑或雨光把视线送到下一状态。

江湖版可以换成木、铁、纸、印泥和雨的音色，但必须保留“动作触发声音，声音解释材质”的关系。不能给每张角色卡都配一次三拍句式。

## 迁移后的 QA

- 主动作不逐帧看也能读出预备和释放。
- 镜头结束时人物、道具和相机有明确尾状态。
- 任何墨效、光效、纸效都能回答“谁触发、遮住什么、如何交棒”。
- 群像镜头能读出主次与关系，而不是一排等权角色。
- 连续三镜不重复同一主运动语法；重复时要有明确叙事升级。
