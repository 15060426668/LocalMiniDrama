# 沙盘拓展（通用）

本文件是空间沙盘工序的执行依据，全部内容与具体项目无关。项目专属信息（场景结构、资产码、人物事实）由用户在对话中提供，不写进本文件。

## 一、坐标与方位约定

- 一律使用世界方位描述空间：东、南、西、北与四个斜向（东北、西北、东南、西南）。
- 俯视沙盘按地图习惯绘制：上＝北，右＝东。
- 人物与摄影机各有一个朝向；画面左右永远由摄影机朝向推导，不由人物朝向推导。

## 二、摄影机朝向 → 画面方位换算表（逐镜查表，不凭感觉）

| 摄影机朝向 | 画面深处 | 画面左 | 画面右 |
|---|---|---|---|
| 朝北 | 北 | 西 | 东 |
| 朝南 | 南 | 东 | 西 |
| 朝东 | 东 | 北 | 南 |
| 朝西 | 西 | 南 | 北 |
| 朝东北 | 东北 | 西北 | 东南 |
| 朝西北 | 西北 | 西南 | 东北 |
| 朝东南 | 东南 | 东北 | 西南 |
| 朝西南 | 西南 | 东南 | 西北 |

规律：画面右＝摄影机朝向顺时针转九十度的方位；画面左反之。每换一次机位朝向重查一次，不沿用上一镜。

## 三、逐镜五问（答不齐的镜头不写）

1. 每个人物在世界哪个位置、面朝哪？
2. 摄影机在哪、朝哪拍、什么高度？
3. 这个机位下我们看到主体人物的哪一面？
4. 画面左、右、深处各是什么？（查上表）
5. 谁在画框内、谁在画框外？（由机位与景别推导，见下）

## 四、机位几何类型（按"要看到什么"选机位）

设人物面朝方向为 0°，机位偏离该方向的水平夹角为偏角：

- 偏角 0–30°：接近正脸。
- 偏角 30–70°：四分之三正面。
- 偏角约 90°：侧面。
- 偏角 110–150°：四分之三背面。
- 偏角 150–180°：背影。

选位规则：

1. 需要表情、视线转移或口型的镜头，机位必须在人物正面半球（偏角小于 90°）；背面机位只能安排背影承担得起的动作。
2. 仰角要出气势，必须从正面半球仰拍；从背面低角仰拍得到的是臀部与后腰。
3. 排除某个人物出画，唯一可靠手段是把机位架在几何上拍不到该人物的位置，或用长焦收窄画框；人物位于摄影机与主体连线之间时必然入画，必须换机位。
4. 拍队列用斜向机位形成纵深，正面平拍得到的是无层次的一字排开。
5. 全景纵深沿场景长轴方向拍，一次交代空间全貌；这类镜头里所有在场者都会入画，逐一核对每个人该不该出现。
6. 两人同框时，用前后错位与身高差建立层次；两人在摄影机视线上重叠时后者被遮挡，需要都可见就错开站位或错开机位。
7. 过肩镜要让前景人物的肩线入画，机位必须贴近两人连线（轴线附近），且视野角放宽到约 45°；机位偏离连线过远或视野过窄时，前景肩会整个出框，过肩构图不成立。

## 五、禁忌几何模式（沙盘阶段必查）

1. 背面低角仰拍面向别处的人物 → 臀部镜。
2. 要求"看到 A 的正脸"同时"画面里有 A 正在看的 B" → 地面机位无法同时成立（B 在镜头背后），必须二选一或改用侧面机位。
3. 机位与主体之间夹着第三人 → 该人必然入画，"不入画"类语句无效。
4. 摄影机越到既定轴线另一侧 → 画面左右翻转，与前后镜穿帮。
5. 多视角场景资产与摄影机朝向不匹配 → 背景穿帮；场景资产只按摄影机朝向选。

## 六、风险与建议栏（随沙盘输出，只提示、不强制，由用户裁决）

逐条检查，命中的写进沙盘下方的"风险与建议"栏：

1. 相邻同主体镜头在角度、高度、景别上差异过小，有被合并成一个长镜的风险。
2. 存在越轴或接近越轴的机位。
3. 无台词短镜（时长明显短于同条其他镜头）可能被拉长并挤压后续镜头。
4. 构图在几何上勉强成立但容错很小（前景遮挡、贴边、极限视角）。
5. 用户分镜存在几何矛盾时的改写方案：改了什么、为什么、如何退回。

## 七、沙盘输出格式

文字沙盘表，每镜一行：

```text
镜N｜时间段｜机位（位置·朝向·高度·焦段）｜看到主体的哪一面｜画面左／右／深处｜画框内：…｜画框外：…
```

表格之后接"风险与建议"栏。多条提示词可一次输出全部条目的沙盘统一确认。

## 八、可视化沙盘脚本

脚本：`scripts/sandtable.py`（纯 Python 标准库，无依赖）。

用法：

```text
python scripts/sandtable.py 输入.json -o 沙盘.html
```

输入 JSON 格式（世界坐标：x 东为正、y 北为正，单位任意；facing 用八向字母 N/S/E/W/NE/NW/SE/SW、中文八向（东/南/西/北/东北/东南/西北/西南）或角度数，角度按东 0°、北 90°）：

```json
{
  "title": "本条标题",
  "scene": {
    "bounds": {"w": 24, "d": 36},
    "landmarks": [ {"name": "北端平台", "x": 0, "y": 15, "w": 14, "h": 4} ],
    "zones": [ {"name": "东侧队列", "x": 8, "y": 0, "w": 3, "h": 18} ]
  },
  "shots": [
    {
      "id": "镜1", "time": "00:00-00:03",
      "camera": {"x": 0, "y": 4, "facing": "S", "fov": 40, "label": "72mm 中景 胸口高度"},
      "chars": [
        {"name": "角色A", "x": 0, "y": -1, "facing": "N", "main": true},
        {"name": "角色B", "x": 2, "y": 1, "facing": "N"}
      ],
      "note": "本镜要点"
    }
  ]
}
```

脚本输出一个 HTML：每镜一张俯视图（场景、区域、人物与朝向箭头、摄影机与视野扇形），图下自动标注画面左右换算与画框内外名单（按视野扇形几何判定）。自动判定与手工声明不一致时，以几何判定为准复查提示词。
