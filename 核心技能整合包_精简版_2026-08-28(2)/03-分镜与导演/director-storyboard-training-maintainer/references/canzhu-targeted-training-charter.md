## 1. 当前训练结论

2026-07-12 首轮 R01-R09 已完成吸收。九个题目不建立九条路线，合并为六个能力引擎：

```text
回应阈限 = R01主动不回应 + R05熟悉名字造成无意回应
证据与规则物反证 = R02文档/声音预入 + R06物理规则测试
非战斗双身 = R03同步、失同步、独立选择
制度型多人权力对话 = R04出口、物件、信息和执行权限
重复空间与背景见证 = R07稳定框架、单变量变化、智能复测、知情状态
程序连续性双模式 = R08程序化收容 + R09虚假安全回收
```

当前不再按“凑够每组十部”主动扩张。只有真实设计、生成或连续性测试暴露失败，或新素材带来不同规则/边界/组合时，才重开对应批次。首轮材料没有连续视频或逐帧截图，命名影片的逐镜与精确参数保持C级；匿名状态链和执行关系按B级沉淀。

## 2A. 第二轮场景覆盖与电影候选

第二轮不再重复病房醒来、普通走廊追逐、门阈限和基础声音诱导。重点补“主角如何聪明验证”“机构如何消化异常”“亲情如何成为最终证据”“异常结束后留下什么”。以下影片均先按B级候选使用，只有核对连续视频、截图或可靠制作资料后才能升级逐镜事实。

|---|---|---|---|---|
| R10 | 最终母亲正脸、认亲后才发现不可能 | 熟悉手势/短句先于脸；先认亲后认错；触碰权限改变；温柔而非怪脸 | `The Sixth Sense`, `The Others`, `Arrival`, `Relic`, `The Orphanage`, `Lake Mungo`, `The Father`, `A Tale of Two Sisters` | 第二轮A批完成：8个差异机制 + R10导演合成配方；只在表演生成失败时补A级校准 |

## 4. 用户投喂格式

不要求持续提供完整电影视频。以下任一种材料均可进入审计：

- 片名 + 明确场景功能 + 简洁镜头笔记。
- 6-16张能看清起幅、过程和落幅的连续截图。
- 目标片段视频或公开链接。
- 剧本段落、字幕、台词转录或可靠制作资料。
- 已整理的分镜表，但其中的精确参数默认先按C级审计。

推荐命名：`CZ-R04-01`、`CZ-R05-03`。同一影片进入不同批次时，必须对应不同场景或不同机制，不能复制同一段分析。

每份材料尽量附：

```text
编号：
片名 / 集数或场景识别：
对应批次：R01-R09
材料类型：视频 / 截图 / 文字拉片 / 剧本 / 制作资料
场景功能：
你认为值得学的点：
```

## 6. 可信度与污染防火墙

- A级：已观看视频、连续截图、可靠剧本或制作资料。可以记录实际可见动作；精确焦段和混音参数仍需来源。
- B级：影片与机制可靠，但未核对完整片段。只保留机制，不声称精确秒数、镜头顺序或技术参数。
- C级：二手概述、生成式拉片、象征解读或补写动作。只可转成匿名原创模板。

每条素材必须执行：

```text
原片事实
-> 分镜机制
-> 删除人物身份、世界观、结局和标志造型
-> 转成《残烛》可替换变量
-> 写失败边界
-> 写SD正向执行锚点
```

## 7. 精简、合并与停止规则

1. 新样本必须至少带来一项：新规则、新失败边界、新组合模板、新SD锚点或对现有规则的明确反证。
2. 只重复已有结论的样本登记为覆盖证据，不增加技能正文。
3. 同一机制连续两个新样本都没有新增内容，立即停止该机制的主动收集，切换下一批次。
4. 一个地点、影片或运镜术语不自动生成新技能、新文件或新路线。
5. 多人对话、声音诱导、规则物测试、双身、重复空间和家庭虚假安全分别进入已有通用模块；《残烛》文件只保存项目触发方式和应用约束。
6. 电影世界观、医生身份、异常解释、角色关系和结局均为替换变量，不进入通用卡池。
7. 每批最多更新1-2个主模块；其余只登记来源，防止一次投喂横向污染全部技能。

## 8. 单批训练流程

```text
1. 核对实际素材数量、来源类型和是否重复。
2. 将逐镜事实分成A/B/C级。
3. 比较同批次已有样本，标出新增与重复。
4. 提取可复用规则、失败边界、迁移模板和SD锚点。
5. 只更新1-2个目标模块。
6. 更新来源登记，不把项目剧情写入通用库。
7. 用一个《残烛》微型场景和一个匿名场景反向触发测试。
8. 连续两个样本无新增时关闭该批主动扩张。
```

## 9. 批次验收

每个批次完成时必须回答：

- 是否获得至少3种机制不同的导演解法，而不是十部电影重复同一构图。
- 是否能说明为什么在这里切镜、为什么是这个站位、谁拥有信息和出口。
- 是否形成一份4-15秒可迁移模板。
- 是否能转成正向、可执行的SD锚点。
- 是否明确哪些内容只适用于《残烛》，哪些已匿名化进入通用能力。
- 是否达到饱和停止条件。

未满足以上条件的批次继续补样本；满足后关闭扩张，只在真实生成失败时重新打开。
