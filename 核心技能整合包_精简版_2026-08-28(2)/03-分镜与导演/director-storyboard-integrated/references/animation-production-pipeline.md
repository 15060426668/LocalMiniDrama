# Animation Production Pipeline v6

本文件是动画项目从故事到视频执行词的唯一流程权威。各技能只拥有自己的阶段，不复制相邻阶段的规则。发生冲突时，项目锁和用户最新确认高于本文件；上游已批准事实高于下游优化。

## 1. 六步主链与所有权

```text
Step 1 story-framework
  项目命题、世界、人物、类型、长线方向与硬约束
-> Step 2 script-writing
  场景事件、角色行动、节拍、进入状态与退出变化
-> Step 3 script-roundtable
  诊断结构、人物、节奏和观众体验，不直接改稿
-> Step 4 dialogue-doctor
  台词声纹、潜台词、冲突策略、信息效率与最终台词锁
-> Step 5 director-storyboard-integrated
  场景可拍闸门、方案池、分镜细则、时长、空间和连续性
     + animation-suspense-performance
       动画表演、timing/spacing、画面法则、全画面运动与归模
-> Step 6 dream-suspense-sd
  只把已批准分镜编译为纯文本 BASE LOCK + A，不改故事和镜头
```

下游发现问题时必须回传给拥有该问题的上游：

| 问题 | 返回层 | 下游不得做 |
|---|---|---|
| 人物动机、世界规则、场景存在理由不成立 | Step 1/2 | 用镜头或旁白掩盖 |
| 节拍缺失、转折无因、结尾无变化 | Step 2 | 在分镜中临时发明剧情 |
| 台词同声同气、信息重复、时长超载 | Step 4 | 擅改最终台词 |
| 轴线、调度、切点、观看权限不成立 | Step 5导演层 | 让SD模型自行理解 |
| 动作、接触、离模、归模、环境反馈不成立 | Step 5动画层 | 用特效遮盖动作空缺 |
| 来源覆盖、时序或连续性丢失 | Step 6 | 回写上游内容 |

## 2. 项目锁与当前段入口

每次只恢复当前任务需要的事实，不重新讲完整项目。进入当前段前内部锁定：

```text
媒介与画幅：
目标平台与时长：
角色/场景参考绑定：
人物关系与当前情绪债：
世界规则与不可改事实：
上一段尾态：姿势 / 视线 / 屏幕方向 / 物件 / 光源 / 声尾 / 残留
本段入口：硬切新镜头 / 连续跟拍 / 动作匹配 / 遮挡接续 / 声音先行
本段必须完成的变化：
本段禁止提前发生的事实：
```

参考图已经锁定人物或场景时，不重新描写外貌和建筑。只写参考绑定、当前服装或状态差量、动作所需的易丢特征。没有参考图时才建立必要的可见身份锁。

## 3. 场景可拍闸门

分镜方案之前必须证明场景不是空壳。普通小场景可内部快速完成；剧情、台词或因果有争议时显式输出并返回上游。

```text
场景功能：这段在整集里为什么存在
入口状态：谁正在做什么，关系/风险处于什么水平
角色目标：此刻具体想得到、避免、隐瞒或证明什么
阻力来源：谁、规则、物件、空间或时间怎样阻止
行动策略：角色实际采用什么办法，不用情绪词代替
触发事件：哪项可见/可听事实迫使策略开始
节拍链：尝试 -> 反馈 -> 误判/确认 -> 策略变化 -> 后果
段内转折：观众的问题、关系权力或行动方向怎样改变
退出变化：人物、关系、物件、空间或观众认知至少改变一项
下一段债务：留下什么未完成动作、问题、承诺或残留
```

拒绝进入方案池的条件：角色无理由行动；信息来源缺失；笑点只靠角色突然变笨；转折只靠巧合；台词说完但任何人和物都没变化；本段结束后可以无损删除。

## 4. 类型节拍只选一条主脊柱

30秒允许多个小节拍，但只能有一个主戏剧事务。按类型选择主脊柱，再根据当前故事调整：

```text
情景喜剧：日常任务 -> 错误判断/规则冲突 -> 升级 -> 包袱兑现 -> 反应或补刀
关系对话：触发 -> 提议/试探 -> 抵抗 -> 策略变化 -> 决定/破裂 -> 余波
温情日常：正常任务 -> 细小需要 -> 笨拙照顾 -> 被看见/未说破 -> 日常继续但关系变近
悬疑：正常基线 -> 异常证据 -> 主动试探 -> 解释改写 -> 新代价或残留
动作：意图 -> 起势 -> 障碍 -> 调整路线 -> 接触/后果 -> 恢复或新威胁
意识流：现实锚 -> 心理触发 -> 单一画面法则越界 -> 发展/换权 -> 归还 -> 现实残留
```

类型模板不是固定秒表。包袱、揭示或情绪落点必须由前面的可见因果挣得，不能在尾端凭空出现。

## 5. 台词逻辑与表演时间

台词先作为戏剧行为成立，再进入口型和镜头。每句关键台词内部登记：

```text
说者目标：希望听者做什么或相信什么
表层意思 / 潜台词：
声纹：这个人物独有的词汇、句长、回避或攻击方式
新信息：本句新增什么，删掉后是否损失
策略动作：安抚 / 试探 / 转移 / 挤兑 / 威胁 / 求助 / 隐瞒 / 补刀
听者变化：先听见，再理解，再身体反应，再决定是否回应
台词前动作 / 重音动作 / 尾音动作：
口型窗口与停顿：
```

规则：

- 不因谁说话就自动切给谁。镜头只因信息、动作、空间、关系权力、反应或节奏改变而切换/移动。
- 关键包袱、揭示和伤人句之后必须留反应窗口；笑点可用沉默、视线、物件或第三人补刀，不立刻用下一句淹没。
- 说者执行主动作时，听者保留独立任务和延迟反应；不要让所有人同拍停手看向说者。
- 台词时长不够时，先回报超载并给出上游删改建议；未经批准不得在分镜或SD层擅改字词。
- 台词已经批准时，SD逐字继承；不得润色、翻译、补写或把潜台词变成旁白。

## 6. 分镜方案阶段

方案回答“这段采用什么导演机制”，不提前写正式镜头表和SD。每个真正有差异的方案只包含：

```text
方案名与主戏剧事务
观众体验曲线
类型节拍与30秒内的时间骨架
画面所有者如何变化
空间调度与主要摄影机语法
动画主表达引擎（普通段可写现实法则）
声音/物件/环境如何参与因果
方案兑现的尾态
AIGC风险与修复方向
```

可以零到六个方案，不为凑数制造同义变体。对标作品只贡献机制，不贡献角色、剧情、台词、时长或视觉商标。用户批准一个方案或组合后才进入分镜细则。

## 7. 正式动画分镜

正式分镜是Step 6的唯一内容来源。先给段级事实锁，再按镜头写，不把同一事实同时塞进镜头表、运动台账和连续性表。

### 7.1 段级事实锁

```text
段落任务 / 类型脊柱 / 目标时长
入口状态 / 退出变化 / 下一段债务
信息权限与不可提前事实
空间、轴线、屏幕方向和角色站位
参考绑定、物件所有权、光源与持续声床
最终台词锁与预计口型窗口
```

### 7.2 每镜最小完备字段

```text
镜号与整秒时间
戏剧变化：本镜新增的动作、信息、关系或后果
镜头与构图：起始机位、画面所有者、景别/空间、路径、触发原因、落点
主体与关系表演：意图、姿势链、脸/呼吸、重心手脚、说听错时、接触与恢复
物件/环境/NPC：原任务、受力/延迟、独立反应、状态改变
动画表达：现实基准、主变量、进入、发展、归还、残留；普通段写现实法则
声音与台词：声源、口型窗口、重音/停顿、可见反应、声桥
转场与尾帧：结束姿势、视线、方向、物件、光声、残留、下一镜第一动作
```

复杂连续动作或一镜到底另附逐拍运动台账；简单镜头不重复抄一遍镜头表。台账只记录镜头表无法清楚表达的时间内变化。

## 8. 动画表现深化

`animation-suspense-performance`接收段级事实锁和导演镜头，不改镜头的戏剧目的。它负责：

- 把动作标题展开为意图、预备、支点、发力、路径、接触、峰值、恢复和尾态。
- 统一脸、呼吸、肩脊髋、手脚、衣发、道具、环境、声音和摄影机的先后关系。
- 在普通段与表现段之间做选择；普通段不强迫离模，表现段只选一个主表达引擎。
- 设计timing/spacing、hold、阶梯帧、smear、离模/归模和画层换权。
- 证明复合运镜的世界锚、摄影机路径、主体路径、遮挡连续和最终落点。
- 将每拍结果交给下一拍；发现导演镜头不可执行时返回Step 5修正，不私自改戏。

动画深化完成后，正式分镜才进入批准锁。

## 9. 4-30秒时间架构

- `4-15秒`：可以是单次动作、单个包袱、一次试探或一个小转折。
- `16-30秒`：默认仍是一段、一份正式分镜和一条SD文本；不在15秒重启场景、BASE或人物状态。
- 内部动作拍通常为`2-4秒`，由动作完成、台词停顿、信息变化、遮挡节点或摄影机落点决定，不机械均分。
- `12-18秒`附近至少出现一次有因果的刷新：策略改变、听者确认、物件改义、空间换权、声音夺权、镜头重新获得目标或关系转折。
- 额外时长优先给准备、听者反应、环境接力、后果和恢复，不给同一时间窗增加多个主动作。
- 只有总时长超过30秒、用户明确要求多段，或内部动作拍顺序拆分后仍不可执行时才新开一段。

## 10. 批准锁与差量变更

用户批准正式分镜后建立内部来源账本：

```text
源镜头号 -> 时间范围 -> 必须保留事实 -> 易丢锚点 -> 尾态
```

之后任何阶段只允许三种变更：用户明确改动；生成失败后针对首个失败层修复；发现不可执行事实后返回拥有该事实的上游。每次改动列出差量，不重写未变部分。

## 11. 纯文本SD承接

`dream-suspense-sd`只做语义编译，用户可复制的唯一格式是：

```text
【BASE LOCK】
跨整段稳定且会影响生成的参考绑定、媒介、身份、空间、道具初态、光色基准、运动帧感和持续声床。

【A区块·模型执行词】
第X-X秒｜源镜头号
镜头与构图：
主体动作与表演：
关系/物件/环境反馈：
声光与转场触发：
尾帧与连续性：
```

BASE只写一次；A只写时间差量。每个A拍起点必须等于前一拍尾态，除非明确写出硬切或转场。来源名、对标名、推理、审核分数、E索引、数值混音和自审报告不进入可复制提示词。

JSON仅可存在于内部配置、测试夹具或验证器输入输出中，永远不是SD/Seedance用户交付格式。即使用户临时索要JSON，也先说明当前生产契约只交付纯文本SD，并继续给出纯文本结果。

## 12. 返工顺序

生成失败时只修第一个失败层：

```text
源故事/台词错误
-> 正式分镜缺失或矛盾
-> 动画动作/画面法则不可执行
-> SD来源覆盖或时序丢失
-> 模型执行偏差
-> 后期声音/剪辑问题
```

修复后重新检查受影响层及其所有下游，不借机改写已批准的其他内容。

## 13. 最终门

- 本段删掉后剧情或关系必须有损失。
- 每个关键动作有原因、可见过程、反馈、后果和继承。
- 每句关键台词有目的、听者变化和足够时间。
- 镜头变化由戏剧和空间触发，不由说话人机械触发。
- 动画表达有现实基准、主引擎、归还与残留。
- 16-30秒不在中途重启人物、场景或提示词。
- 正式分镜100%映射到纯文本BASE+A。
- 用户侧无JSON、无审计附录、无来源作品名、无抽象情绪指令。
