## Use Protocol

1. Identify the scene function: power, secrecy, desire, betrayal, pursuit, discovery, threshold, truth reveal, aftermath, open ending, parallel action, psychological duel, class pressure, or emotional collapse.
2. Pull 2-4 classic references whose mechanisms differ from each other.
3. Extract only mechanism: gaze, position, threshold, occlusion, cut point, reaction, sound bridge, object carrier, or spatial hierarchy.
4. Translate into the current story: concrete body action, gaze target, prop behavior, camera position, light change, sound cue, and cut/transition.
5. Add it to the shot-scheme pool as a `classic lens reference`; state what cannot be copied.

## 1. Gaze Chain / 凝视语言

- `Memories of Murder` final stare: direct-to-camera unresolved accusation. Use for open endings, guilt transfer, truth without closure.
- `The Godfather` office: superior barely looks, subordinate drops gaze. Use for power hierarchy without shouting.
- `Lust, Caution` mahjong: multiple gaze chains expose affair/secrecy. Use for social rooms where the spoken topic is false.
- `The Silence of the Lambs` first Lecter meeting: unblinking stare breaks the visitor's control. Use for interrogation and psychological duel.
- `Oldboy` corridor pre-fight: distant stare freezes time before violence. Use for confrontation before motion.
- `The Shining` bar/Grady: smiling unblinking wrongness. Use for human-looking threat or mental infection.
- `Pulp Fiction` diner flirt: look-caught, look-avoidance, look-return. Use for attraction or forbidden curiosity.
- `Se7en` desert: villain knows more, watches with pity/pleasure. Use for antagonist with hidden leverage.
- `Parasite` car smell glance: class violence through one casual look. Use for humiliation and status wounds.
- `Psycho` parlor: one-second eye switch reveals a second self. Use for double-faced characters and unstable masks.

## 2. Blocking / Axis / Threshold

- `The Godfather` office: dark rear center owns power; distance from desk marks loyalty. Use for authority rooms.
- `The Shining` tricycle corridors: strict central axis creates fate; danger appears when the axis breaks. Use for corridors and institutions.
- `Parasite` rain descent: class as vertical geography. Use for social fall, shame, and return to lower space.
- `Taxi Driver` mirror rehearsal: mirror as self-threshold. Use for split self, rehearsal, self-hypnosis.
- `In the Mood for Love` thresholds: desire trapped at doors, corridors, corners. Use for separation and unsaid emotion.
- `The Dark Knight` interrogation: table axis; crossing it equals loss of control. Use for quarrel, interrogation, and negotiation.
- `2001` monolith: unknown object owns central axis. Use for rule objects, anomalies, sacred/alien items.
- `Farewell My Concubine` stage/offstage contradiction: performed relation and real relation split by axis. Use for public lie/private truth.
- `Kill Bill` tea house duel: empty center line belongs to duelists. Use for face-off and decision fight.
- `A City of Sadness` doorway return: one foot in each world. Use for homecoming, release, and irreversible re-entry.

## 3. Foreground Occlusion

- `Psycho` shower: translucent curtain, water, shadow let the viewer complete violence mentally. Use for non-graphic implied harm.
- `Blade Runner 2049` casino: fog, rain, hologram, glass delay recognition. Use for search, sci-fi dread, and low visibility.
- `Oldboy` corridor: bodies, hands, weapons dirty the frame. Use for messy pressure instead of clean action.
- `Memories of Murder` field: reeds/grass hide clue/body until discovery. Use for investigation and absence reveal.
- `In the Mood for Love`: curtain, doorway, passerby separate people. Use for forbidden closeness.
- `Se7en` crime scenes: flashlight gives partial permission to see. Use for darkness investigation and controlled reveal.
- `The Godfather` restaurant: table hides gun/hand. Use for concealed action under polite conversation.
- `The Shining` columns: rhythmic occlusion reveal. Use for corridor apparition, stalker, and sudden presence.
- `Suzhou River`: rain, glass, hair, crowd make subjectivity unstable. Use for searching, intoxication, emotional panic.
- `The Revenant`: low grass/snow/branches produce hunted vulnerability. Use for ground-level chase and wounded escape.

## 4. Cut-Point Language

- `The Godfather` baptism montage: sacred line cuts to crime. Use for hypocrisy, parallel action, and moral contradiction.
- `Psycho` shower montage: cut on action peak, not full contact. Use for implied violence and panic.
- `Fight Club` Tyler flashes: 1-3 frame intrusion. Use for mental leakage, memory contamination, or hallucination.
- `2001` bone to spacecraft: match shape/motion. Use for time jump, identity jump, and object-based transition.
- `Se7en` box: cut to reaction/villain, not contents. Use for truth reveal through response.
- `Pulp Fiction` accidental shooting: skip impact, land in aftermath. Use for shock, accident, sudden consequence.
- `Oldboy` post-fight anti-climax: relief cuts to worse captivity. Use for false safety.
- `Inception` multi-layer kick: synchronized action point across spaces. Use for parallel dream/space/time events.
- `Memories of Murder` final black: cut as realization lands. Use for unresolved truth.
- `The Shining` elevator: sound pre-lap, door slit before impact image. Use for shock reveal with controlled threshold.

## 5. Reaction-First Language

- `Se7en` box: multiple reactions assemble truth. Use when the object itself should remain unseen.
- `The Silence of the Lambs`: listener face while speaker stays off-screen. Use when a story becomes terrifying through the listener.
- `The Shining` manuscript: reader's face and retreat tell the madness. Use for evidence discovery.
- `The Godfather` restaurant aftermath: killer's blank delay carries consequence. Use for irreversible decision.
- `Memories of Murder` witness fear: unseen source becomes terrifying through witness reaction. Use for off-screen dread.
- `Farewell My Concubine` betrayal: smile-freeze-tears-rupture. Use for public betrayal and emotional collapse.
- `Parasite` former housekeeper knock: group freeze before door reveal. Use for sudden interruption.
- `Titanic` Jack death: living person's face/touch carries loss. Use for grief without graphic display.
- `Joker` TV aftermath: protagonist face isolated from surrounding chaos. Use for dissociation after rupture.
- `The Godfather Part III` silent grief: mouth opens before sound. Use for unbearable loss and delayed scream.

## 6. Flash Cut / Subliminal Intrusion

- Keep a stable base shot, insert a very short image, then return before the viewer fully processes it.
- Give the intrusion one owner: memory leak, identity leak, future clue, sensory shock or object association.
- Preserve one bridge across the intrusion: sound tail, gaze direction, body pose, color, shape or motion.
- Use repeated intrusions to accumulate meaning; vary the evidence rather than extending the same flash.
- Strong candidate pool: `Fight Club`, `The Exorcist`, `Sunshine`, `The Ring`, `Black Swan`, `Jacob's Ladder`, `Don't Look Now`.
- Failure boundary: random shocking frames, unrelated gore, or inserts that change no information create noise rather than psychology.

## 7. Flashback Entry / Return

- Enter memory through a motivated trigger: object contact, sound, gesture, location, color, smell reaction or repeated framing.
- State whether the flashback is reliable, partial, distorted, imagined or later reinterpreted.
- Connect the entry through match action, sound pre-lap, focus transition, material overlap or a repeated screen position.
- Return to the present on the same body/object state or on a changed residue that proves the memory affected the character.
- Strong candidate pool: `Memento`, `The Godfather Part II`, `Once Upon a Time in America`, `Arrival`, `Shutter Island`, `Martha Marcy May Marlene`, `Eternal Sunshine of the Spotless Mind`, `The Limey`.
- Failure boundary: a flashback that only explains plot, has no present trigger, or returns with the body state reset becomes exposition rather than dramatic memory.

## 8. Dolly Zoom / Vertigo Effect

Execution contract:

```text
camera translates along the lens axis
while focal length changes in the opposite direction
-> subject size stays nearly stable
-> background perspective expands or compresses
-> hold long enough for the spatial change to read
```

- Use it for a sudden realization, threat recognition, spatial refusal, dissociation or a power shift.
- Build visible depth with corridor lines, road edges, crowd layers, architecture, furniture or landscape.
- Lock the subject distance and body reaction; the shot works because the world changes around a relatively stable subject.
- Strong candidate pool: `Vertigo` staircase, `Jaws` beach, `Goodfellas` diner, `The Lord of the Rings` road, `La Haine` city, `Poltergeist` hallway.
- Failure boundary: digital zoom alone, a flat wall background, large subject movement or an unmotivated lens trick produces style without perception change.
