# Storyboard To SD Compiler Contract v6

本文件只定义Step 5到Step 6的交接边界。字段写法由 `../../dream-suspense-sd/SKILL.md` 和其动画执行参考拥有；完整流程见 `animation-production-pipeline.md`。

## 1. 允许进入SD的来源

必须满足：

- 当前段正式分镜已经被用户批准，或用户明确指定某份文件为批准源。
- 时长、媒介、角色/场景参考、台词、入口和尾态已锁定。
- 动画项目的动作、表演、画面法则和恢复尾态已经过动画层深化。
- 不存在需要下游自行决定的剧情、台词、镜头顺序或结局。

方案池、粗略想法、对标分析、静态参考图和未批准草稿不能直接编译。缺口返回拥有该事实的上游。

## 2. 唯一来源映射

编译前内部建立：

```text
源镜头号
-> 源时间
-> 必须保留的可见/可听事实
-> BASE或A的唯一归属
-> 2-4个易丢锚点
-> 源尾态
```

来源覆盖默认100%。一个事实有一个主归属；稳定事实放BASE，时间差量放A，审核和数值制作数据留在模型载荷外。

## 3. 用户交付

用户侧只允许纯文本：

```text
【BASE LOCK】
...

【A区块·模型执行词】
第X-X秒｜源镜头号
镜头与构图：
主体动作与表演：
关系/物件/环境反馈：
声光与转场触发：
尾帧与连续性：
```

JSON仅供内部配置、测试夹具和验证器使用，永远不是SD/Seedance交付格式。E索引、混音表、自审和来源报告如需输出，必须标为独立制作附件，不得并入可复制提示词。

## 4. 30秒规则

- 一份已批准`4-30秒`分镜默认对应一个BASE和一条提示词。
- `16-30秒`不在15秒重启BASE或人物状态。
- A按自然`2-4秒`动作拍覆盖全段；`12-18秒`附近保留批准的中段刷新。
- 每拍尾态等于下一拍入口，明确硬切或转场除外。
- 超过30秒或顺序拆拍后仍不可执行时才新开提示词。

## 5. 不得下游改写

SD层不得：

- 新增或删减剧情动作、台词、人物、道具、转场和结局。
- 将对标作品名、来源时间、内部评分和推理写入模型载荷。
- 用外貌长描述覆盖已绑定参考图。
- 用抽象情绪、审美评价或否定清单代替执行动作。
- 因字符压力把动作、听者反应、接触、落点或尾态压成摘要。

发现不可执行内容时，报告源镜头号、冲突事实和应返回的上游层。

## 6. 通过条件

- 源镜头全部映射。
- 时间连续、总长准确、字段齐全。
- 台词逐字继承并落入可执行口型窗口。
- 主体动作有起势、过程、接触/反馈、恢复和尾态。
- 摄影机有起点、触发、路径和落点。
- 关系、物件、环境、声光和转场与主体形成因果。
- 最终提示词无JSON、无审计附录、无来源作品名。
