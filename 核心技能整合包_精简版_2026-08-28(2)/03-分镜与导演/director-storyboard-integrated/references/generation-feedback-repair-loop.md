# Generation Feedback Repair Loop

用途：分镜 -> 梦导SD -> 出图/视频 -> 用户反馈 -> 回修分镜/SD/训练模块 的闭环。

目标：当用户指出生成结果“不对、不像实拍、动作没了、空间错、光影错、转场没兑现”时，先定位失败层，再决定回修分镜源表、A区块、执行锚点或训练模块。不要只重写一版更长提示词。

---

## 1. 先判定失败层

| 失败层 | 常见症状 | 回修位置 | 判断标准 |
|---|---|---|---|
| 分镜源表失败 | 分镜本身没写清构图、人物动作、光源、材质、转场过程 | 回分镜表 | 源分镜读完后仍画不出画面 |
| A区块编译失败 | 分镜有细节，但SD输出词压缩成一句氛围描述 | 回A区块 | `源分镜镜头号 -> A区块时间段 -> E区块索引` 断链 |
| 模型执行失败 | A区块清楚，但生成仍跑偏、脸崩、空间错、动作不连 | 强化正向锚点 / 拆段 / 参考图 / 角色锁定 | 文本已有但模型负载过高 |
| 连续性失败 | 镜头之间人物方向、门位、光源、服饰、道具状态跳变 | 回空间锁定和连续性字段 | 同一场景无法画出稳定平面图 |
| 真实度失败 | 画面像塑料、CG、海报、游戏截图、摆拍样片 | 回画面基调/质感与实拍摄影证据 | 缺少真实光源、材质瑕疵、镜头缺陷、空气层 |
| 节奏失败 | 15秒段落信息少、停留太久、剪点没理由 | 回短剧节奏和剪点 | 0-3秒无钩子，8-15秒无认知变化 |
| 声画失败 | 声音和画面不互相触发，只是背景音乐 | 回声音设计和声画同步 | 声音没有来源、距离、层次、节拍变化 |
| 转场/VFX失败 | 只看到硬切或随机变形，看不出过程 | 回转场过程字段 | 缺少旧画面、触发、第一变化、中段变形、新画面、残留 |

---

## 2. 反馈症状 -> 回修字段矩阵

| 用户反馈 | 先问的诊断问题 | 必修字段 | 修法 |
|---|---|---|---|
| 画面很空、像阅读理解 | 构图画面是否能直接画出来？ | 构图画面 / 画面内容 | 补前景遮挡、中景人物、背景信息点、主体比例、负空间方向、可见动作 |
| 人物没在表演 | 是否写了眼神、嘴角、肩颈、手指、脚步、呼吸？ | 画面内容 / 表演微动作 | 把情绪词改成身体动作链，写清声音触发后的反应 |
| 动作丢失 | 单段是否塞了太多动作？ | A区块 / E区块 / 剪点 | 将连续动作拆成2-3个时间段，每段只保留一个主动作和一个微动作 |
| 空间错乱 | 门、窗、床、走廊、人物方向是否锁定？ | 空间连续性 / 机位与运镜 | 写清屏幕左/右、前/后、入口/出口、运动路线、镜头轴线 |
| 光影不对 | 光源来自哪里？光是否随镜头变化？ | 光影/色彩 | 补光源、光位、光质、光比、阴影占比、色温变化 |
| 不像实拍 | 哪个物理细节证明这是摄影机拍到的？ | 画面基调/质感 / 实拍摄影证据 | 补材质磨损、空气层、镜头眩光、轻微运动模糊、黑位、颗粒、真实反射 |
| 转场没兑现 | 是否写出了连续变形过程？ | 转场 / VFX锚点 | 写成“旧表面 -> 触发 -> 初变 -> 中段形变 -> 新空间 -> 残留痕迹 -> 声光同步” |
| 声音太薄或混成一团 | 是否缺少唯一主声源、ENV/BODY/OBJ/VOX/FX/INT/MUS路由、方向距离、RMS/peak/相对电平、空间处理、闪避、LUFS-S和声桥？ | 声音设计 / post cue sheet | 回到`声音任务 -> 主声源 -> 启用总线 -> 空间/计量 -> 闪避 -> 声画反应 -> 尾音`重编，并用`calculate_sound_mix.py`检查叠加和余量 |
| 节奏太慢 | 是否有超过4秒的静态单机位？ | 时长 / 转场 / 叙事目的 | 增加切点、焦点变化、物件状态变化、画外声触发、反应镜头 |
| SD丢细节 | A区块是否逐镜继承？ | SD承接锚点 / A区块 | 对照源分镜逐条补齐构图层、动作、光、材质、声音、转场 |

## 3. 反修流程

```text
1. 复述用户反馈中的具体失败点，不泛化成“需要更高级”。
2. 判定失败层：分镜源表 / A区块编译 / 模型执行 / 连续性 / 真实度 / 节奏 / 声画 / VFX。
3. 对照源分镜镜头号，找出最先失真的字段。
4. 若源分镜缺字段，先回修分镜；不要直接加长SD提示词。
5. 若源分镜完整但A区块丢字段，回修A区块，并保持正向词。
6. 若A区块完整但模型执行失败，降低单段负载：拆段、强化角色/空间/光源锚点、加入参考图或稳定尾帧。
7. 若同类失败重复出现，把失败写入 complaint-driven-correction-library 或对应训练模块。
8. 输出反修版时标明：修了哪个失败层、改了哪些字段、仍需保护哪些锚点。
```

---

## 4. 分镜源表回修规则

当失败来自源分镜，按字段修，不许只补形容词：

| 字段 | 回修要求 |
|---|---|
| 构图画面 | 写清前景/中景/背景、人物比例、屏幕方向、遮挡物、视线引导、负空间或几何线条 |
| 机位与运镜 | 写清高度、角度、距离、起止画面、运动路径、焦点变化、剪点理由 |
| 光影/色彩 | 写清真实光源、光位、光质、光比、阴影占比、主色/强调色、曝光状态 |
| 画面基调/质感 | 写清场景子类型、胶片/数字质感、颗粒、黑位、镜头特性、材质优先级 |
| 实拍摄影证据 | 写清材质瑕疵、真实反射、空气层、轻微运动模糊、镜头缺陷、连续性痕迹 |
| 画面内容 | 写清身体动作、眼神、手脚、道具状态、背景动静物、微反应 |
| 运动生态/层级交互 | 写清注意力所有者、信息权限/知情状态、公开行为与私下信号、主运动、NPC与道具反应、环境力、材质响应、光影摄影机、声音触发、残留和尾帧；保持运动主次层级 |
| 声音设计 | 写清声源、距离、层次、节奏、变化、静音、声桥、声音触发的画面反应 |
| 转场 | 写清旧画面、触发点、变化过程、新画面、残留痕迹、声光同步 |

---

## 5. A区块回修规则

A区块不是重新创作，它是分镜编译。

每个A段必须保留：

- 源分镜镜头号和时间范围。
- 最脆弱的构图层：前景遮挡、主体位置、背景信息点、负空间方向。
- 最脆弱的动作细节：手、眼、脚、道具状态、反应瞬间。
- 机位和运动：高度、角度、起止画面、焦点变化。
- 光影和材质证据：光源方向、表面反射、颗粒、黑位、空气层。
- 声音触发：哪一个声音让人物或画面发生变化。
- 转场尾帧：下一段继承什么视觉残留。

如果一个用户可见A区块总长超过30秒则拆成新提示词；单个内部A拍通常保持2-4秒，包含两个独立核心动作时先拆内部A拍。

## 6. 模型执行失败反修

当A区块已经写清但生成仍错，优先做执行层修复：

| 失败 | 执行层修法 |
|---|---|
| 脸不稳 | 单独写角色锁定：年龄、脸型、发型、服饰、神态基准、镜头距离；必要时用参考图 |
| 空间跑偏 | 写空间锁定：门/窗/家具/走廊方向、屏幕左右、主光方向、人物移动路线 |
| 动作变形 | 缩短段落，只保留一个主动作；复杂动作拆成起势、过程、结果 |
| 光源漂移 | 每段重复关键光源位置和光色，保留同一主光方向 |
| 质感发假 | 增加真实摄影证据，而不是堆“cinematic”；用材质、镜头、空气、瑕疵说话 |
| 转场随机 | 把变形绑定到一个物体或表面，不让整个画面无源乱变 |
| 声画不同步 | 在A段写明“某声音出现时，某动作/灯光/转场发生” |

所有修法只写正向锚点。不要写禁止词、负向词或“不要怎样”。

---

## 7. 生成结果训练沉淀

一次失败只有在满足以下条件时才写入训练库：

- 失败可复现，不是单次随机小错。
- 能定位到明确字段或链路节点。
- 能形成可迁移规则，而不是只针对一个镜头补丁。
- 能提升分镜到SD的稳定承接。

沉淀格式：

```text
失败现象：
失败层级：
源分镜缺口：
A区块缺口：
模型执行负载：
修复动作：
可复用规则：
应写入模块：
下次自检问题：
```

```text
反修判断：
- 失败层：
- 首要问题：
- 不改什么：
- 必改字段：

反修方案：
1. 分镜源表修正：
2. A区块修正：
3. 执行锚点：
4. 需要拆段/参考图/尾帧继承：

验证：
- 源分镜镜头号 -> A区块时间段 -> E区块索引 是否不断链。
- 构图、动作、光源、材质、声音、转场是否全部可追踪。
```
