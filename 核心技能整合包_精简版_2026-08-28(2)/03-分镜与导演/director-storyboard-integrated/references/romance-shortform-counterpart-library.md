# Romance And Rom-Com Short-Form Counterpart Library

用途：为都市偶遇、欢喜冤家、非语言暧昧、共乘、爱情蒙太奇和亲密动作提供机制级对标。当前条目默认B级，只借机制，不声称精确时间码或焦段。

## Romance Physical Contact Chain

```text
接近理由
-> 第一接触点
-> 双方重心与手部反应
-> 接触持续或撤回
-> 眼神确认
-> 社会/情感后果
-> 下一次主动靠近
```

## Short-Form Relationship Compression

15秒内从陌生到亲密时，使用明确的时间省略：

- 动作匹配：扶腰 -> 后座环腰。
- 物件匹配：第一次递头盔 -> 后来熟练扣好头盔。
- 重复构图：第一次保持距离 -> 第二次主动靠近。
- 光线与服装状态：日间偶遇 -> 数日后傍晚共乘。
- 声音回收：第一次刹车声 -> 后来红灯停车声。

## Intimacy Staging

- 拥抱、扶腰和接吻先锁脚步、重心、手部接触和头部路线。
- 双人近距离镜头保持一名动作发起者和一名延迟回应者。
- 车辆场景先完成减速、撑地和静止，再安排回头、靠近与接吻。
- 镜面亲密动作属于高风险构图，准备直接侧面双人近景作为稳定覆盖方案。
