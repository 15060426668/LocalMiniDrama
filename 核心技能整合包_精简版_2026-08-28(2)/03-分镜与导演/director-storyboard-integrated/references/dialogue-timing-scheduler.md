# Dialogue Logic And Timing Scheduler v6

用途：在正式分镜前验证台词是一种行动，并量化口型、停顿、听者反应、身体动作、物件和摄影机，避免“谁说话就切谁”或所有轨道同时抢占。

## 1. 台词行动卡

每句关键台词先内部回答：

```text
说者目标：希望听者做、停、信、怕、误解或承认什么
表层意思 / 潜台词：
人物声纹：词汇、句长、语气、回避或攻击习惯
新信息：与前句相比新增什么
策略动作：安抚 / 试探 / 转移 / 挤兑 / 威胁 / 求助 / 隐瞒 / 补刀
听者先前状态 -> 听后变化：
台词前动作 / 重音动作 / 尾音动作：
```

删掉台词后场景没有任何变化，或该句只重复观众已看见的事实时，返回 `dialogue-doctor` 或 `script-writing`。分镜层不得擅自润色已批准句子。

## 2. 时长基线

中文自然表演先按区间估算，再根据角色状态和断句调整：

| 状态 | 建议语速 | 适用 |
|---|---:|---|
| 克制、试探、审问 | 每秒2.5-3.5个汉字 | 留出呼吸、视线和物件动作 |
| 普通对话 | 每秒3.5-4.5个汉字 | 信息清楚、动作适中 |
| 激烈争吵、追逐短句 | 每秒4.5-6个汉字 | 只适合短句和打断 |
| 规则音、系统音 | 每秒3-4个汉字 | 关键词可听清 |

标点、吸气、吞咽、犹豫、抢话、笑声和重音单独占时间。任何连续15秒都不能塞满台词；30秒段至少保留准备、听者反应、物件反馈和尾态窗口。

可运行：

```powershell
python ../scripts/estimate_dialogue_timing.py <dialogue.txt>
```

脚本只估算时长，不判断台词质量。

## 3. 句内时间窗

```text
起句准备：吸气 / 视线锁定或回避 / 手部停顿 / 听者触发
口型窗口：实际发声，不自动叠复杂主动作
重音词：完成一次明确指向、接触、越界或表情泄露
短暂停顿：听者理解、摄影机/焦点交接、物件或背景反应
尾音：嘴部闭合、声音衰减/被打断/被覆盖，行动结果出现
余拍：关系或任务进入新状态
```

台词不是贴在动作上。动作应在台词前准备、重音处完成关键变化、停顿时把信息交给听者，或在尾音后暴露真实意图。

## 4. 并发预算

一个`2-4秒`对话拍通常最多保留：

```text
一个主要口型轨
+ 一个主路线或姿态变化
+ 一个手部/物件动作
+ 一个听者延迟反应
+ 一个低优先级背景事件
+ 一个摄影机或焦点操作
```

出现第二个完整口型、重大转身、递物完成、碰撞、复杂运镜或世界法则变化时，放入停顿或拆下一拍。抢话可重叠短词，但必须写谁盖住谁、谁停口、听者接收哪一句。

## 5. 说者与听者

```text
声源先到
-> 听者眼神或手部任务短暂停顿
-> 面部/呼吸出现理解或误读
-> 身体决定靠近、后退、继续装作没听见或改变动作
-> 说者根据反应调整下一策略
```

听者不必立刻看向说者。低反应人物可通过握物压力、脚尖方向、眨眼延迟、吞咽、过度继续工作或避开目光表现。背景人物按距离和知情路径错峰反应。

## 6. 镜头权限

切镜或移动只允许由以下原因触发：

- 新信息首次可见。
- 人物越过空间、身体或关系边界。
- 听者反应比说者口型更重要。
- 物件改变所有权或意义。
- 画外声改变注意方向。
- 停顿、包袱、揭示或权力变化需要重新分配画面。

“下一句换人说”不是切镜理由。能在同一构图中通过走位、前后景、拉焦、遮挡或群体反应完成时，不机械正反打。

## 7. 类型节奏

### 情景喜剧

```text
铺垫：人物认真执行日常任务
-> 误判/规则冲突：角色按自身逻辑理解
-> 升级：行动比解释先走一步
-> 包袱：一句话、物件或第三人让前义翻转
-> 反应：留0.5-1.5秒可读窗口
-> 补刀/恢复：继承上一反应，不另起无关笑点
```

不要让全员同时大反应；为每人保留符合人设的动作。嘴贱人物的笑点来自明知危险仍补一句，温柔人物的笑点可来自平静说出危险事实，神经大条人物的笑点来自任务注意力错位。

### 争吵

争吵不是持续提高音量，而是逐级改变行动权限：回避目光 -> 抢回物件 -> 越过家具/门框 -> 阻断路线 -> 说出不可撤回信息 -> 一方停止争吵并采取行动。每级一个主升级动作。

### 温情与潜台词

照顾行为先于解释。人物可以谈别的事，但手、物件、距离和停顿完成真正关系变化；避免在结尾补一句总结主题。

## 8. 30秒对话段

- 全段只围绕一个主要谈话事务或喜剧任务。
- 前半段建立立场和第一次策略；`12-18秒`附近由听者确认、误解加深、物件改义、第三人察觉或策略变化刷新。
- 后半段兑现决定、包袱或关系后果，并给余拍。
- 不在15秒重置站位、语气、话题或摄影机。
- 台词字数超过可用口型窗口时，报告预计超载秒数并返回台词层，不私自加速或删句。

## 9. SD交接轨

批准后向SD层只交付：

```text
台词/口型：逐字文本、开口/重音/停顿/闭口时间
身体：支点、路线、姿态和重心变化
手部/物件：接触、阻力、所有权和落点
听者/NPC：感知、理解、身体反应和后续行动
背景：持续任务、延迟反应和尾态
摄影机/焦点：由哪个动作、重音或反应触发
声尾：覆盖、衰减、笑声、静默或声桥
```

潜台词、台词诊断理由和字数计算不进入模型载荷。
