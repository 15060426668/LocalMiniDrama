# Scene-Family Realism Router

用途：把“画面质感训练 / 实拍感训练 / 单帧真实度 / 对标构图拆解”统合进分镜分类。  
目标：正式分镜不是只写“冷色调、电影感、真实质感”，而是按场景类型调用对应的摄影证据包，让每个关键画面像真实摄影机拍到的瞬间。

## 0. 使用方式

正式分镜前先判断场景属于哪一类，再激活对应质感证据。短剧节奏下，不需要把所有知识都堆进每行，只写真正影响画面可信度、生成稳定性和观众感知的部分。

### 分镜字段统合规则

基础分镜仍保留：

```text
镜头 | 时长 | 景别/焦段 | 构图画面 | 机位与运镜 | 光影/色彩 | 画面基调/质感 | 画面内容 | 运动生态/层级交互 | 声音设计 | 转场 | 叙事目的
```

当镜头承担视觉质感、实拍感、规则物、特写、复杂空间、梦境变形、科幻系统、雨夜水面、病房低光、走廊纵深时，在该镜头的 `画面基调/质感` 后补一行或一列：

```text
实拍摄影证据：摄影机 / 光源 / 材质 / 空间 / 人物瞬间 / 瑕疵 / 连续性
```

短剧压缩写法：

```text
实拍摄影证据：24mm低机位边缘拉伸；星球投影作主光；黑金属划痕与玻璃指纹；前景控制台/中景首领/背景投影；首领眼神微停；投影颗粒和暗角；同一冷白投影方向连续。
```

## 1. 场景分类总表

| 场景类型 | 必须写的质感证据 | 可省略的内容 | 主要服务 |
|---|---|---|---|
| 太空舰桥 / 冷系统 / 巨物压场 | 金属、投影、玻璃、屏幕光、星球纹理、尺度标尺、黑位层次 | 生活化污渍、雨水、病房细节 | 深空舰、AI主体、星球投影、生命星体归属反转 |
| 雨夜悬疑 / 水面反射 | 雨滴、湿地、水痕、镜面反射、路灯/车灯、衣物吸水重量 | 宏大尺度、科幻UI | 城市追踪、夜逃、门口犹豫 |
| 病房 / 密闭弱光 / 机构空间 | 荧光灯、监护仪光、床单皱褶、墙皮、金属床栏、塑料管、皮肤状态 | 宏大外景、复杂舰队 | 病房醒来、规则揭示、收容空间 |
| 狭长走廊 / 追逐 / 纵深压迫 | 一点透视、重复灯格、墙面磨损、空气尘粒、脚步冲击、运动模糊 | 长时间静态等待 | 冷开场层过道追逐、门前压迫 |
| 人物近距离特写 / 反应镜头 | 皮肤、眼睛高光、汗、手指发白、吞咽、呼吸、浅景深、微瑕疵 | 大量背景解释 | 恐惧确认、身份反转、心理崩溃 |
| 规则物 / 证据特写 | 纸纤维、蜡油、金属磨损、指纹、微尘、手部接触、光源反射 | 大面积世界观说明 | 卡片、规则火源、档案、控制台、封装符号 |
| 门 / 阈限 / 门后恐怖 | 门缝光、门框遮挡、把手磨损、门后黑位、空间色温差、手部动作 | 直接揭示怪物全貌 | 开门、进门、出门、门后转场 |
| 梦境 / 幻觉 / 空间变形 | 旧空间材质、触发点、变形过程、连续锚点、残留痕迹、声光同步 | 抽象“梦感”标签 | 梦中梦醒来、走廊坍塌、现实错位 |
| 科幻生物 / 高能生命体 / 山谷目标 | 地貌纹理、空气折射、生命脉动、尺度对比、扫描线、目标小比例 | 过度怪物设计 | 山谷单一高能生命体 |
| 对话对峙 / 权力审判 | 轴线、前景障碍、桌面/屏幕/玻璃分界、脸部光比、反应特写 | 平铺正反打 | 夫妻争吵、审讯、首领与AI对话 |

## 2. 太空舰桥 / 冷系统 / 巨物压场

核心：巨物尺度、投影主光、冷系统几何、金属/玻璃/屏幕材质、人物被系统压小。

| # | 对标素材 | 可借机制 | 分镜质感写法 |
|---:|---|---|---|
| 1 | Dune - 舰船/巨物降临 | 巨物先像天象，再像机器 | 舰队阴影作为画面上沿黑色天象，舰体只露冷边光和金属尺度，不急给结构全貌 |
| 2 | Sunshine - 观察室看太阳 | 巨大天体投影成为主光 | 星球投影照亮人物侧脸、控制台、玻璃反射，投影不是背景图 |
| 3 | Event Horizon - 太空鬼船走廊/核心 | 黑金属、深黑位、哥特几何压迫 | 甲板金属有刻蚀、霜雾、暗角，圆形/弧形投影像审判核心 |
| 4 | 2001 - HAL与白色空间 | 系统观察感，红/白/黑极简控制 | AI光源简洁精准，人物像被系统测量 |
| 5 | Alien - 工业舰船 | 管线、雾气、仪器、真实污损 | 控制台按钮磨损、屏幕玻璃指纹、低雾让舰桥有物理空气 |
| 6 | Prometheus - 深空舰/起源空间 | 生物机械材质、起源神庙尺度 | AI主体内部脉络和星球地貌纹理形成生物机械呼应 |
| 7 | Blade Runner 2049 - 巨大投影压人 | 人小空间大，冷系统审判 | 首领体量小于投影，背景影像像墙一样压住他 |
| 8 | Arrival - 巨物静默 | 未知物完整、安静，人类设施低矮 | 山谷目标不喧闹，静止小白点比大怪物更压迫 |
| 9 | Ex Machina - AI隔离玻璃 | 人与AI隔着透明层，反射叠身份 | AI主体与首领之间有投影/玻璃/光层分隔，AI不贴人站 |
| 10 | Solaris - 活体星球纹理 | 星球像记忆/生命载体 | 生命星体归属反转前让地表纹理像旧伤疤，瞳孔里反出星球轮廓 |

分镜启用字段：

```text
画面基调/质感：冷系统科幻悬疑，黑金属、玻璃投影、冷白屏幕光、深黑位、微颗粒、空气尘粒。
实拍摄影证据：摄影机机位/焦段；投影或屏幕光源；金属/玻璃/军装/皮肤/星球云层材质；前中后景尺度；人物眼神/手指微动作；投影颗粒/玻璃指纹/暗角；同一冷白投影方向连续。
```

## 9. 梦境 / 幻觉 / 空间变形

核心：梦境不是随机奇观。必须写清楚起点材质、触发点、变形过程、连续锚点、残留痕迹。

| # | 对标素材 | 可借机制 | 分镜质感写法 |
|---:|---|---|---|
| 1 | Inception - 折叠城市/旋转走廊 | 抽象规则物理化 | 天花板、墙面、地面按可见轴线折叠或旋转 |
| 2 | Paprika - 梦境游行/空间跳转 | 场景连续变形 | 物体材质保留锚点后变成另一空间 |
| 3 | Black Swan - 镜中异己 | 反射不同步 | 镜像动作慢半拍，镜面划痕证明真实介质 |
| 4 | Perfect Blue - 身份空间错位 | 日常场景突然变成另一个身份空间 | 门框或镜头遮挡后，场景替换但姿态连续 |
| 5 | Mulholland Drive - 梦逻辑 | 正常日常里渗出异常 | 声音先不对，光色后不对，最后空间才不对 |
| 6 | Annihilation - 折射区 | 空气和生物材料异化 | 墙纸、植物、皮肤、光线边缘互相渗透 |
| 7 | Solaris - 记忆实体化 | 人和空间像记忆生成 | 旧物和当下空间并置，色温不完全一致 |
| 8 | Stalker - 区域空间 | 门后规则改变但物理真实 | 水、锈、墙皮保留现实触感，规则不解释 |
| 9 | Jacob's Ladder - 医院幻觉 | 快速主观异化 | 灯、床、身体、走廊以运动模糊和声音变闷连接 |

分镜启用字段：

```text
画面基调/质感：梦境/幻觉空间变形，真实材质先成立，再发生物理化异变；旧空间残留痕迹贯穿新空间。
实拍摄影证据：旧空间摄影机位置；触发光源/声音；墙纸/地砖/床单/玻璃/水面材质；前景旧物与背景新空间重叠；人物动作持续；变形边缘颗粒、裂纹、残影；光源方向和角色位置连续。
转场写法：旧材质 -> 触发点 -> 首个变形边缘 -> 中段运动方式 -> 新空间形成 -> 残留痕迹 -> 声光同步。
```

## 12. 输出自检

每次正式分镜自检：

```text
1. 这个镜头属于哪个场景类型？
2. 这个类型最影响质感的证据是什么？
3. 画面基调/质感是否区别于光影/色彩？
4. 是否有至少5个单帧真实度证据：摄影机、光源、材质、空间、人物瞬间、瑕疵、连续性？
5. 短剧节奏下是否只写了能影响画面和生成的内容？
6. 是否有对标机制，而不是对标片名装饰？
```

短剧高密度分镜最小合格线：

```text
每个关键镜头：构图能画出来；动作能演出来；光源能找得到；材质能摸得到；声音能定位；转场有锚点；质感不是空词。
```
