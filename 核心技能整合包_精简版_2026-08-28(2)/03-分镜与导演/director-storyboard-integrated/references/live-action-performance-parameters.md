# Live-Action Performance Parameters

Use this reference when a真人镜头 feels like an emotion label, a generic reaction face, or a stagey performance. Convert the character's objective into a small, repeatable set of visible and audible parameters before choosing coverage.

## Parameter Menu

Choose one primary mode and, at most, one secondary mode. Do not stack every mode in one beat.

| Dimension | Useful choices | What the camera can verify |
| --- | --- | --- |
| Intensity | 10 / 30 / 60 / 90 percent | amplitude and duration, not a label |
| Direction | outward / inward / opposite / hidden / performed | public behavior versus private pressure |
| Reaction timing | immediate / delayed / after reading another face / sudden stop | when the body changes relative to the trigger |
| Gaze | direct / displaced / empty / lowered / searching / locked on an object | attention and avoidance |
| Breath | held / shallow / shortened / irregular / released late | pressure before dialogue changes |
| Hands | grip / release / rub / hover / straighten / protect / reach then stop | leakage or task control |
| Weight | forward pressure / retreat / frozen / unstable / toes toward exit | power, fear, hesitation or escape |
| Speech | low volume / clipped / pause / slower / shorter sentences | control and subtext without shouting |
| Leak point | eyes / throat / jaw / fingers / shoulder / feet / mouth corner | where control first fails |

## Core Modes

- **Delayed reaction:** keep the task running for a beat; the eyes empty or the body freezes before breath and hands reveal the impact.
- **Restrained leakage:** face and voice remain controlled while fingers, throat, breath or timing betray the pressure.
- **Opposite behavior:** the visible task contradicts the internal need: tidy an object while grieving, pour tea while afraid, speak more softly while angry.
- **Cold processing:** reduce movement and facial change; let a small gaze shift, stopped gesture or slower sentence carry danger.
- **Instinctive body response:** shoulders, breath, hands or feet react before the character understands the threat.
- **Hidden agenda:** public words stay polite while gaze, object ownership or measured pacing evaluates or controls another person.
- **Performed normality:** keep the social mask intact but let one detail be too long, too precise, slightly unfocused or rehearsed.
- **Everyday reaction:** use routine actions (straightening, wiping, sorting, checking, touching) as the emotional carrier.
- **Sudden shutdown:** stop a gesture mid-air at the key word or object; hold the interruption before recovery.
- **Low-voice threat:** lower volume, slow the sentence and close distance instead of shouting.
- **Displaced gaze:** look at a cup, door, floor, shoulder or object rather than the person being addressed.
- **Weight shift:** show fear, attack, retreat or escape through the base of support and foot direction.

## Public / Private Dual Channel

For concealment, false intimacy, social pressure or performed ignorance, write five tracks:

```text
public face/voice
public body task
private leak or signal
who can perceive the leak
residual state after the performance
```

Both channels must serve one intention. The private signal can be visible only to the audience, only to a close partner, or to both. State that perception rule; do not give every character the same reaction.

## Timing And Coverage

1. Establish the baseline task and body weight.
2. Trigger the information or pressure.
3. Hold the first controlled response long enough to be readable.
4. Let one leak point change before the face becomes explicit.
5. Place the decisive action, line or distance change after the leak.
6. End on a residual state that the next shot can inherit.

Close-ups should observe the leak point, not replace it with a generic “sad/angry” face. Wide shots should preserve route, distance, exit ownership and who is allowed to move. For a key line, protect the mouth window; place handoffs, larger turns and listener reactions in phrase gaps or immediately after the line.

## Group Scenes

Never synchronize a whole group to one emotion. Assign each person a different task, reaction delay, gaze target, sound contribution or recovery pattern. A group becomes believable through differentiated timing, not by adding more laughter, shouting or nodding.


## Input And Beat Contract

Before directing a live-action performance, reduce the request to three inputs:

- character: identity, pressure habits, defense mechanism, and what the character wants here;
- relationship: each person's objective, approach/retreat, guilt, control, and fear of loss;
- environment: public/private pressure, danger, intimacy, routine, or impending rupture.

If details are missing, state a work assumption instead of asking for a long biography.

Break an important beat into seven visible stages:

1. entry state and social mask;
2. trigger;
3. first involuntary reaction;
4. suppression or recovery attempt;
5. leak point;
6. strategy or distance turn;
7. aftermath that the next shot can inherit.

## Universal Emotion Arc

Do not enter maximum intensity without a baseline. Use the five-layer arc as a timing scaffold:

| Layer | Function | Observable evidence |
| --- | --- | --- |
| baseline | ordinary control and body weight | routine task, stable breath, neutral distance |
| stimulus | information or pressure arrives | gaze catches, breath changes, hand pauses |
| suppression | the character protects the public mask | delayed answer, displaced gaze, controlled task |
| threshold | control becomes costly | voice drops, fingers tremble, gesture stops, distance changes |
| release and tail | action or emotion lands, then leaves a residue | consequence, shutdown, retreat, empty task, or inherited posture |

Choose one emotional lane rather than stacking all of them:

- anger: calm -> offense -> suppression -> cold/hot threshold -> consequence and退潮;
- grief: daily routine -> fracture -> immersion -> digestion -> absence or留白;
- joy: baseline -> trigger -> doubt -> belief -> release and shared afterglow;
- play: setup -> ignition -> escalation -> loss of control -> comic or social reset;
- crying: restraint -> rupture -> release -> connection, exhaustion, or quiet aftermath.

## Reality Gates

Before handoff, confirm:

- each reaction has a trigger and a character-specific defense;
- each short beat uses only one or two physical details;
- interaction changes the listener, distance, object ownership, or strategy;
- a prop action protects, conceals, tests, threatens, or reveals;
- high intensity has a cost and a recovery/tail state;
- groups differ in task, delay, gaze, sound contribution, or recovery;
- negative directions name the failure to avoid, not merely “more cinematic.”

## Prohibitions

- Do not use emotion words as the only direction.
- Do not start at maximum intensity without a baseline and trigger.
- Do not use shouting, staring, crying or object throwing as default shortcuts.
- Do not let a prop action be decorative; it must protect, conceal, test, threaten or reveal.
- Do not change the character's public and private channels into unrelated personalities.

## Handoff Sentence

For each important performance beat, write one compact sentence in the formal storyboard:

```text
mode + trigger + visible leak + listener/audience permission + residual tail
```

Example: `restrained leakage after the accusation; voice stays level, thumb rubs the cup rim, only the audience sees the breath catch, he leaves the cup exactly where it was.`
