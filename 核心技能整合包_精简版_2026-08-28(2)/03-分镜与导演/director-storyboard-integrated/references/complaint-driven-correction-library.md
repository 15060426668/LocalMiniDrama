# Complaint-Driven Correction Library

用途：把用户在训练中反复指出的失败点，沉淀成反向训练样本和纠偏流程。  
目标：高强度训练时不只是继续吃素材，而是让技能对“敷衍、空泛、漏细节、节奏慢、SD丢失”等错误产生稳定免疫。

---

## 0. 使用方式

当用户说以下内容时，先读本库：

- “敷衍”
- “画面内容太浅”
- “不是我要的构图功能，是构图画面”
- “光影不是冷色调三个字”
- “声音太薄”
- “短剧节奏太慢”
- “SD丢了分镜”
- “没有对标”
- “你只是阅读理解”
- “不够实拍”
- “转场没写清”
- “几部电影组合后运镜不连贯”
- “继续高强度训练 / 投诉素材训练”

内部处理：

```text
识别投诉类型 -> 定位失败字段 -> 调用对应专项库 -> 按纠偏模板重写 -> 过 suspense-quality-gate
```

## C01. 构图只有功能解释

失败表现：

```text
构图：负空间制造压迫，前景遮挡增强窥视感。
```

为什么失败：这是解释，不是画面。用户看不到镜头里到底有什么。

纠偏模板：

```text
构图画面：
21:9横幅。前景左侧有半开的门框黑边，占画面约25%，边缘虚焦；中景人物站在画面右三分之一，肩膀被门框切掉一小块；背景是一条纵深走廊，天花灯一格一格延伸到黑处，右侧70%空白走廊没有人，但尽头有一小块不稳定冷光。地面反光把人物脚下拉出细长影子，观众视线被灯线推向黑暗尽头。
```

合格线：删除“压迫、悬疑、窥视”等抽象词后，仍然能画出画面。

## C02. 光影色彩空泛

失败表现：

```text
光影：冷色调，阴影重。
```

纠偏模板：

```text
光影/色彩：
主光来自走廊顶部失效中的冷白荧光灯，沿人物前进方向间隔闪烁；灯管只擦亮额头、眼窝和肩部，下半张脸落入带环境反色的暗部。侧面门缝透出窄幅暖色规则火光，只照到手背和卡片边缘。走廊尽头保持低照度但保留墙皮层次；冷白灯归属走廊，暖光只归属门内规则火源。
```

合格线：必须有光源、方向、光质、光比/阴影占比、色彩归属和画面变化。

## C03. 画面内容像剧情摘要

失败表现：

```text
画面内容：女主害怕地逃跑。
```

纠偏模板：

```text
画面内容：
逃跑者向前冲，右脚落地时踩进一小片积水，水花溅到裤脚；左手扶墙借力，指尖在潮湿墙皮上划出一道短痕。跑到半途听见耳边规则声，头没有完全回转，眼睛先向左后方扫，肩膀瞬间缩紧；下一步踉跄，膝盖几乎撞到墙角。背景灯管闪一下，走廊尽头的门牌号变成规则纹路。
```

合格线：必须写身体、眼神、手脚、道具、背景变化和声音触发的反应。

---

## C04. 声音太薄

失败表现：

```text
声音：走廊环境音，紧张音乐。
```

纠偏模板：

```text
声音设计：
底噪是走廊电流和远处管道水声；近景拟音是鞋底踩湿地、衣料急促摩擦和指尖刮墙；画外压力从后方左侧传来，像有人隔着门轻轻吸气；主观层是耳内心跳和压低的自我提示声，贴近右耳；灯闪瞬间底噪短暂抽空，只剩一口吸气；转场前门后传出极轻的金属锁舌弹动。
```

合格线：至少三层声音，必须有进入/退出/变化点。

## C05. 短剧节奏太慢

失败表现：

```text
一个固定画面停留8秒，只表现人物站着害怕。
```

纠偏原则：

- 固定镜头1-4秒必须刷新信息。
- 15秒段落至少完成：钩子 -> 证据 -> 反应 -> 认知变化。
- 长运镜可以超过4秒，但每2秒必须有新画面信息。

纠偏模板：

```text
0-2秒：脚步低机位冲入画面。
2-4秒：灯闪，墙面门牌变成卡片纹路。
4-6秒：女主回头，背景人影没有加速但距离变近。
6-9秒：她推门，门缝暖光扑脸。
9-12秒：门内不是出口，是病房床。
12-15秒：她在病床上猛醒，卡片压在枕边。
```

合格线：每3秒至少有一个可见新信息。

## C06. SD输出丢分镜细节

失败表现：

```text
A区块：女主在阴森走廊奔跑，电影感，恐怖氛围。
```

纠偏原则：

- 分镜是源代码，SD是编译。
- 构图、机位、光影、质感、画面内容、声音、转场不能丢。
- 信息太密就拆A段，不压缩。

合格A段片段：

```text
第0-3秒｜镜头1
景别/焦段/景深：低机位脚部特写，24mm广角，浅景深落在右脚落地水花。
构图画面：21:9横幅，地面占画面下三分之二，左侧墙角斜切入画，远处走廊灯格形成纵深线。
机位与运镜：镜头贴近地面后退跟拍，轻微荷兰角，脚步从画面深处冲向前景。
光影/色彩：顶部冷白荧光灯一格格扫过脚背，地面积水反射绿色暗光。
画面基调/质感：潮湿走廊实拍质感，磨损地砖、水迹、墙皮脱落、运动模糊。
画面内容：逃跑者右脚踩进积水，水花溅起，衣摆擦过镜头边缘，呼吸急促。
声音设计：赤脚湿响、衣料摩擦、走廊电流底噪，右耳近处出现压低自我提示声。
转场：脚步踩过一块水面反光，反光里闪出病房天花灯。
```

## C07. 没有对标

失败表现：直接生成分镜，不说明借了什么电影机制。

纠偏模板：

```text
对标机制：
- 方案A《It Follows》某段：完整背景慢速威胁运镜。
- 方案B《Triangle》某段：完整重复走廊证据递增运镜。
- 方案C《The Others》某段：完整门与光线边界运镜。
拆段：若总时长超过30秒，先按当前动作、转场、信息翻转和尾帧自适应拆成4-30秒自然段，不套固定数字模板；16-30秒默认保留为一段并细分内部节拍。
筛选：针对当前场景拆解多部电影的可复用分镜机制，用户可逐步排除、选择或组合。
定版：先统一导演语法，再根据当前故事和短片时长重新设计镜头顺序、运镜、调度、声音和转场；不报告电影时间区间。
```

合格线：重要场景先按总时长自适应拆段；返回0-6个有实际帮助的电影分镜机制，不凑数，不要求等时或单片绑定。人物认知、环境和剧情变量不同不构成淘汰；无可用参考时进入原创方案。

## C08. 转场/特效抽象

失败表现：

```text
转场：梦境坍塌转场。
```

纠偏模板：

```text
转场：
旧画面是走廊墙面的潮湿墙纸。灯闪瞬间，墙纸边缘先像泡水一样鼓起，花纹从边角开始融开成黑色水迹；水迹沿墙面下流，流到地面后反向拉长成病房床单褶皱。镜头继续向前，走廊地砖的缝线和床单褶皱对齐，最后地面完全变成病房白床单，只残留一小块走廊门牌数字像污渍贴在床单边。
```

合格线：源表面、触发点、变化过程、新表面、残留痕迹、声光同步都要有。

---

## C09. 质感不真实

失败表现：

```text
画面质感：电影级真实感。
```

纠偏模板：

```text
实拍摄影证据：
摄影机贴近地面造成广角透视拉伸；光源来自可见荧光灯和门缝烛光；材质有潮湿地砖、脱落墙皮、皮肤汗、粗棉睡衣、卡片纸纤维；空间有前景门框、中景人物、背景走廊灯格；人物瞬间是脚落水、手扶墙、肩膀缩紧；瑕疵包括镜头边缘轻微拖影、水滴反光不均、墙面污渍；连续性保持冷白走廊光和暖黄门缝光的方向一致。
```

合格线：七维摄影证据至少五维有效。

## C10. 盲从用户方案

失败表现：用户给任何想法都直接说好。

纠偏模板：

```text
Verdict: adopt with changes.
Why it works: ...
Main risks: ...
Director correction: ...
Protected story rules: ...
```

合格线：必须指出至少一个风险或保护条件，除非方案已经完全成熟。

## C11. NPC、道具和环境像静态背景板

失败表现：

```text
女主在餐厅里争吵，背景有人，窗外下雨。
```

纠偏模板：

```text
运动生态/层级交互：
女主把钥匙推过桌面为主运动；男方原本倒水的手在钥匙碰杯声后停住，杯口水线继续上升并溢出；背景服务员先保持擦桌动作，听见杯子震响后只抬眼一次，另一桌客人继续交谈；窗外横风从画面右侧压动雨线，同一气流推起窗帘下缘和盆栽外层叶片，叶片上的水滴延迟半拍坠落；摄影机保持双人轴线，只在水流接近钥匙时转移焦点；尾帧保留湿钥匙、悬停的水壶、服务员回落的视线和仍在摆动的叶片。
```

合格线：主体、听者、NPC、共享物件、环境力、材质响应、摄影机、声音和尾帧形成一条可追溯因果链；背景动作有任务、有延迟、有不同优先级。

补充合格线：明确谁看见、听见、知道、误判或装作不知道；角色只能在获得可见、可听、可触或从他人反应推断出的信息后行动。

## C12. 多片机制未经统一就直接拼接

失败表现：

```text
用《红辣椒》负责空间换景，用《人类之子》负责长镜头，用《盗梦空间》负责重力变化，再把三套运镜组合成一个镜头。
```

纠偏模板：

```text
1. 先读取本次总时长；4-30秒默认保留一段，超过30秒再按动作完成、转场落点、信息翻转和尾帧自适应拆成4-30秒自然段；相邻段回调，消除1-3秒机械尾段。
2. 针对当前场景返回0-6个有用电影机制，每项说明构图、运镜、调度、信息释放、声音、转场、可替换变量和失败边界。
3. 用户逐步筛选，可只选一个，也可指定多个机制组合。
4. 组合前必须确定一个主导演语法，并处理摄影机哲学、轴线、焦段、节奏、声音与转场冲突。
5. 根据当前短片时长重新设计完整镜头顺序和相对节奏，不照搬电影秒数。
6. 正式分镜成为唯一执行来源；梦导SD只继承该分镜和连续性总线。
```

合格线：电影参考可以多源，但最终导演方案必须单一、连贯、可执行；每个4-30秒段只以批准后的正式分镜为执行来源，并继承上一段尾帧与连续性总线。

## C13. 流程说明被误判成一次性跨阶段输出

纠偏：把用户描述的完整流程写入MD并长期遵循。当前轮只输出当前阶段；选源后停住，收到 `进入分镜细则` 再给正式分镜，收到 `进入SD输出` 再编译梦导SD。

合格线：每轮只有一个用户可见阶段，阶段推进拥有明确用户指令。

---

## C14. 用剧情概述冒充分镜相似

纠偏：对标必须落到连续镜头短语，写清源画面的起始动作、摄影机路径、人物调度、空间/剪辑变化、结束动作、覆盖目标节拍和未覆盖节拍。若只覆盖“坍缩后惊醒”，就只绑定该段，不能声称覆盖后续“发现仍在梦中”。

合格线：删除片名和剧情简介后，剩余文字仍能让人画出源片镜头并逐拍映射目标段。

## 14. 输出前强制纠偏句

正式输出前内部问：

```text
这段有没有用户过去投诉过的失败症状？
如果有，是 C01-C14 哪一种？
我是否已经按对应纠偏模板修过？
```
