# Core Workflow v6

本文件只定义导演层运行顺序。完整六步所有权、场景可拍闸门、动画深化和纯文本SD承接见 `animation-production-pipeline.md`。

## 1. 恢复当前状态

先判断当前任务停在哪一层：

```text
项目/剧本未就绪
分镜方案比较中
方案已批准，等待分镜细则
正式分镜已批准，等待SD
已有生成结果，等待修复
```

继续最近确认的层，不重复已经批准的工作。用户讲解完整流程不等于要求一次交付所有层。

## 2. 输入锁

只恢复当前段需要的事实：

```text
媒介 / 画幅 / 平台 / 目标时长
场景功能 / 类型 / 角色目标 / 阻力 / 策略
信息权限 / 世界规则 / 禁止提前事实
人物位置 / 轴线 / 屏幕方向 / 物件归属
参考绑定 / 批准台词 / 上一段尾态
用户当前要的阶段
```

缺少的事实分三类处理：

- 可从当前材料安全推断：说明最小假设并继续。
- 会改变故事、台词或人物：返回对应上游，不擅自补写。
- 只影响一个镜头执行：给出明确导演判断并继续。

## 3. 场景可拍闸门

方案前验证：

```text
入口状态 -> 触发 -> 角色策略 -> 对抗/反馈
-> 误判或确认 -> 策略改变 -> 可见后果 -> 退出变化
```

同时检查：

- 角色只能对有来源的信息反应。
- 每个关键动作改变信息、风险、身体、物件、空间或关系之一。
- 每句关键台词有目的、潜台词、听者变化和足够时间。
- 情景喜剧的包袱来自人物性格、任务冲突、误判或规则碰撞，不来自临时降智。
- 本段删除后必须造成叙事或关系损失。

不通过时返回上游；不要用漂亮镜头掩盖。

## 4. 当前段时间骨架

保持用户请求的`4-30秒`总长。先按类型脊柱安排段内变化，再决定镜头：

```text
0-?s 入口任务与第一可读问题
?-?s 触发和第一次策略
12-18s附近 有因果的中段刷新（长段）
?-?s 转折/兑现/后果
尾端 反应、恢复、残留或下一段债务
```

内部动作拍通常`2-4秒`，不机械均分。固定镜头每`1-4秒`仍需通过动作、视线、焦点、声音、物件或空间刷新信息。

## 5. 方案池

方案只解决导演机制，不提前写镜头表。每案必须在以下至少两项上真正不同：

- 画面所有者和信息释放。
- 空间调度和角色路线。
- 摄影机语法和剪辑策略。
- 动画表达引擎或现实法则。
- 声音、物件或环境的因果角色。
- 结尾兑现方式。

每案写：主戏剧事务、体验曲线、时间骨架、调度/摄影机、动画或视觉机制、声物环境、尾态和风险。零到六案，不凑数。

对标只提取可迁移机制。一个方案可以综合多部作品的不同机制，但最终必须像一个导演决策，不像剪贴册。对标时长、镜号和人物不进入当前设计。

## 6. 正式分镜

用户批准方案后执行：

1. 锁段级事实和准确总时长。
2. 先排人物、物件、入口、画外区、轴线和屏幕方向。
3. 给每镜写唯一戏剧变化；没有变化的镜头合并或删除。
4. 决定画面所有者、景别、构图、焦点、摄影机起点/路径/落点。
5. 分配主体、听者、NPC、物件和环境的并行动作。
6. 把台词拆成准备、口型、重音、停顿、尾音和听者反应。
7. 动画项目交给动画技能深化动作和画面法则，再合并回同一份分镜。
8. 写转场和精确尾帧，证明下一镜第一动作。
9. 检查AIGC可执行性；过载先拆内部动作拍，不先砍表演。

镜头变化触发优先级：信息变化 > 行动越界 > 空间关系 > 听者反应 > 节奏停顿 > 装饰。谁开口不构成切镜理由。

## 7. 连续性总线

每镜只记录发生变化或容易丢失的总线：

```text
身份与服装/身体残留
站位、轴线、屏幕方向和摄影机落点
姿势、支点、视线和未完成动作
物件所有权、位置、朝向和状态
光源方向、色彩归属和声源尾音
画层/特效状态、材质痕迹和环境运动
角色与观众的信息权限
当前观众问题与下一段债务
```

稳定事实只在段级锁写一次；镜内只写差量。尾帧是下一镜输入，不是气氛总结。

## 8. SD边界

正式分镜未批准前不输出SD。进入SD时调用 `dream-suspense-sd`：

- 当前批准分镜是唯一来源。
- 4-30秒一条纯文本 `BASE LOCK + A`。
- JSON只用于内部验证，不得作为用户交付。
- 下游发现源事实矛盾时返回导演层，不在提示词中偷偷修戏。

## 9. 结果修复

按顺序定位首个失败层：

```text
故事/台词 -> 导演分镜 -> 动画动作/画面法则
-> SD来源覆盖/时序 -> 模型执行 -> 后期
```

每次修复只列：失败证据、所属层、最小改动、受影响下游和保留锁。不得借机整体重写。

## 10. 停止条件

当前阶段已经回答用户问题且通过对应门时停止。不要为显得完整而附下一阶段、全套研究、内部评分或重复模板。
