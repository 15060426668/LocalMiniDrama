# Suspense Subgenre Drill Library

用途：按悬疑电影子类型组织专项训练，作为 `suspense-specialty-router.md` 的素材支撑。  
目标：遇到一个场景时，不先问“像哪个导演”，而先问“它属于哪类悬疑任务”，再选对标机制和镜头执行。

## 0. 使用方式

每个子类型只提供创作时最有用的镜头训练，不做百科式片单。

正式分镜前先选：

## 1. 密闭规则悬疑

代表对标：Identity, Saw, Cube, The Others, Shutter Island, Exam  
核心任务：角色被困在规则空间里，必须通过物件、门、灯、声音理解规则。

训练机制：

1. 空间先封闭：门锁、窗、雨夜、机构墙、摄像头、灯源共同证明出口不存在。
2. 规则先通过物理证据出现：卡片、编号、倒计时、灯闪、门开关、事件痕迹位置。
3. 主角误判一次，再被物件纠正一次。
4. 环境不是背景，是规则执行机器。
5. 第一轮不要解释完规则，留一个反常细节做钩子。

镜头模板：

- 0-2秒：醒来/进入，低机位扫到门、床、墙角、唯一光源。
- 2-5秒：手触碰规则物，特写材质和字迹。
- 5-8秒：尝试违反规则，门/灯/声音立刻反馈。
- 8-12秒：主角反应，空间显示另一个隐藏出口或更深限制。

反例边界：不能让旁白替代规则证据；不能把密室拍成空房间。

## 2. 调查推理 / 证据平面

代表对标：Zodiac, Se7en, Memories of Murder, Prisoners, Cure, The Silence of the Lambs  
核心任务：证据如何排列，角色如何从证据中看到不可承受的图案。

训练机制：

1. 桌面、墙板、档案、照片、地图是画面主角。
2. 人脸反应不要抢在证据之前，先让观众看见证据。
3. 证据平面要有手指、笔迹、胶带、纸张、血迹、折痕。
4. 调查空间用冷静光线，让恐惧来自逻辑而不是阴影。
5. 关键线索最好在画面边缘出现，观众二刷能回收。

镜头模板：

- 证据板全景 -> 手指停在一个错误细节 -> 角色眼睛重新对焦 -> 背景声音消失 -> 切到证据特写。

反例边界：不能只说“发现线索”，必须拍出线索为什么不对。

## 3. 餐桌 / 聚会 / 礼貌压迫

代表对标：The Invitation, Get Out, Coherence, Parasite, The Celebration, Ready or Not  
核心任务：正常社交空间如何变成陷阱。

训练机制：

1. 餐桌构图先建立秩序：谁坐主位，谁靠出口，谁被夹在中间。
2. 礼貌话术不重要，重要的是杯子、刀叉、手、眼神和停顿。
3. 门外黑暗或走廊可作为另一个真相空间。
4. 观众要比主角早发现一两个站位异常。
5. 声音从热闹逐渐变窄，最后只剩杯子/餐具/呼吸。

镜头模板：

- 宽景建立座位 -> 餐具特写 -> 主角眼神扫出口 -> 微笑者挡住出口 -> 声音突然变干。

反例边界：不能让聚会戏只靠角色吵架；站位和物件必须讲压迫。

## 4. 家庭心理悬疑

代表对标：Hereditary, The Babadook, The Others, The Witch, The Shining, Relic  
核心任务：亲密空间如何变成精神陷阱。

训练机制：

1. 家不是温暖背景，而是记忆、愧疚和规则的容器。
2. 卧室、餐桌、门口、楼梯、阁楼要有明确心理功能。
3. 家庭成员的身体距离比台词更重要。
4. 儿童房/母亲房/旧照片/衣柜适合承载恐惧。
5. 情绪崩溃必须有身体细节：眼泪、吞咽、手指、肩膀、衣料。

镜头模板：

- 家庭空间远景像模型 -> 人物孤立在房间中心 -> 背景门缝/柜门轻动 -> 近景捕捉脸部崩裂。

反例边界：不能把家庭恐怖拍成普通闹鬼，必须保留亲密关系的压迫。

## 5. 异常收容 / 不可见威胁

代表对标：Alien, The Thing, Annihilation, Nope, The Host, A Quiet Place  
核心任务：异常如何被环境、设备、声音和人物生理反应证明。

训练机制：

1. 不急着展示威胁本体，先拍环境反应：风、灯、设备、液体、门、玻璃、人物呼吸。
2. 异常空间要有材质：管道、金属、水汽、山谷、森林、实验室。
3. 检测物中心可以制造群像悬念。
4. 声音常常先于画面确认威胁。
5. 威胁露出越少，空间证据越要真实。

镜头模板：

- 空间负区域 -> 设备异常 -> 人物听见画外声 -> 材质发生变化 -> 只露局部影子或环境反应。

反例边界：不能用威胁全貌替代悬念；不能让异常没有物理影响。

## 6. 仪式 / 群体压迫

代表对标：Midsommar, The Wicker Man, The Wailing, The Witch, Suspiria, The Empty Man  
核心任务：群体秩序如何吞掉个人。

训练机制：

1. 群体队形是构图核心，主角在图案里失去个体性。
2. 同步动作、同步呼吸、同步凝视比单个威胁更压迫。
3. 白昼也可以恐怖，靠过度秩序和漂亮色彩制造反差。
4. 仪式声音要有层级：鼓、歌、脚步、布料、呼吸。
5. 主角的每次反抗都被温柔地纠正回队形。

镜头模板：

- 高亮宽景建立队形 -> 俯拍图案 -> 主角脸部不适 -> 群体同时看向她 -> 声音同步加强。

反例边界：不能只写“邪教氛围”，要写队形、动作和声音。

## 7. 背景慢速威胁

代表对标：It Follows, Halloween, The Strangers, Cure, Pulse, The Ring  
核心任务：普通背景人物如何成为观众先发现的威胁。

训练机制：

1. 威胁不要快，越慢越让观众无助。
2. 背景深处要有清楚距离和路线。
3. 角色通常没有立刻发现，观众先替她着急。
4. 威胁像普通人或普通关系，不能一眼标签化。
5. 声音保持日常，发现后再进入主观层。

镜头模板：

- 主体前景做日常动作 -> 背景人影直线靠近 -> 主体继续没发现 -> 观众看见距离缩短 -> 主体突然回头。

反例边界：不能让背景威胁乱飘；速度、方向、遮挡必须清楚。

## 8. 社会伪装 / 正常关系恐惧

代表对标：Get Out, The Invitation, Rosemary's Baby, Speak No Evil, The Stepford Wives, Burning  
核心任务：礼貌、家庭、朋友、恋人如何变成控制系统。

训练机制：

1. 威胁不靠大喊，靠过分友善、过分礼貌、过分平静。
2. 触发物常常很小：茶杯、手机、照片、门锁、餐具、酒杯。
3. 主角的身体反应比对方台词更关键。
4. 出口被站位占住，礼貌变成牢笼。
5. 声音从社交噪声变成一个小物件节奏。

镜头模板：

- 温暖社交中景 -> 小物件特写 -> 主角身体僵住 -> 微笑者挡住出口 -> 主观声音下沉。

反例边界：不能把社会恐惧拍成外露恶人，要保留“正常”的伪装。

## 9. 科技 / 监控 / 系统悬疑

代表对标：Black Mirror, Ex Machina, 2001, Minority Report, Panic Room, The Conversation  
核心任务：系统如何看见、记录、控制人。

训练机制：

1. 屏幕、摄像头、传感器、投影不是装饰，是权力眼睛。
2. 人物被网格、框线、监控画面切碎。
3. 冷光和低饱和色彩制造系统无情。
4. UI信息必须少而准，不要满屏科技噪音。
5. 声音使用电流、服务器、通知音、监控静音。

镜头模板：

- 监控视角俯看人物 -> 屏幕特写显示异常参数 -> 人物抬头看不到监控 -> 系统声音先一步锁定。

反例边界：不能让科技悬疑变成蓝色UI海报；系统必须改变角色处境。

## 10. 结尾反转 / 最后一镜覆写

代表对标：The Sixth Sense, Identity, Triangle, The Others, The Vanishing, Saw  
核心任务：最后一个画面让观众重新理解前面所有画面。

训练机制：

1. 最后一镜必须回收旧证据，而不是新增设定。
2. 反转载体最好是物件、空间、接触关系、声音缺席、重复动作。
3. 结尾不一定解释完，但必须让观众感到“前面都变了”。
4. 镜头停留要短而准，留下余韵。
5. 声音可用旧声音回放、静音或一个小物件声完成覆写。

镜头模板：

- 回到旧空间 -> 旧物件出现新位置/新状态 -> 主角或观众意识到前面误读 -> 声音抽空 -> 黑场。

反例边界：不能用嘴解释反转；不能最后凭空出现关键证据。

## 11. 可复用规则

- 子类型先行，避免所有悬疑场景都写成同一种黑暗走廊。
- 每个子类型都有自己的物理证据：密闭靠门和规则，调查靠证据平面，餐桌靠站位，家庭靠亲密空间，异常靠环境反应，仪式靠队形，社会伪装靠礼貌和触发物。
- 短剧压缩不是删逻辑，而是在 8-15 秒内完成“证据出现 -> 角色反应 -> 认知变化”。
- 光影、质感、声音都必须服务子类型，而不是全片一套冷色调。
- 反转和循环必须提前埋证据，不能靠结尾补课。

## 12. 反例边界

- 不能跑偏到泛电影类型；本库只服务悬疑、惊悚、心理恐怖、科幻悬疑。
- 不能把每个子类型都写成突发巨响或贴脸惊吓。
- 不能只列代表片，不提可借机制。
- 不能在SD转译时丢掉子类型证据。
