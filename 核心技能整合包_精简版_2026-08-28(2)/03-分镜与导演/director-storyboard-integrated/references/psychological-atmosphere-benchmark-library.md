# Psychological Atmosphere Benchmark Library

用途：训练“心理恐怖压抑环境氛围”的分镜能力。  
目标：不走血腥、贴脸、怪物惊吓，而是让雨夜、旅馆、房间、机构、走廊、证据物、记忆碎片和声音环境持续压迫人物心理。

原则：只借氛围机制、空间调度、构图、光影、声音、物件证据和结构转译；不照搬剧情、角色、台词、凶案细节或标志性造型。

---

## 1. 什么时候启用

用户或场景出现以下意图时启用：

- 心理恐怖、压抑环境、氛围悬疑、不是惊悚但要不舒服。
- 雨夜、旅馆、破旧房间、病房、机构、车内、走廊、家庭旧屋。
- 失忆、身份错位、人格碎片、记忆断层、不可靠认知。
- 致命ID、记忆碎片、禁闭岛、机械师、小岛惊魂、X圣治、彗星来的那一夜、恐怖游轮等结构/心理氛围对标。
- 用户反馈画面“有事但不压抑”“只有恐怖元素没有心理压力”“环境像背景板”。

核心判断：

```text
环境是否正在替人物的心理说话？
空间是否不断剥夺安全感？
物件是否证明认知正在错位？
声音是否让观众觉得空间有记忆？
```

## 2. 氛围压迫五件套

| 层 | 必须设计 | 合格画面 | 失败表现 |
|---|---|---|---|
| 空间 | 出口、深处、遮挡、重复结构、错误方向 | 旅馆房门一排延伸，雨幕切断外界，门牌和车灯变成身份格子 | 房间只是“阴森背景” |
| 光影 | 实用光源、局部亮区、黑位、反光、光线禁忌 | 霓虹招牌被雨水打碎，房间灯只照出床角和钥匙牌 | 只写昏暗冷色 |
| 物件 | 身份物、记忆物、规则物、重复物、错误物 | 房号钥匙、拍立得、便签、车牌、照片、药瓶、钟表改变意义 | 物件只作装饰 |
| 身体 | 眼神迟疑、手部停顿、呼吸、步伐、微反应 | 主角看着照片，手指停在不该出现的人脸上，呼吸停半拍 | 只写害怕/崩溃 |
| 声音 | 环境底噪、近景拟音、画外声、主观声、声桥 | 雨声盖住人声，荧光灯嗡鸣变成耳鸣，纸张摩擦突然变清 | 只有紧张音乐 |

## 3. 重点拆解：Identity / 致命ID

场景类型：雨夜旅馆 / 密闭群像 / 身份拼图 / 外层审判空间。  
可借核心：**环境不是案发背景，旅馆是人格碎片的棋盘。**

### 3.1 十个可借机制

| # | 机制 | 分镜转译 |
|---:|---|---|
| 1 | 雨夜切断外界 | 用雨幕、车灯、水面、断路、电话失效证明空间封闭，不靠台词说“出不去”。 |
| 2 | 旅馆房间像身份格子 | 房号、钥匙牌、门缝光、窗帘影子反复出现，人物被分配到空间格子里。 |
| 3 | 群像互疑靠站位 | 人物不是围成一团吵，必须有人靠门、有人守电话、有人坐在床边、有人占前台。 |
| 4 | 身份物件先行 | 身份证、钥匙、行李、车牌、鞋印、雨衣等先被镜头记录，再改义。 |
| 5 | 外层空间冷静切入 | 旅馆的雨夜黑色电影质感，与审讯/医疗空间的冷平光形成心理层级。 |
| 6 | 事件顺序像倒计时 | 每次空间变化都要有可见残留：空房、湿脚印、熄灯、钥匙位置变化。 |
| 7 | 雨声压过理智 | 群像争吵时雨声不退，越吵越像被同一个环境噪声吞没。 |
| 8 | 小人物/小物件隐藏最大信息 | 构图边缘、门缝后、桌角物件需要保留二刷可见证据。 |
| 9 | 旅馆与心理空间互为镜像 | 房间排列、人物编号、钥匙顺序可以暗示内在结构。 |
| 10 | 最后回收旧物件 | 反转应回收前面已经出现过的钥匙、号码、声音、站位或手势。 |

### 3.2 可迁移镜头模板：雨夜旅馆心理棋盘

```text
第一步：雨幕切断外界，车灯/霓虹/水面给出封闭空间。
第二步：前台或走廊建立房号、钥匙、门的排列，让空间像棋盘。
第三步：人物带着各自身份物件进入不同格子。
第四步：第一处异常不拍结果，拍空房、错位钥匙、湿脚印、电话杂音。
第五步：群像在同一空间汇合，站位和视线开始互相怀疑。
第六步：外层空间或冷静证据镜头切入，提示观众“这不只是旅馆事件”。
```

### 3.3 15秒短剧压缩示例

```text
0-3s：雨夜旅馆门牌在水里倒着闪，车灯扫过一排房门。
3-6s：前台钥匙牌被手指划过，缺了一个号码，雨声压住人声。
6-10s：一个房间门半开，床边有湿脚印，窗帘被风吸向门缝。
10-15s：群像回到走廊，所有人看向同一把钥匙，远处电话自动响起。
```

SD承接锚点：雨幕、倒影门牌、缺号钥匙、湿脚印、自动响起的电话、冷色外层空间切入。

## 4. 重点拆解：Memento / 记忆碎片

场景类型：失忆叙事 / 证据物心理 / 倒叙拼图 / 身体记忆。  
可借核心：**结构不是炫技，结构让观众和角色一起失去过去。**

### 4.1 十个可借机制

| # | 机制 | 分镜转译 |
|---:|---|---|
| 1 | 信息顺序制造共情 | 镜头不要一次解释前因；每个片段只给一个当前目标和一个错误证据。 |
| 2 | 证据物替代记忆 | 拍立得、便签、纹身、地图、钥匙、手机记录要比台词更可信。 |
| 3 | 物件可能撒谎 | 证据不是答案，证据也可能被过去的自己污染；镜头要拍出手写、涂改、折痕。 |
| 4 | 颜色区分认知层 | 彩色可代表当前混乱，黑白可代表程序化自述；短剧可用冷暖/锐软区分。 |
| 5 | 倒叙段落要有钩子 | 每段开头先让观众困惑“为什么会在这里”，结尾解释上一段的起因。 |
| 6 | 手部动作是记忆动作 | 拍照、翻照片、摸口袋、看手写字、贴便签要成为角色的职业动作。 |
| 7 | 近景比大场面重要 | 记忆断层靠眼神重新对焦、指尖停顿、呼吸断裂表现。 |
| 8 | 转场用物件接物件 | 照片白边、便签纸纹、皮肤文字、车窗反光可做匹配转场。 |
| 9 | 真相是自我选择 | 最后不是“知道真相”，而是人物选择相信哪个证据。 |
| 10 | 片段必须能独立成立 | 每个15秒片段都要有：看到证据、误判、动作、反证。 |

### 4.2 可迁移镜头模板：记忆断层证据链

```text
第一步：角色醒来/停下，手先找物件，脸后反应。
第二步：证据物特写，纸纤维/照片白边/手写痕迹清楚。
第三步：角色按证据行动，空间只给当前方向。
第四步：背景或物件边缘出现一个矛盾细节。
第五步：角色眼神重新对焦，手停在证据上。
第六步：转场回到更早一段，让观众发现刚才的证据被污染。
```

### 4.3 15秒短剧压缩示例

```text
0-3s：手从湿外套口袋里摸出一张照片，照片背面只有半句手写字。
3-6s：角色按照片找门，门牌号和照片角落编号一致。
6-10s：他准备开门，照片边缘湿掉后露出被覆盖的另一个字。
10-15s：眼神停住，手指擦掉水痕，照片里的门其实不是这扇门；切到更早的走廊。
```

SD承接锚点：照片白边、半句手写字、湿痕露字、门牌编号、手指擦水、眼神重新对焦。

## 5. 同类氛围片机制库

| 对标 | 可借机制 | 环境如何施压 | 分镜转译 |
|---|---|---|---|
| Shutter Island / 禁闭岛 | 机构与岛屿层级真相 | 海风、雨、病院、灯塔共同封住主角认知 | 外部环境越大，人物越小；越接近核心房间，构图越清晰残酷 |
| The Machinist / 机械师 | 身体和工业空间共同泄密 | 工厂噪声、荧光灯、金属油污、消瘦身体持续压迫 | 机器节奏变成心理倒计时；便签和身体状态承担记忆缺口 |
| Cure / X圣治 | 日常空间静态感染 | 房间留白、重复提问、水/火/光的小动作控制人 | 长固定镜头里让观众等人物出错；声音干、慢、重复 |
| The Others / 小岛惊魂 | 光线禁忌与房屋规则 | 窗帘、门锁、蜡烛、暗室让房子像规则机器 | 光进入不是照明，是危险；门和窗要成为规则开关 |
| Coherence / 彗星来的那一夜 | 家庭餐桌现实分叉 | 停电、手持、门外黑暗和桌面小物件让日常裂开 | 一张桌子、一扇门、一个重复物件就能制造版本怀疑 |
| Triangle / 恐怖游轮 | 重复空间证据累积 | 同一空间每次出现多一层痕迹，越干净越不安 | 走廊、甲板、门把、纸条、痕迹逐次污染 |
| The Sixth Sense / 灵异第六感 | 缺席关系反转 | 温柔家居空间里没人真正回应/接触主角 | 通过视线、接触、椅子位置、门缝证明“缺席” |
| Enemy / 宿敌 | 城市雾感与双身心理 | 黄灰城市、重复公寓、镜像站位压住身份 | 同一构图换人物/物件细节，制造心理押韵 |
| Session 9 | 废弃机构记忆污染 | 旧病院墙皮、录音、空走廊、灰尘光束像旧创伤 | 声音档案和空间灰尘一起讲过去 |
| Jacob's Ladder | 医院/城市幻觉闪断 | 日常空间突然被医疗/战场质感污染 | 运动模糊、主观声变闷、灯光频闪做短促记忆侵入 |

## 6. 压抑环境分镜模板

### 模板A：雨夜密闭空间

```text
0. 外界先被天气切断：雨幕、车灯、电话杂音、断路。
1. 空间给主人物分格：房号、门牌、床位、钥匙、座位。
2. 物件先失序：缺号钥匙、错位照片、湿脚印、未接电话。
3. 人物身体反应滞后：先看物，再看人，再看出口。
4. 声音持续压迫：雨声/电流声/远处电话不断，角色说话被吞。
5. 尾帧留一个错误物件，让下一段改写上一段。
```

### 模板B：失忆证据链

```text
0. 角色只知道当前动作，不知道前因。
1. 手先找证据，镜头先拍手和物件。
2. 证据物给出一个行动方向。
3. 空间边缘出现矛盾细节。
4. 角色微反应：眨眼停、手指停、呼吸断、眼神重新对焦。
5. 用照片/纸纹/皮肤文字/门牌做匹配转场，进入更早或更深一层。
```

### 模板C：日常房间心理污染

```text
0. 先建立普通房间，不急着阴森。
1. 一个日常声音变得不合时宜：冰箱、灯、钟、电话、楼上脚步。
2. 一个物件位置不对：杯子、照片、钥匙、椅子、鞋。
3. 人物试图恢复秩序，却让第二个错误暴露。
4. 光线或色温开始轻微错位。
5. 空间仍是原空间，但观众已经不信它。
```

## 7. 声音专项：压抑环境声

| 声音 | 用法 | 转译 |
|---|---|---|
| 雨声 | 切断外界，吞掉台词 | 雨点打玻璃，车灯下水声扩大，人物声音被雨幕压低 |
| 荧光灯嗡鸣 | 机构/旅馆/病房压迫 | 灯管嗡鸣逐渐像耳鸣，角色停下时嗡鸣变清 |
| 电话铃 | 空间主动发声 | 没人碰的电话响，铃声在空走廊里回荡 |
| 纸张摩擦 | 证据物在说话 | 照片/便签/档案翻动声变成剪点 |
| 低频房间声 | 环境像活的 | 空调、管道、远处机器形成不可定位的身体压力 |
| 静音缺口 | 认知断层 | 发现矛盾证据时，雨声/房间声突然抽掉半拍 |
| 重复小声 | 结构钩子 | 同一滴水、同一钟声、同一门响每次出现意义不同 |

声音门槛：每个压抑环境镜头至少写出一个真实声源、一个近景拟音、一个变化点；不能只写“压抑配乐”。

## 8. 可复用规则

- 心理恐怖的核心不是“出现了可怕东西”，而是环境持续证明人物对现实的判断不可靠。
- 雨夜、旅馆、房间、机构和走廊都必须是压力机器，不是气氛背景。
- 失忆/身份错位要靠证据物、手部动作、构图缺席和声音断层表达。
- 反转证据必须提前在画面中出现，只是第一次看不懂。
- 压抑氛围要有正常基线，先让空间可信，再让一个变量错位。
- 短剧压缩时，每15秒至少完成一次“环境证据改写认知”。
- SD转译时，氛围必须落到可见物和可听声：雨水、门牌、钥匙、照片、纸纹、灯嗡鸣、湿脚印、窗帘、电话。

## 9. 反例边界

- 不能把心理压抑写成“阴森恐怖氛围”四个字。
- 不能用大音量惊吓替代环境压力。
- 不能让雨夜/旅馆/病房只作为漂亮背景，必须改变角色判断。
- 不能只靠台词说失忆、人格、幻觉，要拍出证据物和动作断层。
- 不能一次混用太多结构：人格、循环、失忆、鬼屋、平行宇宙只选一个主机制。
- 不能让每个镜头都黑，压抑来自信息被限制，不是单纯看不清。

## 10. 写入模块

模块名：心理恐怖压抑环境 / 结构氛围对标。  
位置：场景机制层，位于结构悬疑库与场景质感路由之间。  
触发词：心理恐怖、压抑环境、氛围悬疑、致命ID、记忆碎片、失忆、身份错位、雨夜旅馆、机构空间、环境压迫、不可靠认知、不是惊悚但要压抑。

## 11. 专项强化：心理恐怖场景拆分第二批

用途：补足家庭空间、独居房间、礼貌社交、老屋记忆、身体焦虑、缺席悬念等短剧高频场景。  
原则：只借压力机制，不借标志性角色、台词、造型和结局；所有素材必须能转成构图、机位、光影、声音、物件和SD锚点。

| 对标片段 | 场景类型 | 可借机制 | 环境如何施压 | 镜头/构图转译 | 声音转译 | SD承接锚点 | 不能照搬 |
|---|---|---|---|---|---|---|---|
| The Babadook | 家庭空间污染 / 母子失控 | 家不是避难所，而是情绪回音室 | 儿童房、客厅、楼梯都被玩具、书页、夜灯和门缝分割，母亲越想恢复秩序，空间越显得逼窄 | 多用门框套门框、床边低机位、母亲半身被家具切割；先拍她收拾物件，再拍物件位置反常 | 夜里钟声、床板响、孩子呼吸、书页摩擦声比配乐更靠前 | 儿童房夜灯、翻开的书页、凌乱玩具、门缝黑线、母亲手指停顿 | 不照搬书中形象和家庭关系设定 |

## 13. 本批新增规则

- 心理恐怖不一定要黑；明亮、公整、礼貌、干净的空间同样可以压迫，只要它限制人物选择。
- 家庭戏的恐惧来自“我最熟的地方不再听我的”，不是多摆恐怖道具。
- 社交压迫要先让所有人看似正常，真正的危险藏在站位、出口、手机和杯子里。
- 缺席悬念比出现悬念更适合短剧审查：拍空位、未接电话、少掉的物件，让观众自己补问题。
- 老屋和病房要拍材质记忆：墙皮、门轴、床单、管道声、相框灰尘都要承担过去。
- 身体焦虑要通过呼吸、吞咽、手指、肩颈僵硬表达，不能只写“她害怕”。
- SD转译时，心理压迫必须落成稳定视觉物：门缝、空椅、窗帘、风口、杯子、照片、墙皮、手电光、未接电话。

```text
2. 第二遍突出一个不同的词或噪声，意义开始变化。
3. 镜头从设备特写拉到人物孤立的空间，证明他被声音困住。
4. 空间里出现一个与声音对应的可见物件。
5. 尾帧停在设备继续运转，角色已经不确定自己听见了什么。
```

### 模板E：影像证据不可信

```text
0. 画面先像普通空镜，随后揭示这是监控/录像/照片。
1. 人物反拍屏幕，观众同时看见屏幕和人物反应。
2. 对画面边缘进行局部放大，出现一个不确定细节。
3. 现实空间里出现同一物件或位置，观众开始比对。
4. 录像继续正常播放，人物的呼吸/手部先失控。
5. 尾帧留在暂停画面或黑屏反光，让下一段承接。
```

### 模板F：认知布景漂移

```text
0. 第一次建立房间平面：门、窗、沙发、桌子、照片位置清楚。
1. 角色离开或转身，声音保持连续。
2. 回到相似机位，家具/照片/门位只变一个点。
3. 角色先按原动线行动，动作失败或停顿。
4. 镜头不解释，停在错误物件上。
5. 用同一声源接下一镜，证明不是普通换景，而是认知错位。
```

## 16. 第三批新增规则

- 监听戏必须让声音改变意义：同一句话至少两次出现，每次听见的信息不同。
- 监控/录像戏不能只拍屏幕，必须拍“屏幕内容 + 观看者身体反应 + 现实空间对应物”。
- 儿童视角不等于可爱或无辜，要用低机位、边缘空白、成人看不见的方向制造信息差。
- 认知布景漂移要少改，只改一个家具、照片或门位，比大变形更像真实心理恐怖。
- 创伤闪回不要做花哨转场，最好用同一个动作、同一个声音，把现实无缝错接到过去。
- 自然白昼压迫要靠比例和沉默，不靠夜色；人越小，自然越像不可解释的规则。
- 偏执悬疑的SD锚点优先写设备、屏幕、反光、边缘细节、重复声源、人物手部停顿。

## 17. 专项强化：日常流程校验崩坏

来源：用户投喂“N组：日常空间恐怖”文字表。首批N01-N02实际包含深夜写字楼电梯与小区地下停车场2组、20行；补强批N03-N06实际包含独居回家、便利店夜班、公司加班与出租屋邻墙4组、40行。精确秒数、焦段、亮度百分比、Hz、dB、命名人物动作和连续剧情按C级训练性设计处理；去除这些伪精确后仍成立的流程、系统、物件和权限机制按B级匿名机制沉淀。

核心判断：日常空间让人安心，不是因为它明亮，而是因为角色能预测下一步。电梯、门禁、车锁、车位、道闸、工牌、楼层牌和家门一旦给出互相冲突的反馈，熟悉感就会变成恐怖证据。

### 17.1 可复用规则

1. 先建立完整的日常流程校验和：角色从哪里来、按什么键、期待哪个数字、物件平时归谁、出口如何打开。观众至少看清三个正常步骤，第一处异常才有判断依据。
2. 第一处错误只破坏一个变量。按钮仍亮但方向相反、钥匙能转但门内已有占用、车锁声正常但第二个物件同步响应，比所有系统同时失控更可信。
3. 让角色进行一次聪明的交叉复核：看墙面标识、核对楼层、摸工牌、按车钥匙、看车牌、问同事或保安。复核动作本身就是镜头调度，不用台词解释“这里不对”。
4. 第二套独立系统确认同一个错误时，异常才升级为现实规则。例如空间坐标错误后，所有权物件也给出同样答案；机械显示、声音反馈和实体残留至少命中两项。
5. 日常设备是客观见证者：楼层数字、按键灯、锁车蜂鸣、双闪、门禁提示、道闸、手机时间和声控灯都要有输入、反馈、延迟和尾态，不能只当布景。
6. 异常递进按权限层级推进：公共设施失去方向控制 -> 半私人财产出现所有权冲突 -> 家庭门锁或熟人否认角色身份。每次推进只改变一个权限问题。
7. 反光人影、双身或画外脚步只能是证据载体之一。核心恐惧应在摘掉超自然解释后仍成立：熟悉系统连续证明“你的位置、物件或身份不再属于你”。
8. 每次误以为恢复正常，都必须留下一个可继承残留：错误数字、重复蜂鸣、湿轮胎印、缺失工牌、门内日常声或未复位的按键灯。下一场从残留继续，而不是重新起惊吓。

### 17.2 反例边界

- 不把楼层数字、车位号、时间点当成固定恐怖公式；数字只在角色和观众已经知道正常基线时有意义。
- 不连续重复“门开了但没人”“回头又消失”。同类异常第二次出现时必须改变证据权限、人物选择或退出路线。
- 不让所有按钮、灯、门、手机和车辆同时随机故障。至少保留一套稳定系统作为复核见证，否则画面只像设备坏了。
- 不默认“只有主角能看见”。NPC是否看见、听见、误判或装作正常必须逐拍锁定，并产生可见反应差。
- 不让角色明知熟悉空间异常却放弃核对。日常恐怖依赖角色对空间有经验，角色越会检查，错误证据越有力。
- 不把20-35秒电影式单拍直接移植到短剧。4-30秒段内部的前15秒微循环优先完成一次“正常步骤 -> 单点错误 -> 交叉复核 -> 错误被确认”，后半段继续改义或兑现后果。
- 不保留生成式训练表中的Hz、dB、亮度百分比和未观察微动作作为影片或现实精确事实。

### 17.3 可迁移镜头模板：熟悉流程的双重校验失败

```text
0-3秒：用一个连续动作建立熟悉流程，至少露出位置标识、操作物和预期出口；环境声正常重复。
3-6秒：角色完成输入，设备给出一个轻微但明确的错误反馈；摄影机保持空间关系，让观众自行比对。
6-10秒：角色用第二套独立证据复核，手部完成核对动作，眼神在两个证据间移动；第二系统确认错误。
10-15秒：异常从坐标升级到所有权或权限，出现实体残留；尾帧停在失效出口、错误物件或被占用的私人边界。
```

镜头执行：起幅采用能看清流程的中广景或固定空间图；异常出现后才进入设备/物件近景；角色反应顺序为手停 -> 眼神复核 -> 身体转向出口。运镜由操作物或验证路线触发，不因恐怖形容词随机移动。

声音执行：保留一个稳定日常声纹作为基线，例如电机、蜂鸣、广播、空调、车库混响或门锁声；错误反馈改变声源方向、次数或对应物；发现残留后让基线声继续正常运转，形成声画矛盾。

SD承接锚点：固定空间标识、操作手、输入反馈灯、第二见证系统、角色眼神复核路线、所有权物件、实体残留、出口状态、稳定日常声纹、尾帧权限边界。

### 17.4 应写入哪个模块

- 主模块：`psychological-atmosphere-benchmark-library.md`，作为日常空间心理压迫与环境证据机制。
- 检索入口：`suspense-scene-motif-index.md` 的“日常流程校验崩坏 / 熟悉系统撒谎”。
- 已有覆盖：反光双身、错误楼层、湿脚印、身份漂移、阈限状态机和画外脚步继续调用既有结构/声音库，本节只负责把它们统一到日常流程复核链。
- 触发关键词：日常空间恐怖、深夜电梯、停车场、小区门口、公司门禁、便利店、自家门口、熟悉地方不对、按钮失灵、错误楼层、重复车辆、门锁权限、系统反馈异常。

### 17.5 补强机制：私域占用证据链

核心判断：一个杯子少了水、坐垫有余温、衣物换位或房间传来一声轻响，单独出现都可能只是记错。真正有效的私域恐怖，是让不同材质和系统留下的证据连成一条空间路线，逐步证明“有人使用过这里、刚离开这里、仍能进入这里，甚至正在根据你的行动调整自己”。

可复用规则：

1. 先锁定私域基线：谁拥有物件、离开前如何摆放、哪个入口被锁、正常设备停在哪个状态。没有所有权和日常习惯，物件错位只是布景变化。
2. 证据必须连成路线，而不是堆成清单。入口状态 -> 被使用的日常物 -> 新鲜接触痕迹 -> 可能藏身或退出区域，至少三个节点能在空间图上首尾相接。
3. 相邻证据使用不同物理介质交叉证明：位置/朝向、温度/冷凝、湿度/泥尘、设备历史、声源方位或门锁状态。至少两种介质指向同一个占用事实。
4. 时间压力逐级收窄：先是“不知何时被动过”，再到“刚刚被使用”，最后到“当前空间内有回应或权限变化”。余温、未干水痕和持续运行的设备只表达新鲜程度，不写未经测量的精确分钟数。
5. 摄影机先用中广景锁住入口、人物和主要遮挡区；发现证据时进入手部/材质近景；随后回到同一空间图，让下一处证据落在可理解的路线方向。连续特写会切断推理。
6. 第二见证者到场后异常停止，可以成为“行为性静默”：环境维持正常，威胁不再发声或移动；见证者离开后，同一声纹或物件变化恢复，证明异常会识别人数组合。沉默必须与后续恢复或实体残留配对，不能单独当结论。
7. 监控、邻居、保安、同事或门禁记录只验证一个关键事实，不代替整段解释。外部见证最有价值的作用，是让角色的主观怀疑获得一条独立证据，同时保留位置未知。
8. 结尾落在访问权限被夺走：正确钥匙不再只属于角色、反锁空间存在第二套进入方式、设备记录显示陌生使用、藏身区与入口形成闭环。恐惧终点是私域不再由角色控制，而不是必须露出威胁全貌。

反例边界：

- 不连续摆放半杯水、歪拖鞋、热坐垫、开门缝等“诡异物件套餐”。每条证据必须至少收窄位置、时间或权限中的一项。
- 不把余温、气味、湿痕写成万能测谎器；材质、通风、天气和时间尺度必须合理，无法判断时只写角色察觉异常新鲜度。
- 不让威胁从隔墙、门外或监控画面无过程地瞬移到室内。路线转换必须留下门锁、孔洞、脚印、设备记录、遮挡移动或声音方位变化中的至少一种桥接证据。
- 不靠角色放弃报警、出口或基本核对来延长悬念。角色可以撤离、求助、记录和交叉检查；阻碍必须来自明确空间或权限条件。
- 不把“有同伴时没声音”直接等同于超自然规则。必须出现同伴离开后的重复、设备记录或实体残留，才能升级为行为性证据。
- 不用监控反光、衣柜缝、隔墙敲击或湿脚印的表面形象重复制造新卡；它们分别调用既有监控、阈限、画外声和材质痕迹机制，本节只管理证据之间的路线关系。

### 17.6 可迁移镜头模板：占用路线从过去收紧到现在

```text
0-3秒：中广景完成一个熟悉私域动作，同时看清入口、日常物和一个潜在遮挡区；正常设备声建立基线。
3-6秒：一个所有权物件出现轻微错位；角色先凭习惯复位或核对，不立刻惊慌。
6-10秒：手部接触第二种介质，确认痕迹仍新鲜；摄影机沿人物视线或移动路线回到空间图，把证据指向门、走廊、隔墙或藏身区。
10-13秒：第二见证系统介入，或异常在他人到场时停止、离开后恢复；角色获得独立确认。
13-15秒：访问权限发生变化，入口、钥匙、门锁、设备记录或近身声源证明占用仍在继续；尾帧保留未知位置和可继承残留。
```

声音执行：日常底床持续稳定；异常声先拥有可判断方位，再在人物复核时改变距离、停止或恢复。行为性静默中保留冰箱、空调、雨声、灯管或远处交通等正常底床，让“少了哪个声音”可被听见。恢复时沿用同一节奏或材质指纹，不用巨响替代识别。

SD承接锚点：私域空间图、入口与退出路线、日常物正常状态、第一处所有权错位、第二种物理介质、新鲜痕迹、人物手部核对、视线连接的遮挡区、第二见证系统、同伴在场/离场状态、异常声停止与恢复、访问物件、尾帧权限残留。
