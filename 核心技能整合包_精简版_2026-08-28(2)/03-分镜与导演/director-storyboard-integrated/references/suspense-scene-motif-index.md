# Suspense Scene Motif Index

Use this file when the user asks for 悬疑场景清单, 镜头母题, 画面母题, 常用悬疑技巧, 找对标吃素材, 大量投喂悬疑电影片段, or wants a map of what scene types should be trained next.

审查与风格锁定：默认训练方向是悬疑、心理压迫、信息差、规则恐惧、空间不安、物件焦虑、声音悬念、现实错位。主动训练池不走血腥暴力、尸体猎奇、怪物跳脸、低级 jump scare、开膛破肚、虐杀展示。遇到经典恐怖/犯罪片段时，只提取“信息控制、反应镜头、遮挡、声音留白、空间调度、物件状态”的可过审机制，不学习直接血腥画面和跳脸刺激。

## 2. 画面母题补充清单

这些不是完整场景，而是可插入任何场景的“画面钩子”：

- 眼睛里出现门缝、火苗、屏幕、追者、母亲脸、系统目标框。
- 门把手慢慢回弹，手还没碰到。
- 玻璃杯水面自己起波纹。
- 相框倒下，露出裂开的合照。
- 走廊尽头灯一盏盏熄灭。
- 电梯数字停在不存在的楼层。
- 床底拖鞋摆反方向。
- 镜中人物比现实人物慢半拍眨眼。
- 手机屏幕亮起，但没有来电显示。
- 手电光扫过墙面，影子晚一秒移动。
- 脚印从湿地面延伸到干燥墙面。
- 椅子轻轻转动，画面里没有人碰它。
- 旧照片里人物位置变化。
- 钥匙孔里有呼吸雾。
- 纸张边缘被水汽慢慢卷起。
- 蜡烛火苗向门内倒伏。
- 监控画面里出现现实中没有的人。
- 电视雪花噪点里短暂显出房间布局。
- 角色说话时背景里有人静止不动。
- 主角伸手碰证据，先缩回再触碰。
- 电梯按键确认向下，楼层数字却连续向上。
- 一次车锁操作让两辆同款车辆同时闪灯回应。
- 熟悉车位、工位或储物柜出现与本人完全一致的第二份私人物件。
- 门锁接受钥匙却显示内部已经有人占用，日常声音仍从门后继续。
- 同一条画外声在同伴到场后消失，送走同伴后按原节奏恢复。
- 错位物件、尚未消退的接触痕迹与设备记录沿同一条室内路线依次出现。
- 外部见证只确认“有人进入过”，室内访问物件仍留在角色无法解释的位置。

## 4. 审查友好训练筛选

优先训练：

- 信息差：观众比角色多知道一点，或角色比观众先知道一点。
- 空间压迫：走廊、房间、门、楼梯、电梯、地下室、病房、舰桥。
- 物件焦虑：卡片、照片、钥匙、戒指、杯子、蜡烛、手机、屏幕、门锁、账单。
- 声音悬念：画外声、房间嗡鸣、电话、脚步、呼吸、静音、机械提示音。
- 反应镜头：不展示恐怖本体，展示看见者的眼神、手、呼吸、停顿。
- 日常异化：普通空间中一个细节不对劲。
- 规则压力：一个规则立刻改变角色行为。
- 心理对峙：对话、沉默、距离、桌面物件、眼神和手部。

降级为避坑边界：

- 血腥暴力展示。
- 尸体猎奇特写。
- 怪脸贴脸。
- 巨响硬吓。
- 虐杀过程。
- 以恶心生理反应替代悬念。
- 为刺激而刺激的恐怖物正面展示。

经典片段含有以上内容时，只拆可过审机制：

```text
不拆血腥画面 -> 拆遮挡、声音、反应、剪点。
不拆跳脸 -> 拆等待、声音停止、视线转移、慢揭示。
不拆尸体猎奇 -> 拆环境异常、人物反应、证据物状态。
不拆虐杀过程 -> 拆后果、道具变化、空间痕迹、沉默余韵。
```

## 5. 对标素材采集规则

每个母题至少收 5 个片段，重要母题收 10 个片段。不要按片名收，要按“机制不同”收。

有效采集：

- 同样是追逐，一个训练低机位脚步，一个训练轴线方向，一个训练背景慢速威胁，一个训练前景遮挡。
- 同样是对话，一个训练正反打权力，一个训练餐桌物件，一个训练沉默反应，一个训练声音中断。
- 同样是梦境，一个训练空间折叠，一个训练物件变形，一个训练醒来落地，一个训练现实残留。

无效采集：

- 只列片名。
- 只写剧情简介。
- 只说“氛围很压抑”。
- 只写导演风格。
- 没有画面内容、声音、转场、SD锚点。
