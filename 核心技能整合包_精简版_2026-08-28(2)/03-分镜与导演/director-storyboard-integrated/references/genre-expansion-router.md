# Genre Expansion Router

用途：当任务不是悬疑主类型时，保留完整导演流程，但切换情绪发动机、对标池和节奏判断。悬疑技能的摄影、运动生态、声音、连续性和SD承接仍然复用。

## Route Table

| 类型 | 核心发动机 | 优先载体 | 节奏重点 | 专项参考 |
|---|---|---|---|---|
| 都市爱情 | 距离变化、偶遇、选择靠近 | 视线、手部、并行路线、共享交通工具 | 接触前快，确认情感时短暂停顿 | `romance-shortform-counterpart-library.md` |
| 浪漫喜剧 | 失误、误会、身体尴尬转化为好感 | 道具、路线冲突、反应差、声音打断 | 建立、失控、停顿、反转 | romance library + `dialogue-timing-scheduler.md` |
| 生活流 | 日常动作中的关系细节 | 餐具、衣物、门、光线、重复习惯 | 动作小，状态变化清楚 | `material-social-story-language.md` |
| 职场 | 权限、效率、身份和关系交换 | 桌位、文件、屏幕、门禁、任务物件 | 信息刷新与站位变化 | `shot-object-language-library.md`, `dialogue-physical-interaction-grammar.md` |
| 青春成长 | 第一次选择、试错和身体能量 | 跑动、教室、公共交通、群体距离 | 节奏明快，反应真实 | `character-performance-bible.md`, romance library |
| 温情家庭 | 照顾、回避、代际关系和物件记忆 | 饭桌、衣物、旧物、门口、身体距离 | 留出动作余韵 | `material-social-story-language.md`, `sound-design-grammar.md` |

## Shared Workflow

```text
类型发动机
-> 人物目标与关系距离
-> 三个机制不同的对标方案
-> 空间与身体路线
-> 关系变化可见证据
-> 细致分镜
-> SD无损母版
-> 目标模型执行版
```

## Genre Guardrails

- 类型变化只替换情绪发动机，不删除构图、光影、质感、实拍证据、运动生态、声音和连续性字段。
- 爱情戏通过距离、视线、接触、共同动作和选择证明关系，不用抽象“心动感”替代画面。
- 喜剧依靠准备、失误、反应和后果，笑点必须有物理或社会因果。
- 生活流镜头仍需状态变化；日常不等于画面停滞。
- 非悬疑任务使用对应类型片对标，悬疑导演语法只在确实需要信息差、压迫或不安时作为辅助。
