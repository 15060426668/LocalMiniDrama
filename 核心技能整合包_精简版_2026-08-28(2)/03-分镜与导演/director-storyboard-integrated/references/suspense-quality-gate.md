# Suspense Quality Gate

用途：悬疑电影分镜输出前的硬自检矩阵。  
目标：把“空泛、拖沓、漏细节、光影质感混乱、声音薄、转场抽象、SD丢分镜”挡在输出前。

---

## 1. 输出前核心检查

正式分镜输出前必须内部通过：

非悬疑任务先把“悬疑子类型”替换为对应类型发动机，同时保留其余摄影、表演、声音、连续性和SD门槛。

1. 悬疑子类型是否明确？
2. 观众知道什么、角色知道什么、隐藏什么是否明确？
3. 当前4-30秒段是否先经过分镜可移植性门槛？若有电影对标，其镜头顺序、摄影机路径、调度、节奏、声音和转场是否能在替换人物/认知/环境/道具/剧情后直接使用？
4. 每个镜头是否有叙事目的？
5. 构图是否能直接画出来？
6. 光影/色彩是否和画面基调/质感分开？
7. 实拍摄影证据是否足够支撑真实感？
8. 画面内容是否是客观动作，而不是剧情摘要？
9. 声音是否有层次和时间变化？
10. 转场/VFX是否写成可见过程？
11. 多镜头段落是否锁住连续性总线：空间方向、道具状态、服装/身体状态、光源方向、声音尾巴和尾帧继承？
12. 主要角色是否有表演指纹：身体基准、眼神/手部习惯、压力反应、关系动作、职业动作和情绪升级链？
13. 多场戏/多SD段是否有整集钩子链：0-3秒视觉问题、15秒信息刷新、30秒问题转向、尾帧钩子和下一段继承？
14. 心理压抑环境是否让空间、物件和声音改变人物判断，而不是只提供阴森背景？
15. 心理恐怖场景族群是否明确：家庭污染、独居裂变、礼貌社交、老屋记忆、身体焦虑、缺席悬念、光线禁忌、静态感染，至少选一个主机制？
16. 偏执/监听/监控/伪纪录/认知漂移场景是否有可误读证据：同一句声音、同一段影像、同一房间平面或同一动作被二次改义？
17. 焦点、画外空间、负空间、尺度、群体或屏中屏是否至少有一个承担信息控制，而不是只做装饰？
18. 每次切镜或长镜头内部节拍是否改变了信息、权力、距离、方向、焦点、光线权限、声音位置、物件/身体状态或空间规则？
19. 关键伏笔是否有埋设、提醒、误认、回收和行动后果，而不是孤立彩蛋？
20. 材质、物件所有权、重复画面差异、身体局部、天气或制度物件是否至少有一项承担故事证据，并留下连续状态？
21. 是否返回0-6个具有具体视觉机制的电影参考；是否没有因人物认知或剧情不同而误删可用候选，也没有为凑数加入仅主题相似的影片；是否避免时间码、等时和单片强绑定？
22. 边说边走/边操作时，是否明确口型窗口、主路线、手部动作、听者反应和背景动作的先后与主次？
23. 跌撞、急停、挤门或障碍接触是否包含力方向、接触点、阻力、身体压缩、惯性、恢复与残留状态？
24. 每镜是否写清主运动、陪体/NPC、道具机械、环境力、材质响应、光影摄影机、声音触发、交互后果和尾帧，而非只有主体人物在动？
25. 角色知识、规则触发权限、物件能力、动作后果和残留状态是否因果成立？
26. 台词按实际中文语速、停顿和口型窗口计算后，是否仍给听者反应、手部动作、镜头落点和环境后果留出时间？
27. 高风险镜头是否完成复杂度判断，并在需要时准备不改变叙事结果的稳定覆盖方案？
28. 每镜声音是否锁定唯一主声源、启用总线、方向距离、计量单位、逐轨RMS/peak/相对电平、空间处理、闪避、LUFS-S、母版LUFS-I/dBTP、可见反应和声桥，并用对数方式估算叠加？
29. 多电影机制是否在正式分镜前被统一为一个连贯导演方案？正式分镜和SD是否只沿用批准后的分镜来源？下一段是否完整承接连续性总线？
30. 对标是否落到连续镜头短语，并写清起始动作、摄影机/调度路径、空间或剪辑变化、结束动作、覆盖节拍和未覆盖节拍？
31. 当前轮是否只输出用户明确进入的阶段，而非把流程说明误判为一次性输出全部阶段？
32. 局部对标是否只绑定覆盖的几秒，原片无关后续是否已丢弃，剩余分镜是否根据当前剧本原创扩展并继承供体尾帧？

任一失败，先改分镜，不要输出。

## 2. 字段合格标准

| 字段 | 合格 | 失败表现 |
|---|---|---|
| 景别/焦段 | 说明景别、焦段家族、景深/焦点变化如何服务心理 | 只写近景/全景，没有镜头目的 |
| 焦点路径 | 起焦对象、延迟、触发、移动速度、落焦对象、信息变化清楚 | 装饰性拉焦；只写“焦点转到门” |
| 构图画面 | 前景/中景/背景、主体位置、负空间、遮挡、线条、信息点清楚 | 只写“压迫感构图/电影构图” |
| 机位与运镜 | 高度、角度、距离、运动路径、起止画面、信息变化清楚 | 只写推拉摇移 |
| 光影/色彩 | 光源、光位、光质、光比、阴影占比、色彩归属清楚 | 只写冷色调/昏暗 |
| 画面基调/质感 | 子类型质感、胶片/数字、黑位、颗粒、镜头特性、材质优先级清楚 | 只写电影感/高级质感 |
| 实拍摄影证据 | 摄影机、光源、材质、空间、人物瞬间、瑕疵、连续性至少5项有效 | 只写真实感/超写实 |
| 连续性总线 | 色彩剧本、场景陈设、道具状态链、服装/身体状态、主光方向、声音桥、尾帧继承清楚 | 每镜都像不同场戏，角色/道具/光源/空间跳变 |
| 高级镜头控制 | 画外源方向、负空间任务、光源动机、尺度关系、群体反应或屏中屏证据按需明确 | 标签齐全但没有任何机制控制观众注意力 |
| 材质/社会故事载体 | 初始状态或所有者、变化触发、物理/制度过程、反应后果、尾帧状态清楚 | 材质、天气、表单、徽章、身体局部只做装饰 |
| 画面内容 | 身体动作、眼神、手脚、道具、背景动静物、微变化可见 | 只写角色害怕/争吵/逃跑 |
| 运动生态/层级交互 | 每个时段有一个注意力所有者；谁看见、听见、知道、误判或装作不知道可追溯；公开行为与私下信号分层；主运动、陪体、NPC、道具、机械、环境力、材质、光影、摄影机、声音触发和残留形成清晰因果层级；同一环境力保持方向并按重量、距离、延迟传播 | 角色对未感知信息提前反应；主角在动，背景人物死站；风雨水滴植物与物件各自随机运动；群体无原因同步；所有层同时抢焦点 |
| 角色表演 | 同一角色的身体基准、眼神/手部习惯、压力反应、关系动作、职业动作、崩溃边界可继承 | 每个镜头像不同演员临时表演；只写情绪标签 |
| 整集节奏/钩子链 | 每15秒有新信息/新风险/新选择；每30秒观众问题转向；尾帧有下一段继承锚点 | 单镜头好看但整段散，段落结尾没有继续看的理由 |
| 心理压抑环境 | 环境空间、证据物、声源、身体微反应共同证明认知错位 | 只写雨夜/旅馆/病房很压抑，没有可见证据改变判断 |
| 声音设计 | 唯一主声源；ENV/BODY/OBJ/VOX/FX/INT/MUS按需启用；声源权限、方位/距离、频段、遮挡、RT60、RMS dBFS、peak dBFS、相对电平、ducking、LUFS-S、LUFS-I/dBTP、可见反应和声桥可执行；叠加值使用对数估算 | 只写紧张音乐/环境音；裸写`-20dB`；所有声层同响；直接相加分贝；把估算值冒充最终母版实测 |
| 转场 | 起始画面、变化过程、连接锚点、结束画面清楚 | 只写转场/梦境切换 |
| 叙事目的 | 说明释放什么信息或制造什么问题 | 镜头只是好看 |
| 镜间变化/尾帧 | 说明相对上一镜改变什么、为何此刻切、下一镜继承什么 | 连续换角度但信息和状态不变 |

## 3. 短剧节奏门槛

- 0-3秒：必须有视觉问题或动作钩子。
- 固定单机位：1-4秒内必须有信息刷新。
- 8-15秒段落：必须完成一次证据出现、角色反应或认知变化。
- 15-30秒：必须完成第一次转向，安全变陷阱、出口变入口、证据改义、声音撒谎、关系变位至少一项成立。
- 30-60秒：必须锁定主任务、代价、限制、敌我关系或倒计时，不能只是换背景。
- 多SD段：每段尾帧必须留下可继承的门、眼神、物件、光源、声音或未完成动作。
- 长运镜：可超过4秒，但画面必须持续变化，不允许空走。
- 对话戏：每句重要台词必须有画面行为、反应或物件变化配合。
- 快剪不是价值本身：每一剪必须有镜间变量变化；只有角度变化的快剪应合并。

## 4. 悬疑电影专项门槛

| 子类型 | 必须出现的证据 |
|---|---|
| 密闭规则 | 出口限制 + 规则物 + 规则反馈 |
| 走廊追逐 | 纵深方向 + 身体消耗 + 空间变化/画外压力 |
| 心理对峙 | 眼神权力 + 手部/道具 + 沉默/呼吸 |
| 规则物 | 材质特写 + 手部接触 + 状态变化 |
| 梦境错位 | 触发点 + 变形过程 + 残留痕迹 |
| 异常收容 | 环境反应 + 设备/声音证据 + 延迟确认 |
| 社会伪装 | 礼貌表情 + 出口/站位控制 + 小物件触发 |
| 仪式压迫 | 队形 + 同步动作 + 集体声音 |
| 调查系统 | 证据平面 + 程序压力 + 反应镜头 |
| 心理压抑环境 | 空间封闭/重复 + 错位物件 + 环境声变化 + 身体微反应 |
| 家庭空间污染 | 熟悉物件复位失败 + 家具/门框切割人物 + 日常声变刺耳 |
| 礼貌社交压迫 | 正常笑脸 + 出口被站位占住 + 杯子/手机/门锁触发不安 |
| 缺席悬念 | 空位/未接电话/少掉物件 + 正常环境持续运转 + 角色等待动作 |
| 偏执监听 | 真实声源 + 重复播放/倒带 + 第二遍改义 + 设备继续运转 |
| 影像证据不可信 | 屏幕内容 + 观看者反应 + 现实空间对应物 + 边缘细节 |
| 认知布景漂移 | 同一房间平面 + 单点陈设变化 + 人物按旧动线失败 |
| 结尾反转 | 旧证据回收 + 新意义 + 余韵留白 |

## 5. SD转译门槛

分镜转SD/Seedance前必须确认：

- A区块继承每个分镜行，不合并丢细节。
- 正式分镜若明显会进入SD，分镜表先补 `SD承接锚点`，再转A区块。
- 多镜头或多A段必须先锁 `连续性总线`：空间地图、屏幕方向、关键道具状态、服装/身体状态、光源方向、声音尾巴、尾帧继承。
- 多镜头、多段、图生视频、重复角色/道具或复杂VFX必须建立共享场景清单，并按 `BASE MANIFEST -> SEGMENT DELTA -> TAIL STATE -> NEXT SEGMENT START` 编译。
- 当前段只建立批准正式分镜的来源锁；上游电影参考不进入SD来源状态。
- 梦导SD用户可见区域只出现批准分镜的 `分镜语法锁定`；作品名、导演名、场景名、片中位置和电影时间不进入SD来源校验和。
- 一条用户可见提示词不超过30秒；内部A节拍共同继承同一份批准正式分镜。
- 16-30秒动画段保持单一戏剧主线，在12-18秒附近至少完成一次信息、身体、物件、焦点、声音或空间状态刷新，并以精确尾态落在请求终点。
- 下一SD段沿新的批准分镜差量执行，角色、空间、道具、光影、声音和尾帧通过连续性总线继承。
- 只写正向词，风险改成正向锚点。
- 画面基调与质感锁定不替代每段光影。
- 声音轨和A段声音一致。
- 转场特效写成过程：旧画面 -> 触发 -> 变化 -> 新画面 -> 残留。
- 如果一个分镜信息太密，拆成多个A段。
- 每个A节拍内部计算复杂度：`0-3`保持紧凑，`4-5`分离动作轨，`6+`拆段；同一节拍出现两条摄影机路径或两次转场时直接拆段。
- 对正式Markdown产物运行 `scripts/validate_storyboard_sd.py`；脚本通过后仍需完成导演质量审查。

生成结果出来后，如果用户反馈画面/视频不对，先用 `generation-feedback-repair-loop.md` 判定失败层：

- 分镜源表失败：构图、画面内容、光影、质感、声音、转场本身没写清，先回修分镜。
- A区块编译失败：分镜有细节但A段丢失，先回修A区块。
- 模型执行失败：分镜和A段都清楚但生成跑偏，拆段、强化角色/空间/光源/尾帧锚点。
- 连续性失败：人物方向、空间方位、道具状态、光源跳变，回修空间锁定和连续性字段。
- 真实度失败：像CG、塑料、海报、游戏截图，回修画面基调/质感和实拍摄影证据。
- 声画/VFX失败：声音不触发画面，或转场没有过程，回修声音节拍和可见变形链。

## 6. 删除/精简原则

输出前删除：

- 空泛词：高级、电影感、压迫感、诡异感、氛围感，除非后面有可见证据。
- 重复风格标签：同一段不要堆多个导演名字。
- 无用镜头：没有叙事目的、没有信息变化、没有情绪推进的镜头。
- 无来源光效：找不到光源或异常理由的漂亮光。
- 无功能道具：不改变视线、规则、情绪或信息的装饰物。

保留：

- 影响故事规则的物件。
- 影响人物判断的声音。
- 证明真实空间的材质。
- 改变观众认知的构图信息。
- 影响SD生成稳定性的空间方向和光源。

## 7. Four-Round Regression Drill

Run these compact tests after major skill edits. The output does not need to be stored; the gates and source fields must be recoverable.

| Round | Test scene | Must route | Pass condition | Regression sign |
|---:|---|---|---|---|
| 1 | 狭长走廊女主被追 | chase dynamics + off-screen pressure + scale + sound | direction readable, body force visible, background proves speed, every cut changes distance/risk | only “快速奔跑/手持跟拍/紧张音乐” |
| 2 | 家庭琐事升级为离婚争吵 | gaze/blocking + object ownership + reaction + shot delta | table/door/prop axis changes power; listener and background keep acting; lighting and sound differ by angle | alternating talking heads with identical light and frozen room |
| 3 | 梦中推门后惊醒 | threshold + visible VFX process + continuity + tail frame | start image, trigger, deformation/contact, wake-body reaction and inherited object/light/sound are traceable | white flash, hard cut or “空间变化” without process |
| 4 | 监控/手机画面暴露线索 | screen-within-screen + focus route + reaction-first + payoff | screen anomaly readable, physical room corresponds, watcher reaction changes action, clue can return later | tiny illegible UI or dialogue explains everything |

Each round must also pass:

- formal table includes `实拍摄影证据` and `镜间变化/尾帧`.
- static shots refresh within 1-4 seconds.
- no shot exists only to change angle.
- likely SD handoff has positive, traceable `SD承接锚点`.

These four cases are the runtime smoke test. Structural cross-skill regression is a separate maintenance task and is not loaded during ordinary storyboard design.
