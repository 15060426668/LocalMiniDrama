# Sound Mix Metering

用途：把分镜中的声音设计写成可执行、可测量、可交接的逐镜声轨。涉及“每层多少分贝、叠加后多少、哪个是主声源、声音从哪里来”时必须读取本文件。

## 1. Core Rule

声音参数必须先声明计量口径。单独写 `-20 dB` 没有执行意义，因为它可能指数字峰值、均方根、节目响度、真峰值或现实声压级。

正式分镜采用以下口径：

| 指标 | 用途 | 写法 |
|---|---|---|
| `RMS dBFS` | 稳态声层的数字平均能量参考 | `-28 RMS dBFS` |
| `peak dBFS` | 单条声轨瞬态峰值与余量 | `-10 peak dBFS` |
| `LUFS-S` | 当前镜头/短节拍约3秒的主观响度目标 | `-19 LUFS-S` |
| `LUFS-I` | 整段或最终成片综合响度 | `-14 LUFS-I` |
| `dBTP` | 最终母版重建后的真峰值上限 | `-1 dBTP` |
| `relative dB` | 其他声层相对当前主声源的退后量 | `主声源 -8 dB` |
| `dB SPL` | 现场录音、监听或放映环境的物理声压 | 只在明确讨论现场/播放环境时使用 |

`RMS dBFS`、`LUFS` 与 `dBTP` 不是同一种数值，不能互相替代。最终交付必须用响度表和真峰值表实测；分镜中的数字是混音目标与层级约束，不是假装已经完成母带测量。

## 2. Seven Stem Families

每镜必须审查七类声源，但只启用服务当前戏剧任务的层。短节拍通常启用2-5类，且只有一个主要听觉注意力。

| Bus | 声源类别 | 包含内容 | 典型任务 |
|---|---|---|---|
| `ENV` | 环境/空间底床 | room tone、风雨、城市、HVAC、低频压力、群体远声 | 建立空间、常态与压迫基线 |
| `BODY` | 主体/身体拟音 | 呼吸、脚步、衣料、吞咽、手指、重心、身体碰撞 | 身体状态和表演证据 |
| `OBJ` | 物件/机械 | 门锁、钥匙、杯子、钟、屏幕、车辆、医疗设备 | 线索、规则、机械因果 |
| `VOX` | 台词/人声 | 同期对白、画外话语、广播、电话、NPC人声 | 信息与权力；记录口型所有者 |
| `FX` | 动画/VFX/设计音 | 空间折叠、粒子、能量、数字故障、非现实材质变化 | 为可见特效提供物理过程与尺度 |
| `INT` | 主观/心理 | 耳鸣、血流、心跳强化、听觉收窄、记忆声、梦层失真 | 进入角色认知；必须有进入/退出规则 |
| `MUS` | 音乐/结构静默 | 配乐、持续音、节奏母题、主动抽空 | 结构和释放；静默写成哪些总线被撤走 |

空间声学不是第八条声轨，而是跨声轨处理层：距离衰减、方位、遮挡、EQ、早期反射、混响、延迟和声像均在这里统一处理。

## 3. Per-Cue Contract

每条启用声源至少记录：

```text
cue_id / bus / source_name
diegetic_status: 画内 / 画外 / 主观 / 结构性
narrative_owner: 谁制造、谁听见、谁忽略、谁误判
screen_position: 左右/前后/上下/方位角
distance_m: 与听觉视点的距离
frequency_focus_hz: 主体频段与需要让位的频段
start_s / end_s / envelope: attack -> sustain -> release
target_rms_dbfs / peak_dbfs / relative_to_primary_db
occlusion_eq: 门墙遮挡、LPF/HPF或频段削减
reverb: space、RT60、pre-delay、dry/wet
ducking_masking: 谁为谁闪避、闪避多少dB、持续多久
visible_reaction: 声音触发的眼神、肌肉、动作或环境响应
tail_bridge: 结束、延续、J-cut、L-cut或下一镜继承
```

`narrative_owner` 与 `visible_reaction` 是悬疑信息权限的一部分。观众先听到而角色未反应时，要明确写“观众可听 / 角色尚未感知”；角色听到后再安排可见反应，不能提前表演。

## 4. Per-Shot Mix Contract

正式分镜的 `声音设计` 至少包含：

```text
主声源：cue_id + 具体来源 + 画内/画外/主观 + 方位/距离
启用声层：ENV / BODY / OBJ / VOX / FX / INT / MUS 中实际启用项
逐层电平：每条声轨的 RMS dBFS + peak dBFS + 相对主声源电平
空间处理：频段重点 + 遮挡/EQ + RT60 + dry/wet
动态关系：起音/停止/包络 + ducking/masking + 声音先后
镜头总线：目标 LUFS-S + 估算能量和 + 峰值余量
母版目标：选定 delivery profile 的 LUFS-I + dBTP
声画触发：谁先听见、谁反应、哪个可见动作被触发
声桥/尾音：J-cut / L-cut / cut / decay + 下一镜继承状态
```

推荐的紧凑写法：

```text
主声源[OBJ-01]：门锁齿轮，画左后2m、画外，-21 RMS/-9 peak；BODY-01呼吸-27/-15，相对主声源-6dB；ENV-01走廊底床-35/-25，相对-14dB。空间：门板遮挡LPF 3.5kHz，RT60 1.2s，wet 18%。动态：锁芯起音时ENV闪避3dB/0.4s。总线：-20 LUFS-S，估算能量和-20.0 RMS dBFS，峰值余量8dB；母版：social_balanced -14 LUFS-I/-1 dBTP。触发：她先肩颈僵住再回头；锁声L-cut 1秒。
```

## 5. Logarithmic Summation

分贝不能线性相加。对同一时间窗内近似不相关的稳态声层，估算能量和：

```text
combined_rms_dbfs = 10 * log10(sum(10 ** (Li / 10)))
```

其中 `Li` 是每条同时活跃声轨的 `RMS dBFS`。

最坏情况下，同相瞬态的峰值上界可用振幅相加估算：

```text
worst_coherent_peak_dbfs = 20 * log10(sum(10 ** (Pi / 20)))
```

其中 `Pi` 是各轨 `peak dBFS`。该值是压力测试上界，不等于实际真峰值。实际结果还受相位、频谱重叠、压缩、EQ、混响、声像和限制器影响。

示例：`-24`、`-30`、`-36 RMS dBFS` 同时存在时，能量和约为 `-22.9 RMS dBFS`，不是 `-90 dB`，也不是简单取最大值。

## 6. Delivery Profiles

以下是工作流起点，不是所有平台的永久法律。平台、发行商或项目有明确规范时，以项目规范为准。

| Profile | 用途 | 段落/母版目标 | 真峰值上限 | 动态策略 |
|---|---|---|---|---|
| `social_balanced` | 手机端短剧默认 | `-14 LUFS-I` | `-1 dBTP` | 对白稳定，关键拟音清楚，环境留层次 |
| `social_dense` | 高密度动作/预告 | `-12 LUFS-I` | `-1 dBTP` | 更紧的动态，瞬态仍保留辨识度 |
| `dialogue_led` | 对话、家庭冲突、调查 | `-16 LUFS-I` | `-1 dBTP` | 人声优先，物件与环境按关键词闪避 |
| `suspense_low_dynamic` | 手机端心理压迫 | `-15 LUFS-I` | `-1 dBTP` | 安静细节可听，避免超宽动态导致手机端丢失 |
| `cinema_preview` | 影院感预演，不作为影院正式母版 | `-18 LUFS-I` | `-2 dBTP` | 保留更宽动态与低频余量 |

常用镜头短时目标起点：

| 节拍类型 | 建议 `LUFS-S` |
|---|---:|
| 低声压环境建立 | `-28` 至 `-23` |
| 微拟音/线索主导 | `-24` 至 `-19` |
| 克制对白 | `-21` 至 `-16` |
| 激烈争吵/追逐 | `-17` 至 `-12` |
| 主动静默 | 保留必要room tone；用撤走哪些总线描述，不写虚假的绝对 `-∞` 成片 |

## 7. Spatial And Frequency Execution

每条主声源至少确定：

- 方位：画左/画右/正前/身后/上层/下层；必要时加方位角。
- 距离：近身 `0.2-1m`、室内中距 `1-4m`、走廊远距 `4m+`，再按空间校正。
- 频段：低频提供体感与尺度，中频承载动作实体，高频承载锁舌、布料、气息和危险点描。
- 遮挡：隔门/墙时削减高频并增加早期反射；开门后恢复直达声与清晰度。
- 混响：以场景材质和体积决定RT60，不能用“恐怖混响”替代空间证据。
- 声像：镜头切换或人物转头时，声源方位要连续，不随画面随意跳边。

## 8. Masking And Priority

每个时间段只允许一个主声源。混音优先级由剧情决定，不固定由对白永远占据。

常用让位：

- 关键词台词出现：ENV与MUS在1-4kHz削减或整体闪避2-5dB。
- 门锁、钥匙、针落地等线索拟音出现：ENV短暂闪避2-4dB，attack 30-120ms，release 250-700ms。
- 呼吸成为主观焦点：外界声收窄高低频，BODY/INT上升，但保持可追溯的现实底床。
- VFX变化：FX只在可见变形边界移动时取得主位，落地后退回ENV/OBJ。
- 激烈争吵：只保留一个主要可读口型；抢话者、听者呼吸、家具碰撞与背景声按句间窗口错开。

## 9. Output Levels

按任务深度选择输出：

- 方案池：声音任务、主声源、声画关系、主要风险，不填伪精确数值。
- 细致分镜：每镜必须给主声源、启用声层、方向/距离、逐层电平、空间处理、镜头总线、声画触发和声桥。
- 梦导SD：默认模型载荷的A区块只保留可听事件、方位、先后、强弱关系、主观处理、可见反应和声桥；数值混音参数进入独立后期cue sheet或结构化mix manifest，不在模型提示词中重复。
- 后期交接：输出完整cue sheet与mix manifest，并用计算脚本检查叠加、余量和主声源。

## 10. Quality Gate

逐镜声音不通过的情况：

- 只写“环境音、脚步声、紧张音乐”。
- 数字没有单位，或把LUFS、dBFS、dBTP、SPL混为一谈。
- 所有声层一样响，或没有唯一主声源。
- 声音无来源、无方位、无距离、无角色感知权限。
- 只列声音名，没有起止、包络、遮挡、混响、闪避和尾音。
- FX与画面变化不同步，动画/空间变形没有起因、过程和落地声。
- 分贝直接相加，或把估算能量和冒充最终真峰值。
- 声音触发后人物、NPC、道具和环境没有可见反应。
