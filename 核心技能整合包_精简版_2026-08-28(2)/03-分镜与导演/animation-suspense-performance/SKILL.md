# Animation Suspense Performance

Runtime contract: `v6.0 / 2026-08-08`

本技能是Step 5内部的动画表现层。它把导演批准的镜头变成可见、可计时、可继承的动画表演，不改剧情、台词和镜头的戏剧目的。

## 每次必读

1. `../director-storyboard-integrated/references/animation-production-pipeline.md`
2. `references/animation-runtime-core.md`

普通任务读完即开始。只有命中专项问题时再读一份参考；两个真正独立的复杂问题最多读两份。

## 输入合同

从导演层接收：

```text
段落任务与类型脊柱
入口状态、退出变化与下一段债务
信息权限和不可提前事实
角色站位、轴线、屏幕方向与物件归属
镜头目的、起点、路径、落点
批准台词与口型窗口
参考绑定、光源、声床和上一段尾态
```

输入不完整时指出缺口并返回导演层。不得用动画炫技自行填剧情。

## 所有权

本技能拥有：

- 现实动作基准、动画视觉命题和普通段/表现段选择。
- 主体意图、姿势链、支点、受力、路径、接触、恢复和尾态。
- 脸、视线、口型、呼吸、肩脊髋、手脚和公开/私下表情的错时关系。
- timing/spacing、一拍一/二/三、hold、阶梯帧、smear、冲击帧、离模与归模。
- 图形、线条、色彩、媒介、Q版、颜艺、故障、碎屏、空间或时间改写的主表达引擎。
- 对手、听者、NPC、道具、衣发、环境力、光影和声音的独立接力。
- 摄影机与主体双重运动、遮挡连续、世界锚和镜头落点。
- 2D主体进入真人底片时的透视、支点、遮挡、影子、反射和材质接触证明。

本技能不拥有：

- 故事结构、场景目标、台词改写和导演镜头目的。
- 静态人物/场景画风、MJ出图描述和参考图选择。
- 最终SD/Seedance提示词结构或任何用户侧JSON。

## 主流程

1. 验证输入事实锁，确认当前拍不能改什么。
2. 写一句动画视觉命题：关系怎样变化，哪项可见变量承担变化，现实留下什么。
3. 建立正常动作循环和现实基准；普通段直接设计，关键段再比较身体、物件、环境三类引擎。
4. 只选一个主表达引擎，最多一个辅助算子；明确进入、发展、换权、归还和残留。
5. 把每个动作按八槽链展开：意图 -> 预备/支点 -> 发力 -> 路径 -> 接触/阻力 -> 峰值 -> 恢复 -> 尾态。
6. 同步脸/呼吸、身体、关系、物理和观看权限五层。
7. 给听者、NPC、道具、环境、光影和声音分配错时反应；它们保持自己的任务。
8. 复合运镜分别写摄影机路径和主体路径，证明世界锚、遮挡、焦点和最终落点。
9. 按自然`2-4秒`窗口写逐拍运动台账；后一拍入口严格继承前一拍结果。
10. 锁定最终姿势、支点、视线、方向、物件、持续运动、声尾和效果残留。
11. 静音审读、物理审读和连续性审读通过后，合并回正式动画分镜。

## 普通段与表现段

### 普通段

日常、群聊、吃饭、做事和情景喜剧不需要每拍离模，但必须持续有：

- 说者和听者各自的任务。
- Moving Hold，而非所有人冻结等台词。
- 视线、呼吸、手部、坐姿或道具的低幅变化。
- 背景人物、厨房、门口、楼梯、风、火、水或声音的反节拍。
- 台词、动作或包袱结束后的新状态。

### 表现段

只有现实表演不足以准确表达时才激活主引擎：

```text
现实基准 -> 可见触发 -> 第一处越界 -> 连续发展
-> 主体/关系参与 -> 峰值换权 -> 归还现实
-> 后果 -> 残留/下一镜接力
```

速度线、smear、冲击帧、Q版、颜艺、线稿突变、媒介切换和故障都必须回答：谁触发、从哪里进入、怎样改变行动或关系、怎样归还、留下什么。并排堆效果不算创意。

## 台词与喜剧表演

- 逐字继承批准台词，不润色、不翻译、不补旁白。
- 口型只占实际发声窗口；起句前有吸气/视线/手部准备，尾音后给听者或环境反应。
- 不因说话人变化而切镜。多人群戏可让说者、听者、第三人和背景任务在同一构图中错峰接力。
- 包袱结构至少包含铺垫、误判/升级、兑现和反应；补刀必须继承前一个反应，不另起一个无关笑点。
- 颜艺和Q版只放大已存在的意图或反应，不能替代铺垫。

## 16-30秒

- 保持一个主戏剧事务和一份段级事实锁，不在15秒重置角色、场景或画面法则。
- 普通窗口以`2-4秒`为宜；克制hold或连续摄影机运动可更长，但画面每`1-4秒`需由动作、视线、焦点、声音、物件或空间刷新。
- `12-18秒`附近必须出现策略、关系、信息、物件、声音、画面权限或空间状态变化。
- 后半段继承前半段支点、视线、道具、环境力、绘画状态、摄影机落点和声尾。
- 额外时间优先给准备、反应、后果和恢复，不在同一窗口塞第二个主动作。

## 一行运动台账

复杂连续动作使用：

```text
[时间] 画面/时间所有者
| 主体任务与八槽进度 | 脸/呼吸 | 支点/重心/手脚
| 接触/次级材质 | 对手/听者/NPC | 道具/环境力
| 声音/光影/线条 | 摄影机路径与落点
| 结果、残留、下一拍继承
```

主体动作占最大文字预算。压缩时先删不变背景、重复质感和同义形容；动作、表情、接触、反应和尾态装不下时拆时间窗。

## 输出

动画层的结果直接合并进正式分镜，不再并行生成一份重复文档。需要单独展示时使用：

```text
导演事实锁
动画视觉命题
普通段/表现段判断
主表达引擎（如启用）
关键视觉状态图
逐拍运动台账
恢复与尾帧
SD承接锚点
真实风险
```

交给SD层的是可见执行事实和尾态，不是提示词。SD层只输出纯文本 `BASE LOCK + A`。

## 硬伤门

- 动作只有标题，没有意图、支点、路径、接触、恢复或结果。
- 只做脸部表情，身体轮廓和重心不承载意图。
- 对手、听者、NPC、道具和环境冻结或同拍同幅反应。
- 特效无进入、接力、归还和残留，或用特效遮住动作错误。
- 接触没有重量、阻力、反作用和新状态；接触影粘在脚下不变。
- 主体自转或背景滚动冒充环绕；复合运镜无世界锚、路径和落点。
- 2D人物像贴纸：无支点、遮挡交换、视差、动态影或材质后果。
- 歌词、抽象情绪、作品名、训练卡编号或内部审核信息进入模型载荷。
- 16-30秒在15秒处重启，或后半段忘记前半段尾态。
- 动画层擅改剧情、台词、镜头任务或输出JSON。

## 验证

```powershell
python scripts/validate_animation_performance.py <artifact.md>
python scripts/validate_animation_performance.py <artifact.md> --profile expressive
python scripts/validate_animation_performance.py <artifact.md> --profile scene
python scripts/validate_animation_performance.py <artifact.md> --profile mixed-reality
python scripts/validate_animation_performance.py <artifact.md> --mode handoff
```

验证器只补充判断。结构通过但动作仍抽象、环境仍冻结、镜头无落点或尾态不能继承时，仍必须返工。
