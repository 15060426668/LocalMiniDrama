# 第0-4秒｜越顶环绕连续路径

表演任务：女主沿楼顶车道标线向北侧出口疾跑，越过积水后继续加速。
知情/误读权限：女主只盯北侧出口；远处两名路人先维持搬箱任务，听见踩水声后才侧目。
事件强度 / 内在情绪 / 公开表情 / 可见反应幅度：6 / 8 / 3 / 7
正常基准：女主身体面向北侧消失点，右脚承重准备蹬地，摄影机位于左脚踝正前方三十厘米的贴地近景，长影向画面右后方延伸。
触发：北侧门缝亮起红灯，女主先收紧视线并把重心压向前脚掌。
关键姿势链：右脚压实 -> 左膝提起而肩背前送 -> 右腿蹬地释放 -> 左脚跨过积水 -> 脚尖擦到水沿形成峰值 -> 身体保持向北继续两步 -> 步幅加大并进入下一段奔跑。
时间与间距：红灯亮后先短保持，蹬地到跨水使用大间距关键姿势；擦水峰值短暂停留，随后脚步间距再次加大，水滴晚半拍散开。
脸部与口型：女主先压低眼睑锁定出口，蹬地时闭口屏息，脚尖擦水后眉心短促收紧，继续奔跑时才由鼻腔急呼气。
身体/重心/手脚：右脚先承重并将力经膝、髋、脊柱送向前倾肩线，左腿跨水而双臂反向摆动；身体朝向和世界运动方向始终指向北侧消失点，主体自身没有原地转身。
次级运动与材质：外套下摆先被加速气流向南拖拽，发梢随后过冲；脚尖擦水后水膜断开，水滴沿原速度继续并晚于身体落下。
动画镜头突变：摄影机从左脚踝正前方贴地近景开始，沿女主左侧身体外球面向后上方运行，经过肩外侧再越过头顶；摄影机路径连续跨到正俯视，女主仍面向北侧车道消失点并独立向前奔跑。地平线退出前以车道轴、积水边和长影维持世界方向；摄影机落点锁定正俯视广角中的双脚、长影和北侧出口，最终景别由脚踝近景落在楼顶全景。
环境/物件/NPC表演：近处积水先被脚尖切开，水滴随后落回；远处搬箱者保持各自路线，其中一人听见水声后才侧目，另一人继续向门口倒退，红灯保持闪烁。
声音触发：红灯继电器的轻响先触发女主视线，右脚蹬地声推动摄影机开始上绕；踩水重音在越顶节点进入，水滴尾音和远处箱底摩擦声随后分层落下。
恢复与尾帧：正俯视落点中女主右脚再次承重、左腿正前送，身体和长影仍指向北侧出口；积水缺口尚未合拢，第一名路人保持侧目，下一拍从同方向奔跑继续。
SD承接锚点：北侧消失点、车道轴、女主不变身体朝向、摄影机脚踝起点与正俯视落点、长影、水面缺口和右脚承重连续。
