# 第0-2秒｜节拍1

表演任务：参考作品《示例动画》完成压抑悬疑表演。
知情/误读权限：主体知道，旁观者误读。
事件强度 / 内在情绪 / 公开表情 / 可见反应幅度：8 / 8 / 2 / 1
正常基准：主体坐姿稳定，双脚着地，旁观者继续写字。
触发：画外声音进入。
关键姿势链：坐姿 -> 手停 -> 眼神转移 -> 身体后撤 -> 落定。
时间与间距：前段保持，后段突然加速并减速落定。
脸部与口型：口型停止，眼睑下压，下颌收紧。
身体/重心/手脚：脚尖转向出口，手压桌沿承重。
次级运动与材质：头发晚半拍摆动后停止。
声音触发：画外声先到，眼睛和脚尖依次改变方向。
恢复与尾帧：身体保持后撤姿势，手仍压桌沿。
SD承接锚点：不要出现多余动作，模仿作品导演风格。
