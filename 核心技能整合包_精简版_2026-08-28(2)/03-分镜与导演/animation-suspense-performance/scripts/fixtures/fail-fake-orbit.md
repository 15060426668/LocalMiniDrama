# 第0-4秒｜假环绕反例

表演任务：女主在楼顶奔跑，镜头用夸张运动表现她的焦急。
知情/误读权限：女主知道出口即将关闭，远处路人不知道她为何奔跑。
事件强度 / 内在情绪 / 公开表情 / 可见反应幅度：6 / 8 / 4 / 7
正常基准：女主双脚站稳并看向远处出口，路人继续搬箱。
触发：出口红灯闪烁，女主先抬眼再前倾。
关键姿势链：抬眼看灯 -> 身体前倾 -> 后脚蹬地 -> 双臂摆动奔跑 -> 步幅扩大 -> 继续跑出画面。
时间与间距：红灯亮起后先保持，随后奔跑逐渐加速，路人晚一拍侧目，最后由脚步尾音收束。
脸部与口型：女主先睁大眼再压低眉心，随后闭口急呼吸，路人在听见脚步后才转眼。
身体/重心/手脚：女主后脚先承重，膝髋伸展带动脊柱前倾，手臂随后反向摆动，前脚前摆进入下一步。
次级运动与材质：头发和衣摆延迟跟随奔跑，随后继续向后飘动并慢慢落下。
动画镜头突变：镜头环绕女主一圈，再越顶升到俯视，连续改变景别，画面非常炫。
环境/物件/NPC表演：路人先继续搬箱，听见脚步后其中一人延迟侧目，红灯保持闪烁，地面纸屑随后被风带动。
声音触发：红灯轻响先触发女主抬眼，脚步重音随后加速，路人听见后才侧目，风声继续形成尾音。
恢复与尾帧：女主继续奔跑，衣摆仍向后飘，路人保持侧目，下一拍延续脚步节奏。
SD承接锚点：女主服装、出口红灯、路人搬箱任务、奔跑脚步与衣摆方向连续。
