# 镜头1｜普通对话

表演任务：两个人完成一段对话。
知情/误读权限：两个人都知道谈话内容。
构图观看权限：摄影机依次观看两个人。
证据释放链：说话者 -> 听者 -> 说话者。
事件强度：3/10
内在情绪：4/10
公开表情：4/10
可见反应幅度：3/10
四项强度：3/4/4/3
正常基准：两人站在房间内，双脚着地，保持普通谈话姿势。
触发：第一人开始说话。
关键姿势链：第一人说话 -> 第二人听见 -> 第二人回答 -> 两人停下。
时间与间距：前半段第一人说话，后半段第二人回答。
脸部与口型：说话者张嘴，听者闭嘴。
身体/重心/手脚：两人保持站姿，双手自然下垂。
次级运动与材质：头发轻微摆动。
动画镜头突变：正反打切换人物近景，最后回到双人中景。
环境/物件/NPC表演：房间保持稳定。
声音触发：台词结束后切换镜头。
恢复与尾帧：两人保持站姿。
SD承接锚点：人物服装和房间位置保持连续。
