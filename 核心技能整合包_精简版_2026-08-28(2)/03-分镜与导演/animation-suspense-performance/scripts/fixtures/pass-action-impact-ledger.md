# 第0-3秒｜动作节拍

表演任务：守门者在狭窄门廊内用短棍挡住袭来的长刀，并把对手逼离门槛。
知情/误读权限：守门者提前听见右侧脚步并隐藏准备；对手只看见她上身静止，误判她没有防守。
事件强度 / 内在情绪 / 公开表情 / 可见反应幅度：8 / 7 / 2 / 8
正常基准：守门者左脚在前贴近门槛，短棍垂在右腿外侧，肩线放松；对手在两步外举刀前进，门帘被右向风持续吹动。
触发：对手右脚踏响木地板并抬刀越过肩线，守门者的视线先锁住刀镡。
关键姿势链：左脚压实门槛 -> 右肩和腰胯反向蓄力 -> 短棍由腿侧斜挑 -> 棍刀在门框前接触并短暂停留 -> 守门者借反作用下沉转髋 -> 棍端沿刀背推开 -> 对手后脚补步而守门者收棍落定。
时间与间距：前一秒低幅保持，蓄力逐渐加密；接触前快速释放，接触峰值短保持；推刀后先快后慢，最后由对手补步和门帘回摆收束。
脸部与口型：守门者先移眼再压低眼睑，接触时闭口屏息，推开后鼻腔短促呼气；对手在刀路偏离后才张口，视线晚半拍追向棍端。
身体/重心/手脚：左脚持续承重，右脚后蹬把力送到腰胯、肩、肘和手腕；接触时双膝下沉吸收冲击，左手晚半拍扶住棍尾，对手后脚横跨一步重建支点。
次级运动与材质：守门者袖口晚于手腕扬起，发梢在接触后过冲；棍身轻微弯曲回弹，刀穗和门帘按各自重量继续摆动并依次停下。
动画镜头突变：接触峰值由交叉棍刀取得画面中心，门框透视线短暂向接触点收紧；两人脚下门槛保持现实尺度，推刀后透视沿棍端方向恢复。
环境/物件/NPC表演：近处门帘先被刀风掀开，棍刀接触后门框落下一粒木屑；对手的同伴在远处先停步再抬头，没有同步上前，木地板震动晚于接触扩散。
声音触发：右侧脚步先触发守门者视线，棍刀接触短暂压低环境声，金属重音随后进入；木屑落地和门帘拍框声在两人落定后形成尾音。
恢复与尾帧：守门者左脚仍压住门槛，短棍横在胸下并轻微回弹；对手后脚刚落地、刀尖偏向画外，门帘和刀穗仍向右摆，远处同伴保持抬头姿势。
SD承接锚点：门槛支点、交叉接触位置、守门者左脚和横棍、对手偏斜刀尖、右向门帘、远处同伴抬头与金属尾音连续。
