# 贴纸式混合现实反例

混合现实路由：校园短片。
真人底片锁：实拍校园很好看。
2D角色层锁：手绘女生很可爱。
跨媒介融合证据：她站在画面里。
手绘区别保留：精致动画风格。
双层尾态：镜头结束。

## 第0-4秒

表演任务：女生捡纸。
知情/误读权限：女生知道，路人不知道。
四项强度：2/4/2/3。
正常基准：女生站在校园里等着事情发生。
触发：一张纸落下。
关键姿势链：看见纸 -> 伸手 -> 捡起来 -> 站好。
时间与间距：先看见，然后伸手，再站起来。
脸部与口型：眼睛看纸，嘴巴闭着，呼吸自然。
身体/重心/手脚：手伸向纸，脚站在地面，身体弯下去。
次级运动与材质：头发随后飘动，衣服慢半拍落下。
动画镜头突变：镜头保持中景，角色始终处在画面中心。
环境/物件/NPC表演：路人继续任务，纸张随后被拿起。
声音触发：纸张声源先响，女生随后反应。
恢复与尾帧：女生站好，下一拍继续走路。
SD承接锚点：女生、校园、纸张和中景构图。
