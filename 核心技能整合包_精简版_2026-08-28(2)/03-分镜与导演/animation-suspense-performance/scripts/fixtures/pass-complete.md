# 第0-2秒｜节拍1

表演任务：在公开笑闹中让身体动作自然越过安全支点。
知情/误读权限：主体不知道回弹会造成后果；两名旁观者看见动作但只作低幅观察。
事件强度 / 内在情绪 / 公开表情 / 可见反应幅度：8 / 3 / 8 / 1
正常基准：主体坐在桌边，双脚着地，双手靠近腹部，肩部随笑声小幅弹动；旁观者保持坐姿和聊天任务。
触发：一句话的末尾笑声加重，主体的笑动作取得身体主导权。
关键姿势链：坐姿笑 -> 双手捧腹前折压缩 -> 脊柱依次展开回弹 -> 髋部越过支点 -> 身体向后离开构图 -> 空椅与衣摆落定。
时间与间距：前半段一拍二，前折末端短保持；回弹间距突然拉大，峰值短时提高动作密度，尾部减速落定。
脸部与口型：笑声口型连续，前折时眼睛挤闭；回弹中嘴形仍保留笑，离开构图前下颌开始失去控制。
身体/重心/手脚：肩和脊柱带动前折，骨盆留在椅面；回弹时髋部越过椅背支点，双手晚半拍向两侧寻找支撑，双脚仍在桌下。
次级运动与材质：头发、衣摆和挂件滞后上扬，主体离画后分重量回落；椅面轻晃后停止。
动画镜头突变：主体回弹峰值由笑动作取得画面权限，摄影机保持原轴位但短暂使用轻微强制透视，让后仰的脸和双手靠近镜头、髋部与椅面支点后缩；以椅背、桌沿和双脚方向作为现实锚点，主体离画后恢复正常教室透视并落在空椅尾帧。
环境/物件/NPC表演：椅面与衣摆承担动作余波；两名旁观者保持原座位和聊天任务，一人手抬几厘米、一人轻抬下巴，均为R1反应；教室其他同学和环境底噪继续正常频率，空椅成为事件后果的视觉中心。
声音触发：主体笑声为主声，旁白保持更近更清楚；关键词结束时笑声加重并触发回弹，教室底噪持续。
恢复与尾帧：主体在画外完成落点；空椅轻晃，衣摆末端刚落下；两名旁观者仍坐着，一人手抬几厘米，一人轻抬下巴。
SD承接锚点：连贯捧腹前折到向后回弹；回弹中笑形残留；髋部越过支点；旁观者R1反应；空椅、衣摆和教室底噪尾桥。
