# 第0-4秒｜承重式拥抱

表演任务：两名久别角色从一步距离靠近，以互相承重的拥抱确认关系仍然成立。
知情/误读权限：两人都理解拥抱意图；远处路人只感知到他们停步，不参与关系判断。
事件强度 / 内在情绪 / 公开表情 / 可见反应幅度：5 / 8 / 4 / 5
正常基准：两人面对面站立，各自双脚承重，手臂自然垂下，呼吸尚未同步。
触发：左侧角色先向前半步并抬眼，右侧角色看见她眼眶湿润后闭合剩余距离。
关键姿势链：相互确认 -> 左右支撑脚分别压实 -> 躯干与肩先软接触并缓冲 -> 双臂一前一后环抱 -> 手掌加压而衣料压缩 -> 共享重心落定 -> 呼气后分阶段松开。
时间与间距：确认与靠近使用一拍二，接触前间距缩短；躯干接触短保持，手臂环抱稍晚，落定转为一拍三，松开速度慢于靠近。
脸部与口型：左侧角色先抬眼再闭眼，下颌微收并屏住半拍呼吸；右侧角色眼睑放松，贴肩后缓慢呼气，两人没有对白口型。
身体/重心/手脚：左侧角色右脚、右侧角色左脚各自承重并接住来势；胸肩接触时双方上身后让几厘米缓冲，骨盆保持在支撑面内，双臂随后环紧，手掌在背部确认重量。
次级运动与材质：发梢和外套下摆晚于停步贴向对方，背部衣褶在手掌加压后压缩；松开时头发、袖口和衣褶按重量依次回落。
动画镜头突变：镜头保持中景和共同地面，只在共享重心落定时轻微收紧人物间负空间；双脚与地平线持续作为现实锚点，松开后恢复原距离构图。
环境/物件/NPC表演：近处纸片先被两人闭合距离带起，随后落回脚边；远处路人继续行走，只一人晚一拍侧目，背景风保持原方向。
声音触发：鞋底摩擦声先触发双方支撑脚压实，衣料近声在躯干接触后出现，右侧角色呼气取得落定节拍，远处脚步继续形成尾音。
恢复与尾帧：两人先松开躯干再松开手臂，各自后退半步重新落定；左侧角色手仍停在对方袖口一瞬，眼眶湿润和被压皱的衣料留给下一拍。
SD承接锚点：相对支撑脚、胸肩接触位置、双臂环抱先后、背部手掌压力、衣褶压缩、分阶段松开和袖口残留连续。
