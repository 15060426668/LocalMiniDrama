# 镜头1｜15秒关系破裂对话

表演任务：通过普通对话和裂杯说明两人关系破裂。
知情/误读权限：两人都清楚谈话内容，观众跟随当前说话者。
构图观看权限：双人中景建立后，当前说话者依次取得画面。
证据释放链：双人中景 -> A过肩 -> B反打 -> A近景反应 -> 杯子特写。
动画表达引擎：正反打、近景反应和杯子裂开完成情绪递进。
情绪特效链：正常比例 -> 轻微影子图形 -> 眼睑眯缝 -> 杯子裂开。
效果接力链：A台词交给B反打 -> B台词继承到A反应 -> A视线交给桌边物件 -> 物件落成裂杯残留。
环境响应链：背景冷光继续，桌面物件在最后取得注意。
环境换手：杯子裂开后桌面和背景继续并接管余波。
视觉状态刷新：双人中景 -> A过肩 -> B反打 -> A脸部特写 -> 杯子特写。
动画专属镜头：杯子裂开形成短暂图形，桌边作为现实锚点，随后恢复普通静物比例。
动画转场与归模：硬切回桌面现实，人物保持标准比例，裂杯作为残留。
