# 第0-4秒｜空洞拥抱反例

表演任务：两个人走近拥抱，表达久别重逢。
知情/误读权限：两人知道彼此想和好，旁人继续赶路。
事件强度 / 内在情绪 / 公开表情 / 可见反应幅度：5 / 7 / 5 / 5
正常基准：两人面对面站着，双脚稳定，手臂垂下。
触发：左侧角色看见右侧角色微笑。
关键姿势链：互相看见 -> 同时走近 -> 张开手臂 -> 已经抱在一起 -> 分开站好。
时间与间距：靠近时逐渐加速，中间短暂停顿，随后减速分开。
脸部与口型：两人先抬眼，随后闭眼微笑并呼气。
身体/重心/手脚：两人的脚站稳，肩膀转向彼此，双手抬起后放到对方身后。
次级运动与材质：头发和衣摆延迟跟随手臂，随后慢慢落下。
动画镜头突变：镜头保持中景，人物靠近时轻微推近，分开后回到原构图。
环境/物件/NPC表演：旁人继续赶路，一人随后侧目，路边树叶保持摆动。
声音触发：脚步声先触发靠近，呼吸声随后进入，环境声继续。
恢复与尾帧：两人分开后各自站稳，手臂放下，下一拍继续对视。
SD承接锚点：两人相对位置、抬手方向、分开后的站位和对视连续。
