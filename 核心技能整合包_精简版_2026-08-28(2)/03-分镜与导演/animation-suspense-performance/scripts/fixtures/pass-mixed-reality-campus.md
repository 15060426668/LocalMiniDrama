# 真人校园底片中的2D手绘角色

混合现实路由：2D主体表演 / 真人校园底片，动画路由持续拥有角色动作、线条和分拍。
真人底片锁：固定胸口高度机位，视平线穿过中景学生肩部，走廊单点透视；前景真人从右向左经过，中景是角色与纸张，后景学生沿走廊继续路线；左侧窗光为柔和主光，地面阴影向右，保留浅景深、轻微运动模糊、相机颗粒和真人NPC各自路线。
2D角色层锁：成年高中女生的身高尺度服从中景真人，稳定轮廓和服装识别色；压力变化的粗铅笔线、局部断续和重画痕，哑光平涂与两级阴影块；常态选择性分拍和局部线沸腾，动作峰值允许短促离模，随后以脸型、脚底和发型锚点归模。
跨媒介融合证据：右脚脚底支点贴合真实地砖，接触投影在鞋底最实；前景真人先从角色前方遮挡交换，角色再从其后方穿出；弯腰时手掌接触真实纸张，纸边弯曲、位移并发出摩擦声，亮地面保留低强度倒影和正确视差、景深与运动模糊。
手绘区别保留：主轮廓具有笔压变化、断线、搭线与重画痕，发梢局部线沸腾；常态选择性分拍，伸手峰值以前一张压缩姿势和后一张跨距姿势形成可读失帧姿势跳跃。
双层尾态：底片摄影机继续固定，真人学生沿原路线离开；2D女生右脚承重、左手托住纸张，粗线和线沸腾回到常态；纸边仍微弯，下一拍从她抬眼寻找失主的未完视线开始。

## 第0-4秒

表演任务：女生发现真人学生掉落的纸，决定捡起并递还。
知情/误读权限：女生先看见纸张，失主继续向前尚未察觉，近处一名真人学生只看到她减速。
四项强度：事件强度 2/10，内在情绪 4/10，公开表情 2/10，可见反应幅度 3/10。
正常基准：女生在中景随真人学生同向步行，右脚准备落地，手臂低幅摆动，纸张平放在前方地砖上。
触发：窗边阵风掀起纸角，纸张擦过她右鞋前方并发出轻响。
关键姿势链：右脚落地减速 -> 视线先落到纸角 -> 左脚补成稳定支点并屈膝 -> 脊柱前倾、右手沿弧线接近 -> 指尖压住纸角 -> 拇指与食指夹起、纸边弯曲 -> 身体由腿部发力站回中景 -> 左手托住纸张并抬眼寻找失主。
时间与间距：前段步行保持均匀分拍；纸响后脚先减速，视线晚半拍锁定；下蹲逐步减速，指尖接触短暂停留，夹起后站起更慢，尾部保持带呼吸的moving hold。
脸部与口型：纸响后眼睑抬高，瞳孔先下移，嘴唇轻闭并短吸气；捏住纸后眉间放松，站起时视线越过前景真人肩部寻找失主。
身体/重心/手脚：右脚先承重刹住，左脚向外半步扩大支撑面；膝髋屈曲让重心下降，右肘微弯、指尖先压纸，站起时力量由脚掌传到膝髋和脊柱，左手随后托住纸张。
次级运动与材质：身体停下后发梢和裙摆延迟向前过冲，蹲下时书包带继续滑动，站起后发梢慢半拍落下；粗铅笔轮廓只在发梢和手腕局部沸腾。
动画镜头突变：绘画系统保持真人底片与2D粗线的双媒介基准，纸角轻响时焦点从真人前景转到中景手和纸，摄影机不追近，遮挡后的重新出现交还观看权限。
环境/物件/NPC表演：阵风先掀纸角，随后吹动女生发梢；前景真人继续走并从她前方遮挡，近处学生晚半拍侧眼后继续任务，失主仍向远处走；纸张在指尖接触后先弯曲再离地。
声音触发：右前方纸张摩擦声是声源，先触发眼睛下移再触发脚步减速；真人脚步和远处球场声保持声床，纸离地的轻响晚于手指接触。
恢复与尾帧：女生站回右脚承重姿势，左手托纸、右手轻压纸边，呼吸恢复；真人前景遮挡已经离开，纸边弯曲与窗风尾音残留，下一拍继承向远处寻找失主的视线。
SD承接锚点：中景尺度、右脚地砖支点、左窗光与向右投影、前景真人遮挡交换、纸边弯曲、粗铅笔断续线和选择性分拍。
