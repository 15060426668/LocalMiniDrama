# 动画表演到SD的无损承接契约

> 运行状态：转换失败诊断接口。标准SD/Seedance编译直接交给 `dream-suspense-sd`；只有字段丢失、旧产物兼容或承接修复时读取本文件。

## 核心锁

只要用户没有明确命令删减，所有已经批准的动画表演事实都必须进入内部无损编译状态，并在 `BASE LOCK`、对应时间段的 `A区块` 或制作附件中获得唯一目的地。

```text
允许压缩 = 删除重复措辞、合并同义表述、把稳定事实提升到BASE
禁止压缩 = 删除唯一动作、反应、节奏、声音触发、恢复或尾态
```

字符上限与完整性冲突时：

1. 先消除纯重复。
2. 再把稳定基准移入BASE。
3. 再把复杂表演拆成连续A节拍。
4. 单条提示仍超限时，按连续时间拆成多条提示并声明继承关系。
5. 不得用“精简总结”替代原有唯一事实。

## 正式输入字段

每个动画表演节拍应包含：

```text
表演任务：
知情/误读权限：
事件强度 / 内在情绪 / 公开表情 / 可见反应幅度：
正常基准：
触发：
关键姿势链：
时间与间距：
脸部与口型：
身体/重心/手脚：
次级运动与材质：
声音触发：
恢复与尾帧：
SD承接锚点：
```

## 字段映射

正式表演字段先进入内部无损状态，再压入下游五字段；控制标签不得逐项照抄到模型提示词。

| 动画表演源字段 | 五字段目的地 | 必须保留的可见事实 |
|---|---|---|
| 表演任务、知情/误读权限、四项强度 | 内部控制 -> 主体动作与表演 / 关系/物件/环境反馈 | 转成谁先反应、动作量、观看方向和保持/误读行为 |
| 正常基准、触发、关键姿势链、时间与间距 | 主体动作与表演 | 起始支点、触发、预备、峰值、速度变化、恢复 |
| 脸部与口型、身体/重心/手脚 | 主体动作与表演 | 只保留承担意图、发力、接触、口型或落点的局部 |
| 次级运动与材质、旁观者反应 | 关系/物件/环境反馈 | 延迟、过冲、反应幅度、分重量落定和环境继续项 |
| 主观视角与美术所有权 | 镜头与构图 / 主体动作与表演 / 关系/物件/环境反馈 / 声光与转场触发 | 视角取得、单一主变量、跨层锚点和客观材质归还 |
| 声音触发 | 声光与转场触发 | 会改变口型、姿势、视线、镜头、剪点或尾桥的声源 |
| 恢复与尾帧、SD承接锚点 | 尾帧与连续性及对应动作/物件字段 | 精确落点、残留、2-4个易丢锚点和下一拍起点 |

### 双视角人物重定义的SD拆分

当批准分镜使用“主角眼中的自己 / 他人眼中的主角”时，按连续A节拍分别保留：

```text
A1 自我视角人物基准：删减哪些现实材质、保留什么动作和物件
A2 见证者取得权限：视线方向、迟疑表演、观看距离
A3-A5 现实证据扫描：脚/支撑、手/物件、胸口/衣领/呼吸，每段一个主信息
A6 见证者反应：现实意义由谁确认、反应幅度和口型残留
A7 客观全身落地：全部材质归还、环境尺度、身体姿态和视线
A8 余波物件/环境：跨层锚点继续存在，环境接管声音和转场
```

每个扫描节拍必须写清构图裁切、材质证据、身体承重、当前观看者和下一镜新增的信息。完整全身在证据扫描与见证者反应之后落地。

## 动画A节拍模板

下游固定使用五字段结构；每栏只承担自己的事实，不用空话凑字：

```text
第X-X秒｜源镜头号/源表演节拍

镜头与构图：开场构图、画面所有者、摄影机起点/路径/速度/落点、遮挡与焦点交接。
主体动作与表演：正常基准 -> 触发 -> 预备 -> 主动作/峰值 -> 后果 -> 恢复；保留脸、口型、重心、手脚和接触。
关系/物件/环境反馈：听者/NPC错峰反应、物件接触与新状态、次级材质延迟和环境继续项。
声光与转场触发：只写本拍变化并产生可见作用的声源、光色、媒介和转场触发。
尾帧与连续性：结束姿势/视线/支点/物件状态；2-4个易丢锚点；下一拍直接起点。
```

五栏全部保留；某类差量很小时写当前可见状态和接力关系，不使用“无变化”“自然过渡”等空占位。完整表演控制字段留在内部覆盖账本，不在模型载荷中逐栏复述。

## 无损覆盖账本

编译前为每条唯一事实分配ID：

```text
P 关键姿势
T 时间/间距
F 脸部/口型
B 身体/重心/手脚
S 次级运动/材质
R 旁观者/NPC反应
A 声音触发
Y 风格越界/回落
L 落点/连续性
```

示例：`P01前折压缩`、`P02沿同一弧线回弹`、`B01髋部越过支撑面`、`R01旁观者保持坐姿`、`R02手抬三厘米`、`L01尾帧空椅仍在轻晃`。

内部检查每个ID必须出现一次或有明确BASE归属。重复出现可去重；没有目的地就是遗漏。

## 可删与不可删

可删：

- 同一稳定服装、发型、房间结构在多个A节拍中的逐字重复。
- “压抑、悬疑、电影感、动画感”等已被具体动作和画面证明的抽象形容词。
- 同一尾态在动作字段、物理字段和尾帧字段中的三次复述，保留一次精确版本。
- 数值混音在模型执行词中的重复；数值进入声音后期附件。

不可删：

- 关键姿势的先后、动作弧线、支点变化和峰值。
- 反应幅度锁，尤其“保持坐姿、只轻抬手/抬头/转眼”。
- 口型停止点、主声与次声的声画关系。
- 预备、加速、过冲、次级惯性、恢复和残留。
- 风格变化的权限所有者、触发、持续、回现实锚点。
- 尾帧中人物、物件、环境和下一镜必须继承的状态。

## 术语转成模型可见动作

| 上游术语 | 下游写法 |
|---|---|
| 一拍一爆发 | 峰值短时提高动作密度，相邻姿势跨越清楚，快速接触仍保留落点 |
| 一拍二/三保持 | 主姿势以阶梯节奏保持，眼/手/呼吸或材质层低幅变化 |
| smear | 沿运动方向短暂拉伸或出现方向明确的残影，下一姿势恢复标准轮廓 |
| impact frame | 接触瞬间短暂高反差/粗线/简化，下一姿势出现物理后果 |
| off-model | 峰值短暂压扁、拉长或改变线条，随后恢复标准身份比例 |
| moving hold | 主姿势保持，呼吸、眼睑、发丝、衣物或线条轻微变化 |
| deadpan | 日常任务和身体高度保持，只允许锁定的低幅眼/手/头反应 |

## 声音边界

模型执行词保留：

```text
谁在说/发声
-> 主次声音层级
-> 进入和覆盖顺序
-> 角色口型、姿势、视线或间距如何变化
-> 声音如何连接尾帧或下一镜
```

RMS、peak、LUFS、dBTP、EQ、RT60、ducking等数值可留在制作附件，但不能因此删除“谁是主声、谁被压低、谁的动作被声音触发”。

## 来源隔离与正向输出

- 模型执行词只写当前角色、场景、动作、媒介和视觉事实。
- 作品名、作者名、导演名、工作室名、IP名、来源镜头位置和研究标签全部留在上游登记。
- 使用正向可见/可听描述，不把风险说明或负面提示词混入模型执行词。
- 若用户要求“某作品式”，先在上游拆成线条、比例、帧密度、表演幅度、色彩权限和构图机制，下游只写这些可执行属性。

## 最终检查

```text
每个批准的姿势是否有目的地？
每个时间/间距变化是否仍存在？
脸、口型、身体、重心、手脚是否都按镜头需要承接？
次级运动是否写了延迟和落定？
旁观者反应幅度是否原样保留？
主声/次声和可见反应是否完整？
风格越界是否写触发和回落？
尾帧是否能直接成为下一A的起始？
字符限制是否通过拆分解决，而不是通过删事实解决？
模型执行词是否清除了全部来源/IP名称？
```
