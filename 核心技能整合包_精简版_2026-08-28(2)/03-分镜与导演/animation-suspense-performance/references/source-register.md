## 资料吸收规则

1. 只有能写成 `触发 -> 姿势 -> 间距 -> 受力 -> 反应 -> 恢复 -> 尾态` 的结论才进入运行时语法。
2. 同一规则出现多个来源时，保留一个运行时表述，在本表登记多源支持，不复制多份规则。
3. 作品分析只提炼机制，不把角色、剧情、镜头时长和作品名写入下游提示词。
4. 网页打不开、只看到标题或只有二手转述时，保持C级。
5. 书目未在本轮全文阅读时，不声称“已看完”，只登记其公认主题和待核验用途。
6. 新材料先进入来源表，再决定是否更新运行时文件。
