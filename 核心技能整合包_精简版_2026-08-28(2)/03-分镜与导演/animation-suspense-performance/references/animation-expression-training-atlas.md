# 动画表达训练机制图谱

> 运行状态：训练/溯源档案。核心门禁已收敛到 `animation-runtime-core.md`；仅在审计用户训练素材、核对机制来源或教学展开时读取本文件。

本图谱把用户提供的《动画表达与镜头语言训练库》压缩为可迁移的运行机制。它负责两件事：

1. 在分镜前主动判断何时需要动画原生表达，以及应调用哪一类表达。
2. 在表达接管画面时，保证主体动作、表情、配角、道具、环境、声音、光影、镜头和尾帧属于同一条因果时间线。

作品名、角色名和来源时间只属于上游研究登记；本图谱只输出机制。外部素材中的精确帧数、物理常数和个别来源判断属于候选参考，除非已有逐帧核验，不升级为全局硬规则。

## 1. 总算子

正式动画节拍必须按下列顺序思考：

```text
主体任务
-> 感知/信息权限
-> 可见触发
-> 预备与支点
-> 脸、视线、呼吸显露意图
-> 肩脊髋、手脚、重心的发力链
-> 主动作路径、间距和峰值
-> 接触/阻力/反作用
-> 过冲与恢复
-> 次级物、NPC、环境、声音、光影的错时接力
-> 镜头或绘画系统响应
-> 尾帧、继承状态与残留
```

任何气流、速度线、残影、闪帧、冲击帧、Q版、颜艺、透视、光影夺权、媒介突变或转场，都是这条链的放大器。它们不能代替主体链，也不能在主体尚未完成时抢夺信息预算。

### 1.1 一拍一账

把每个关键节拍写入 `full-frame-motion-ledger.md`。每一行回答“谁先动、谁因其而动、谁晚几拍接管、什么状态交给下一拍”。表格字段平行出现，但内容必须按同一时间轴互相引用。

### 1.2 一个主动作所有者

“一个主动作所有者”是层级规则，不是静止许可：主体承担当前戏剧动作；听者、NPC、道具、环境和镜头仍以独立幅度、感知延迟和物理后果响应。高峰可以暂时把画面交给影子、声音、群体或媒介层，但必须写清接管和归还。

## 2. 主动调用门

先写现实基准和主体任务，再做以下扫描。满足一项即可候选调用；满足两项以上时必须在“表达机制选型”中提出至少两个候选，并说明采用或保持基准的理由。

| 触发信号 | 优先候选 | 最小执行证明 |
|---|---|---|
| 速度、重量、急停或距离仅靠普通镜头读不清 | 间距分层、smear/残影、压缩-过冲-回弹、气流路径 | 支点、加速段、峰值帧、延迟后果、落定 |
| 动作峰值需要记忆点或存在接触冲击 | 冲击 hold、反作用、碎裂/波纹递进、声音延迟 | 接触点、阻力、峰值停留、环境范围逐层扩散 |
| 武器/工具动作需要快准或危险感 | 慢蓄力-快释放、刀路/工具路、空气割裂、伤害延迟 | 手指/腕/腰胯顺序、路径、接触证据、纳刀/收势 |
| 普通日常动作正在承担犹豫、等待、亲密或疲劳 | moving hold、任务循环、微重心、呼吸/眨眼错时 | 正常任务、最小泄露、次级微动、环境反节拍、尾态 |
| 笑点来自预期差、无语或旁观者低反应 | Q版突变、反应错拍、字面化、动作偷渡、静默尾刀 | 笑点触发、单一突变、识别锚、对手基准、现实落点 |
| 情绪需要逐级失控而非一句“崩溃” | 三级以上颜艺递进、身体离模、光色/声音同步扭曲 | 每级脸部变化、身体支点、旁人幅度、回落残留 |
| 群体信息从近处传播到远处 | 反应波、群体拓扑、个体任务分裂 | 距离/知情差、延迟、至少三种个体动作、拥堵或空位 |
| 声音是动作的主因或峰值载体 | 前置静音、重音可视化、声源换权、声画错位 | 声源位置、静音窗口、身体触发、波/文字/材质路径、尾音 |
| 光影或影子比角色更能承载威胁/规则 | 影子独立运动、光色夺权、照明边界变化 | 正常投影、第一处异常、主体反差、光学锚、恢复 |
| 角色关系依赖媒介或风格差异 | 单主媒介突变、双媒介拒绝融合、画格/纸面介入 | 触发、每套系统的动作/线条差异、共处锚、回落残留 |
| 时间地点需要连续但不想用说明性蒙太奇 | 同构图循环、动作接力、物件状态升级、声音节拍压缩 | 每轮只改一项、共同锚、状态累积、打破循环的触发 |
| 场景切换本身是动作或意义的一部分 | 形状匹配、前景擦屏、动作偷渡、声桥、物件接力 | 前态末端、共同方向/轮廓/声音、后态落点、连续物件 |
| 歌词、内心句或抽象情绪不能直接拍成事实 | 身体局部变空间、环境承接心理、普通物件语义链、主角静/人群动、记忆现实同框 | 当前可见事实、主体动作触发、载体变形过程、现实锚、新意义与下一镜接力 |

若没有这些触发信号，保持现实绘画与运动基准，并在台账中写清主体任务循环、听者/NPC微反应、道具状态和环境反节拍；“无显性突变”不是“无表演”。

## 3. 十二类机制的可执行语法

每类机制都必须经过：`入口 -> 发展 -> 峰值/换权 -> 归还 -> 残留`。下面是机制骨架，不是固定帧数。

### 3.1 基础表演与 Moving Hold

- 停步：脚先承重，躯干随后刹住，头最后转；衣发、道具和声音在后续拍错时收束。
- 递接：递出者保持托举，接收者先视线确认、指尖触碰、确认重量、手指收拢、承重再收回；双方不同时松手。
- 犹豫/等待：大动作停止，呼吸、眨眼、肩起伏、脚尖、手指任务循环继续；“想动又停下”至少出现一次。
- 尾态：说出口/接稳/决定后，支点和任务循环必须改变，例如肩放松、手松开、视线终于抬起。

### 3.2 速度、惯性与间距

先设计关键姿势与 spacing，再分配一拍一/二/三和 hold；曝光密度不是速度标签。高速可以用少量大间距关键张，慢动作也可能用一拍一保存微小位移。常见候选波形是 `预备保持 -> 大间距释放 -> 峰值关键姿势/短 hold -> 余波重新分拍`，但必须按动作可读性重算。Smear 或残影只占运动路径上的峰值短窗口；关节、剪影和接触点在极端帧仍可读。急停遵循 `压缩 -> 过冲 -> 回弹 -> 稳定`；气流、速度线和背景拉伸从主体边缘、运动方向或空气受压处生长。

### 3.3 武器、工具与接触冲击

拔刀、挥拳、挥棒、拉弓、开门等动作按 `解除阻力 -> 反向蓄力 -> 腰胯/肩腕传力 -> 路径释放 -> 接触 -> 伤害/物理后果延迟 -> 收势` 展开。快释放前必须有准备；命中后的血线、裂纹、碎片、声音或敌方反应可晚于接触，形成信息冲击。写清握持者、支点、阻力和收势，效果不能凭空替代动作。

### 3.4 镜头张力与尺度断裂

静止或低幅基准先建立尺度，再以低角度、强制透视、鱼眼/边缘压迫、焦距突切或完整身体延迟揭示改变权力。镜头突变必须由主体峰值、声音、影子或空间规则触发；极端透视不破坏结构锚，峰值后回到可识别的站位与方向。

### 3.5 Q版与可爱突变

笑点峰值时快速压缩比例、线条和阴影系统，保留发型、服装色、标志物和动作方向；对手/旁观者可保持正常比例以制造反差。Q版只承担一个笑点，不延长到失去叙事。归模后保留叹气、青筋、汗滴、错位道具或旁观者低反应。

### 3.6 颜艺与身体离模

颜艺不是瞬间贴图：至少设计三个升级台阶，例如眼睑/瞳孔变化 -> 嘴角/下颌 -> 脸部线条和阴影块 -> 躯干后仰或支点过冲。五官相对位置、身体受力和角色识别锚必须保留；对手和旁人可低幅或静默，让主角的幅度更可读。回落时呼吸、头发、色晕或眼神残留继续存在。

### 3.7 群体、NPC与反应波

反应按知情路径和距离传播，不做全员同步。最近者先看到、定住、改变视线或失去支点；中层转头、让路、拉人或继续任务；远层晚拍才理解，可能指点、茫然或维持日常。每个 NPC 至少有一个独立任务、支点或路线；拥堵、碰撞、回头、空位和物件掉落证明群体几何改变。

### 3.8 声音取得画面

声音链为 `声源 -> 距离/遮挡 -> 静音或重音 -> 身体/物件响应 -> 声音图形或空间扩散 -> 尾音/恢复`。静音可让观众等待；重音可以让空气、线条、波纹、文字或灯光从声源向外扩散。声音延迟必须改变表情、支点、镜头或剪辑权限，而不是只添加音效名。

### 3.9 光影与影子行动

先显示正常光源与投影，再让影子、光斑、色温或明暗边界独立移动、吞没或夺回画面。主体可保持低幅，与影子的主动性形成反差；光源方向、接触面和影子边界是现实锚。光线恢复时仍留金粉、黑痕、错位影或动作余波。

### 3.10 媒介、线条与风格突变

媒介变化必须回答“谁在解释世界”：线条粗细、填色边界、帧率、漫画格、纸片、网点、像素或三维光照只改一个主变量，辅助材质最多一个。跨媒介时保持脸型、发型、服装色、道具位置、动作方向和共同地面；风格切换不能切断动作连续性。回落后留下笔触、故障闪烁、折痕或异质声响。

### 3.11 时间压缩与重复腐化

固定门、课桌、路线、放包、开灯等任务循环重复，每轮只改变方向、速度、物件材质、所有者或结果之一。用物件破损、空位、群体朝向、声音打断或画格歪斜累积时间，不用旁白代替。第三次循环应出现可比较的偏差或打破触发。

### 3.12 转场接力

转场写成 `前态动作末端/物件轮廓/声拍 -> 遮挡或形状匹配过程 -> 后态同方向落地 -> 锚点保持 -> 声桥与光色渐变 -> 新场景尾态`。动作、风、衣发、道具和脚步跨过转场时保持同一方向或节拍；只有场景/媒介/时代变化，主体任务和识别锚仍连续。

## 4. 跨机制因果门

### 4.1 歌词与意识流语义转译门

歌词或抽象概念只在上游提供节奏和意义任务。进入分镜与视频模型前，必须编译为：

```text
抽象情绪 / 歌词功能
-> 当前现实中可见的事实
-> 承载它的身体局部、普通物件、环境、影子、声音或空间
-> 主体可见动作触发
-> 载体怎样逐步变形、换权或污染现实
-> 始终可追踪的支点、物件、声源、视线或空间锚
-> 峰值产生的新关系或新意义
-> 归还现实后的残留与下一镜接力
```

- 不把歌词逐句贴成插画，也不把“孤独、自由、迷茫”直接当画面动作。
- 身体局部可以变成空间，环境可以接住心理，普通物件可以沿使用方式、形状、声音或所有权连续改义；每次改义都要由上一状态留下的证据触发。
- 记忆与现实同框时，先锁当前现实锚，再让记忆层完成一个决定性动作；归还后当前人物、物件或环境必须已经改变。
- 以画面后期对歌词的 MV 工作流中，歌词原句只留在上游节奏表，不进入视频模型画面提示词；下游只接收时间窗、可见动作、声画触发与尾态。

### 4.2 特效证据预算

特效可以有意夺取画面、遮脸、遮身体、碎屏、花屏、闪白或让主体暂时消失，不能把“特效不遮主体”写成绝对禁令。每个时间窗必须登记：

```text
当前画面所有者
必须读懂的主体证据：意图 / 支点 / 动作方向 / 脸 / 手 / 接触点 / 结果之一
允许被遮挡的证据和时长
效果从哪个身体、物件、声源或现实表面进入
何时把观看权限还给哪个证据
遮挡后留下什么物理、空间、声音或意义残留
```

冲击帧可以短暂清空细节，故障可以夺权，裂片可以切断身体；但在需要观众理解动作之前或之后，核心动作证据必须重新可见。若效果只是盖住动作错误，不算动画表达。

### 4.3 帧法所有权

每次换拍说明“谁拥有时间”：主体、衣发/道具、环境、真人底片、回忆层或故障层。主体 hold 时，呼吸、眼睑、线沸腾、风、NPC任务或声源可以继续；环境继续不等于所有层同速。固定帧数、固定比例和“某类型一定使用某拍法”只作试拍值，最终由 timing、spacing、峰值可读性与生成稳定性决定。

## 5. 五层同步检查

每一拍至少检查以下五层，不能只写前三层：

1. **主体层**：意图、感知、预备、发力、接触、过冲、恢复。
2. **表情层**：眼、眉、口、下颌、呼吸与身体意图同拍但可有延迟。
3. **关系层**：对手、听者、NPC 的知情、误读、反应幅度和任务保持。
4. **物理层**：手持物、衣发、碎片、风、地面、光影、声音的先后和接触证明。
5. **观看层**：画面所有者、证据释放、镜头/画层响应、尾帧继承与残留。

若一拍只有“角色冲过去/拔刀/很害怕/场景变黑”，判为抽象摘要，必须拆成姿势链和同步台账。主体动作占最大文字预算；删减时先删重复质感和不变背景，再顺序拆拍。

## 6. 节拍参考与证据边界

素材给出的帧数可作为起始试拍值：smear 约 1-2 帧、冲击 hold 约 2-3 帧、Q 版突变约 6-8 帧、三级颜艺按小步递进、反应波随距离延迟、静音先于重音、转场动作连续。这些数值必须结合项目帧率、动作尺度、媒介 cadence 和生成模型重算；它们不能替代动作意图、间距图和接触证明。

证据等级：

- **机制已采纳**：主体优先、全身表演、错时接力、主表现机制加少量接力、现实锚与残留。
- **候选节拍**：来自用户训练文档的数字示例，适合试拍和 SD 初稿，不作为绝对规则。
- **待核验事实**：具体作品镜头、原始帧率、声速/物理常数、精确时间码；只能留在上游研究登记。

## 7. 失败边界与返工顺序

发现以下任一问题，按顺序返工：

1. 主体动作只有一个抽象动词：补意图、触发、支点、路径、接触、过冲、落定。
2. 有动作没有表情或有表情没有身体：把脸、视线、呼吸与重心和手脚对齐。
3. 所有层同时动：指定主动作、感知延迟和物理延迟，给每层独立幅度。
4. 只有特效没有来源：从主体、道具、声源、光源或既有表面长出，写发展路径和回收。
5. NPC 复制粘贴：恢复任务差异、距离差和个体支点。
6. 关键峰值一闪而过：增加冲击 hold、反作用、声音延迟或尾帧。
7. 风格切换断身份：保留轮廓、识别色、道具、共同地面与动作方向。
8. 归模后全部消失：保留姿势、折痕、声音尾巴、空位、错位物或光影残痕。
9. SD 词只剩形容词：按 `入口 -> 发展 -> 峰值 -> 归还 -> 残留` 重写，并让 A2 主体字段占最大预算。
