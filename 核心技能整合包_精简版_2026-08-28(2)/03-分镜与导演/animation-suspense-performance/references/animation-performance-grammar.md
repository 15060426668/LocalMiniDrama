## 1. 姿势与受力

| 手法 | 执行锚点 | 适用 | 失败边界 |
|---|---|---|---|
| 关键姿势链 | 起始、预备、动作、峰值、过冲、落定六态可画 | 任何重要动作 | 只写动作名称，没有峰值和尾态 |
| Pose to pose | 先锁信息最清楚的关键姿势，再设计中间节奏 | 对话、悬疑、复杂身体动作 | 中割平均化导致每一帧都同样无力 |
| Straight ahead | 从力源连续推进形变和次级运动 | 失控、火烟、水、狂乱动作 | 角色比例和落点漂移 |
| Anticipation | 先给反向蓄力、视线或呼吸准备 | 跳、转、后仰、扑、突然大笑 | 预备过长提前泄露结果 |
| Squash and stretch | 体积感保持，压缩方向与拉伸方向对应受力 | 喜剧、宠物、情绪爆发 | 只拉脸，不改肩胯和重心 |
| Arcs | 头、手、髋、脚沿清楚弧线运动 | 自然动作、挥手、跌落、转身 | 机械直线让身体像平移图层 |
| Weight transfer | 支撑脚/臀部/手掌承重，重心越过支撑面 | 起身、跌倒、窗沿、碰撞 | 身体漂浮，没有支点 |
| Force chain | 力源、接触点、阻力、主运动、次级惯性、落定 | 撞击、抓取、推门、坠落 | 接触后各部位同时移动 |
| Overshoot | 主体到达目标后继续少量越界再回收 | 回头、甩手、大笑、急停 | 过冲幅度与速度无关 |
| Settle | 不同部位按重量先后回稳 | 衣发、长耳、裙摆、道具 | 所有层同帧停住 |
| Counterpose | 肩线、髋线、头部形成反向关系 | 克制、疲惫、扭转、关系表演 | 全身平行导致姿势僵硬 |
| Silhouette pose | 关闭内部细节仍能读出意图 | 大全景、低照度、群体戏 | 手臂贴身、轮廓相互粘连 |

## 2. 时间与间距

| 手法 | 执行锚点 | 心理效果 | 失败边界 |
|---|---|---|---|
| Timing | 决定动作占多少帧/秒 | 重量、决心、犹豫、突然性 | 只写快慢，没有动作阶段 |
| Spacing | 决定相邻姿势距离 | 加速、减速、冲击、悬停 | 均匀间距抹掉力量 |
| Slow in / slow out | 起止密、中段疏，或反向设计 | 柔和进入、蓄力、确认 | 所有动作都柔滑，失去断点 |
| Hold | 保持姿势，同时允许呼吸、眼睛或环境层变化 | 压力、等待、误读、余波 | 整帧死停，信息也停止 |
| Moving hold | 主姿势保持，局部线条、呼吸、衣发轻变 | 有生命的静止 | 局部变化过大抢走主姿势 |
| Stepped timing | 明确跳过中间位置，姿势阶梯式变化 | 紧张、喜剧、认知错拍 | 随机抽帧导致方向不清 |
| Burst on ones | 峰值短时提高绘制密度 | 冲击、甩动、坠落峰值 | 全段高密度导致重点消失 |
| Hold on twos/threes | 正常段使用较低绘制密度 | 有限动画、克制对话 | 关键接触仍低密度而糊掉 |
| Asymmetric cadence | A角色流畅，B角色保持或低帧 | 知情差、关系错位 | 帧率差没有叙事权限 |
| Pause before answer | 口型前加入视线、吸气或手部停顿 | 思考、撒谎、压制 | 每句话都停，节奏做作 |
| Delayed reaction | 触发先发生，反应按感知路径后到 | 真实认知、悬疑 | 角色对未感知信息提前反应 |
| Reaction suppression | 触发后保持原动作，只允许小泄露 | 社会伪装、冷漠、压抑 | 完全无可见变化，观众读不到 |
| Abrupt cut-off | 动作或声音在峰值前突然结束 | 失联、坠出、意识断开 | 没有尾部残留，像剪辑错误 |
| Aftermath hold | 高潮后让空间、物件或低幅反应持续 | 压抑、后果、道德距离 | 余波中又加入第二高潮 |

## 3. 面部、轮廓与身体

| 手法 | 可见设计 | 使用建议 | 失败边界 |
|---|---|---|---|
| Eye lead | 眼睛先到目标，头和身体后到 | 观察、试探、发现 | 每次都全头转向，缺乏层级 |
| Head-body lag | 头先转、肩后跟，或身体先走头停留 | 犹豫、留恋、警觉 | 颈部像断开 |
| Lid acting | 上下眼睑张力和闭合速度承担情绪 | 克制、疲惫、轻蔑 | 只用瞳孔缩放表达一切 |
| Pupil focus route | 对焦目标、失焦、重新聚焦 | 认知变化、抽离 | 无镜头尺度支撑的极细变化 |
| Mouth-shape residue | 台词或笑结束后保留半个嘴形 | 反应延迟、尴尬、冷漠 | 嘴形残留过久变成模型错误 |
| Jaw and throat | 下颌松紧、吞咽、喉部起伏 | 压住哭、恐惧、愤怒 | 所有压力都用咬牙 |
| Breath acting | 吸气、停顿、呼气改变肩胸腹 | 任何情绪转折 | 呼吸幅度与景别不匹配 |
| Shoulder rhythm | 肩膀弹跳、下沉、紧缩、错拍 | 大笑、哭泣、压力 | 只移动肩，不影响脊柱 |
| Spine phrase | 腰背、胸椎、颈部按顺序展开或压缩 | 前折、回弹、崩溃 | 整个躯干像硬板旋转 |
| Pelvis ownership | 髋部决定坐、站、转、坠的重心 | 全身动作 | 只动上半身，腿脚漂浮 |
| Hand intention | 手先试探、抓、压、放、悬停 | 道具、关系、支点 | 手是装饰性挥舞 |
| Foot direction | 脚尖先暴露心理路线 | 想走、想逃、想靠近 | 上身和脚意图矛盾却无叙事理由 |
| Shape language shift | 圆、尖、扁、长改变轮廓情绪 | 宠物、喜剧、主观层 | 角色身份在变形后无法恢复 |
| Off-model peak | 峰值允许短暂超出标准脸型/比例 | 强烈笑、怒、惊、冲击 | 峰值前后缺少正常模型锚点 |
| Snap-back | 峰值后快速恢复标准比例并留下残留 | 喜剧转现实、冲击落地 | 恢复过早削弱动作重量 |
| Asymmetry | 两侧眉眼、嘴角、肩线略有差异 | 复杂情绪、伪装 | 随机歪脸破坏身份 |

## 4. 有限动画与日本动画常用手法

| 手法 | 执行锚点 | 优点 | 失败边界 |
|---|---|---|---|
| Selective animation | 画面大部分保持，仅嘴、眼、手或风层移动 | 节省绘制并集中注意力 | 选择的移动层没有信息任务 |
| Held cel + camera | 人物姿势保持，摄影机或合成层移动 | 强化构图、主观压力 | 用无意义推镜掩盖表演空缺 |
| Mouth-flap economy | 口型数量受控，关键辅音/开闭口与节奏匹配 | 对话稳定 | 嘴持续开合而身体停死 |
| Eye-only beat | 身体保持，眼睛或眼睑完成一次信息转移 | 克制、怀疑 | 景别太远导致不可读 |
| Hand-only beat | 脸维持公开表情，手部泄露压力 | 社交伪装 | 手被构图遮住 |
| Key-pose dominance | 少量强姿势承担动作意义 | 有限动画、强表演 | 关键姿势轮廓不清 |
| Smear frame | 运动方向上拉伸、拖长、合并形体 | 快速甩动、回弹、转头 | 停留时间过长可见为畸形 |
| Multiple images | 同一肢体出现多个连续位置 | 高频震动、快速手势 | 方向和主位置不清 |
| Impact frame | 接触峰值使用高反差、简化或反色短帧 | 冲击、认知击穿 | 没有真实接触和后果 |
| Effect background | 现实背景短暂换为速度线、平面色、图形 | 主观夸张、喜剧、爆发 | 没有触发和回落锚点 |
| Graphic abstraction | 取消透视，保留关系、形状或动作 | 回忆、误读、天真层 | 抽象层承担了现实因果 |
| Line-weight burst | 峰值线条变粗、断裂或速度化 | 力量、失控 | 全段粗线导致基准消失 |
| Line boil | 静止轮廓轻微变化 | 焦虑、手绘生命感 | 所有物件同时抖动 |
| Shadow-mask acting | 阴影形状改变信息权限 | 压抑、遮脸、主观层 | 无光源或主观理由 |
| Background drift | 人物近稳，背景层缓慢偏移或失配 | 抽离、眩晕、错误现实 | 破坏空间连续性却无落点 |
| Cut-in insert | 极短眼、手、物件或嘴形切入 | 认知阈值、动作证据 | 重复使用成为视觉喊叫 |
| Model simplification | 远景或高速动作减少细节 | 保证轮廓和速度 | 近景仍简化导致身份丢失 |
| Bank/reuse variation | 重复动作保留基准，只改变一项状态 | 循环、关系重演、伏笔 | 完全复制导致机械重复 |

## 5. 反应与群体表演

| 手法 | 执行方法 | 悬疑用途 | 失败边界 |
|---|---|---|---|
| Reaction amplitude lock | 给每个角色0-10反应上限 | 防止自动升级 | 只写“平静”而无动作量 |
| Deadpan observer | 坐姿和任务保持，只抬手、抬头或转眼 | 大事件/低反应错位 | 完全静止变成漏画 |
| Uneven cascade | 最近者先停手，远者后抬眼，其他人继续 | 群体真实感 | 所有人同帧同步 |
| Performed normality | 继续说话、整理或工作，泄露点很小 | 社会恐怖 | 公开层和私人层像两个人 |
| Residual smile | 事件后嘴角或眼形仍保留上一状态 | 认知迟滞、冷漠 | 残留缺少时间边界 |
| Gaze handoff | A看事件，B先看A反应，再看事件 | 知识传播 | B直接知道画外事实 |
| Collective held pose | 群体因共同规则保持姿势 | 仪式、制度压迫 | 没有共同命令却同步 |
| One mover in group | 群体保持，唯一角色改变身体高度或路线 | 孤立、排斥 | 移动者没有关系意义 |
| Calm after rupture | 事件结束后恢复日常动作频率 | 压抑、残酷 | 立刻切走，没有余波 |
| Micro-copy reaction | 两三人用相似小动作回应，如都轻抬头 | 非人感、群体默契 | 完全一致像复制粘贴 |

## 6. 主观层与绘画系统变化

每次变化写：`权限所有者 -> 触发 -> 只改变的主变量 -> 峰值 -> 回现实锚点`。

### 视角所有权与美术所有权

主观层首先决定“谁在解释当前画面”，再决定画风怎样变化。同一地点和动作可以在不同观看者之间切换绘画证据：

```text
客观现实中的视线/接触/步伐
-> 眼睛、手或同构动作取得画面权限
-> 主观者重排颜色、空间纵深、材质细节或人物轮廓
-> 保留同一视线目标、手势、物件或运动方向
-> 他人/客观视角重新取得权限
-> 污渍、伤痕、杂物、真实距离、衣物重量和身体疲态重新出现
```

- 天真、美化或理想化视角可把空间压平、清理杂乱、提高光泽并把人物整理成可靠的完整轮廓。
- 客观、旁观者或受伤者视角负责归还现实材质和距离证据。
- 进入瞳孔必须先让目标人物的倒影可见，再由倒影的颜色、轮廓或光扩张为主观空间。
- 视角切换至少保留一个连续锚点：物件、手势、脚步、眼神、身体朝向、声音或几何轮廓。
- 主观美化表达观看者的理解，不改变客观事实、角色能力或事件结果。

可选主变量：

- 线条：粗细、断裂、速度笔触。
- 形状：压扁、拉长、轮廓简化。
- 帧密度：流畅、阶梯、短保持。
- 空间：取消透视、平面化、背景漂移。
- 色彩：由某角色/声音取得色彩所有权。
- 光影：阴影块吞没或释放局部信息。
- 细节：突然简化或过度清晰。

一次短节拍通常只让一个主变量越界。回落时保留一个动作、声音、接触、形状或物件作为连续锚点。

## 7. 声音驱动表演

| 声音关系 | 可见动画反应 |
|---|---|
| 关键词进入 | 眼神、手、口型、姿势或节奏中的一个先变 |
| 声音保持平稳 | 大事件可以发生，旁观者动作仍低幅 |
| 主声源换权 | 新主声源取得动作或剪辑所有权 |
| 突然撤走声层 | 保留room tone，身体进入更可读的静止 |
| 画外声接近 | 先改变听者的耳、眼、肩，再改变路线 |
| 失真或重复 | 角色先验证声源，再改变表演策略 |
| 声音尾桥 | 上一动作的情绪或节奏进入下一镜 |

## 8. 组合设计模板

### 压住的情绪

```text
正常任务 -> 关键词 -> 公开动作继续 -> 一处局部泄露
-> 过度补偿 -> 身体路线改变 -> 尾态保留公开表情残留
```

### 喜剧动作滑向灾难

```text
小幅笑 -> 笑形放大 -> 肩膀/脊柱/双手加入
-> 身体压缩 -> 连续回弹 -> 越过安全支点
-> 周围低幅反应 -> 环境恢复主位
```

### 大事件、低反应

```text
事件主体完成大动作
-> 旁观者保持坐姿/任务
-> 手停或抬几厘米
-> 下巴抬几度/眼睛转移/眨一次
-> 环境声持续
-> 空间尾帧停留
```

### 主观画风越界

```text
现实基准 -> 触发词/接触/认知
-> 单一变量越界 -> 动作峰值
-> 同一声音/手势/形状接回现实
-> 正常比例中的残留
```

### 自我叙述被他人目光修正

```text
客观空间中的小人物
-> 自我视角的完整/干净人物基准
-> 见证者取得观看权限并出现迟疑
-> 脚与支撑状态证据
-> 手与随身物件证据
-> 胸口/衣领/呼吸证据
-> 回到见证者脸确认意义
-> 大环境中的完整客观人物
-> 小物件保留理想自我残片
-> 环境余波
```

- 自我层可通过减少污渍、伤痕、衣物重量和空间杂乱表达角色尚未正视自身状态，不必进入明显幻想背景。
- 他人层按身体由低到高扫描，每个局部只增加一种新现实证据；扫描可在眼睛前停下，再用见证者反应完成情感判断。
- 完整客观人物最后出现，并让环境尺度远大于人物，形成认知合流而非单纯揭丑。
- 保留一个干净的小物件作为跨层锚点，使自我层、现实层和余波转场属于同一人物。

## 9. 动画化镜头突变

动画镜头突变不是给常规镜头套滤镜，而是让摄影投影、人物造型、背景层和动作节奏共同服从某一瞬间的叙事权限。

统一写法：

```text
叙事任务 -> 画面所有者 -> 触发 -> 投影/绘画主变量
-> 身体与重心 -> 背景/NPC/物件响应 -> 连续锚点 -> 落地帧
```

| 算子 | 触发与执行 | 身体/背景耦合 | 回落锚点 | 失败边界 |
|---|---|---|---|---|
| 恐慌广角/鱼眼夺权 | 角色被逼近、后退或认知失控时，近处脸、手或脚被夸大，边缘空间弯曲，消失点压向角色 | 头颈后缩、肩胯错位、支撑脚迟疑；门框、桌边或地面线向压力源汇聚 | 角色抓住物件、脚落地、视线重新对焦 | 只做镜头畸变，身体仍像正面立绘 |
| 强制透视全身动作 | 动作意图先由前景手脚进入，躯干和脸后到；近端肢体放大，远端压缩 | 手脚路线、髋部转移和接触点必须可读 | 接触、越过支点或完成路线后的正常比例姿势 | 只有“大手大脚”，没有受力或空间目标 |
| 尺度断裂 | 从群体/空间中的小人物突然切到眼、嘴、手、物件极近景，再落回更远空间 | 极近景只让一个感觉或证据独占画面 | 同一声音、手势、物件或视线 | 连续切近只增加刺激，不增加信息 |
| 摄影机-身体共振 | 身体冲击、急退、扑近或回弹成为摄影机位移/倾斜的力源 | 摄影机反应晚于或同步于主力峰值，次级材质继续过冲 | 支点恢复、画面水平线重新稳定 | 手持乱晃与动作无因果关系 |
| 几何空间挤压 | 社会压力或恐惧升高时，门框、桌椅、走廊线、前景身体逐步缩小主体可用空间 | 主体身体高度下降、路线变窄，群体或物件不必移动很多 | 出口、空位、桌边或门槛 | 只把人物放角落，没有逐步改变可行动空间 |
| 层速度错位 | 人物保持或阶梯移动，背景/图形/前景以不同速度滑动 | 速度差必须表示抽离、眩晕、执念或时间跳变 | 脚步、呼吸、重复物件或固定地平线 | 无叙事权限的视差炫技 |
| 线条系统替换 | 接触峰值或认知击穿时，正常轮廓短暂变成粗黑笔触、断线或速度墨块 | 力源和运动方向决定笔触方向 | 接触结果、正常比例中的伤痕/喘息/姿势残留 | 全段粗线，基准与峰值不可区分 |
| 细节权限切换 | 主观自我删除污渍、重量和杂乱；见证者或客观层逐项归还细节 | 同一姿势和物件保持，只有现实证据增减 | 手势、脚步、衣物、随身物件或视线 | 直接切“漂亮版/脏版”，没有观察路径 |

短节拍通常只让一个投影或绘画主变量越界。若同时需要透视、线条、色彩和帧密度变化，按触发顺序拆成连续阶段，不能同帧全部爆发。

## 10. 图形层侵入现实

图形层有四种不同权限，必须先选一种：

| 模式 | 执行 | 叙事用途 | 必留证据 |
|---|---|---|---|
| 完整替换 | 现实背景退出，人物进入平面色、星光、白场或插图空间 | 说明、回忆、纯主观想象 | 同构动作、物件、视线或声音 |
| 边界侵入 | 图形线、星光、色块或触手从角色/物件发出，穿过真实桌椅、门框和人物 | 欲望、误读或关系压力开始夺权 | 真实空间几何和接触关系 |
| 材质污染 | 图形层接管色彩与气氛，但血迹、污渍、伤口、破损或物件重量继续存在 | 天真解释与客观后果同时出现 | 至少一种不可消除的现实材质 |
| 假性净化 | 主观层删除杂乱和伤痕，把人物整理得完整、轻盈、可靠 | 自我叙述、理想化、否认 | 下一视角逐项归还现实证据 |

侵入过程写清：

```text
来源角色/物件 -> 第一条图形边界 -> 覆盖路径 -> 哪些现实层被遮住
-> 哪些证据坚持可见 -> 主观动作如何继续 -> 谁夺回画面 -> 剩余残迹
```

图形层越明亮可爱，越需要明确它属于谁的理解。可爱色彩本身不等于安全、善良或现实改善。

## 11. 环境、物件与群体共同表演

### 11.1 群体拓扑

群体关系优先通过以下变量改变，而不是靠反应特写宣布：

- 谁处于桌椅、人墙或镜头中心形成的闭环内。
- 谁被前景身体、椅背、门框或物件遮断。
- 谁改变身体高度、朝向、路线或与群体的接触通道。
- 目光和物件传递从谁转向谁。
- 群体是否继续原任务，只让一人停顿或移动。

关系转移链：

```text
原中心/边缘 -> 一人发声或行动 -> 最近者先换视线
-> 身体朝向和物件通道改指新目标 -> 原边缘者进入圈内
-> 新目标被遮挡、挤出路线或成为唯一运动者 -> 群体恢复日常频率
```

### 11.2 环境反表演

- 美丽天空、夕阳、花、蝉声和明亮教室可以保持正常，拒绝替人物悲伤。
- 风、雨、云、树影、路灯和机器声可在人物离场后继续，取得余波所有权。
- 环境变化必须继承一个人物残留：小物件、空位、污迹、门缝、声音尾巴或未完成动作。

### 11.3 物件剪辑

物件可承担四种任务：

1. 证据平面：鞋、手、衣领、包、地面痕迹逐级修正观众认知。
2. 动作支点：手抓、脚踩、身体靠住后改变受力和选择。
3. 转场锚点：圆形、星形、花、时钟、门、照片或接触轮廓跨空间保留。
4. 道德见证：事件后物件仍在原位，人物和群体已离开或恢复日常。

物件特写必须改变下一镜的信息、行动或关系。只说明“这里有这个物件”不构成动画叙事。

## 12. 关键段落验收模板

一个重要动画节拍不能只回答景别和正反打。至少回答：

```text
现实基准是什么？
谁拥有画面解释权？
触发来自台词、视线、声音、接触还是物件？
哪一个动画变量越界：透视、形体、线条、背景、色彩、帧密度、细节或尺度？
越界怎样进入脸、肩脊、髋、手脚和重心？
环境、物件和NPC是响应、误读、继续日常还是保持？
保留哪个现实锚点证明因果仍连续？
高潮后谁取得画面：人物、物件、群体还是环境？
尾帧留下什么后果，下一镜如何继承？
```

判废条件：关键情绪阈值只有“中景对话 -> 近景反应 -> 反打”，没有画面权限变化、身体动作峰值、群体/环境调度、物件因果或余波中的任何一项。

## 13. 构图即观看权限

动画悬疑构图先决定观众被放在谁的位置，再决定景别。摄影机不是默认中立：它可以属于偷看者、群体、孩子、权威、被排斥者、物件见证者或不介入的环境。观看位置一变，同一人物的比例、遮挡、材质和完整程度都可以改变。

### 13.1 九格构图控制卡

关键段落先填完：

```text
画面所有者：谁的观看方式决定当前画面？
第一眼信息：观众不思考就先读到什么？
第二眼发现：停留半拍后才发现什么？
扣留信息：当前故意不让观众看全什么？
前景障碍：门缝、身体、桌椅、栏杆、窗框或物件怎样限制观看？
关系几何：人物间的高低、距离、朝向、闭环、出口和空位是什么？
局部证据链：脚/支撑 -> 手/物件 -> 衣领/呼吸 -> 见证者反应，实际选哪些？
大全景判决：完整人物或完整空间何时出现，它最终判定什么？
环境余波：人物失去画面后，什么日常环境和残留证据继续？
```

### 13.2 局部不是装饰，是证据释放

局部镜头按因果增量排列，每一格只增加一种新事实：

| 局部 | 优先证明 | 可改变的前一镜含义 |
|---|---|---|
| 脚与支撑 | 身体能否站稳、是否被困、是否正准备离开 | 把“平静站立”改读为勉强支撑或逃跑前态 |
| 手与物件 | 求助、隐瞒、责任、所有权、压力泄露 | 把公开微笑改读为用力维持或不敢介入 |
| 衣领、胸口、呼吸 | 身体成本、疲态、伤势、压住的情绪 | 把沉默改读为承受而非空白 |
| 见证者反应 | 谁理解了证据，理解到什么程度 | 给前述局部赋予社会或道德意义 |
| 完整全身 | 真实尺度、距离、狼狈程度、关系结果 | 结束局部猜测，形成客观判决 |

证据链不必机械走完五步；保留能逐项修正认知的最短链。连续两个局部若只重复“她很难过”，合并或删除。

### 13.3 完整画面延迟与大全景判决

- 开场建立空间不等于必须立即交代完整空间。先给门缝、脚、手或见证者，可以让观众被迫从有限位置理解事件。
- 完整人物越晚出现，越像客观事实夺回画面；但必须有局部证据和连续锚点，不能无因硬藏。
- 大全景不是廉价空镜。它应判定至少一项：人物在群体中的位置、帮助是否可达、权力尺度、坠落高度、空间责任、离开路线或后果不可逆。
- 判决完成后，不再立刻切回同义脸部特写解释一次。让环境、空位、物件或低幅旁观反应接手。

### 13.4 压迫来自关系几何

| 几何载体 | 可见执行 | 压迫含义 |
|---|---|---|
| 门缝/门框 | 只允许一只眼、半张脸或身体局部进入 | 未获许可的观看、家庭边界、无法介入 |
| 成人腿/群体身体 | 前景高大截断，孩子或弱者落在缝隙或画面下沿 | 权威先以尺度存在，脸可以延迟出现 |
| 桌椅/家具网格 | 横竖线切割身体，出口被桌角或椅背占用 | 日常空间变成制度或群体的笼子 |
| 栏杆/窗格 | 重复竖线压缩活动区，外部仍明亮 | 可见自由与实际不可达并存 |
| 道路分叉/走廊分流 | 人物路线从共同方向裂成单独方向 | 关系变化直接成为空间选择 |
| 空位/巨大负空间 | 缺席者的位置清楚，其他人保持日常尺度 | 环境承认缺席，但不替人物悲伤 |

### 13.5 可调用的压抑构图链

```text
有权限限制的局部起手
-> 第二证据修正第一印象
-> 见证者或群体反应给证据定性
-> 完整人物/空间迟延出现并判定关系
-> 美丽或普通环境继续原节拍
-> 空位、物件、污迹、未完成动作或声音尾巴留下后果
```

另一条适合家庭或权威场景：

```text
门外/地面/孩子高度的观看位置
-> 成人先以腿、手或阴影进入
-> 家具与门框切断可达路线
-> 台词仍属日常，身体高度和距离先说明权力
-> 最后才给完整房间，空间替角色宣布谁被困住
```

### 13.6 镜间变化验收

每次切镜至少改变一项：

- 观看者。
- 新增证据。
- 被扣留信息。
- 主体尺度。
- 人物高低、距离、朝向或可达路线。
- 前景遮挡或画框权限。
- 动作支点、物件所有权或身体后果。
- 环境是否取得余波所有权。

仅改变角度、焦段或表情大小，信息和关系完全不变的镜头属于覆盖性废镜。动画炫技、鱼眼、颜艺和图形层只能放大已经成立的观看权限，不能替代这条构图链。
