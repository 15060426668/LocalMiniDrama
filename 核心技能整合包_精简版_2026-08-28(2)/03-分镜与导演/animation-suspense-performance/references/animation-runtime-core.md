# 动画运行核心 v6

本文件是普通动画任务唯一必读参考。它把表演、动画表达、全画面运动、连续性与下游交接压在同一条因果时间线上。长篇图谱只在路由命中专项时读取，不得为了“更保险”重复加载。

## 1. 先锁任务，不先堆镜头

只导入导演事实锁：事件因果、知情与误读、角色/物件位置、轴线和世界方向、时长、对白时间、必须出现的证据、入口状态与尾态。事实锁不可被动画炫技改写。

先写一句动画视觉命题：

```text
关系或情绪怎样变化
-> 哪个可见变量取得画面
-> 主体怎样用动作触发
-> 环境/物件/声音怎样接力
-> 现实以什么新状态收尾
```

普通日常可以保持现实法则，但仍需有动作与环境的状态变化。关键表现段先设计 `4-7` 个视觉状态；每一态至少改变动作阶段、观看权限、空间关系、材质/媒介、群体关系、声音或后果之一。禁止只换景别、滤镜或特效名称。

## 2. 主体动作是最大信息预算

每个主要动作使用八槽因果链，按实际动作合并相邻槽，但不可漏掉关键因果：

```text
1 意图与感知：想做什么，看见/听见/误读了什么
2 支点与预备：承重脚/手/座面，呼吸、反向蓄力、视线先行
3 发力与传导：力从脚/髋/脊柱/肩/肘/腕怎样传递
4 路径与间距：身体、手脚、道具沿什么弧线，怎样加减速
5 接触与阻力：先碰哪里，摩擦、重量、压缩和反作用怎样出现
6 峰值与过冲：关键姿势、smear/冲击帧、身体和道具越界多少
7 回弹与恢复：谁先停、谁延迟，怎样归模或有意保持离模
8 尾态与继承：新支点、视线、距离、持有关系、残留和下一拍起点
```

“走、跑、打、抱、拔刀、害怕、犹豫、看向”只是动作标题，不是可执行动作。必须补齐当前节拍真正发生的姿势、受力、时序和结果。

### 2.1 脸、身体与支点同步

- 眼睛可先于头，头可先于肩；呼吸、下颌、喉部、肩脊、骨盆、手脚各有提前或延迟，不能同帧齐动。
- 公开表情和私人泄露可分轨：人物继续任务，眼睑、指尖、脚尖、吞咽或过度补偿泄露真实意图。
- 关键姿势关闭五官细节后，轮廓、重心和手脚路线仍应可读。
- Moving hold 不是死帧：主体姿势保持时，呼吸、眼睑、线沸腾、衣发、物件、环境或听者仍执行低幅任务。

### 2.2 临界接触 B12

“想碰又不敢碰”必须可见：确认对象和对方知情状态 -> 支点或躯干微靠近 -> 手从肩/肘启动 -> 指尖接近临界距离 -> 视线、呼吸或手指泄露犹豫 -> 停住、绕开、撤回，或获得允许后触碰。若触碰，补重量、受力和接触后状态；若未触碰，空隙本身必须在构图中可读。

### 2.3 五层同步

每个时间窗同时核对：

1. 主体：意图、感知、姿势、支点、路径、接触、恢复。
2. 表情：眼眉口、下颌、呼吸与身体意图的错时关系。
3. 关系：对手、听者、NPC 的知情、误读、独立任务和反应幅度。
4. 物理：道具、衣发、碎片、风、表面、光影、声音的延迟与后果。
5. 观看：画面所有者、证据释放、镜头/画层响应、尾帧继承。

## 3. 动画表达只选一个主引擎

表现段先比较三类候选：身体驱动、物件驱动、环境驱动。用新颖度、因果性、静音可读性、接力连续性、情绪精度和生成可行性筛选一个主引擎，最多借一个辅助算子。普通段不强行离模。

主引擎统一写成：

```text
现实基准 -> 可见触发 -> 第一处越界 -> 发展路径
-> 主体/关系层参与 -> 峰值换权 -> 归还锚点
-> 现实后果 -> 残留/下一镜接力
```

可用变量包括形体、线条、帧密度、空间、时间、物理、色彩、光影、图形层、声音文字、群体拓扑和媒介。短节拍通常只允许一个主变量越界；其他效果必须继承它的形状、方向、节奏、色彩、材质、声音或观看权限，不能并排贴效果。

### 3.1 特效证据预算

特效可以遮脸、遮身体、碎屏、切割、花屏、闪白，甚至短暂夺走主体，但每个时间窗必须锁定：

```text
当前画面所有者
必须读懂的一项主体证据：意图/支点/方向/脸/手/接触/结果
允许遮挡什么、遮多久
效果从哪个身体/物件/声源/现实表面进入
何时把画面还给哪项证据
遮挡后留下什么物理、空间、声音或意义残留
```

效果的末端必须成为下一效果或现实动作的起点。高潮后不清空一切；至少留下姿势、空位、污迹、裂纹、错位物件、声尾、光痕或同形转场。

### 3.2 帧法所有权

每次换拍说明谁拥有时间：主体、衣发/道具、环境、真人底片、回忆层或故障层。先按 timing 与 spacing 设计姿势，再决定一拍一/二/三、hold、阶梯帧或短爆发；固定帧数只作试拍值。高速不等于随机抽帧，慢动作不等于全层同速。

### 3.3 歌词与意识流转译

歌词和抽象概念只留在上游节奏/意义表，不进入视频模型提示词。下游只接收：

```text
当前可见事实 -> 普通身体/物件/环境/影子/声音载体
-> 主体动作触发 -> 连续变形或换权过程
-> 现实锚 -> 新关系/新意义 -> 残留与下一镜接力
```

不得逐句贴图，也不得把“孤独、自由、迷茫”直接当动作。记忆或心理层进入后，必须由当前现实中的动作、接触、物件、声源或视线归还。

## 4. 全画面运动生态

### 4.1 NPC、道具与环境

- NPC 按距离、知情路径和当前任务错峰反应：近者先停手/换视线，中层让路或误读，远层晚拍理解或继续日常；禁止全员同帧同幅度。
- 道具必须有持有者、原任务、材质、接触点和新状态。物件特写必须改变下一镜的信息、行动或关系。
- 环境不必配合人物情绪。风、雨、晨光、蝉声、机器和人流可保持正常，并在人物离场后接管余波。
- 同一风场中的头发、衣角、纸张、树叶和重物按受风面积、质量、固定方式与距离产生不同幅度和延迟；禁止整幅同速摆动。
- 次级运动遵循主体先、轻层后、远层更晚；停止时重层先落，轻层继续过冲再回稳。

### 4.2 光影、声音与接触证明

- 声音写声源、距离/遮挡、出现时序、身体或物件可见反应、尾音/声桥。关键词、脚步、敲击、断声可取得剪辑或画面权限。
- 光影变化必须有现实光源或明确主观所有者。光可夺取注意力，但要保留方向、表面与恢复锚点。
- 接触影是动作：脚底压实、手掌按下、身体坐下时收紧/加深/随支点移动；分离时先变软再拉开。它必须与真实表面、主体受力和接触声音同拍，不能是贴在脚下的静态黑块。

### 4.3 2D主体进入真人底片

并行锁定两层：

```text
真人底片：地平线、透视、摄影机路径、景深、光向、颗粒、真人NPC路线
2D主体：身份、比例、粗糙断续线、平涂/阴影块、阶梯曝光、允许离模范围
跨媒介：支点、遮挡交换、视差、动态接触影、反射、真实材质后果
双层尾态：底片尾态与2D尾态分别继承
```

主体可位于远、中、近景，不自动站前景。至少一次与真人/实物交换前后遮挡，或让真实物件对接触产生可见后果。线沸腾、粗线与选择性分拍证明其为2D；真实光照方向、接触和深度关系让其属于现场。发光描边不能代替融合证据。

## 5. 摄影机与主体共用一条物理连续线

普通镜头写清开始构图、主体屏幕方向、摄影机响应原因和落点。环绕、越顶、贴地拉升、俯冲、穿遮挡、连续变焦或身体化 POV 必须展开：

```text
开始机位：高度/方位/距离/景别
世界锚：地平线、消失点、门窗、道路或固定几何
主体锚：朝向、支点、目标、运动方向
摄影机路径：围绕谁，经过哪些高度、方位和遮挡
双重运动：摄影机与主体各自速度、转向和角度
遮挡连续：进出遮挡的尺度、屏幕方向、视差和焦点
落点：最终机位、景别、画面所有者、主体与影子尾态
```

可有意越轴，但越轴过程必须可追踪，或在俯视、POV、共同目标、遮挡节点后重建方向。角色自转、背景滚动或抽象“镜头旋转”不能冒充环绕。没有落点的运镜视为未设计完成。

## 6. 一行运动台账

每个连续时间窗使用一行；复杂动作按因果拆行：

```text
[时间] 画面/时间所有者 | 主体任务与八槽进度 | 脸/呼吸
| 支点/重心/手脚 | 接触/次级材质 | 对手/NPC
| 道具/环境力 | 声音/光影/线条 | 摄影机路径与落点
| 结果、残留、下一拍继承
```

先写主体，主体字段占最大文字预算。压缩时先删不变背景和重复质感形容词；若动作、表情、接触和尾态装不下，拆时间窗，不得删因果。

### 6.1 16-30秒单段架构

时间所有权统一遵循 `../../director-storyboard-integrated/references/animation-production-pipeline.md`。本层只补动画执行：不在15秒重启动作基准或画面法则；继续按自然2-4秒窗口写台账；后半段继承支点、视线、道具、环境力、绘画状态、摄影机落点和声尾；额外时间优先给准备、听者反应、后果和恢复。

## 7. 输出与下游边界

按任务规模输出，不强迫每次展开全部研究过程：

- 快速单拍：事实锁 + 动画视觉命题 + 逐拍台账 + 尾态。
- 正式动画分镜：事实锁、视觉命题、候选筛选摘要、状态图、逐镜设计、关键逐拍台账、连续性与风险审计。
- 表演字段保持可识别：`表演任务`、`知情/误读权限`、`四项强度`、`正常基准`、`触发`、`关键姿势链`、`时间与间距`、`脸部与口型`、`身体/重心/手脚`、`次级运动`、`动画镜头突变`、`环境/物件/NPC表演`、`声音触发`、`恢复与尾帧`、`SD承接锚点`。

动画技能只交付可见动作、画面机制、运动台账和连续性锁。最终视频提示词由 `dream-suspense-sd` 编译为纯文本 `BASE LOCK + 五字段A区块`。JSON只用于内部验证，永不作为用户交付。歌词原句、训练作品名、来源名、评分、审核码和内部索引不进入模型载荷。

## 8. 硬伤门

出现任一项即返工：

- 抽象动作摘要，或有动作无表情/支点/接触/尾态。
- 只顾主体，遗漏对手、NPC、道具、环境、声音或光影的必要响应。
- 特效与动作无触发、无接力、无归还、无残留，或用特效遮盖动作错误。
- 复合运镜无世界锚、独立摄影机路径或最终落点。
- 接触没有重量、阻力、反作用和接触后状态。
- 同一风场所有物体同幅同速，或接触影静态粘贴。
- 2D主体像贴纸：无支点、遮挡交换、视差、动态影或材质后果。
- 歌词原句进入视频提示词，或意识流画面没有现实入口和归还锚点。
- 输出用户侧JSON，或让镜头之间丢失方向、姿势、物件和尾态。
