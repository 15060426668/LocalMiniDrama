## 1. 四轴强度模型

把以下四项分别记为 `0-10`，不要默认同步升高：

| 变量 | 问题 | 可见载体 |
|---|---|---|
| 事件强度 E | 客观发生了多大的事 | 位移、碰撞、坠落、物件状态、空间后果 |
| 内在情绪 I | 角色实际承受多少 | 呼吸、支点、肌肉张力、动作策略 |
| 公开表情 P | 角色允许别人看到多少 | 社交脸、语气、姿态、继续执行的日常任务 |
| 可见反应 R | 镜头实际给观众读到多少 | 眼、手、头、身体高度、路线和动作延迟 |

常用错位：

- `E高 / R低`：重大事件发生，旁观者只轻抬手、抬头、转眼或眨一次。
- `I高 / P低`：角色承受强烈压力，仍保持礼貌、微笑或正常作业。
- `P高 / I低`：夸张社交表演、假热情、群体起哄或故意演给别人看。
- `E低 / I高`：一个词、物件或停顿触发私人崩塌，外界仍属日常。
- `P高 -> 0`：动作还在惯性中，公开表情突然失去维持力。
- `R延迟`：触发先到，角色在看到他人、听到第二声或感到物理后果后才反应。

每个节拍先锁四轴，再设计姿势。只写“平静”“震惊”“崩溃”不算完成。

## 2. 基准、裂缝与越界

压抑悬疑表演先建立可重复的正常基准：

```text
正常任务循环
-> 一个词/声音/接触进入
-> 循环中只有一个变量错拍
-> 角色试图修正或掩盖
-> 错拍扩展到身体路线
-> 结果落定
-> 世界或群体恢复原频率
```

正常基准至少回答：

- 身体高度、支撑面、朝向和常用手。
- 说话、听话、写字、吃饭、走路或整理物件的正常节拍。
- 眼神通常先到哪里，头和身体跟随多快。
- 头发、衣物、长耳、挂件或道具的正常延迟。
- 群体正常任务与谁拥有注意力。

裂缝一次只优先占用一个载体：口型停住、笑形残留、手指加压、脚尖转向、呼吸断拍、眼神错过目标、身体高度下降、动作循环漏一步。其余层先维持基准，裂缝才可读。

## 3. 单人表演机制

| ID | 机制 | 动画执行链 | 适用 | 失败边界 |
|---|---|---|---|---|
| SA-01 | 公开正常、私人泄露 | 正常任务 -> 关键词 -> 社交脸保持 -> 手/脚/呼吸先变 -> 补偿动作 -> 尾态残留 | 社交压力、撒谎、被排斥 | 公开层和私人层像两个无关人格 |
| SA-02 | 动作惯性越过情绪 | 大笑/挥手/说话已启动 -> 情绪发生变化 -> 身体仍沿原弧线前进 -> 表情在动作中失去维持 -> 落到新结果 | 温馨转危险、喜剧转灾难 | 先停住再换表情，动作被切成两段 |
| SA-03 | 笑形残留 | 笑声结束 -> 肩部先停 -> 嘴形保留半拍 -> 眼睛先失焦 -> 下颌和嘴角最后回收 | 认知迟滞、冷漠、错位 | 残留没有明确结束点，像模型卡帧 |
| SA-04 | 身体路线背叛台词 | 嘴仍说肯定句 -> 脚尖先对准出口 -> 髋和肩逐级跟随 -> 台词结束后才移动 | 礼貌恐惧、想逃离 | 全身同帧转向，私人泄露过大 |
| SA-05 | 过度补偿 | 小泄露被意识到 -> 笑更大/动作更勤快/语速更稳 -> 补偿超过正常基准 -> 身体控制在尾部失败 | 强装轻松、群体迎合 | 一开始就夸张，没有被掩盖的前态 |
| SA-06 | 支点寻找 | 冲击进入 -> 膝、髋或脊柱先失去稳定 -> 手寻找桌沿/墙/衣物 -> 接触承重 -> 呼吸重新组织 | 恐惧、眩晕、崩溃 | 手碰物件却不承担重量 |
| SA-07 | 动作循环腐坏 | 重复写字/整理/擦拭 -> 每轮只变一项间距或力度 -> 漏掉一步 -> 突然停住或把对象弄坏 | 强迫、压抑、被念头占据 | 每轮变化太多，观众无法比较 |
| SA-08 | 延迟理解 | 触发出现 -> 原任务继续 -> 看见他人反应/第二证据 -> 手先停 -> 眼神重新定位 -> 身体选择 | 悬疑揭示、群体信息传播 | 对角色未感知的信息提前表演 |
| SA-09 | 选择性冻结 | 主姿势保持 -> 只让呼吸、眼睑、手指或材质层移动 -> 一项运动停止 -> 注意力被锁定 | 等待、压制、恐怖余波 | 整帧完全不动，画面没有生命 |
| SA-10 | 高峰离模、立即归模 | 正常比例 -> 预备 -> 峰值短暂压扁/拉长/粗线 -> 过冲 -> 恢复标准比例 -> 保留喘息、泪痕或姿势残留 | 笑、怒、冲击、宠物表演 | 离模全段持续，身份无法恢复 |
| SA-11 | 未完成的帮助动作 | 手抬起 -> 在接近目标前停住 -> 指形或腕角改变 -> 手回到自己任务或停在半空 | 道德犹豫、冷漠、群体压力 | 手势没有目标距离，意义模糊 |
| SA-12 | 声音夺取身体 | 环境声/关键词进入 -> 口型或当前动作被截断 -> 耳眼肩依次转向 -> 重心和路线后到 | 画外威胁、主声源换权 | 声音与可见反应无因果顺序 |
| SA-13 | 恐慌透视夺权 | 正常空间 -> 压力源进入 -> 近端脸/手/脚放大 -> 边缘空间弯曲或汇聚 -> 身体支点失稳 -> 抓住现实锚点回正 | 惊恐、逼近、后退、失控 | 只有镜头畸变，身体和背景不响应 |
| SA-14 | 尺度击穿与回落 | 群体/空间中的小人物 -> 单一局部极近景 -> 一项认知或材质独占 -> 硬切/动作锚点回远景 | 认知阈值、羞耻、死亡确认 | 连续切近只为了刺激 |
| SA-15 | 图形层侵入现实 | 图形从角色/物件边界发出 -> 穿过真实空间 -> 接管色彩/线条 -> 现实证据仍保留 -> 他人或后果夺回画面 | 天真误读、欲望、错误幸福 | 图形层把现实因果全部擦掉 |
| SA-16 | 见证者证据扫描 | 见证者迟疑 -> 脚/支撑 -> 手/物件 -> 衣领/呼吸 -> 回见证者脸 -> 完整客观身体 | 自我否认、伤势、道德确认 | 一刀切出全身惨状，观众没有修正过程 |
| SA-17 | 材质型哭泣升级 | 正常脸 -> 眼眶湿润 -> 泪液附着/拉丝/下坠 -> 鼻口与下颌失控 -> 双手接触脸或对象 -> 过曝/极近景峰值 -> 呼吸与身体回落 | 告别、悔恨、求助 | 只放大泪珠，不改变口、下颌、呼吸和手 |
| SA-18 | 环境接管余波 | 人物动作结束/离场 -> 小物件或空位保留 -> 环境声和自然力继续 -> 尺度拉远 -> 下一场继承天气/光/声音 | 死亡、告别、社会冷漠 | 余波空镜漂亮但没有人物残留 |
| SA-19 | 声层撤走后的空间判决 | 动作峰值/关键词结束 -> 音乐与密集人声撤走 -> 保留room tone或单一机械声 -> 空场/物件取得画面 -> 后果延迟进入 | 暴力余波、死亡确认、情绪消失 | 把所有声音剪成绝对静音，空间失去材质和位置 |
| SA-20 | 同构动作跨解释层 | 现实接触/步伐/运动方向建立 -> 主观层改写颜色或介质 -> 同一动作轮廓继续 -> 客观层归还材质和重量 -> 落到同一接触点 | 回忆、误读、时间重写、理想化反转 | 主观层换了动作方向或位置，像无关MV |
| SA-21 | 道具清单化因果升级 | 第一件物件落地/被握 -> 下一物件改变行动选择 -> 每件只增加一项危险或知识 -> 手脚与目光跟随 -> 最后一件物件触发决定 | 暴力预备、秘密暴露、侦查、愿望因果 | 连续物件特写只是列清单，不改变下一步动作 |
| SA-22 | 重复基准微改 | 先前镜头顺序和环境基准复现 -> 只改一项人物关系/物件状态/路线 -> 观众完成比较 -> 新时间线或新关系继续 | 时间重置、关系反转、创伤残留 | 完全复制旧镜头且没有可比较差异 |

## 4. 群体与旁观者机制

### 4.1 反应幅度等级

| 等级 | 可见动作上限 | 适用 |
|---:|---|---|
| 0 | 保持任务与姿势，只保留呼吸或材质微动 | 故意不承认、画面低优先层 |
| 1 | 眼睛转移、一次眨眼、手停或抬几厘米、下巴抬几度 | 大事件低反应、冷漠旁观 |
| 2 | 头部转向、上身轻移、手离开原任务但不站起 | 察觉但不介入 |
| 3 | 坐姿明显改变、身体前倾/后撤、物件动作中断 | 关注、犹豫、评估 |
| 4 | 站起或后退一步，仍未进入事件中心 | 轻度介入或自保 |
| 5-6 | 接近、阻挡、扶持、追问，成为次级行动者 | 明确介入 |
| 7-8 | 奔跑、扑救、强烈喊叫、全身冲击反应 | 高度紧急且剧情批准 |
| 9-10 | 群体失序、逃散、同步爆发或极端变形 | 灾难、仪式、系统级刺激 |

事件强度不会自动提高这个等级。用户或正式分镜锁定 `R=1` 时，禁止自行补出起身、扑救、尖叫和同步震惊。

### 4.2 群体机制

| ID | 机制 | 调度与表演 | 悬疑作用 |
|---|---|---|---|
| GA-01 | 不均匀级联 | 最近或最警觉者先停手，第二人先看第一人，第三人仍继续任务 | 让信息按路径传播 |
| GA-02 | 集体正常化 | 多数人继续聊天、写字、收拾，只允许少数局部泄露 | 把异常变成群体默认 |
| GA-03 | 唯一运动者 | 群体保持姿势和节拍，只有一人改变高度、方向或路线 | 画出孤立和排斥 |
| GA-04 | 反应错因 | 旁观者看见后果，却把原因理解成玩笑、笨拙或普通事故 | 延迟道德和悬疑确认 |
| GA-05 | 残留同步 | 事件后两三人保留上一句的微笑、口型或手势残留，再以不同延迟恢复 | 制造平静的不适感 |
| GA-06 | 未共享知情 | A知道、B怀疑、C无知；三人的眼神、任务和反应幅度不同 | 防止群体同帧同反应 |
| GA-07 | 任务优先 | 旁观者先保护自己的手机、书本、座位、队列或社交位置 | 把社会关系写进动作选择 |
| GA-08 | 余波恢复 | 主事件落定后，群体以原频率继续任务，只留下一个停顿者或空位 | 强化世界没有停下来 |
| GA-09 | 社交几何迁移 | 目光、身体朝向、物件通道和遮挡逐步从旧对象改指新对象 | 不用对白画出孤立对象转移 |
| GA-10 | 前景权限封锁 | 同学、椅背、门框或成人身体占据前景，只留缝隙给主体 | 表现谁能被看见、谁被群体吞没 |
| GA-11 | 单人高度突变 | 群体保持坐姿/站姿，唯一角色蹲下、站起、后退或跌出共同高度 | 让关系变化在静音状态可读 |
| GA-12 | 物件优先传播 | 笔、书包、纸张、手机或座位先改变所有者/方向，目光和身体随后跟进 | 用物件路径传播权力和知情 |

### 4.3 低反应写法

不要只写“旁边的人很平静”。写成：

```text
坐姿保持，髋和脚仍在原位；右手从桌面抬起三到五厘米后停住；
下巴轻抬，眼睛先越过桌沿看向事件位置；一次眨眼后嘴形仍保留上一句的微笑；
没有改变座位关系，环境任务在尾帧继续。
```

## 5. 压抑悬疑组合模板

### 5.1 正常交流突然失去支点

```text
正常坐姿与聊天节拍
-> 公开笑形扩大，双手和脊柱加入
-> 身体前折压缩
-> 回弹沿原动作弧线向后
-> 重心越过支撑面
-> 手脚来不及重新建立支点
-> 人物离开构图或落到新高度
-> 旁观者保持R1级反应
-> 环境声和日常动作继续
```

关键：情绪变化发生在连贯动作内部；不要插入“突然阴沉特写”把动作切断。

### 5.2 温馨表演逐步变得不正常

```text
可爱/轻松的动作循环
-> 第一轮愿望或帮助获得良好结果
-> 相同动作在后续重复
-> 中间因果开始出现不协调残留
-> 角色仍沿用原来的快乐姿势和语气
-> 后果越来越重，反应却滞后
-> 某次结果终于迫使动作基准改变
```

恐怖来自同一善意动作在现实后果中的持续，而不是把可爱角色突然演成阴谋者。

### 5.3 大事件、低反应

```text
事件主体完成E7-E10动作
-> 最近旁观者保持坐姿
-> 手停/抬几厘米
-> 下巴轻抬或只转眼
-> 第二人看第一人而非事件
-> 一次眨眼或口型残留
-> 群体任务恢复
-> 尾帧停在空间、空位或物件后果
```

### 5.4 公开快乐、私人崩塌

```text
笑、点头或合群动作保持
-> 关键词进入
-> 眼睛失去对焦但嘴形继续
-> 手部加压或脚尖转向
-> 公开动作扩大以遮盖泄露
-> 身体高度/路线改变
-> 笑形作为尾部残留
```

### 5.5 群体孤立转移

```text
群体原有中心和边缘关系
-> 一人替边缘者发声
-> 其他人先停止对原对象的排斥动作
-> 目光、身体朝向和物件通道逐步改指发声者
-> 原对象进入群体中心但保留迟疑
-> 发声者成为唯一运动者或画面边缘者
-> 群体以正常社交表演掩盖关系转移
```

## 6. 风格突变权限

使用：

```text
权限所有者 -> 触发 -> 改变的唯一主变量 -> 峰值时长
-> 对身体动作的影响 -> 回现实锚点 -> 现实残留
```

适合压抑悬疑的单变量变化：

- 线条突然变粗、断裂或速度化，只持续在受力峰值。
- 人物形状压扁/拉长，背景和色彩仍维持现实基准。
- 背景透视取消为平面色，人物动作沿同一弧线继续。
- 帧密度从保持切到短时一拍一，再回一拍二/三。
- 阴影块取得脸部或身体的一部分，不改全场色调。
- 细节突然过度清晰或大幅简化，只属于某个认知主体。

回落必须保留同一动作、声音、接触点、形状、物件或视线中的至少一个。风格变化不能替现实因果完成动作。

## 7. 动画化镜头与现实层机制

### 7.1 关键阈值的镜头变形

关键阈值按以下顺序设计：

```text
稳定空间和正常人体
-> 压力源/关键词/接触取得画面权限
-> 透视、尺度、线条、帧密度或背景中的一项越界
-> 身体重心和动作路线同时改变
-> NPC/物件/环境按各自知情权限响应
-> 同一接触点、物件、视线或声音把画面带回现实
-> 留下可见后果
```

正反打、侧中景和普通近景可以建立信息，但不能成为情绪顶点的唯一手段。顶点必须至少改变信息所有权、身体受力、群体拓扑、物件状态、绘画系统或环境余波中的一项。

### 7.2 天真图形层与严重后果同框

```text
严重后果已经存在
-> 天真角色以可爱图形/星光/高饱和层解释它
-> 图形层覆盖空气和色彩，但伤口、污迹、倒地姿势或破损物件仍可见
-> 天真动作继续完成自己的目标
-> 客观机位、见证者或环境重新取得权限
```

恐怖来自解释与事实并存，不来自把天真角色突然演成恶意角色。

### 7.3 美丽环境的拒绝配合

美丽天空、夕阳、花朵、春日、蝉声和暖光保持自己的正常节拍。人物痛苦只改变人物局部、遮挡和空间尺度；环境不自动变暗。高潮后让环境继续，人物残留由空位、物件、污迹或声音尾巴维持。

## 8. 构图驱动的压抑引擎

压抑首先来自观看受限和关系被几何化，不来自全程黑脸、慢推或低照度。关键场景优先选择一个主引擎：

| ID | 引擎 | 执行链 | 判定结果 |
|---|---|---|---|
| CA-01 | 门缝目击 | 黑暗前景/门缝 -> 单眼或局部 -> 室内事实迟延出现 -> 观看者反应 | 观众被放进无权介入的位置 |
| CA-02 | 局部证据扫描 | 支撑 -> 手与物件 -> 呼吸/衣物 -> 见证者 -> 完整全身 | 观众的判断被逐项修正，而非一次性告知 |
| CA-03 | 权威尺度 | 成人腿/手/阴影先占前景 -> 弱者落在画面下沿 -> 脸延迟 -> 完整空间 | 权力先以物理尺度成立，台词只是表层 |
| CA-04 | 群体封锁 | 前景身体/桌椅形成闭环 -> 主体只在缝隙可见 -> 物件与视线通道改向 -> 主体失去入口 | 孤立由拓扑完成，静音也能读懂 |
| CA-05 | 路线判决 | 共同路线 -> 分叉/门槛 -> 唯一角色改变方向或高度 -> 远景固定新距离 | 选择和关系破裂成为空间事实 |
| CA-06 | 大全景判决 | 局部扣留 -> 见证者定性 -> 完整人物/空间迟延出现 -> 不再解释性特写 | 尺度、责任、不可逆后果一次落定 |
| CA-07 | 环境拒绝配合 | 重大后果 -> 天空/夕阳/饭桌/蝉声保持正常 -> 人物退出 -> 残留物留场 | 世界继续运转形成道德压力 |
| CA-08 | 垂直尺度判决 | 地面小人物 -> 重复窗格/楼层/栏杆向上延伸 -> 出口或目标离开同一高度 -> 俯拍反向压小人物 | 楼层、坠落、住宅、机构与权威高度成为可读事实 |
| CA-09 | 前景活动帘揭示 | 风吹纸片/人群/帘布/车流先占前景 -> 前景按自身物理逐层移开 -> 主体被发现 -> 前景继续而非停成框 | 环境运动完成揭示，避免无动机推镜和凭空露人 |
| CA-10 | 固定机位群体流过 | 摄影机固定 -> 群体身体/腿/物件依次横穿前景 -> 社交中心随运动迁移 -> 背景主体只做低幅动作 -> 空位或距离落定 | 用持续遮挡和路线表达孤立、排斥与被忽略 |
| CA-11 | 阈限暖光反证 | 门外冷层/暗层 -> 门内暖光与日常声音 -> 成人/家庭物件先出现 -> 弱者停在门槛外 -> 暖光保持但关系事实恶化 | 暖色不自动等于安全，门槛和可达路线决定归属 |

使用时必须写明：画面所有者、第一眼信息、第二眼发现、扣留内容、关系几何、新增证据、大全景判决和环境余波。鱼眼、颜艺、图形入侵或帧密度爆发只能作为其中一个阈值，不能取代构图引擎。

## 9. 失败边界

- 把压抑等同于全程低头、黑脸、慢动作和微表情。
- 把动画夸张等同于只换眼睛、嘴和颜艺贴图。
- 大事件发生后自动让所有人起身、尖叫、扑救或同步转头。
- 角色在未看见、未听见、未感到接触前提前反应。
- 夸张动作没有预备、支点、力源、过冲、恢复和尾态。
- 风格突变同时改线条、色彩、比例、背景、镜头和声音，失去主信息。
- 用无意义抽帧代替有设计的节拍和间距。
- 余波立刻切走，或在余波里再制造第二个高潮。
- 把善意、天真或可爱角色靠反派化来制造悬疑。
- 把心理说明直接写进模型提示词，却没有可见动作。
- 把鱼眼、广角、旋转、快速推拉当作独立炫技，没有画面所有者和身体后果。
- 关键段落只有正反打、侧中景、特写递进，没有动画变量越界或现实落点。
- 图形层一出现就擦除所有现实证据，使主观误读失去反讽。
- NPC只在台词结束后统一反应，群体关系无法从站位、遮挡和物件路径读出。
- 一开始就给完整人物和完整空间，之后再用局部重复已经知道的信息。
- 把大全景当普通建立镜头，浪费了它对尺度、责任、孤立或后果的判决能力。
- 摄影机始终是无立场的旁观机位，没有任何角色、群体、权威、物件或环境拥有观看权限。
- 门框、桌椅、栏杆、成人身体和道路只做装饰，没有改变谁能被看见、接近或帮助。
