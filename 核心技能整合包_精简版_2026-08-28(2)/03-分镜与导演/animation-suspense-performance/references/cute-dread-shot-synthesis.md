## 1. 第一原则

可爱图形不是情绪滤镜，而是角色对现实提出的一条可见命题。阴暗事实也不是另一套色调，而是身体、物件、空间和声音留下的客观证据。

```text
客观事实 F
+ 主观命题 P
+ 画面所有者 O
+ 坚持可见的现实证据 E
+ 夺回解释权的角色/物件/环境 R
= 可爱与阴暗的有效反差
```

先写清 `F` 和 `P` 的冲突，再决定星光、爱心、放射线、Q版、平面插图或可爱音效。图形越华丽，现实证据越要具体；否则只剩风格装饰。

## 2. 反复使用的机位家族

以下是压抑悬疑动画中反复有效的布局家族。它们是剧情功能，不是固定截图。焦段、摄影设备和完整机位执行仍由 `director-storyboard-integrated` 决定。

| ID | 机位/构图家族 | 第一眼 | 第二眼/扣留 | 主要目的 | 动画优势 |
|---|---|---|---|---|---|
| CD-C01 | 环境主位远景，人物很小 | 漂亮或普通空间 | 人物被放在边缘、光岛或远端 | 让环境拒绝配合痛苦，判定帮助距离 | 背景可保持，人物只需低幅姿势与路线 |
| CD-C02 | 孩子高度低机位 | 成人腿、手、门槛或家具 | 成人脸与完整事件延迟 | 先用尺度建立权力，不靠台词宣布 | 可夸张近端身体与纵向高度 |
| CD-C03 | 门缝/窗框/前景身体观看 | 障碍和一小块可见区域 | 室内事实、完整人物、帮助路线 | 把观众放在无权介入的位置 | 遮挡层可独立运动，控制揭示节拍 |
| CD-C04 | 固定低机位，群体流过前景 | 腿、书包、桌椅和社交通道 | 背景孤立者只做低幅动作 | 用群体拓扑表现排斥和中心迁移 | 复用稳定背景，以前景节奏制造关系变化 |
| CD-C05 | 脚/手/物件/衣领局部链 | 单一身体或物件事实 | 完整人物与意义延迟 | 逐项修正观众判断 | 每个局部可改变线条、材质和帧密度而不丢身份 |
| CD-C06 | 高位或俯拍后果平面 | 身体、物件、污迹的相互位置 | 面部情绪暂缓 | 把事件从私人感受变成客观后果 | 几何与物件位置可直接承担因果 |
| CD-C07 | 贴地双人/侧面关系框 | 身体高度、支点和距离 | 谁能靠近、谁被门框或家具切断 | 让对话静音后仍能读出关系 | 全身姿势、手和道具可在同一受力平面工作 |
| CD-C08 | 眼睛/反射/物件极近景 | 单一图形或倒影 | 主观画面所有者即将换权 | 用于阈值、记忆入口或错误确信 | 图形可从可见表面扩张，不必凭空换画风 |
| CD-C09 | 大全景判决 | 完整空间与人物尺度 | 前面局部证据在此获得最终意义 | 确认孤立、不可逆后果、责任或离开路线 | 允许人物细节简化，姿势轮廓和环境面积主导 |
| CD-C10 | 环境/物件余波空镜 | 空位、门、花、信号灯、道路或遗留物 | 人物已经离开或失去画面权 | 阻止高潮被第二次解释，让世界继续 | 低成本保持也能依靠风、光、声音产生生命 |

选择顺序：`当前关系问题 -> 谁拥有观看权 -> 需要先看局部还是整体 -> 哪个机位家族最直接`。不得从“想用鱼眼/特写”倒推剧情。

## 3. 镜头链而非单镜炫技

常用压力链：

```text
空间或关系基准
-> 有权限限制的局部
-> 第二证据改写第一印象
-> 一次动画突变夺取注意力
-> 物件/见证者/大全景夺回解释权
-> 环境或日常动作接管余波
```

常用可爱反讽链：

```text
现实后果已经成立
-> 天真角色仍按原动作和语气解释
-> 可爱图形从角色/道具/声音位置进入
-> 图形接管空气、色彩或构图
-> 一项关键现实材质始终可见
-> 客观机位或环境给出判决
-> 图形留下小块残迹或完全退出
```

单镜可以耀眼，但镜头链必须完成 `提出解释 -> 保留反证 -> 改写意义 -> 落回后果`。

## 4. 可爱图形层的八种任务

| ID | 任务 | 进入方式 | 现实证据策略 | 退出方式 |
|---|---|---|---|---|
| CD-G01 | 世界观说明 | 道具居中、平面放射、图标逐项出现 | 现实因果尚未承压，可完整替换背景 | 物件动作完成后硬切现实 |
| CD-G02 | 天真自我展示 | 全身压缩回弹、配件逐项贴合、Q版或简笔层 | 保留角色标志轮廓和手中物件 | 落地、碰撞或他人台词打断 |
| CD-G03 | 愿望/关系可视化 | 线、带、星轨从眼睛、手或道具发出并穿过真实空间 | 桌椅、门框、人物位置和接触点保持 | 关系拓扑或物件路线落回现实 |
| CD-G04 | 错误解释覆盖严重后果 | 星光、云、爱心、火箭或庆祝音从边缘涌入 | 伤口、污迹、倒地身体、破损物件至少保留一项 | 客观地面、见证者或环境远景夺回 |
| CD-G05 | 注意力偷取/延迟理解 | 高饱和图形先占满画面 | 证据暂时被遮挡但位置和声音仍连续 | 图形让路后直接露出证据 |
| CD-G06 | 假性净化 | 删除污渍、重量和杂乱，把人物整理得完整轻盈 | 同一姿势、物件和运动方向保持 | 他人视角按脚、手、衣物逐项归还现实 |
| CD-G07 | 记忆/时间/告别 | 倒影、接触点、照片、白化或同构形状扩张 | 保留一项触摸、轮廓、物件或声音 | 普通社会动作、空手或环境尺度落地 |
| CD-G08 | 图形污染现实 | 图形只接管色彩、空气和局部线条，现实与主观层同框 | 最严重的材质证据保持清晰 | 图形声层衰减，现实room tone和物件重量继续 |

同一节拍只选一个主任务。若同时需要说明、喜剧、误读和记忆，拆成顺序清楚的多个节拍。

## 5. 极暗场景为何使用极可爱表达

1. **可视化认知差**：角色真诚相信“问题解决了”，图形层让这条错误理解拥有与现实同等的画面力量。
2. **让两种真相同框**：可爱层说“幸福”，物件和身体说“伤害”。观众无需等待解释就能读到冲突。
3. **重置感受阈值**：持续阴暗会让观众适应。短暂高亮、轻快和圆润造型重新打开感受，再由客观证据切断。
4. **偷取注意力再归还**：观众会本能追随高饱和图形；当图形移开，原本就在场的证据带来迟到的理解。
5. **制造道德不适**：观众短暂接受了一个方便、可爱的解释，随后被迫承认自己也想快速跳过复杂痛苦。
6. **保护天真角色一致性**：恐怖来自理解能力的局限，而不是把可爱角色突然写成阴谋者。
7. **推动母题变质**：同一星光、笑脸、铃声或圆润图形可从说明、希望，逐步变成误读、污染、告别和记忆残留。

反差不是“粉色背景配尸体”这个表面配方。真正配方是：`善意解释持续有效 + 现实证据持续存在 + 两者无法互相取消`。

## 6. 双重曝光控制卡

在使用可爱层前填写：

```text
客观事实 F：镜头静音后仍成立的身体/物件/空间后果是什么？
主观命题 P：当前角色真诚相信什么结果已经成立？
画面所有者 O：谁有权改变色彩、线条、空间或帧密度？
进入触发 T：台词、眼神、接触、道具、声音还是结果确认？
主变量 V：背景、色彩、轮廓、线条、帧密度、细节权限中只选哪个？
现实证据 E：哪一项伤痕、污迹、重量、路线、门框、地面或物件坚持可见？
误读动作 A：角色在图形层中继续完成什么身体目标？
夺回者 R：见证者、地面物件、客观远景、环境声或另一句台词？
残留 L：回现实后留下什么图形、声音、姿势或物件残迹？
```

当 `E`、`R` 或 `L` 为空时，图形层通常只是在装饰。

## 7. 从机制到原创镜头

原创不是回忆更多截图，而是重算以下七个变量：

```text
1. 剧情功能：说明 / 误读 / 关系变化 / 记忆 / 暴力峰值 / 后果 / 告别
2. 观看位置：天真者 / 受害者 / 群体 / 孩子 / 权威 / 物件 / 环境
3. 基准机位：从 CD-C01 至 CD-C10 选一个
4. 客观证据：身体支点 / 手中物 / 地面痕迹 / 群体拓扑 / 门槛 / 声源
5. 动画算子：从 CD-G01 至 CD-G08 选一个
6. 夺回机制：硬切 / 遮挡移开 / 物件落地 / 台词打断 / 见证者反应 / 大全景
7. 尾帧任务：下一选择、未完成动作、空位、物件状态或环境余波
```

原创重算规则：至少替换观看位置、客观证据和夺回机制中的两项；重新设计人物支点、动作路线、当前时长和尾帧。只替换角色与地点属于换皮。

### 机制变体方法

- **换观看者**：同一事件分别由宠物、孩子、群体、物件或环境观看，画面权限和完整度随之改变。
- **换证据载体**：把血迹换成折断物、空位、停止的机器、未送出的饭、沾灰的鞋或持续响的提示音。
- **换夺回者**：让现实由地面、门框、他人迟疑、窗外天气、声音撤走或普通日程夺回。
- **换动作目标**：图形层中角色继续庆祝、整理、解释、护送、命名或完成仪式，而非统一地微笑。
- **换残留**：星光可留在泪珠、金属边、窗户、照片、灰尘、屏幕或声音尾巴中，意义随剧情阶段变化。

## 8. 任务组合矩阵

| 剧情任务 | 推荐基准 | 图形任务 | 现实证据 | 推荐夺回 |
|---|---|---|---|---|
| 介绍能力/规则 | CD-C07或CD-C08 | CD-G01 | 道具所有权与手部动作 | 道具落定、现实反应 |
| 天真角色卖弄或喜剧误会 | CD-C02或CD-C07 | CD-G02 | 身体支点与手中物 | 落地、台词续句 |
| 愿望或关系想象 | CD-C04或CD-C08 | CD-G03 | 真实座位、距离、接触点 | 群体拓扑落地 |
| 严重后果被误读 | CD-C05或CD-C06 | CD-G04/CD-G08 | 最严重物件或身体材质 | 地面证据、大全景 |
| 先骗观众再揭证据 | CD-C03或CD-C08 | CD-G05 | 声源与证据位置 | 遮挡让路、焦点归还 |
| 角色美化自己 | CD-C01或CD-C07 | CD-G06 | 同一姿势和随身物件 | 见证者证据扫描 |
| 记忆进入或时间重写 | CD-C08 | CD-G07 | 倒影、触摸或同构物件 | 普通动作与社会距离 |
| 高潮后余波 | CD-C09或CD-C10 | 图形残迹或现实基准 | 空位、遗物、天气、room tone | 环境持续到尾帧 |

## 9. 图形母题的意义递进

同一图形语法应随剧情变化：

```text
第一次：纯说明，观众学会语法
第二次：希望或良好结果，建立信任
第三次：图形覆盖不协调残留，产生轻微疑问
第四次：图形与严重现实证据同框，意义变质
第五次：角色终于理解后，图形变成记忆、悔恨或告别
第六次：图形只在普通生活的小物件或动作中残留
```

每次重复至少改变一项：所有者、证据、颜色权限、声音、进入边界、动作目标、夺回者或残留。完全复用同一星爆只会像功能按钮。

## 10. 时间与声音

- 现实基准先占足够时长，让观众知道正常空间、人体和声音。
- 4至15秒节拍通常只安排一次主要图形接管；其余变化负责预备和回落。
- 说明/喜剧层可采用阶梯式关键姿势、短促高密峰值和明确可爱音效。
- 严重后果同框时，图形声层可以明亮靠前，但客观物件声、呼吸或room tone至少保留一条。
- 夺回现实可由物件落地、口型中断、声音骤薄、环境底恢复或见证者吸气触发。
- 高潮后优先减少声层并延长物件/环境尾音，让观众自己完成判断。

## 11. 失败边界

- 图形层没有明确画面所有者。
- 客观事实只写在剧情说明里，镜头内没有身体、物件、空间或声音证据。
- 可爱层擦除全部严重后果，回现实后也没有残留。
- 角色已经完整理解伤害，画面仍机械使用天真庆祝层，且剧情没有记忆或否认理由。
- 每遇到情绪峰值都使用星光、Q版、鱼眼和粗线，观众失去基准。
- 图形层替代了人体受力、手脚路线和物件接触。
- 只复制某个构图，未重算观看者、证据、动作目标、时长和尾帧。
- 可爱音效覆盖所有现实声源，导致空间与后果失去重量。
- 效果退出后立即补解释性脸部特写，削弱客观判决和余波。
- 全段持续炫技，没有现实基准与回落，所有峰值彼此抵消。

## 12. 正式输出与验收

需要可爱与阴暗反差时，在动画正式输出中增加：

```text
可爱-阴暗双重曝光：
客观事实 F：
主观命题 P：
画面所有者 O：
进入触发 T：
图形主变量 V：
坚持可见的现实证据 E：
夺回解释权 R：
回现实残留 L：
```

验收：

1. 静音后能否读出客观事实、关系和后果？
2. 只看图形层能否读出当前角色真诚相信的命题？
3. 两层同框时是否互相矛盾，而非互相取消？
4. 图形层退出后，身体、物件、空间和声音是否留下可继承状态？
5. 当前镜头是否由剧情功能推导，而非先选特效再找理由？
6. 与核验来源相比，是否重新计算了观看者、证据、动作和尾帧？

## 13. 已核验证据路由

需要上游证据时，查询并视觉核验以下图谱条目：

- `VA-003`：美丽日光、天真色彩与受伤材质并存。
- `VA-010`：平稳解释、明亮环境和死亡事实同框。
- `VA-012`：取消透视的关系插图与脚步连续锚点。
- `VA-017`、`VA-019`：图形从眼或手进入真实空间，并由接触夺回。
- `VA-028`：平面橙黄喜剧误读、逐项变装、硬切现实。
- `VA-034`、`VA-035`：可爱图形污染严重现实并越过空间边界。
- `VA-038`：图形线在真实群体空间中重排关系。
- `VA-041`：同一可爱符号通过颜色和揭示顺序变质。
- `VA-045`、`VA-052`：抽象告别最终落回空手、普通生活和物件选择。

采用前运行 `scripts/query_verified_animation_atlas.py`，打开候选图核对至少两轴。图谱负责证据，本文件负责从证据生成新的镜头决策。
