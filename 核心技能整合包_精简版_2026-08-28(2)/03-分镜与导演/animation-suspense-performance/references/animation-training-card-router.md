# 动画训练卡检索与组合路由

本路由把用户提供的动作训练、镜头对标材料压缩成可调用的功能卡。卡片不是镜头答案，也不是风格标签；它只提供一条需要被当前人物、空间、道具和戏剧任务重新计算的动作机制。

## 1. 证据边界

- 卡片中的动作先后、支点、接触、错时反馈和恢复可作为训练机制。
- 原材料中的作品归因、具体镜头位置、精确帧数、物理常数和“永远如此”的断言未经过逐片核验，只能作为试拍假设。
- 下游模型词只保留可见机制，不出现作品、角色、作者、工作室或风格来源名。
- 原材料中的示意图只用于说明动作链。部分图表文字失真，不作为字段或时间证据。

## 2. 检索键

先写七项，再选卡：

```text
戏剧任务
-> 当前主体与意图动词
-> 可见触发和知情权限
-> 现实动作基准
-> 主要难点：支点 / 重量 / 速度 / 接触 / 情绪 / 群体 / 观看权限
-> 峰值后果
-> 必须继承的尾态
```

按难点检索，不按作品、人物外形或“某某感”检索。无法写出触发、支点或尾态时，先补事实锁，不调用表现卡。

### 2.1 八槽动作因果剖面

调用任何动作卡后，按当前人物、速度、体型、服装、地面、道具和情绪重新填写：

```text
任务与触发
-> 初始支点与重心
-> 第一启动部位
-> 关节/躯干传力顺序
-> 接触、阻力或共同承重
-> 峰值、过冲与反作用
-> 衣发/道具/对手/环境的错时响应
-> 恢复、尾帧与下一拍继承
```

- 接触型动作必须能看见接触前、触碰、确认重量或受力、接触后新状态，不能从“伸手”直接跳到“已经拿住”，也不能从“靠近”直接跳到“已经抱紧”。
- 无接触动作仍要写支点、启动、峰值和落定；“情绪很强”不能替代身体路线。
- 情绪卡按 `触发 -> 感知 -> 眼神 -> 面部 -> 身体 -> 公开/私下差 -> 恢复` 组织，但先后顺序由刺激类型、人物习惯和镜头可见性重算。
- 卡内帧数、比例和“永远/一定”类说法只是试拍假设。当前项目帧率、动作尺度、角色能力和生成模型约束拥有更高优先级。

### 2.2 复合摄影机连续性清单

环绕、越顶、贴地跟拍接俯视、穿遮挡物、连续变景别和身体化 POV 不是一个“炫技运镜”动词。导演确定路径后，动画台账必须逐项锁定：

```text
主体身体朝向与支点
-> 屏幕方向 / 世界方向 / 目标或消失点
-> 摄影机开始机位与高度
-> 摄影机围绕谁、沿什么空间路径运动
-> 主体自身是否同时转身或位移
-> 遮挡前后的尺度、速度、地平线与视差连续
-> 摄影机落点、最终景别与新画面所有者
-> 主体、道具、影子和环境力的尾态
```

- “镜头环绕角色”不等于角色原地转圈。分别写摄影机路径和主体身体路径。
- 可以越轴；越轴前后必须让观众追踪到摄影机跨越过程，或用正俯视、POV、遮挡、共同目标等节点重建方向。180度线不是永远不可越的禁令。
- 穿过真人、门框、车辆等遮挡时，遮挡前的运动方向、角速度和主体尺度必须在重新出现后连续；遮挡不能替代路径设计。
- 复合路径必须有落点。若只写“贴地冲出去再升空”而不锁最终方向、景别和尾态，判为假运镜。

| B07 喷嚏/痉挛 | 慢积累、快释放的生理动作 | 皱鼻吸气 -> 躯干后仰蓄积 -> 瞬间前屈释放 -> 过冲 -> 揉鼻/流泪/呼吸恢复 | 预备长于释放；头颈、脊柱和手共同参与 |
| B08 弯身捡物 | 物件吸引视线、重心下移 | 先看 -> 根据物件距离选择屈膝/髋折叠 -> 支撑手或自由手平衡 -> 指尖接触 -> 握住 -> 下肢发力站起 -> 确认 | 支撑面内重心可读；屈膝不是无条件硬规则，由体型、衣着和距离决定 |
| B09 推门进入 | 阈限、阻力、空间进入 | 握把 -> 解锁/下压 -> 身体前倾施力 -> 门轴响应 -> 脚越门槛 -> 手延迟放门 -> 门惯性落定 | 门把、门轴、手掌和脚跨越共同证明重量与方向 |
| B10 挥手告别 | 亲密、不舍、礼貌 | 先认出对方离开 -> 举手 -> 手腕主导的非机械循环 -> 躯干微前倾 -> 幅度变化 -> 慢放下 -> 视线滞留 | 循环不完全复制；手放下后关系注意仍保留 |
| B11 承重式拥抱 | 重逢、安慰、阻止离开、关系确认 | 双方确认并闭合距离 -> 各自支撑脚接住来势 -> 躯干/肩先发生软接触与缓冲 -> 双臂按人物意图先后环抱 -> 手掌加压或抚背 -> 共享重心落定 -> 身体与手臂按关系节奏分阶段松开 | 两人的支点、来势和反作用都可读；衣褶/头发/呼吸证明接触重量；奔赴拥抱允许手臂提前张开，仍须保留接触缓冲和共同承重 |
| B12 临界接触犹豫 | 想碰又不敢碰、安慰前迟疑、关系边界 | 先确认对象和对方知情状态 -> 支撑脚或躯干微靠近 -> 手从肩/肘启动 -> 指尖接近临界距离 -> 呼吸、眼神或手指泄露犹豫 -> 手停住、绕开、撤回或在获得允许后触碰 -> 新距离与关系尾态 | 至少一次可见的“接近后停住”；手的轨迹、指尖距离、视线和呼吸来自同一意图；若最终接触，补触碰、受力和接触后状态，若未接触，空隙本身必须可读 |

### 3.2 速度与动作 A01-A10

| 卡 | 适用问题 | 不可删动作骨架 | 最小验收证据 |
|---|---|---|---|
| A01 直线打击 | 单次力量释放 | 反向蓄力 -> 后脚蹬地 -> 髋肩传力 -> 拳沿路径释放 -> 接触/峰值 -> 过冲 -> 收回防守 | 力从地面传到末端；对手和环境后于接触响应 |

| A03 奔跑急停转向 | 高速改变方向 | 先建立速度 -> 制动脚摩擦 -> 躯干继续前冲 -> 第二支点接住 -> 髋肩转向 -> 平衡修正 -> 衣发落定 | 制动、过冲和新方向落点均可读 |
| A04 高处落地 | 重量、缓冲、落点危险 | 空中姿态 -> 足部接触 -> 膝髋压缩 -> 最低点 -> 小幅回弹 -> 站稳/继续动作 | 接触面、压缩和地面/衣发延迟共同证明落差 |
| A05 擦身躲避 | 千钧一发、低位移闪避 | 先见攻击 -> 支点保持 -> 躯干弯折/旋转 -> 攻击贴近通过 -> 风压带动衣发 -> 过冲 -> 回正 | 攻击路径和最近距离清楚；风从攻击路径产生 |
| A06 高位踢击 | 平衡、鞭梢释放 | 提膝 -> 支撑腿微屈 -> 髋旋转 -> 小腿释放 -> 峰值 -> 有控制收腿 -> 落脚缓冲 | 支撑腿、骨盆和上身反平衡持续可读 |
| A07 受击飞出 | 受力、无力姿态、二次碰撞 | 接触压缩 -> 支点失去 -> 松散飞行 -> 衣发逆风 -> 二次接触压缩 -> 滑/滚 -> 瘫落 | 两次接触都有不同形变；身体不是刚性平移 |
| A08 起跑加速 | 从静止进入全速 | 重心前送 -> 小步蹬地 -> 步幅和摆臂逐级增大 -> 全速循环 -> 风与尘后进入 | 加速由步幅、间距和身体倾角变化证明 |

| A10 格挡卸力 | 防守、冲击转移 | 先看攻击 -> 架起防护 -> 接触处压缩/弯曲 -> 后撤或转体卸力 -> 脚底摩擦 -> 保持防护 -> 确认后恢复 | 接触点、卸力方向和最终支点一致 |

| E03 Q版吐槽 | 认知落差、单次笑点 | 正常比例 -> 触发 -> 一项先变 -> 快速比例压缩 -> 单一笑点动作 -> 对手保持基准 -> 归模残留 | 身份锚、动作方向和现实落点不丢失 |

| C06 形状/动作匹配转场 | 连续任务跨空间时间 | 前态动作末端 -> 共同轮廓/遮挡 -> 后态同向落地 -> 物件/声音锚保持 | 动作、方向、节拍或物件至少两项连续 |

## 4. 组合规则

默认组合结构：

```text
一张主体动作卡
+ 可选一张情绪卡
+ 可选一张镜头/环境卡
-> 一个共同触发
-> 一个共同接力棒
-> 一个共同尾态
```

- 同类卡只选一张为主卡。例如“急停”和“起跑”可以先后出现，但不能在同一时间窗争夺支点。
- 情绪卡改变主体动作的幅度、间距和抑制方式，不能另起一条与动作无关的脸部轨。
- 镜头卡只在它改变信息权限、尺度、时间或主观身体时进入；角度变化不能替代动作。
- 每拍最多一个主表现机制。辅助机制只继承主机制的方向、形状、节奏、颜色、声源或物件。
- 任意卡进入 `full-frame-motion-ledger.md` 后，必须补齐当前角色、NPC、道具、环境、声光和下一拍继承，不能照抄卡片骨架。

## 5. 经典镜头比较语法

对标研究统一比较九项，不以“像某作品”结束：

| 比较项 | 要回答的问题 |
|---|---|
| 戏剧任务 | 这一动作让关系、信息或风险发生了什么变化？ |
| 正常基准 | 越界前的姿势、节拍、画层和环境是什么？ |
| 姿势链 | 起始、预备、峰值、过冲、恢复分别是什么剪影？ |
| timing/spacing | 哪段持有、哪段加速、哪段减速，间距为何改变？ |
| 支点与接触 | 重量从哪里进入身体，阻力和反作用在哪里出现？ |
| 次级错时 | 衣发、道具、环境、对手和群体分别晚于谁？ |
| 观看权限 | 哪个局部先给，何时允许完整身体/空间出现？ |
| 声光接力 | 声源、静音、光源或影子何时取得/归还画面？ |
| 尾态 | 峰值后什么仍在动，下一镜继承什么？ |

只有九项中至少六项能被当前画面事实回答时，对标机制才算可迁移。精确帧数若未由本地连续帧或原始时间表核验，标为“试拍值”，不得写成硬规则。

## 6. 冲突裁决

不同材料或卡片互相冲突时，按以下优先级裁决：

```text
当前剧情事实与人物能力
-> 身体支点、接触和可见因果
-> 已批准的角色动作指纹
-> 当前镜头的信息权限
-> 卡片示例
-> 未核验的精确帧数与来源说法
```

例如“眼睛先于头”只允许在刺激已经被感知、眼球转动范围合理时成立；“捡物一定屈膝”要根据物件高度、体型、服装、伤病和人物习惯重算。卡片提供观察方向，不凌驾于当前角色身体。
