# 2D人物进入真人底片的手绘动画契约

本契约用于真人照片/视频底片中存在表演型2D角色的动画。真人底片提供空间、光、材质和人群证据；2D角色仍由动画表演、线条和帧感规则驱动。目标不是把角色伪装成真人，而是让角色在同一空间中成立，同时保持明显的手绘媒介差异。

## 1. 路由判定

只要承担主要表演、剧情选择或连续动作的角色是2D绘制角色，整段仍走动画路由，即使背景、道具和周围人物是真人实拍。

```text
真人底片事实锁
+ 2D角色身份与手绘运动锁
-> 动画主体动作链
-> 跨媒介接触、遮挡和反应
-> 真人底片连续性
-> 2D尾态连续性
```

只有真人演员承担主体表演、2D元素只是图形/VFX叠层时，才走非动画路由。

## 2. 双层 BASE 锁

### 2.1 真人底片锁

逐镜记录：

```text
画幅、机位高度、视平线、消失点和镜头畸变
摄影机是否固定，若运动则记录路径、速度、滚转和震动
前景 / 中景 / 后景的真实深度层与可遮挡物
光源方向、软硬、色温、曝光变化和真实阴影方向
白平衡、对比、颗粒、压缩噪声、景深和运动模糊
真人NPC的初始任务、路线、速度、视线和可见反应权限
真实道具的位置、材质、接触面和可变状态
```

底片锁描述现有证据，不把真人摄影质感扩写成角色的绘制风格。

### 2.2 2D角色锁

逐段记录：

```text
身高与空间尺度、轮廓比例、脸型、发型、服装和识别色
线条工具感、粗细波动、断续、重复描线和局部线沸腾
填色边界、阴影块数量、纸面/扫描颗粒和允许的露底
角色常态曝光节奏、moving hold、动作峰值的帧密度变化
角色与底片的色温关系，但保留绘制色块和线稿可见性
允许离模的部位、峰值幅度、归模锚点和尾帧残留
```

手绘区别来自“线条怎样活、动作怎样分拍、填色怎样轻微漂移”，不依赖前景放大、霓虹描边或过度饱和。

## 3. 空间归属六证

每个镜头至少满足其中四项；发生真实接触的镜头必须满足接触、遮挡和光影三项。

| 证据 | 执行要求 |
|---|---|
| 地面/座面接触 | 脚底、臀部、手掌或身体接触点贴合真实平面；接触点附近阴影最实，受力后姿势或真实软材质发生变化 |
| 遮挡交叉 | 至少一个真实物体或真人从角色前方经过，同时角色也遮住一部分后景，证明角色位于深度层而非最上层贴图 |
| 正确投影 | 影子方向、长度、软硬和接触锐度服从底片光源；角色离地时影子与脚底关系变化 |
| 反射/透射 | 玻璃、水面、亮地或金属只在现实存在该现象时给出低强度倒影、色溢或折射；反射服从表面角度和模糊度 |
| 视差与景深 | 摄影机/人物移动时，角色相对前后景产生正确视差；角色所在焦平面服从底片景深、曝光时间和速度逻辑，同时允许2D轮廓保留阶梯曝光，不要求与真人具有同强度模糊 |
| 环境穿越 | 雨、尘、花瓣、蒸汽、树影或人群被分成角色前后两层，并在角色表面留下湿痕、色温、阴影或风力后果 |

“有一团影子”不是充分证据。影子必须和支点、光源与动作同拍。

## 4. 中景融入真人群体

用户要求角色“在周围真人中间”时：

- 把角色放在中景真实行走带、座位列或排队路径中，身高和脚底落点服从同一视平线。
- 至少安排一次真人从角色前方遮挡，或角色从真人后方穿出；遮挡边界继承底片运动模糊。
- 真人NPC先维持各自任务。只有看到接触、听到声音或路线被挡的人才产生低幅反应，且按距离错时。
- 角色不得因“主角显眼”而停在镜头最近处。显眼性由粗粝线条、分拍节奏、局部线沸腾、动作剪影、短暂失帧线和观看权限建立。
- 摄影机可以在群体中暂时丢失角色，再由独特动作、线条节奏、真实遮挡后的重现或声画触发重新捕捉。
- 每个关键动作都要登记“可见起势 -> 遮挡区间 -> 可见结果”。手或道具进入真人遮挡层可以证明融合，但遮挡中的动作不算已经交付；观众至少要看到进入前的意图和离开后的状态变化。
- 遮挡后还有挥手、指向、松手、接物等关键手势时，把该手势交给可见侧肢体，或让角色/摄影机先恢复观看权限。不能把递接和告别连续藏在同一个真人轮廓后面。

## 5. 手绘帧感与真人运动解耦

真人底片的连续运动和2D角色的绘制曝光可以不同步，但动作因果必须同步。

```text
真人底片：保持原始摄影机运动、快门模糊和NPC连续轨迹
2D主体：常态选择性分拍，moving hold 中保留呼吸/眨眼/线沸腾
动作峰值：短暂提高关键姿势密度，必要时用一张方向明确的拉伸/失帧线
次级线条：轮廓重复描线、断线和局部漂移可慢半拍，不做全身均匀抖动
接触节点：脚底、手掌、道具和影子的接触时刻与真人底片严格对齐
恢复：身体先落定，发梢、衣角、线沸腾、环境粒子和影子随后收束
```

- 真人与2D角色共享同一个风场方向、阵风传播和遮挡关系，但按重量、迎风面积、材质、固定点和景深产生不同幅度与延迟；“同一阵风”不等于“所有东西同速摆动”。
- 2D角色的运动模糊服从底片摄影机的曝光方向与相对速度逻辑，可以用轮廓拉伸、重复线或阶梯姿势表达，不必复制真人连续模糊的强度。
- 接触影不是静态黑块：脚底压实、手掌按下或身体坐下时，接触影收紧、加深或随支点移动；分离时先变软再拉开，并与真实表面形变同拍。
- 反射与折射继承真实表面的角度、粗糙度和亮度，2D倒影可保留较少细节与分拍边缘，但位置和运动相位必须成立。

刻意失帧必须产生可读的姿势跳跃：前一张压缩、后一张已经越过较大距离，旁边的短促气流线或重复轮廓只标出路径。它不能表现为随机卡顿、全画面掉帧或持续运动模糊。

## 6. 粗糙手绘线条

模型面对“手绘”常会自动清洁线条，执行词应改写为可见事实：

- 主轮廓由有压力变化的铅笔/干笔触构成，弧线不一次封死，局部有重画痕。
- 转折、手指、发梢和衣褶允许轻微断线、搭线与不完全闭合。
- 线宽随受力和景别变化，背光边缘吃入少量环境色，接触处线更重。
- 运动中相邻曝光的轮廓不完全重合，形成克制的线沸腾；眼鼻口不做随机漂移。
- 填色是哑光平涂或轻微纸面涂抹，边界可有很小的人工偏移，但脸、手、道具接触点保持可读。
- 阴影用少量手绘色块响应真实光源，保留2D块面，不追求真人皮肤的连续体积渲染。

下游正向词写这些存在的属性，不使用“不要精致、不要矢量、不要贴纸”等负面句式。

## 7. 跨媒介接触链

接触必须展开成：

```text
先看真实目标
-> 手/脚/身体沿透视正确的路径接近
-> 接触前的微减速或预备
-> 2D轮廓压住真实表面
-> 接触阴影收紧
-> 真实物件变形、移动、反光或声音响应
-> 2D身体承受反作用和重量
-> 真人NPC在可感知后晚拍反应
-> 手/脚离开时阴影、材质和物件进入新状态
-> 尾帧保留褶皱、位移、湿痕、倒影、纸张弯曲或未完动作
```

不能只写“她捡起纸”“他摸到栏杆”。真实物件必须证明这次接触发生过。

## 8. 混合现实逐拍扩展

在 `full-frame-motion-ledger.md` 每行增加以下检查，不另起脱离时间轴的合成说明：

```text
底片层：摄影机 / 真人NPC / 真实道具此刻发生什么
2D层：主体姿势、表情、线条和曝光节奏
深度层：谁在谁前面，何时发生遮挡交换
接触层：接触点、影子、反射、材质后果
融合层：光色、景深、运动模糊、颗粒如何服从底片
区别层：哪一项手绘线条或分拍节奏继续证明角色是2D
继承层：底片状态和2D尾态分别交给下一拍什么
```

## 9. SD/Seedance 编译

BASE LOCK 分开保存两套不变量：

```text
真人底片不变量：机位、视平线、镜头运动、深度层、光源、颗粒、NPC路线
2D角色不变量：身份、比例、线条、填色、阴影块、常态帧感、允许离模范围
跨媒介不变量：尺度、脚底平面、影子规则、遮挡顺序、道具归属、声床
```

A拍按 `底片可见状态 -> 2D主体动作与表演 -> 遮挡/接触 -> 真人道具和NPC后果 -> 线条/帧感变化 -> 双层尾态` 编译。真人底片没有变化的事实只在BASE出现一次；2D主体动作仍占最大信息预算。

## 10. 失败诊断

| 症状 | 首个失败层 | 修复 |
|---|---|---|
| 人物像贴在最上层 | 深度层 | 增加前后遮挡交换、正确视差、所在焦平面和前景穿越 |
| 人物站不住地面 | 接触层 | 重算脚底平面、支点、接触锐度、投影方向和落地压缩 |
| 人物被融合成真人 | 区别层 | 恢复粗粝线条、选择性分拍、平涂阴影和线沸腾，不靠饱和描边 |
| 人物太像精修动画 | 2D层 | 写压力变化、断续搭线、重画痕、局部填色漂移和不完全闭合 |
| 真人NPC全员看主角 | 权限层 | 恢复任务和视线路径，只让能感知事件的人错时反应 |
| 动作写了却被真人完全挡住 | 观看权限层 | 补可见起势与可见结果；把后续关键手势移到可见侧，或先用角色/摄影机位移交还观看权限 |
| 雨雪蒸汽绕开人物 | 环境层 | 将粒子拆到人物前后，补表面湿痕、遮挡和受风后果 |
| 接触后现实毫无变化 | 材质层 | 补物件形变、位移、声响、反光、褶皱或残留状态 |
| 底片和角色各演各的 | 时间层 | 把触发、接触、声响、NPC感知和双层尾态写回同一台账 |
| 同一阵风让真人、头发、树叶和2D衣摆同速摆动 | 环境力层 | 保留共同方向和传播顺序，按重量、面积、材质、固定点与深度分别计算幅度和延迟 |
| 接触影像贴在脚下的黑贴纸 | 接触层 | 让影子随支点压实、滑动、离地和表面软硬连续改变锐度、面积与位置 |

## 11. 硬验收

正式成片逐镜检查：

- 主体完整动作链和表情链成立，粗线/失帧没有替代动作。
- 角色尺度、脚底、视平线和运动方向服从底片。
- 至少一次可信的前后遮挡交换或真实物件接触。
- 遮挡中的关键动作具有可见起势和可见结果；遮挡结束后的下一项主体手势没有继续被同一遮挡层吞掉。
- 投影、反射、景深、运动模糊和颗粒只按底片证据出现。
- 真人NPC有独立任务和感知延迟，不复制同一反应。
- 真人连续运动与2D选择性分拍共存，接触节点仍同步。
- 手绘区别由线条、填色、帧感和姿势表达建立，而非前景放大或荧光边缘。
- 最后一拍同时锁定底片尾态、2D姿势、道具状态、持续环境力和下一镜入口。
