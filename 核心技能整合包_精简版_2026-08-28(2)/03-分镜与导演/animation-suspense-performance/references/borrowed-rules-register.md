# 跨技能借用规则登记册

目的：允许动画表演技能读取通用分镜机制，但保持知识池单向隔离。此文件只记录“从哪里借、怎样动画化、边界是什么”。动画条目不得反写到导演技能训练库。

## 借用规则

| ID | 来源 | 借用机制 | 动画化改写 | 保留边界 |
|---|---|---|---|---|
| BR-01 | `director-storyboard-integrated/references/character-performance-bible.md`，表演状态链 | 基准 -> 刺激 -> 压制 -> 泄露 -> 选择 -> 残留 | 扩展为正常姿势、预备、关键姿势、间距、支点、过冲、恢复和尾帧 | 导演技能继续拥有镜头记录方式；本技能只拥有动画表演执行 |
| BR-02 | 同文件，Information Permission And Dual-Channel Performance | 公开脸/任务与私人泄露并行 | 为公开层和私人层分别指定身体部位、幅度、延迟和谁可见 | 不创造两个无关人格；同属一个行动意图 |
| BR-03 | 同文件，景别与表演 | 景别决定可读载体 | 全景用轮廓、距离、重心；中景用肩脊手；近景才用眼口呼吸 | 景别和机位由导演技能决定 |
| BR-04 | `dialogue-physical-interaction-grammar.md`，七轨并发 | 口型、身体、手、听者、背景、摄影机、声音分轨 | 移除摄影机所有权，新增次级材质轨；按语句窗口分配关键姿势 | 摄影机路径仍由导演/SD编译器拥有 |
| BR-05 | 同文件，Physical Interaction Chain | 力源、接触、阻力、主运动、惯性、恢复、残留 | 增加压缩/拉伸、smear、impact、离模峰值和分重量落定 | 风格化不得删除接触和后果 |
| BR-06 | `active-frame-background-state.md`，Information Permission Layer | 运动状态与知情状态分离 | 将知情、误读、延迟、装作不知写成眼、手、头、任务循环和反应幅度 | 不把权限变成装饰字段，必须影响动作 |
| BR-07 | 同文件，Reaction Topology | 直接、级联、分裂知情、表演性静止、误读、系统打断 | 为每名角色锁定R值、感知路径和定性延迟 | 禁止无指令的全员同步震惊 |
| BR-08 | 同文件，Background Person Logic | NPC 0-4级动作 | 细化为0-10反应幅度，并保留任务、姿势、路线和尾态 | NPC不能为了“画面丰富”凭空新增 |
| BR-09 | `sound-design-grammar.md`，声源和变化 | 声音必须有来源、位置、变化和信息差 | 每个主要声音绑定口型停止、眼头肩转向、姿势或间距改变 | 数值混音归声音后期，不由本技能生成 |
| BR-10 | `motion-ecology-counterpart-atlas.md`，performed stillness | 知情者维持任务，只泄露一处 | 转成选择性冻结、moving hold、错音、呼吸和手指压力 | 影片名只留在上游来源，不进入动画输出 |
| BR-11 | `storyboard-sd-compiler-contract.md`，BASE -> DELTA -> TAIL -> NEXT START | 稳定事实与时变事实分层 | 稳定身体基准进入BASE；关键姿势、拍法变化、次级运动和反应进入A；恢复落点进入TAIL | SD最终架构由`dream-suspense-sd`拥有 |
| BR-12 | 同文件，Density Gate | 复杂系统过多时拆节拍 | 动画中两条主动作、口型与碰撞争峰值、两次风格越界时顺序拆分 | 拆分不能省略事实或改变批准时长 |
| BR-13 | `director-storyboard-integrated/references/composition-grammar.md`，Composition Core Law | 构图先回答画面所有者、前中后景、几何、尺度与扣留信息 | 改写为动画观看权限卡：第一眼、第二眼、扣留、障碍、关系几何、证据链、判决、余波 | 导演技能继续拥有镜头与焦段；本技能只拥有动画信息释放和表演可读性 |
| BR-14 | 同文件，Viewing Position And Information Gap | 门缝、框中框、已知危险与观看位置制造信息差 | 将障碍转成谁有权看、谁无法介入、谁的动作被遮断，并绑定眼神、支点和反应路径 | 遮挡必须保留核心证据可读，不能以藏画面冒充悬疑 |
| BR-15 | `director-storyboard-integrated/references/suspense-composition-benchmark-library.md`，尺度/证据/空间压迫 | 小人物与大空间、证据平面、局部到整体、环境余波 | 动画化为局部证据递增、完整人物迟延、大全景判决、明亮环境拒绝配合 | 不复制项目绑定范例、作品时长、角色或标志性造型 |
| BR-16 | `director-storyboard-integrated/references/core-workflow.md`，Scene Control Card | 先锁场景功能、规则、知识差、空间、站位、物件、声音和尾帧 | 改写为“导演事实锁”，作为十二轴世界改写前不可擅改的现实底板 | 导演事实不等于最终动画镜头表；动画层必须另做视觉命题和状态图 |
| BR-17 | 同文件，Living Frame | 对话中人物、物件、背景、光和声音持续运行 | 扩展为十二轴可变性扫描，除现实动作外还检查时间、空间、物理、人物形象、绘画媒介和投影 | 扫描全部不等于全部激活；单段只选2-4主轴 |

## 单向隔离

```text
导演技能通用机制
-> 本登记册记录来源和边界
-> 动画技能内部转成姿势/节奏/形变/反应语法
-> SD编译器只读取正式承接字段
```

禁止：

- 把动画案例、动画作品名、拍法条目或风格突变模板写入导演技能的对标池。
- 在导演技能内创建第二套动画表演语法。
- 让本技能接管镜头选择、焦段、光影、故事结构或最终SD输出架构。
- 从导演参考复制整段文字而不登记来源和动画化变化。

允许：

- 在SD接口契约中登记本技能的字段映射。
- 在正式动画分镜中同时调用导演技能决定镜头、调用本技能决定表演。
- 在生成失败时判断问题属于镜头、表演还是编译层，再只修第一处丢失。
