## 1. 动画语言第一原则

动画分镜先设计“画面怎样被情绪改写”，再设计景别和机位。使用统一链条：

```text
戏剧变化
-> 画面所有者
-> 触发词/视线/接触/声音
-> 主动画变量
-> 人物全身动作与形变
-> 环境/物件/声音接力
-> 转场或画面权限换手
-> 归模锚点
-> 现实残留
```

主动画变量从以下类别选择一个：形体、线条、透视、尺度、帧密度、色彩、阴影、材质、图形符号、环境几何。辅助变量最多选择两个，并沿因果顺序进入。

动画效果必须改变信息、关系、权力、动作、空间或后果。只改变眼睛和嘴形属于表情贴图；只改变镜头角度属于常规覆盖；随机粒子、旋转和闪光属于装饰。

## 2. 表达密度模式

### 2.1 高密度炫技模式

用户提出“动画语言、设计感、夸张、炫技、短剧留人、画面一直动”时默认启用。

- 每 `1-3` 秒刷新一次视觉状态；刷新必须改变画面权限、形体、环境、物件、尺度、节奏或后果中的至少一项。
- 一个 `15` 秒段落采用一个贯穿全段的主表达引擎，并由 `2-4` 个辅助效果接力。
- 段内至少包含一次人物或物件的动画形变、一次环境/群体响应、一次观看权限换手、一次带残留的转场或归模。
- 对话每句至少设置一个可听触发点；关键词使身体、背景、物件、线条、帧密度或机位中的一层发生变化。
- 常规正反打只承担基准或落地。连续三个镜头仅按“谁说话给谁镜头”切换时，重新设计整段表达引擎。
- 静止姿势使用 moving hold：呼吸、眼睑、发丝、衣料、图形边界、光影或环境层继续承担信息。

### 2.2 克制模式

用户明确要求克制、写实或低幅动画时启用。仍需保留画面所有者、一个局部动画变量、环境继续项和明确尾态；克制不等于静止覆盖。

## 3. 情绪到动画效果映射

每种情绪提供候选语法，不构成固定贴纸。先按戏剧功能选择，再替换角色、空间、物件、触发和残留。

| 情绪/功能 | 人物形体与表演 | 图形/绘画变量 | 环境与物件 | 镜头、节奏与转场 |
|---|---|---|---|---|
| 喜悦、兴奋 | 躯干弹簧式压缩回弹，手脚沿大弧线甩出，笑形推动肩髋 | 星点、放射线、彩色残影从动作端点喷出 | 轻物件跟随弹跳，窗光和色块随节拍扩张 | 短时一拍一，动作圆弧匹配太阳、圆灯或旋转物件转场 |
| 天真、好奇 | 头先探、身体后跟，眼睛和耳朵分阶段对焦，轮廓圆化 | 手绘问号、圆点、简笔插图从视线目标冒出 | 背景细节暂时简化，目标物件被放大成独立舞台 | 环绕目标的圆形运动接到瞳孔、管道、杯口或门洞 |
| 安心、亲近 | 肩颈下沉，重心靠近，呼吸与触碰对象逐渐同步 | 线条变柔，局部暖色沿接触点扩散 | 布料、窗帘、灯光以慢半拍跟随呼吸 | 接触轮廓或相同手势匹配转场，落地保留温度与物件位置 |
| 尴尬、喜剧惊慌 | 脸先压扁，脊柱后缩，手脚错拍寻找支点 | 紫色波纹、蒸汽、旋涡、Q版轮廓短暂替换现实背景 | 小物件连续掉落或错位，背景人物保持日常任务 | 阶梯式抽帧、突然定格、袖口或头发擦屏归回现实 |
| 惊讶、认知击穿 | 眼睛先到、下颌后落，身体保持半拍后整体弹开 | 单眼极近、瞳孔图形、短高反差冲击帧 | 环境声和背景运动短暂停顿，一个物件仍继续下落 | 尺度突跳后通过同一眼神、手势或落地声回到客观空间 |
| 怀疑、不安 | 一侧眼睑延迟，头与身体朝向分离，手部任务出现错拍 | 阴影楔形切脸，背景透视线轻微偏移 | 门缝、椅背、杯沿或手机逐步遮断目标 | 缓慢焦点转移后以眨眼、物件声或灯光变化切镜 |
| 焦虑、社会压迫 | 身体高度逐级下降，肩胯收窄，脚尖暴露逃离方向 | 线条重复、局部重影、轮廓被桌椅切碎 | 课桌、人墙、门框和走廊线逐步挤压可用空间 | 前景层加速经过，主体保持低帧；出口或空位完成空间判决 |
| 恐惧、恐慌 | 近端脸手脚强制透视放大，脊柱后折，抓住现实支点 | 鱼眼、粗线、速度墨块、帧密度爆发 | 墙线向威胁汇聚，门窗缩窄，灯影沿压力方向扑来 | 压力源推动摄影机，抓握、脚落地或视线重新对焦触发归模 |
| 轻蔑、厌恶 | 眼睑眯缝、嘴角单侧拉长，头颈或手指异常伸长 | 细长笑弧、黏稠线、尖锐轮廓取代圆形基准 | 环境线向被轻视者倾斜，物件停在私人距离内 | 伸长形体绕行或俯压目标，铅笔、杯沿、门框敲击触发弹回 |
| 愤怒、爆发 | 下颌锁紧，肩背蓄力，骨盆和支撑脚先于拳手启动 | 粗黑线、裂纹、斩光、高反差冲击帧 | 桌面、玻璃、水面或纸张先震动再出现后果 | 预备保持后短时一拍一爆发，接触声切到碎片、裂缝或余波物件 |
| 烦躁、挫败 | 重复动作每轮加力，漏掉一个步骤，最终过冲或破坏物件 | 涂鸦线越缠越密，边缘出现抖动与擦除痕 | 笔、拉链、纸、杯子形成逐轮变化的任务循环 | 相同构图重复微改，最后一轮由物件损坏或声音截断转场 |
| 悲伤、失落 | 身体重量向下沉，手臂失去支撑，嘴形在话尾残留 | 水迹、墨晕、下垂线条沿重力扩散 | 雨、窗光、风和路人继续原节拍，空位逐渐清楚 | 低帧 moving hold，泪滴、雨滴、垂落衣角匹配下一空间 |
| 哀恸、告别 | 身体体积压缩，呼吸、鼻口、下颌和双手逐层失控 | 细节先过度清晰再被白场或水膜吞没 | 环境尺度扩大，声音层逐项撤走，遗留物取得中心 | 完整人物最后落入大全景，物件、空手或空位接管余波 |
| 羞耻、内疚 | 目光先落到手和物件，肩胸收拢，手掌反复擦拭或隐藏 | 污迹、字迹、旧动作残影沿身体爬回 | 证据物重复出现，影子指向角色，周围日常保持 | 手/物件局部证据链后才给完整身体；污迹形状匹配转场 |
| 孤独、排斥 | 主体缩小或降低高度，群体朝向和物件通道转向他人 | 主体颜色局部留存，群体简化为重复形状 | 前景身体、桌椅和路线持续遮挡，明亮环境拒绝配合 | 固定机位让群体流过，空位、封闭圈或分叉路线完成判决 |
| 麻木、抽离 | 眼神失焦，动作循环继续，脸部细节逐级减少 | 线条变淡、背景层漂移、人物与声音轻微不同步 | 时钟、风扇、车辆、同学继续运动，角色只保留重复任务 | 帧密度降低并加入长保持，由物件声或他人触碰重新取得现实 |
| 嫉妒、执念 | 眼睛锁定目标，手指和身体沿同一路线反复靠近 | 瞳孔图形、缎带、线团、藤蔓或重复轮廓从视线发出 | 同类物件不断复制，背景图案围绕目标收紧 | 视线轨迹带动环绕、匹配切或图形侵入，残留一条未断的连接线 |
| 假热情、伪装友善 | 笑脸维持，脚尖、隐藏手或肩胯泄露真实路线 | 可爱符号边缘长出尖角，笑弧保持而眼神失温 | 环境过分整齐，物件摆位形成控制边界 | 公开表演使用流畅帧，私人泄露使用低帧局部；物件轻响使伪装瞬间归零 |
| 绝望、崩塌 | 支点逐个失效，身体沿已启动动作继续越过安全位置 | 轮廓碎裂、影块吞没、细节消失、帧密度先降后爆发 | 地平线倾斜，环境面积扩大，出口抬高或远离 | 动作惯性完成坠落/离场，随后由空场、声音尾巴和残留物接管 |
| 希望、释然 | 肩胸展开，脚步重新取得方向，手掌从抓紧变为开放 | 封闭线条断开，小面积亮色从物件或出口扩散 | 门、窗、云层、群体通道出现可达路径 | 呼吸带动慢推或环境开合，光边、脚步或开放手势接入下一场 |

## 4. 人物形体与绘画算子

| 算子 | 执行链 | 必留锚点 |
|---|---|---|
| 全身 squash/stretch | 反向预备 -> 肩脊髋同步压缩/拉伸 -> 手脚改变支撑 -> 过冲 -> 分重量回稳 | 支撑脚、手掌接触或身体体积感 |
| 头颈/肢体伸长 | 衣领/关节作为固定起点 -> 单一连续曲线伸出 -> 末端仍是同一头/手 -> 绕行目标 -> 沿原路收回 | 起点、同一末端身份、收回路径 |
| 脸部离模 | 正常脸 -> 关键词 -> 眉眼先变 -> 嘴颌和脸型进入峰值 -> 短保持 -> snap-back | 同一视线目标、声音或物件敲击 |
| 强制透视 | 近端手脚/脸先进入 -> 远端躯干压缩 -> 背景线向压力源汇聚 -> 接触或退步 | 地面、门框、桌边或抓握点 |
| 尺度断裂 | 空间中的小人物 -> 单一局部独占 -> 意义改变 -> 更远空间判决 | 同一声音、物件、手势或视线 |
| 多重残影/smear | 动作方向确定 -> 2-4张方向残影 -> 峰值接触 -> 标准轮廓落定 | 最终姿势和接触后果 |
| 线条系统替换 | 正常细线 -> 力或认知触发 -> 粗线/断线/墨块沿作用方向进入 -> 后果落地 | 伤痕、喘息、物件状态或姿势残留 |
| 帧密度变化 | moving hold -> 阶梯姿势 -> 峰值一拍一 -> 回到一拍二/三 | 动作阶段和声音节拍 |
| 图形层入侵 | 图形从角色/物件边界出现 -> 穿过现实几何 -> 接管一项色彩/线条/空间 -> 现实证据持续可见 | 触发源、现实物件、回落残迹 |

## 5. 环境、物件与声音共同表演

### 环境算子

- 几何挤压：门框、桌椅、窗格、走廊线改变主体可用空间。
- 层速度错位：主体保持，前景/背景以不同速度流动，表现抽离、孤立或时间错拍。
- 光影夺权：影子沿声源或关系方向扩张，暖光可继续存在并反证安全感。
- 材质响应：纸张起皱、玻璃震动、水面裂开、灰尘落下、布料拖拽证明情绪具有物理后果。
- 环境拒绝配合：蓝天、晨光、蝉声、路人、课堂任务继续，以正常节拍放大沉重事实。
- 环境接管余波：人物退出后，空位、物件、污迹、风、机械声或光线继续完成情绪。

### 物件算子

```text
物件正常任务
-> 关键词/触碰改变所有权或方向
-> 物件取得构图中心
-> 人物动作被物件牵引
-> 物件状态成为转场或后果
```

铅笔可变成线、道路、指针、蛇形轮廓、裂缝或字迹；门可变成压缩框、擦屏面或关系阈限；书包可变成重量、身份、拖拽轨迹或跨层锚点。物件变化必须保留原材质、持有者或接触点中的至少一项。

### 声音算子

- 关键词触发形变、色彩或环境几何改变。
- 敲击、脚步、门声、铃声负责归模、切镜或权限换手。
- 声层撤走后保留 room tone、机械声或环境声，让画面获得余波重量。
- 音节可对应姿势阶梯、图形生长、物件落点或背景层速度。

## 6. 对话动画化

对话段按以下轨道设计：

```text
起句前：物件/视线/环境先取得注意
前半句：角色保持任务，图形或形体开始生长
关键词：主动画变量越界，身体和环境同步改变
停顿：听者反应，摄影机或画面权限换手
后半句：动画效果抵达目标或改变关系
尾音：归模、物件落地、环境接管或转场
```

角色说话期间，画面可由以下载体接管，而非持续拍嘴：字迹在空间生长、影子替角色靠近、物件变形、背景取消透视、身体局部延伸、群体站位变化、声音化成图形、环境物完成擦屏。

## 7. 情绪转场与归模

| 转场族 | 适用情绪 | 执行 |
|---|---|---|
| 动作弧线接力 | 兴奋、愤怒、逃离 | 手、头、身体或物件沿同方向越过画框，新空间接住同一弧线 |
| 图形溢出 | 天真、执念、恐慌 | 星光、线团、墨水、影块从触发源扩张满屏，退开后露出新关系 |
| 物件同形匹配 | 回忆、内疚、关系变化 | 星形、圆形、门、眼睛、铃铛、污迹或字迹在新空间保持轮廓 |
| 观看权限换手 | 羞耻、误读、真相揭示 | 瞳孔、镜面、门缝、手机或他人视线取得画面，归还不同材质证据 |
| 环境擦屏 | 孤独、日常压迫、余波 | 人群、桌腿、窗帘、风吹纸片、车辆或阴影按自身运动遮满再移开 |
| 声音击穿 | 惊讶、恐惧、认知改变 | 关键词、敲击、铃声或断声触发硬切、冲击帧、归模或时间跳跃 |
| 材质连续变形 | 崩塌、梦境、情绪污染 | 线、纸、墨、液体、烟、碎片或植物从明确起点连续改写空间 |

归模必须回答：谁夺回画面、形体沿什么路径恢复、哪个物件/接触/声音保持连续、现实留下什么残留。归模不是清除效果，而是让效果改变现实后的落地。

## 8. 十五秒高留存编排

推荐内部状态数量为 `4-7` 个，不强制等长：

```text
0-2秒：以异常构图、动作或物件提出问题
2-5秒：主表达引擎开始生长，人物任务仍可读
5-9秒：人物形体、环境或图形层取得第一次峰值
9-12秒：画面权限换手或第二解释进入
12-15秒：归模、物件后果、环境余波或强尾帧
```

高密度不等于平均撒特效。使用“效果接力”：人物动作把动势交给图形，图形改变环境，环境运动完成转场，转场落在物件或现实后果。前一效果的末端必须成为后一效果的起点。

### 学校排斥示例

```text
门打开形成阈限
-> 铅笔划线穿过课桌
-> 课桌线条压缩入口
-> 施压者的身体或影子沿铅笔线异常伸长
-> 关键词在受害者耳边落下
-> 铅笔敲击使形体沿原线收回
-> 同一黑线落成课桌上的侮辱字迹
-> 晨光和课堂声音继续
```

这条链只使用“铅笔线”一个主表达引擎，却同时驱动人物形变、环境、声音、转场和后果。

## 9. 反平庸验收

关键动画段落输出前逐项回答：

```text
这段的主动画表达引擎是什么？
哪一个情绪或关系变化触发它？
谁拥有图形、形体、色彩或环境解释权？
人物除脸以外，肩脊髋、重心、手脚怎样参加？
环境、物件、NPC和声音分别怎样接力？
每1-3秒新增了什么视觉状态或意义？
哪一个画面只靠动画才能成立？
效果怎样归模，现实留下什么残留？
关闭对白后，关系、情绪和后果是否仍可读？
```

判废条件：

- 三个连续镜头仅按说话者与听者切换。
- 关键情绪只靠普通近景、眼睛放大和嘴形变化。
- 特效与身体支点、空间、物件和后果没有因果连接。
- 环境保持布景状态，台词开始后所有动作停止。
- 动画效果结束后现实状态完全回到原样。
- 每个镜头单独漂亮，但全段没有贯穿的表达引擎。

## 10. 三引擎方案筛选

正式拆景别前，针对同一个戏剧任务内部生成三套不同的动画表达引擎。三套方案必须改变同一项关系、信息或行动，不能只是换特效名称。

| 候选 | 起点 | 必须回答 | 常见优势 | 淘汰信号 |
|---|---|---|---|---|
| 身体驱动 | 姿势、重心、轮廓、呼吸、手脚或离模峰值 | 情绪怎样穿过肩脊髋、支点、过冲和恢复 | 表演直接、角色记忆点强 | 只有脸变形；环境和后果不响应 |
| 物件驱动 | 当前任务物、随身物、门、桌椅、字迹、食物或声音源 | 物件怎样改变所有权、方向、形状和下一步行动 | 因果清楚、转场稳定、适合AIGC | 道具只是图标；变形后丢失材质或持有关系 |
| 环境驱动 | 群体拓扑、门框、课桌网格、道路、光影、风或机械节奏 | 空间怎样收窄、拒绝配合、换手或接管余波 | 压迫力强、减少常规反打 | 只加气氛；人物路线、信息和权力不变 |

每套方案先写一行完整链：

```text
触发 -> 主变量 -> 人物动作 -> 环境/物件/声音接力
-> 观看权限变化 -> 归模锚点 -> 现实残留
```

再按六项各 `0-5` 分评分：

1. 新颖度：不是当前段落已经用过的同一种噱头。
2. 因果性：每一变化都由台词、动作、接触、声源或关系触发。
3. 留存力：前 `2` 秒有问题画面，随后每 `1-3` 秒有意义刷新。
4. 连续性：前一效果的末端能成为下一效果的起点。
5. 情绪精度：准确表达当前关系，而非笼统的“夸张、恐怖、可爱”。
6. 生成可行性：角色、轴线、支点、物件身份和落地帧可被稳定描述。

选总分最高且无硬伤的一套作为主引擎；从另两套中最多借一个辅助算子。若最高分方案无法形成现实残留、无法静音读懂或需要同帧改变三个以上主变量，直接淘汰。对用户输出时保留三案摘要、评分和选择理由，避免跳过导演筛选直接写第一反应。

## 11. 效果接力编舞

动画效果不是并列清单，而是动势、形状、颜色、声音、证据或解释权的接力。每个效果必须从上一效果继承至少一根“接力棒”。

### 11.1 六类接力棒

- 形状：圆、星、门框、瞳孔、铃铛、污迹、手掌轮廓。
- 方向：角色后退弧线、手臂挥动、铅笔划线、坠落方向、风向。
- 色彩/光：暖光、粉色图形、黑影、白化从明确起点扩散。
- 节奏：口型音节、脚步、敲击、姿势阶梯、帧密度爆发。
- 材质/物件：纸、布、玻璃、水、头发、书包、门、桌面字迹。
- 权限/证据：人物主观把画面交给见证者，见证者再交给物件或环境判决。

### 11.2 强制链式写法

```text
效果A的来源与末端
-> 继承哪根接力棒
-> 效果B怎样改变它的形态或意义
-> 谁取得画面
-> 效果C怎样落成现实动作/物件/空间后果
-> 哪个残留进入下一镜
```

合格例：嘴角细长笑弧把弧线交给伸长的颈部，颈部弧线交给铅笔划痕，铅笔划痕落成桌角字迹，晨光掠过字迹后让普通教室重新取得画面。

不合格例：鱼眼 -> 星星 -> 快切 -> 黑场。四项没有共同起点、动势、物件或后果，属于互不相干的贴纸。

每次接力同时限定一项“不能丢的现实锚点”：脚下支点、手掌接触、桌边、门框、声源、视线目标或物件持有关系。高潮后不清空效果；让它落成污迹、错位物件、身体姿势、空位、声音尾巴或下一场的同形轮廓。

## 12. 日常段动画化

日常段负责建立动画语法，不是等待剧情发生的空白。普通说话、吃饭、走路、等人和整理物件也必须通过动作与环境让画面持续有意义地变化，但不必强行离模。

使用五轨日常循环：

```text
角色任务循环
-> 说话造成一次错拍、漏步或路线变化
-> 物件完成一次所有权/位置变化
-> NPC或环境以独立节拍响应或拒绝响应
-> 声音把动作交给下一镜
```

- 身体轨：坐下、弯腰、转笔、收衣、咀嚼、换支撑脚、抬包带，形成可复用姿势短语。
- 物件轨：杯、筷子、纸、门、拉链、椅子、灯、鞋先承担一句话的动作标点。
- 环境轨：窗帘、树影、风扇、晨光、人流和机械声继续自己的节拍，必要时拒绝配合人物情绪。
- NPC轨：不同距离的人按感知路径错峰抬眼、停手、让路、继续任务，禁止全员同帧反应。
- 图形轨：说明、回忆或天真理解可短暂平面化，但要从现有动作或物件长出来。

高潮不应第一次发明动画语言。先在日常中建立一个无害语法，例如星点、转笔、门声、姿势循环或物件同形；后来只改变其中一两个变量，使同一语法加速、失真、反向、过量、断裂或留下伤害证据。这样高潮是熟悉语言被污染，而不是突然插入MV。

## 13. 视觉语法升级与腐化

重复母题按四阶推进，每次只升级一个主要维度：

```text
建立：母题完成无害、清楚、可爱的任务
-> 变调：相同母题进入新的关系或空间，保留原节奏
-> 腐化：方向、尺度、颜色、材质、帧密度或结果中的一项越界
-> 余波：母题恢复普通外形，但含义和现实状态已经改变
```

可升级维度：

- 方向：靠近变追逐，抚摸弧线变成推开或坠落弧线。
- 尺度：小图标变成占满画面的空间规则。
- 速度：稳定循环变成错拍、漏拍、骤停或一拍一爆发。
- 材质：柔光图形落成墨迹、裂痕、污渍或真实重量。
- 所有者：可爱角色的解释权被受害者、见证者、物件或环境夺走。
- 结果：原本用于安慰的动作继续执行，却通向不可逆后果。

视觉张力采用不对称波形：基准 -> 局部失调 -> 短峰值 -> 假恢复 -> 第二解释 -> 现实判决。禁止每两秒平均增加一个大特效；平均刺激没有峰谷，也无法积累压迫。

## 14. 动画表达评分卡

成稿按六项各 `0-5` 分验收，总分低于 `24/30` 或任一项为 `0` 时重做：

| 维度 | 5分标准 |
|---|---|
| 动画专属性 | 至少一个关键画面依赖形体、绘画系统、帧密度、图形侵入或空间变形，真人覆盖无法等价完成 |
| 因果接力 | 人物、图形、物件、环境、声音和转场之间有清楚继承关系，没有孤立噱头 |
| 观看权限 | 画面所有者、扣留信息、证据顺序和最终判决明确 |
| 表演完整度 | 脸、肩脊髋、重心、手脚、次级惯性、恢复和尾态共同完成动作 |
| 视觉留存 | 15秒内有 `4-7` 个意义不同的状态，首两秒提问，尾部留下后果或强钩子 |
| 情绪精度 | 特效、色彩、构图和节奏准确服务当前关系，并能在静音时读懂 |

额外判废：环境从未取得过动作或余波所有权；唯一的动画专属画面与剧情无因果；效果结束后身体、物件和空间全部复原；日常段只有口型和正反打；高潮使用了前文从未建立的随机视觉语法。
