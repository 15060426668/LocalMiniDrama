# 厚涂阶梯式 AI 动画配置

## 1. 定位

这是一套面向 AI 视频的克制型二维动画配置。它把概念设计式厚涂画面、有限动画节奏、分层运动和电影化因果分镜结合起来，目标不是模拟真人摄影，也不是把一张插画做平滑形变，而是让每次姿势更换都像重新画过一张画。

适用：

- 雪原、荒野、历史、民俗、神话、战争余波和自然压迫。
- 低对白或克制对白、追逐、灾难、动物群体、人与环境关系。
- 需要油画/水粉笔触、低饱和色彩和阶梯式角色运动的 AI 视频。
- 需要以少量强关键姿势和环境运动维持电影感的短片。

不自动适用：

- 精致美型人物主导、皮肤高光和发丝精修优先的唯美幻想插画。
- 光滑赛璐璐、高光泽 3D、照片级真人或全程高帧动作展示。
- 依赖连续液化、融化、形态漂移或无锚点 morphing 的设计。

它是可选风格配置，不是动画技能的全局默认。

## 2. 核心视觉命题

```text
坚实世界保持重量
-> 人物和有形生物以清楚关键姿势阶梯移动
-> 笔触在重绘中轻微沸腾
-> 风、雾、烟、远雪和光影以另一套连续节奏流动
-> 柔软材质晚于主体响应并分重量落定
-> 镜头由身体、风压或观看者呼吸驱动
-> 环境或物件接管余波
```

真正的风格所有者不是“油画”这个形容词，而是以下五层的稳定关系：

1. 固体锚点：山体、地面、建筑、道具主体和空间轴线保持稳定。
2. 阶梯主体：人物、马、狼和前景动作以关键姿势而非滑行换位。
3. 连续气层：雾、烟、远雪、云影和微光持续流动。
4. 延迟材质：毛皮、头巾、衣摆、鬃毛、马具和呼吸晚半拍响应。
5. 有机镜头：静戏是低幅呼吸，动作戏才提高冲击、修正和倾斜幅度。

## 3. 生产体系

### 3.1 剧本与镜头任务先行

每个镜头先锁定：

```text
故事为什么发生
-> 角色此刻必须做出的选择
-> 观众必须先看见的原因
-> 随后才允许看见的结果
-> 环境、物件或声音留下的残留
```

提示词不能替代剧本。没有剧情上下文时，同一句“母亲在雪地里失去孩子”会漂成灾难爽感、猎奇画面或普通追逐。先锁定戏剧任务，再决定显露、留白和动作强度。

### 3.2 按镜头组织版本树

每个镜头建立独立版本空间，至少保存：

- 初始方向稿。
- 可用构图分支。
- 表演强度分支。
- 环境和光色分支。
- 动作/因果修复分支。
- 入选版、备选版和淘汰原因。

早期失败测试不直接删除；标明可继承的笔触、动作、构图或环境机制。版本量本身不等于质量，选择标准必须回到戏剧功能、连续性和执行稳定性。

### 3.3 先做风格锚，再做资产族

全片先确认一张或一组风格锚，然后建立可复用资产：

- 角色标准造型、年龄变化、季节服装和三视/四分之三视图。
- 关键表情不是表情包，而是角色在具体行为中的姿势和脸部状态。
- 动物体型、毛色、步幅和群体差异。
- 人马绑定、人物与道具所有权绑定。
- 建筑、帐篷、家具、武器、首饰和生活物件。
- 环境气氛图：季节、天气、时段、能见度和光色状态。
- 文化事实卡：服装纹样、材料、生活方式和称谓由人工核对。

角色一致性依靠资产族和引用职责，不依靠反复堆叠形容词。

### 3.4 人机分工

AI适合承担：

- 方向探索、环境扩展、构图变体和光色试验。
- 在已锁定关键姿势之间生成动作候选。
- 风雪、雾、烟、群体和动物运动的多个可选版本。
- 高风险动作的覆盖镜头与稳定替代版。

人工必须承担：

- 剧本、分镜、动作因果、站位轴线和信息释放。
- 文化真实性和角色资产校准。
- Photoshop 局部重绘、边缘修正、比例修正和身份修复。
- 逐镜选版、节奏剪辑、逐镜/逐帧调色。
- 声音清理、层次设计、音乐选择和最终混音。

系统不是“一次生成成片”，而是`导演锁定 -> 批量探索 -> 人工筛选 -> 局部重绘 -> 剪辑与后期`。

## 4. 画风圣经

### 4.1 媒介与表面

- 哑光水粉与油画混合的概念设计质感。
- 宽笔触、干湿交错、边缘有取舍，近景局部清楚，远景融入色块。
- 允许轻微笔触沸腾，但不同层幅度不同；不是全画面等幅抖动。
- 角色轮廓和关键接触点清楚，内部细节服从景别与动作速度。
- 表面保持固体感；重绘变化不能把脸、衣物和道具融成流体。

### 4.2 造型

- 人物以轮廓、姿态、服装层次和重心优先，脸部不追求瓷化精修。
- 动物采用可读的大形、脊背线、胸腔重量、步幅差和毛色差，禁止镜像复制群体。
- 毛皮、粗布、皮革和旧木器是主要材质证据；亮面金属只作小面积点缀。
- 服装纹样和民族元素必须来自可信资产，不生成含混的“泛民族风”。

### 4.3 色彩

- 主体色域：暴风灰、灰白、炭黑、板岩灰、低饱和蓝绿和泥土暗色。
- 色温保持自然中性，可略冷，但不使用统一电光蓝滤镜。
- 暗红、锈红、余烬橙和旧金属色只承担稀少叙事点色。
- 白雪保留灰度层次，暗部保留颜色和细节，不压成死黑。
- 调色目标是跨镜头呼吸一致，不是把所有镜头套同一 LUT。

### 4.4 光线

- 阴天、暴雪和黄昏优先使用柔和漫射自然光。
- 光源方向、受光面和材质响应必须可解释。
- 面部在低调照明中仍保持可读，不依靠锐利轮廓光补救。
- 不把体积光、光束和神光当默认电影感。
- 室内允许单一开口或余烬形成局部亮区，亮区服务脸、手或关键物件。

### 4.5 构图

- 默认继承正式动画分镜的`21:9`画幅，项目另有画幅时覆盖。
- 人物常处于大环境中的小尺度位置；山体、风暴、空白和暗色体量建立自然压力。
- 使用三分位置、低地平线、对角运动线和大片主动负空间，但不机械套三分法。
- 暗色人物/狼群与浅色雪地形成块面对比；点色不抢夺主叙事焦点。
- 大全景负责判定人与环境的力量关系，近景负责动作证据和物件所有权。

## 5. 帧率与运动分层

### 5.1 “12fps + on twos”消歧

正式规划默认写成：

```text
24fps播放容器
-> 人物和主要有形动作一拍二
-> 每张姿势保持2个播放帧
-> 约12张不同绘制/秒
```

如果项目确实以12fps文件播放，就直接写`12fps播放，每帧一张`，不要再同时写“一拍二”。“12fps播放且一拍二”会变成约6张不同姿势/秒，除非这是明确选择。

网页 GIF 的10fps或压缩帧率只代表发布预览，不用于反推母版节奏。

### 5.2 混合拍法

- 克制对话：人物一拍二或三，停顿使用 moving hold。
- 普通行走/动物运动：一拍二，以强姿势和清楚弧线维持可读性。
- 抓取、咬合、落地、撞击和方向突变：峰值可短时一拍一。
- 过冲和恢复：回到一拍二，软材质继续晚半拍落定。
- 余波：主体保持，风雪、呼吸、衣料或声音尾巴继续。

### 5.3 分层节奏表

| 层 | 默认节奏 | 任务 |
|---|---|---|
| 山、地面、建筑、重道具 | 稳定或极低幅变化 | 空间和重量锚点 |
| 人物、马、狼、近景动作 | 一拍二的姿势阶梯 | 意图、力和身份 |
| 接触峰值、冲击关键张 | 短时一拍一或单张冲击姿势 | 原因与结果的断点 |
| 毛皮、头巾、衣摆、鬃毛、马具 | 晚于主体，按重量分批落定 | 次级惯性 |
| 绘制的近景雪溅、粉尘撞击 | 与接触动作同拍或晚半拍 | 力量证据 |
| 远雪、雾、烟、云影、余烬光 | 连续缓慢 | 空气和空间连续性 |
| 笔触沸腾 | 局部、低幅、按注意力分配 | 手绘生命感 |

“环境平滑”不等于所有环境元素平滑。受力形成的雪块、雪溅和粉尘属于动作后果，应跟随阶梯节奏；远处漂雪和雾层才承担连续流动。

## 6. 表演与镜头架构

### 6.1 克制对话

```text
公开姿势保持
-> 台词或沉默触发眼神/呼吸/下颌变化
-> 手和纪念物承担私人拒绝
-> 柔软材质与呼吸延迟响应
-> 物件收紧、停住或改变所有权
-> 环境声与空白接管尾帧
```

选择一件真正参与行为的物件。角色要转、握、磨、松开、藏起或拒绝交出它；物件状态变化必须与台词重音或沉默发生因果。不要依靠连续脸部特写重复解释同一种悲伤。

### 6.2 威胁显形

```text
能见度受限的环境基准
-> 声音或痕迹先出现
-> 暗色体量从风雪/雾中获得轮廓
-> 身体动作证明其重量和意图
-> 突然停顿把视线交给画外负空间
-> 环境继续，威胁信息保持未完成
```

狼群、敌人或灾害先作为空间中的体量和运动方向存在，不默认正面扑向镜头。眼睛、耳朵、背线、足迹、呼吸或群体暗流可逐项取得观看权限。

### 6.3 灾难与动作

每个关键后果必须通过以下链条出现：

```text
力源/选择
-> 接触点
-> 第一处可见变化
-> 重量和方向传播
-> 身体失衡或路线改变
-> 环境/材质反馈
-> 结果
-> 残留
```

动作戏先锁空间：人物朝向、危险来源、上下高差、进入方向、画面运动方向和下一镜继承。文章式长提示中最常见的失败是同一段同时写“危险在前方”和“危险在背后”；发现冲突时，以导演事实锁和空间图为准，删除相反指令。

残酷感优先由重量、体量、声音、遮蔽和后果表达。除非故事需要，不依赖解剖细节或持续血腥特写。

### 6.4 镜头有机运动

- 静戏：低幅呼吸式手持，只在身体重心、听觉或注意力变化时微调。
- 环境建立：镜头可缓慢上升、前移或漂移，但必须揭示新层次或改变尺度关系。
- 动作戏：垂直弹跳、倾斜和急修正由奔跑、风压、撞击或跌落驱动。
- 硬切用于动作阶段、信息所有者或能量级别发生明确变化。
- 不使用无因乱晃模拟“电影感”；删掉摄影机形容词后，动作因果仍应成立。

## 7. 段级执行卡

在正式镜头表前填写：

```text
导演事实锁：故事因果 / 信息权限 / 空间与轴线 / 角色物件绑定 / 时长 / 尾态
风格锁：媒介 / 笔触幅度 / 边缘策略 / 色域 / 光线 / 黑位 / 点色
资产锁：人物版本 / 动物差异 / 人马绑定 / 服装道具 / 场景气氛
主世界轴：时间/帧密度 + 绘画媒介 + 环境材质；是否需要投影镜头轴
段级视觉命题：哪一种自然力或物件动作改写关系
运动分层：固体 / 阶梯主体 / 冲击层 / 延迟材质 / 连续气层 / 镜头
状态图：S0基准 -> S1触发 -> S2身体适应 -> S3因果峰值 -> S4环境换手 -> S5残留
表演链：意图 / 正常基准 / 关键姿势 / 拍法 / 次级动作 / 恢复
声音链：主声源 / 画外压力 / 接触声 / 撤声或尾桥
AIGC风险：身份漂移 / 人马互换 / 群体克隆 / 空间反转 / 形态融化 / 蓝滤镜 / 过度平滑
```

这张卡向导演分镜交付画面与表演事实；最终 SD/Seedance 提示结构仍由下游编译技能负责。

## 8. 提示结构去噪

上游镜头说明按以下顺序组织，不复制论文式冗长重复：

1. 稳定风格和资产引用职责。
2. 当前镜头唯一戏剧任务。
3. 空间、朝向和角色/物件绑定。
4. 关键姿势与原因先于结果的动作链。
5. 各层运动节奏和次级惯性。
6. 由动作驱动的镜头变化。
7. 光色、材质和声音触发。
8. 尾帧与下一镜继承。
9. 只保留会真实发生的风险约束。

同一事实写一次。若角色、位置、光线、动作或帧率出现两种互斥说法，必须在进入生成前裁决，不能靠重复强调赌模型选择正确版本。

## 9. 失败边界

- 只写“会动的油画”，没有帧密度、姿势链和运动分层。
- 全画面等幅笔触抖动，导致脸、建筑和地面一起融化。
- 人物、马、狼和雪雾都用同一种平滑插值，失去有限动画节奏。
- 把所有层都设为阶梯运动，空气感消失，画面像低帧卡顿。
- 所有柔软材质与主体同帧启动、同帧停止，重量被抹平。
- 长提示重复摄影术语，却没有力源、接触、方向和结果。
- 固定写死焦段、三分法和手持幅度，即使它们不改变当前戏剧任务。
- 用统一蓝滤镜、锐利轮廓光、强散景和光束冒充电影感。
- 角色服装与文化元素由模型自由补全，形成不可信的混合符号。
- 群体动物镜像、克隆、步幅一致，或人物与坐骑在镜间互换。
- 只选最漂亮版本，不检查前后镜头的动作、光色、身份和尾帧连续性。
- 把长提示词当作控制力证明，忽略人工选版、重绘、调色和声音后期。

## 10. 验收

```text
风格锚和资产引用是否明确？
24fps容器/12fps播放与一拍二的关系是否无歧义？
固体、主体、冲击、软材质、气层和镜头是否分轨？
人物与动物是否通过姿势阶梯移动，而非滑行或融化？
笔触沸腾是否局部、低幅并服从注意力？
静戏是否有物件、呼吸、视线和环境继续项？
动作戏是否先原因、后结果，并保留空间方向和重量？
镜头运动是否能指出身体、风压、声音或观看权限的力源？
光色是否中性低饱和、暗部可读、点色克制？
文化细节、角色身份、人马绑定和群体差异是否人工校准？
结尾是否由环境、物件、声音或身体残留接管？
人工选版、局部重绘、调色和声音后期是否仍在流程中？
```

## 11. 证据边界

本配置由来源卡`B-W27`支持。该来源是可访问的行业公众号文章，正文、公开提示词和内嵌媒体已核对；网页共索引到85项媒体，其中前78项覆盖正文主要设定图和动画片段。内嵌 GIF 多为10fps发布预览，不能证明母版播放帧率。文章中的成本、产量、版本数量和“开源”表述只作为来源陈述，不提升为运行时定律；互相矛盾的提示词已按空间、因果和帧率规则去噪。
