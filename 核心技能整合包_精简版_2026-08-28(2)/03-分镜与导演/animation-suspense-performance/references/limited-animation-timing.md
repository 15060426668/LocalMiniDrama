## 1. 基础单位

默认以 `24fps` 的播放时间讨论，不假定每帧都重画。

- 一拍一：每1帧换一张，24张/秒。
- 一拍二：每张保持2帧，约12张/秒。
- 一拍三：每张保持3帧，约8张/秒。
- 混合拍法：同一动作按信息密度在一拍三、二、一之间切换。
- 保持：主姿势不换，但可保留呼吸、线条轻变、眼睑、嘴、手或环境层。

帧密度不是质量等级。它控制动作的清晰度、突然性、重量、主观感和绘制资源。关键接触、快速方向变化和离模峰值通常需要更高密度；社会压抑、等待和误读常依赖较长保持。

### 1.1 播放帧率与拍法消歧

`fps`描述播放容器每秒显示多少帧；`一拍几`描述同一张绘制保持多少个播放帧。两者必须同时明确：

```text
24fps播放 + 一拍二 = 每张保持2帧，约12张不同绘制/秒
24fps播放 + 一拍三 = 每张保持3帧，约8张不同绘制/秒
12fps播放 + 每帧一张 = 约12张不同绘制/秒
12fps播放 + 一拍二 = 每张保持2帧，约6张不同绘制/秒
```

不要只写“真正的12fps、on twos”而不说明播放容器。面向视频模型时，优先写可见行为：`姿势保持后阶梯切换，主体不滑行；接触峰值短时加密；恢复后回到较长保持`。网页 GIF、平台转码和预览文件的显示帧率不能反推母版拍法。

## 2. 一拍一、一拍二、一拍三

| 拍法 | 视觉特征 | 适合 | 不适合 |
|---|---|---|---|
| 一拍一 | 连续、快速、冲击点清楚、次级运动细 | 坠落峰值、甩动、快速转头、接触、复杂变形 | 全段日常对话，重点会被平均 |
| 一拍二 | 稳定、常规、兼顾姿势和流动 | 大多数角色动作、对话身体表演、正常行走 | 极高速接触若关键姿势不足会糊 |
| 一拍三 | 阶梯感、克制、有限动画味、姿势占主位 | 压抑保持、低幅群体反应、主观错拍 | 精密碰撞、快速手部接触 |
| 混合 | 节奏本身成为表演 | 正常段慢拍 -> 峰值一拍一 -> 余波保持 | 无触发地随机换拍 |

### 推荐切换

```text
正常基准：一拍二或三
预备：保持更久，姿势差变小
动作启动：间距逐渐拉大
峰值：短时一拍一或极少数强关键张
过冲：间距快速缩小
恢复：回一拍二/三，保留材质和呼吸
余波：主姿势保持，局部层继续
```

## 3. 保持与选择性运动

### 3.1 保持类型

| 类型 | 主姿势 | 允许运动 | 叙事任务 |
|---|---|---|---|
| 完全保持 | 角色轮廓不换 | 环境或声音继续 | 取消角色反应权、制造制度冷漠 |
| Moving hold | 姿势近似不变 | 呼吸、线条、衣发、眼睑轻变 | 保持生命感和压力 |
| 嘴部保持 | 身体和头部稳定 | 受控口型、下颌和呼吸 | 密集台词清晰度 |
| 眼部节拍 | 身体与嘴形保持 | 眼神转移、眼睑闭合 | 知情变化、误读、怀疑 |
| 手部节拍 | 社交脸保持 | 手指、腕角、抓握或悬停 | 私人泄露、物件关系 |
| 群体保持 | 多人姿势维持 | 一名角色或一层环境移动 | 孤立、排斥、唯一信息所有者 |

保持必须有信息变化。若角色、声音、环境、光和构图都不变，属于死停。

### 3.2 选择性运动优先级

每个短节拍优先只激活一条：

1. 眼/眼睑：认知和注意力。
2. 嘴/下颌：说话、笑形残留、吞咽。
3. 手/道具：压力、关系和因果证据。
4. 脊柱/重心：情绪控制真正改变。
5. 次级材质：惯性、风、受力和余波。
6. 背景/NPC：信息传播或社会环境。

同一时间激活三条以上时，必须明确主次或拆成连续节拍。

## 4. 动作间距模板

以下数字用于节奏规划，不是所有模型提示词都要写帧号。

### 4.1 突然转头，约0.5秒

```text
F1-F4  起始保持，眼睛先到目标
F5     头部启动
F6-F8  大间距跨越，允许一张smear
F9-F10 头部过冲
F11-F12 回收并落定，肩部后到
```

### 4.2 克制反应，约1秒

```text
F1-F8   正常任务保持
F9-F12  手指或口型停住
F13-F18 眼神转移，头仍不动
F19-F24 一次眨眼/轻呼气，身体保持原位
```

### 4.3 重心越界和跌落，约1.5秒

```text
F1-F8   动作高峰前的压缩或前折
F9-F15  反向回弹，脊柱依次展开
F16-F20 重心越过支撑面，手脚试图补救
F21-F27 下坠加速，衣发/长耳延迟
F28-F32 接触或离开构图峰值，可短时一拍一
F33-F36 次级运动过冲，尾态落定
```

### 4.4 压住哭或怒，约2秒

```text
F1-F12  公开脸和任务保持
F13-F20 下颌/喉部改变，吸气未完成
F21-F28 手部加压，肩膀反向下沉
F29-F36 眼睛失焦或重新对焦
F37-F44 过度补偿：笑、点头或继续任务
F45-F48 尾态保留一项残留
```

### 4.5 大事件、低反应旁观者，约1秒

```text
F1-F10  坐姿和任务保持
F11-F15 手抬三到五厘米/笔尖停住
F16-F20 下巴抬几度，眼睛先转
F21-F24 一次眨眼或嘴形残留，未起身
```

## 5. 对话和表演轨分配

### 5.1 七轨

```text
口型轨
主身体路线
手/道具轨
听者反应轨
NPC/背景轨
次级材质轨
声音触发轨
```

### 5.2 语句窗口

- 密集语句：头胸保持稳定，口型、下颌、呼吸和一个小手势工作。
- 逗号/换气：安排眼神转移、肩部变化或简单手部动作。
- 句尾：安排听者反应、身体转向、物件落定或剪辑触发。
- 打断：新声音先进入，原口型停止，眼/头/身体依次换权。
- 大动作：放在短句、词间空隙或台词结束后；必要时拆节拍。

### 5.3 口型经济

- 先锁开口、闭口、宽口、圆口、咬合和停顿等少量关键口型。
- 下颌幅度、呼吸和脸颊张力要与声音强度一致。
- 口型结束后可保留短暂残形，但必须写回收点。
- 说话者的大幅身体动作与复杂口型不要同时争夺峰值。

## 6. 爆发、离模与恢复

### 6.1 Smear

使用在快速位置跨越中，写清：运动方向、被拉伸的部位、持续极短、下一张正常落点。Smear不是停留造型。

### 6.2 Multiples

同一肢体出现多个连续位置时，保留一个主位置和清楚方向。适合高速手势、抖动或喜剧爆发，不用于慢重动作。

### 6.3 Impact frame

接触峰值可短暂简化、反色、高反差或粗线。前一张必须建立接近，后一张必须出现物理后果、材料反馈或身体恢复。

### 6.4 Off-model

离模前后保留身份锚点：发型轮廓、服装形状、主色块、标志性五官位置、体型关系。离模服务动作峰值，不成为全段默认造型。

### 6.5 恢复

```text
峰值 -> 过冲 -> 主体先回位 -> 重材质后回位
-> 呼吸/支点恢复 -> 表情或动作残留 -> 清楚尾帧
```

若峰值后直接切回标准立绘，动作会失去重量。

## 7. AIGC转译

视频模型可能不稳定执行精确帧号。按以下优先级转译：

1. 先写关键姿势顺序。
2. 再写加速、减速、停顿、突然跳变和持续时长。
3. 再写短时高帧密度、阶梯式变化或保持。
4. 再写smear、粗线、压扁拉长等峰值形变。
5. 最后写恢复、次级惯性和尾帧。

模型执行词示例结构：

```text
她先保持坐姿和笑形，肩部连续弹动；身体向前折叠压缩后沿同一动作弧线回弹，
回弹中速度突然加快，短暂出现方向明确的拉伸残影；髋部越过椅面支点，双手晚半拍寻找支撑，
头发和衣摆滞后上扬，身体向后离开构图；尾帧保留空椅、尚未落下的衣摆和旁观者轻抬的手。
```

避免只写“一拍一、作画炸裂、有限动画、夸张颜艺”。这些术语必须落到姿势、间距、受力、形变和恢复。

## 8. 检查表

```text
正常基准是什么？
关键姿势链是否包含预备、峰值、过冲和落定？
当前使用一拍一、二、三或混合拍法的原因是什么？
保持期间哪一层仍在运动或改变信息？
间距怎样表现加速、重量或犹豫？
说话口型与大身体动作是否抢同一峰值？
smear/impact/off-model前后是否有正常锚点？
旁观者反应幅度是否独立锁定？
次级运动是否晚于主体并分重量落定？
尾帧能否被下一节拍直接继承？
```

## 9. 镜头突变与绘画层节奏

镜头突变也需要预备、峰值和恢复，不能把鱼眼、强透视、图形背景或粗线当作一张静态效果图。

### 9.1 约1秒的恐慌广角

```text
F1-F6   正常空间保持，眼睛或压力源先取得注意力
F7-F10  近端脸/手/脚开始放大，身体支点出现迟疑
F11-F15 边缘空间弯曲或透视线汇聚，动作间距拉大
F16-F18 峰值短保持，允许一张拉伸/粗线关键张
F19-F24 手抓物、脚落地或身体退到新位置，空间回正并留喘息
```

鱼眼效果必须由角色与摄影机的相对距离变化支撑。只有背景弯曲而人物大小、手脚距离和重心不变，属于滤镜感。

### 9.2 约1.5秒的图形层侵入

```text
F1-F8   现实背景和人物基准
F9-F12  图形从眼、手、物件或声音位置出现第一条边界
F13-F20 图形沿明确路径穿过真实空间，现实锚点仍可见
F21-F28 主观动作在图形层中完成，帧密度可短时提高
F29-F32 见证者/物件/客观证据夺回注意力
F33-F36 图形退去或留一小块残迹，回到现实尾态
```

### 9.3 4-15秒动画段落的密度分配

```text
现实基准 30%-45%
压力建立与局部失调 20%-30%
一次主要镜头/绘画突变 10%-25%
现实回落与余波 20%-35%
```

比例按剧情调整，但通常只安排一次主要突变。其余变化服务预备和回落，避免全段持续高密度导致没有峰值。

### 9.4 16-30秒动画段落的密度分配

16-30秒保持一份段级事实锁，并在内部形成两个相互继承的节奏相位。第一相位建立任务与压力，第二相位发展、反转或兑现；12-18秒附近必须出现可见状态刷新。每个2-4秒时间窗仍只允许一个主动作链。主要绘画突变可以在不同相位各出现一次，但第二次必须继承第一次的形状、方向、色彩、声音、物件或画面权限，并在30秒内完成现实回落或明确残留。
