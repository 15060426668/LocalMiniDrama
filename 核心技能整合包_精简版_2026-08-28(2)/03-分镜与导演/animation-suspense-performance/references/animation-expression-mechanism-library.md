## 1. 使用方法

本库解决“知道人物很轻蔑、恐惧或内疚，却只想到邪笑、瞪眼和正反打”的问题。先发散表达机制，再决定机位。不要从情绪标签直接跳到脸部肌肉。

对关键阈值先做五域发散：

```text
形体域：身体或轮廓能违反什么现实规则？
意象域：视线、语言、关系或欲望能具象成什么？
空间域：建筑、距离、尺度和通路能怎样改写权力？
时间域：回忆、预想、重复和后果能怎样侵入现在？
媒介域：线条、纸张、像素、文字、声音或喜剧格式能怎样换权？
```

至少生成三种不同域的方案，再把它们归入身体驱动、物件驱动、环境驱动三套可执行候选。三套候选不能只是把“黑影”换成“红线”或把“邪笑”换成“蛇眼”。

每套机制必须写成：

```text
戏剧任务 -> 画面所有者 -> 现实触发 -> 第一处越界
-> 发展路径 -> 人物全身参与 -> 环境/物件/声音接力
-> 现实锚点 -> 归还触发 -> 残留后果
```

## 2. 机制选择卡

| 问题 | 选择方向 |
|---|---|
| 对方的威胁正在逼近 | 视线外化、强制透视、私人距离被吞噬 |
| 两人关系不再属于现实交流 | 异常心理空间、空间折叠、尺度断裂 |
| 一句话暴露旧伤或动机 | 环境裂开、物件开门、声音重建回忆 |
| 角色把抽象概念说得很具体 | 文字/符号实体化、道具变形、图解空间 |
| 日常场景要越来越压抑 | 群体几何、环境拒绝配合、重复基准腐化 |
| 严肃段落需要短暂幽默 | 错拍、字面化、格式恶搞、反应省略、前景擦屏 |
| 现实与主观理解冲突 | 双层材质、绘画系统换权、客观证据保留 |
| 时间跨度大但不想说明性蒙太奇 | 重复动作微改、物件状态升级、声音节拍压缩 |

选择不是找最华丽的效果，而是找最能改变关系、信息或行动的画面规则。

## 3. 身体与轮廓越界

### 3.1 形体隐喻

让身体成为关系的几何，而非只做表情：

- 轻蔑：颈部、手指或笑弧变成长而细的单一曲线，绕过正常社交距离。
- 恐惧：躯干被压扁，四肢先寻找支点，头与视线被压力源拉向错误方向。
- 羞耻：身体像纸一样沿肩线折起，手和膝盖把自己收进越来越小的轮廓。
- 愤怒：肩背先压缩成楔形，骨盆和支撑脚启动，脸在最后一拍才离模。
- 欣喜：身体成为弹簧或球形节奏，压缩、回弹、过冲和分重量落定清楚。

执行锁：形变必须有固定起点、受力方向、同一身份末端、峰值时长、收回路径和残留姿势。

### 3.2 尺度与透视

- 把威胁者的近端手、脸或脚推成强制透视，弱者仍由栏杆、门槛或地面保持现实尺度。
- 让被排斥者逐级缩小，而群体并不变大；空间占有率变化就是社会事实。
- 极近局部独占画面后，落回大全景重新判定真实距离。

失败：只把脸做大、眼睛做红，身体支点和关系距离完全不变。

## 4. 视线与威胁外化

视线不是一句“阴冷注视”，而是一条可以进入世界的路径。

### 4.1 蛇形注视

```text
眼睑压低，瞳孔锁定目标
-> 一条细冷高光从瞳孔边缘游出
-> 高光沿栏杆、墙缝或衣领的既有曲线前进
-> 曲线分叉成数条蛇形影线，缠住出口和听者脚下台阶
-> 威胁者身体仍站在原处，影线替她越过私人距离
-> 一声鞋底/栏杆敲击让影线收回
-> 现实中听者的包带、袖口或栏杆影仍被勒成弯曲形
```

可以短暂出现蛇发、蛇影、鳞状反光或石化裂纹，但它们属于被压迫者的主观画面，不把角色客观改造成怪物。

### 4.2 其他视线实体

- 针线：目光像针穿过人物与物件，把群体缝成闭环。
- 聚光灯：被看者之外的世界褪去，所有出口都落在黑暗外。
- 磁力线：物件、头发和身体朝向先被吸向目标，人物最后才移动。
- 捕食影：影子先扑近，真人仍保持礼貌距离，形成公开/私人双轨。
- 石化波：颜色与动作从被注视处逐块冻结，呼吸或手指保留最后一点运动。

外化必须沿现成几何生长。凭空在画面上叠蛇、触手或闪电，只是贴纸。

## 5. 异常心理空间

心理空间用于把关系变成可以行动的场，不是给对白换一张漂亮背景。

### 5.1 空间改写族

| 机制 | 进入过程 | 关系结果 | 回现实锚点 |
|---|---|---|---|
| 楼梯无限延长 | 台词每落一个重音，台阶向上复制一段 | 高位者永远不可达，低位者越走越低 | 鞋底落在原台阶的实声 |
| 黑色审讯场 | 现实墙缝先变黑，黑色沿透视线吞没背景，只剩两人和一件证据物 | 对话从社交转成心理对峙 | 栏杆冷光或门声切回 |
| 走廊挤成细缝 | 门框、柜体、同学身体逐层压缩通路 | 被迫靠近或失去退出权 | 手掌撑墙、包带刮门 |
| 地面倾成深井 | 水平线缓慢竖起，弱者支点不变却像站在井壁 | 关系压力获得重力 | 抓住栏杆后水平线回正 |
| 双方站在不同画层 | 一人保持真实透视，另一人被压平成纸片、剪影或海报层 | 谁被当成“人”、谁被当成标签可见 | 触碰使纸层起皱并归还体积 |
| 尺度法庭 | 空间退成巨大空场，物件或一句话成为中央证物 | 群体判断取代私人交流 | 证物落回真实桌面/手中 |

### 5.2 心理对峙规则

1. 先保留现实基准和相对站位。
2. 只让一种空间规则开始失真。
3. 角色身体必须适应新规则：抓、退、爬、失衡、被遮、改变高度。
4. 至少保留一个现实物件和一个声音位置。
5. 归还后留下一项真实错位，证明心理段改变了行动。

失败：黑背景一换，两个人继续原地对口型；这只是舞台换景。

## 6. 回忆侵入现实

回忆不必靠“白闪 -> 硬切童年 -> 白闪回来”。让现在的空间被过去逐层改写。

### 6.1 六种入口

- 裂缝入口：现实墙面从一个字或撞击点裂开，裂片背面先出现旧场景色光，再重组为完整回忆。
- 剥落入口：墙纸、天空或人物影子像纸层被风掀起，下面是过去空间。
- 反射入口：窗、眼睛、勺面、手机或水面先映出不属于现在的动作，反射扩大夺权。
- 影子入口：现实人物保持当前姿势，影子先重演过去争执，随后真人被影子吞入。
- 物件入口：门把、桌子、行李、碗或照片改变比例，周围建筑按它的空间逻辑重建。
- 声音入口：一句争吵、摔门或餐具声先在现在重复，墙体与家具按声源位置逐件出现。

### 6.2 回忆重建链

```text
现在的关键词落在一个现实表面
-> 表面出现第一道裂纹/反射/影子动作
-> 现在的角色仍留在前景或边缘，保持画面所有权线索
-> 过去的家具、人物和光线从裂口按空间顺序重建
-> 回忆完成一项决定性动作，不复述全部背景
-> 摔门、物件碰撞或现在角色触碰同一表面
-> 回忆碎片沿原路径退回
-> 现在空间保留裂纹状影子、错位物件或声音尾巴
```

决定性动作优先于说明：一张桌子三人的位置、争吵升级、行李被提起、门被甩上，已经能解释怨恨来源。

### 6.3 现在与过去同框

- 现在的说话者可以作为巨大前景剪影，回忆在其身体内部播放。
- 过去人物可沿现实栏杆、窗格或课桌分格出现，形成漫画格但保持同一空间方向。
- 现在的听者可以走过回忆场景，却无法被过去人物看见；脚仍落在现实台阶声上。
- 回忆的争执口型可被现在平静语气覆盖，形成声音与事实错位。

失败：回忆只负责“解释剧情”，没有改变现在人物的动作、关系或下一句台词。

## 7. 物件与符号变形

物件是稳定的AIGC锚点，也是抽象情绪进入现实的入口。

### 7.1 变形路径

```text
物件原任务 -> 台词/触碰改变方向或所有权
-> 保留一种原材质或轮廓
-> 连续变成关系意象
-> 牵引人物动作或空间
-> 由接触声/放手/破损归还
-> 落成真实物件后果
```

例：

- 铅笔线变成蛇形路径、封锁线、裂缝、道路或侮辱字迹。
- 包带变成束缚线，先勒紧肩膀，再沿楼梯扶手封住出口。
- 门把变成争执记忆的开关；旋转角度直接驱动旧房间重建。
- 手机气泡变成群体包围圈，最后落回未读消息或空白头像。
- 面包屑、星点或糖纸组成家乡/愿望图解，再落回手中真实碎屑。

失败：道具突然消失，凭空换成另一个图标，材质、持有者和动作因果全部断开。

## 8. 环境成为行动者

环境可执行五种动词：挤压、诱导、拒绝、见证、掩埋。

- 挤压：栏杆、墙线、课桌、门框逐段缩小角色可用空间。
- 诱导：光带、人流、风和重复物件把人物引向某条路线。
- 拒绝：明亮天空、午休铃、同学聊天继续，不替人物悲伤。
- 见证：空椅、裂痕、污迹、未关的门在人物离场后保留事实。
- 掩埋：人群、作业纸、声音或影子逐层覆盖主体，使其失去社会可见性。

环境响应要改变路线、姿势、信息或余波。单纯“背景变黑、气氛阴沉”不算行动。

## 9. 群体与社会几何

群体的残酷优先通过通道和所有权表现：

```text
原社交中心 -> 一人发声
-> 最近者先改变视线，远者继续任务
-> 身体朝向、椅子开口和物件传递改指新目标
-> 旧目标得到一个入口，新目标被前景和路线封住
-> 群体恢复日常节拍
```

可动画化算子：

- NPC逐渐简化为相同剪影，只有被孤立者保留细节。
- 目光化成线，线先连成闭环，再把某人排除在外。
- 课桌像齿轮轻移，社交圈物理闭合；人物不必全员走动。
- 笑声气泡越聚越大，把受害者压到画面边缘，气泡破裂后只剩真实空位。
- 前景同学自然走过，每次遮挡后站位只变一项，几次遮挡完成关系迁移。

## 10. 绘画系统与混合媒介

媒介变化表达“谁在解释世界”，不能只是风格展示。

| 媒介/系统 | 适用 | 可见过程 | 回落 |
|---|---|---|---|
| 粗笔涂鸦 | 焦虑、愤怒、失控 | 线从手势或声音端点长出，覆盖轮廓 | 擦除后留墨痕/纸屑 |
| 蜡笔/儿童画 | 天真解释、错误理解 | 现实物件先简化成儿童图形，再拼成理想结果 | 成人声音或真实重量打破 |
| 纸片/拼贴 | 身份被标签化、回忆 | 人物或空间沿边缘翘起、折叠、被重新粘贴 | 折痕、胶带或撕口留场 |
| 像素/游戏界面 | 规则误读、喜剧、逃避 | 动作被量化成格子、状态条或失败提示 | 实物碰撞打碎界面 |
| 沙画/墨水/颗粒 | 记忆消散、脑中空白 | 轮廓从接触点散成颗粒又重组 | 手中灰尘/水迹承接 |
| 漫画格/文字排版 | 高速信息、内心争执 | 栏杆、门窗或桌面线变成分格 | 一格扩大回到现实全画面 |
| Q版/极简图形 | 短喜剧、字面误解 | 身体在明确笑点峰值压成符号 | 敲击、眨眼或落地声snap-back |
| 过度写实细节 | 恐惧、伤害确认 | 只有证据物或身体局部细节突然增加 | 视线移开后细节退回基准 |

同一段最多一个主媒介、一个辅助材质。混合媒介必须共享形状、动作方向或声音节拍。

## 11. 声音取得画面

- 重音具象：每个重音让一条线、一层台阶、一块裂纹或一个姿势阶梯出现。
- 回声实体：重复台词沿空间复制成文字、嘴形剪影或物件震动，逐步逼近听者。
- 拟声字入侵：先由真实碰撞产生，再让字形遮挡、压缩或切割空间。
- 音乐断裂：画面仍维持上一动作弧线，只有节奏层断掉，身体晚半拍发现异常。
- 声源换权：现在的台词逐渐被回忆争吵覆盖，空间随新声源位置重建。
- 静默判决：密集声层撤走，只留鞋底、呼吸、灯管或远处人声，让环境取得真实性。

声音必须改变动作、画面权限或空间。只写“诡异音效”不可执行。

## 12. 喜剧、错拍与幽默转场

喜剧不是只能变Q版。它来自预期、延迟、尺度和现实落点的错配。

### 12.1 可调用语法

- 反应省略：大动作发生，听者不做预期反应，继续原任务，半拍后只移动一只眼。
- 反应过量：微小刺激触发全身离模和夸张幻想，现实落地却只是一个普通物件。
- 字面化：角色说“脑子一片空白”，画面从头部边缘被橡皮擦空，再由一句话画回来。
- 错误类型片：角色把普通动作幻想成怪兽片、法庭、游戏或偶像舞台，现实声响立即拆台。
- 前景擦屏：路人、书页、头发、门板、飞行物按自身动作遮满画面，新场景接住同一方向和节拍。
- 动作偷渡：角色跳起、跌倒、转圈或挥手时背景已在遮挡峰值切换，落地即在新空间。
- 文字抢话：字幕/拟声字先于角色出现，压扁或推开人物，再被人物撕掉、踩住或说错。
- 定格批注：动作峰值定格，手绘箭头或错误说明短暂出现，下一帧真实动作推翻它。
- 循环失误：同一小动作重复三次，第三次漏步、过冲或对象改变，笑点直接成为剧情因果。
- 静默尾刀：热闹效果瞬间snap-back，角色保持尴尬落点，环境声单独补上最后一拍。

### 12.2 幽默转场链

```text
现实动作建立方向
-> 夸张预期取得画面
-> 前景/图形/身体在峰值遮满
-> 新空间保持同方向、轮廓或声拍
-> 角色落地才发现环境已变
-> 一个现实物件或旁观者低反应完成笑点
```

失败：无因黑场、随机转圈、表情包插入，既不继承动作也不改变下一场。

## 13. 时间压缩与重复腐化

- 固定构图微改：同一门、座位、走廊或餐桌重复出现，每轮只改变一项物件、路线、身体高度或群体朝向。
- 动作接力日历：拉门、坐下、放包、开灯等动作末端直接接下一天相同动作起点。
- 物件状态升级：干净桌面 -> 小字 -> 多一处破损 -> 物件缺席；不必展示全班全流程。
- 声音节拍压缩：铃声、门声、脚步或点名声每次更早打断人物任务。
- 画格腐化：起初整齐的漫画格逐轮歪斜、挤窄、破裂，最后回到现实完整画面判决。
- 群体替换：前景遮挡每过一次，围绕主角的人或朝向发生一项变化，完成数日关系转移。

重复必须让观众能比较。每轮都换机位、构图和语法，会失去腐化感。

## 14. 可爱与阴暗双层解释

天真角色的可爱层可以继续成立，同时客观事实越来越沉重：

```text
客观事实存在
-> 天真角色从自己的动作/物件生成可爱图形
-> 图形接管颜色、空气或节奏
-> 至少一个伤痕、空位、物件重量、冷漠动作或声音事实保持可见
-> 可爱动作完成自己的目标
-> 客观角色/环境夺回画面
-> 可爱图形落成现实污迹、错位物件或错误结果
```

不要把天真角色突然画成阴谋反派。恐怖来自解释能力不足，而不是隐藏恶意。

## 15. 回到现实与残留

每个越界段必须选择一种归还方式：

- 接触归还：手抓栏杆、脚踩台阶、物件碰桌。
- 声音归还：摔门、铃声、敲击、名字被喊出。
- 视线归还：眨眼、失焦后重新对焦、旁观者看回现实证据。
- 形状归还：蛇形线收回包带，裂缝变回墙缝，星形落回道具。
- 权限归还：主观者失去画面，由环境、证物或见证者接管。

至少留一种残留：姿势、勒痕、折痕、错位物件、裂纹状影子、空位、未完成动作、图形碎屑、声音尾巴、意义改变。

“恢复正常、所有效果消失”不是归模，是取消刚才的动画。

## 16. 组合配方

### 16.1 阴冷注视变心理审讯

```text
瞳孔高光游出
-> 沿栏杆变成蛇形影线
-> 影线封住低位者出口
-> 楼梯透视被拉成长井
-> 一条影线裂开墙面
-> 裂口重建施压者的家庭争吵
-> 摔门声让回忆与蛇影同时收回
-> 现实栏杆影仍缠在低位者脚边
```

这是“意象外化 + 异常空间 + 回忆侵入”的因果接力，不是三个并列特效。

### 16.2 尴尬解释变喜剧转场

```text
角色越说越快，文字气泡从嘴边挤出
-> 气泡把身体压成极简纸片
-> 纸片被路过同学带起的风贴满画框
-> 纸片撕开后已经是下一地点
-> 角色以同一说话姿势落地，才发现听者没跟来
-> 远处一声普通回应完成尾刀
```

### 16.3 罪疚被物件召回

```text
手反复擦桌面
-> 擦痕变成旧字迹
-> 字迹沿指尖爬上袖口
-> 袖口纹理分格成数个过去动作
-> 最后一格扩大为完整回忆
-> 现实铃声切断
-> 手仍保持擦拭，桌上留下擦不掉的一笔
```

## 17. 反匮乏验收

关键段落出现以下任一情况，重新发散：

- 方案核心只有邪笑、眯眼、红眼、黑脸、咧嘴或瞳孔缩小。
- “阴冷、邪恶、压迫、恐怖、崩溃”没有进入可见过程。
- 心理空间只换背景，人物身体和路线不受新空间规则影响。
- 回忆只能硬切，无法从现在的物件、声音、影子、反射或裂缝长出。
- 蛇、花、触手、星星、裂纹只是贴图，没有来源、路径、目标和回收。
- 喜剧只靠Q版脸和音效，没有预期差、错拍、动作继承或现实尾刀。
- 媒介变化与画面所有者无关，结束后全部复原。
- 每种效果各自漂亮，却没有共享形状、方向、节奏、物件或解释权。
- SD承接只能写成形容词，无法写出逐秒进入、发展、归还和残留。

通过标准：关闭对白后，观众仍能读出谁施压、谁被困、什么过去被揭开、现实怎样改变；截取任一中间状态，也能看出它从哪里来、正在往哪里去。

## 18. 风格配置与优先级

外部表现清单提供候选算子，不拥有项目美术和叙事边界。调用顺序固定为：

```text
当前用户锁 / 项目事实
-> 已批准动画视觉命题
-> 风格配置
-> 主算子
-> 辅助算子默认幅度
```

| 配置 | 适用 | 密度 | 允许的绘画变化 |
|---|---|---|---|
| 表现型心理动画 | 压抑悬疑、情绪阈值、用户要求大胆动画语言 | 15秒4-7态；一主算子加1-3个辅助 | 粗糙素描、硬阴影、黑白漫画、透视断裂、图层错位、帧率分裂、强归模残留 |
| 可爱-阴暗反差 | 天真角色误读严重事实、软萌日常变调 | 一主算子加0-2个低幅辅助 | 软圆图形、明亮色、低幅离模、严重事实保留一种客观证据 |
| 克制日常 | 普通对话、行走、等待、任务循环 | 0-1个显性越界；环境和物件持续表演 | moving hold、局部帧率差、物件错拍、背景拒绝配合 |
| 混合媒介图形 | 漫画格、纸面、拼贴、儿童画、文字接管 | 一种主媒介加一种辅助材质 | 媒介入口、身体参与、现实锚点、归还和残留必须完整 |

“所有形状软圆”“十五秒最多两个效果”“日常完全不用特殊语言”“永远保持马卡龙平涂”等只属于特定配置，不能写成全局禁令。

## 21. 双媒介重绘与图层拒绝融合

这是“出界上色”的相邻机制，不是同义词。

### 21.1 区分

- 出界上色：同一画面所有者的填色越过轮廓，重点是填色边界。
- 双媒介重绘：两个主体分别由不同线条、填色、材质、帧率和声音系统重建，重点是绘画权限。
- 图层拒绝融合：两套媒介在同一现实空间交叠时仍保留各自合成规则，重点是关系隔阂。

### 21.2 完整执行链

```text
彩色现实基准
-> 一次快速抽色，整幅画落成共同原画底稿
-> 两名角色同时缓慢重绘
-> A角色：粗糙素描、涂鸦越线、黑白网点、低帧阶梯动作
-> B角色：精致闭合线、干净填充、硬边三渲二、高帧弹性动作
-> B用舞蹈/靠近/说话尝试进入A的视线
-> A先移眼、再转脸、再缩肩，主动回避
-> 两套图层前后错开，交叠处出现纸白夹层
-> 共同吊链、地面、座板或声音保持现实位置
-> 尾帧保留同处一地却分属两套绘画系统的关系结果
```

### 21.3 时间权限

- 抽色速度与上色速度分别设计。快速吸走全部颜色后，可用4-6秒让两套上色缓慢生长。
- 两套重绘可并行，但每套必须有独立起点、绘制方向、完成顺序和尾态。
- 动作在上色完成前保持小幅；上色完成后，帧率差才承担关系表演。

### 21.4 稳定锚点与失败边界

- 稳定锚点：共同地面、座板、吊链、桌边、门框、脚步声或视线目标。
- 失败：把两套媒介简化成一方彩色一方灰色，却没有线条、材质、帧率和动作差异。
- 失败：把“图层拒绝融合”写成能量屏障、颜色绕行或魔法反弹。
- 失败：角色没有回避/靠近动作，图层分离只剩后期滤镜。

## 22. 算子预算与调用卡

每次正式选择一个主算子，并为辅助算子写出继承关系：

```text
戏剧任务：
风格配置：
主算子 / 画面所有者 / 触发：
改变的世界轴：
入口 -> 发展 -> 峰值 -> 归还 -> 残留：
人物脸、肩脊髋、重心、手脚：
环境/物件/NPC/声音接力：
现实锚点：
辅助算子1如何继承主算子的方向/颜色/材质/节奏/权限：
辅助算子2如何继承：
别名去重结果：
AIGC拆分点：
```

预算规则：

- 4-7秒：通常一主一辅。
- 8-15秒表现型段落：一主加1-3个辅助，形成4-7个视觉状态。
- 克制日常段：显性越界0-1个，仍保留任务循环、物件、环境和声音变化。
- 同一重复簇只计一个算子；第二个名称必须变成参数。
- 每个辅助算子必须从主算子继承一根接力棒，并留下共享残留。
