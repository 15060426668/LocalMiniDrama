## 1. 动画与真人分镜的根本差异

真人电影的摄影机通常从已经存在的现实中选择、组织和强调：演员、空间、光线、道具和物理法则先存在，镜头决定观众怎样看。

2D动画从零决定什么存在、怎样存在、何时运动、哪些线条消失、空间是否遵守透视、人物是否保持比例、声音能否成为图形、时间能否停住或折回。摄影机只是其中一个变量，不是默认主宰。

因此动画分镜的基本单位不是“镜头景别”，而是“画面状态发生了什么可读变化”：

```text
故事事实
-> 动画视觉命题
-> 当前世界法则
-> 哪一根世界轴开始越界
-> 人物、空间、物件、声音怎样适应
-> 画面所有权怎样换手
-> 新状态怎样落地
```

真人式方案可以作为现实基准：双人中景、过肩、反打、物件特写、空镜、常规推拉摇移都可使用。但关键对话若只靠这些覆盖完成，动画只是在“画真人剧”，没有使用媒介本身。

动画化也不等于每秒变形或每镜炫技。一张几乎不动的画，只要它精确控制绘制层、时间密度、空白、环境循环、人物细节和观看权限，也可以是纯动画表达。

## 2. 导演事实层与动画创造层接口

### 2.1 导演技能交付的事实锁

从通用悬疑分镜接收：

- 场景功能与剧情因果。
- 角色目标、知识差、误读和权力关系。
- 必须保持的场地结构、入口、出口、基础站位和轴线。
- 当前时间、地点、人物身份、服装、物件所有权和连续性。
- 台词、动作事实、伤害边界、必须出现的证据和结尾状态。
- 目标时长、信息曲线、声音事实和下一场继承要求。

这些是不可擅改的现实底板，不是最终动画镜头表。

### 2.2 动画技能必须完成的二次创作

动画层负责：

- 把戏剧功能压缩成一句可画的动画视觉命题。
- 扫描时间、空间、物理、人体、绘画、投影、环境、物件、群体、声音文字、光色和转场十二轴。
- 决定哪些现实法则保持，哪些在何人主观下暂时越界。
- 建立一条贯穿段落的世界法则与效果接力棒。
- 把台词变成状态变化的触发，而非“当前说话者的镜头许可”。
- 先写视觉状态图，再决定每个状态需要什么观看位置、景别和切换。
- 让动画专属画面、现实落点和下一镜连续性同时成立。

### 2.3 所有权边界

```text
导演技能：决定不能改的故事、空间事实、信息和连续性
动画技能：决定这些事实以什么可变世界规则被看见和感受
导演技能：提供现实摄影与基础调度方案
动画技能：重算投影、绘制层、节奏、形体、空间和媒介状态
SD技能：把批准后的动画状态图无损编译成模型执行过程
```

动画层可改变表现空间，不可改变剧情空间事实。例如楼梯可在主观层无限延长，但现实中两人仍站在确定台阶；角色可被压成纸片，但身份、衣服和客观位置不能无因改变。

## 3. 十二轴世界可变性扫描

设计任何重要2D段落前，十二轴全部扫描。扫描不等于全部启用；通常激活`2-4`根主轴，极复杂段最多`5`根，其余明确保持现实基准。

| 世界轴 | 扫描问题 | 可调用变化 | 必留锚点 |
|---|---|---|---|
| 时间 | 谁感到快、慢、停、重复、提前或错拍？ | 主观保持、循环微改、预演、倒序后果、跨时同构动作、异步帧密度 | 动作阶段、声拍、重复物件 |
| 空间 | 关系能否改写距离、出口、高低和拓扑？ | 压缩、延长、折叠、环形、分层、翻面、嵌套、消失点漂移 | 现实站位、接触面、出入口 |
| 物理 | 当前情绪能否改变重力、惯性、体积或材质规则？ | 选择性重力、弹性、液化、纸化、颗粒化、磁力、影子先行 | 支点、力源、接触和落点 |
| 人物形象 | 角色设计的哪些部分能成为表演器官？ | 轮廓、比例、发型、长耳、衣褶、影子、分身、面具、色块所有权 | 身份特征和归模路径 |
| 绘画媒介 | 谁的理解改变线条、纹理和绘制系统？ | 粗笔、蜡笔、纸片、拼贴、像素、漫画格、沙画、过度写实局部 | 同构动作、物件或声音 |
| 投影/镜头 | 画面怎样违反真人摄影的稳定投影？ | 透视折断、正交平面、多视点同框、鱼眼、镜头穿越轮廓、图层速度错位 | 观看者、方向和落地构图 |
| 环境材质 | 场景能执行什么动词？ | 挤压、诱导、拒绝、吞没、见证、复制、老化、剥落、呼吸 | 地点身份和现实材质 |
| 物件符号 | 哪个物件能从任务物变成世界规则？ | 线、门、照片、食物、衣物、包带、课桌、屏幕连续变形 | 原材质、持有者、接触点 |
| 群体拓扑 | 社会关系怎样直接成为图形和通路？ | 闭环、排除、朝向迁移、复制剪影、群体节拍、唯一运动者 | 感知路径和独立反应幅度 |
| 声音/文字 | 声音、台词和字能否取得画面？ | 重音生成、回声实体、拟声字、字幕推人、声音重建空间、口型节奏图形 | 声源、距离和身体反应 |
| 光色 | 谁拥有颜色和阴影，何时被夺回？ | 局部色权、影块吞没、色彩传染、暖光反证、过曝/留色 | 动机光、现实证据和返回权限 |
| 转场/剪辑 | 状态如何变成下一状态，而非结束后另切？ | 动作偷渡、遮挡、同形、材质变形、声音击穿、画格扩张、人物轮廓开门 | 接力棒、落地动作和尾帧 |

扫描写法：

```text
时间=保持/候选变化；空间=保持/候选变化；……；转场剪辑=保持/候选变化。
激活世界轴=主轴A + 主轴B + 辅轴C；
未激活轴保持什么现实基准：……
```

“利用一切”指把一切都纳入创意检索，不指把十二种效果同时塞进十五秒。

## 4. 动画视觉命题

动画视觉命题是一句能统治整段画面的动词句，不是风格形容词。

差：

```text
这是一段压抑、邪恶、充满动画感的对话。
```

好：

```text
她每说一句礼貌的话，楼梯就从女主脚下多撤走一阶。
两人的谈话逐渐把共享房间折成属于不同人的两张纸。
群体每笑一次，就有一条课桌通道从男生身边关闭。
父亲每回避一次，餐桌蒸汽就替缺席者多完成一个动作。
```

命题必须包含：当前动作、世界变化、变化累积方向和关系结果。它应在静音时仍可辨认。

## 5. 场景架构候选而非特效候选

先生成三种完整场景架构，再比较。每套架构都应覆盖整段开始、发展、峰值和落地，不能只是一个局部特效。

### 5.1 形体/身份架构

关系变化首先改写人物形象：比例、轮廓、分身、影子、脸部细节权限、服装或角色设计附件。空间与物件只作为形体后果。

适合：喜剧惊慌、自我否认、身份冲突、亲密/排斥、强烈主观视角。

### 5.2 空间/物理架构

谈话直接改变可用空间、重力、距离、门路、透视或材质。人物必须在改变后的规则中重新站立、靠近、逃离或失去支点。

适合：心理对峙、孤立、恐惧、权力压迫、梦境、关系破裂。

### 5.3 时间/记忆架构

现在被重复、预想、回忆、并行时间或后果提前侵入。台词不是说明过去，而是改变过去怎样出现在当前画面。

适合：罪疚、创伤、因果揭示、日常恶化、长时间压缩。

### 5.4 环境/群体架构

环境和群体而非主角脸部拥有画面变化：通路关闭、朝向迁移、房间拒绝配合、空位变大、NPC变成重复形状。

适合：校园、家庭、制度、群体冷漠、压抑日常。

### 5.5 物件/图形架构

一个现实任务物不断改变画面规则，串起人物、空间、声音和转场。物件不是象征性插镜，而是段落的动力装置。

适合：规则物、愿望道具、证据、书包、课桌、门、照片、食物、文字。

### 5.6 媒介/喜剧架构

绘画系统、画格、字幕、纸面、像素、儿童画或错误类型片接管一段，再被现实动作拆台或污染。

适合：天真误读、喜剧、认知过载、说明段、残酷反差。

三案必须改变世界的方式不同。`黑影压迫 / 红影压迫 / 蛇影压迫`仍是一案。

## 6. 世界法则、反法则与现实锚点

每段锁定：

```text
主世界法则：段落中反复成立的动画规则。
反法则：某角色、物件或客观现实怎样抵抗/修正主法则。
现实锚点：越界时仍保持的站位、支点、物件、声音或方向。
法则升级：每轮只升级哪个变量。
归还权限：谁、什么动作或什么声音让现实夺回画面。
现实残留：越界结束后仍存在的后果。
```

例：

```text
主法则=对方每个重音让楼梯延长；
反法则=女主手掌始终抓住现实扶手；
锚点=同一台阶、包带、鞋底声；
升级=台阶数量 -> 墙体高度 -> 回忆裂口；
归还=防火门摔响；
残留=女主仍停在试探后撤姿势。
```

没有反法则和锚点的世界变化容易变成无因MV。

## 7. 视觉状态图先于镜头表

一段动画先写`4-7`个意义不同的画面状态：

```text
S0 现实基准
-> S1 第一根轴越界，观众提出问题
-> S2 人物身体被迫适应
-> S3 第二载体继承，关系改变
-> S4 画面所有权换手或第二解释进入
-> S5 现实归还并留下后果
```

每个状态回答：

- 当前世界法则。
- 画面所有者。
- 激活的世界轴。
- 第一眼可读图形。
- 人物动作与支点。
- 环境、物件、NPC、文字和声音状态。
- 与上一状态共享的接力棒。
- 进入下一状态的触发。

镜头的任务是让状态变化最清楚，而不是给每句台词分配脸。一个状态可用一镜完成，也可由两个证据镜头完成；一镜也可跨越多个状态。

### 状态差量门

相邻状态至少改变一项：世界法则、画面所有者、人物形体、空间拓扑、物理规则、绘画媒介、群体通道、声音形态、信息权限或现实后果。

只从中景切近景、从A脸切B脸、从人切杯子，不构成动画状态变化。

## 8. 2D动画镜头与投影语言

动画镜头不仅是虚拟摄影机移动，还可改变画面投影和绘制逻辑。

### 8.1 投影算子

- 正交压平：透视退出，人物与物件像图表一样排列，适合规则、孤立和荒诞。
- 多视点同框：同一画面同时展示正面、侧面、俯视或物件内部，适合认知冲突。
- 消失点夺权：消失点从环境移到人物眼、手、嘴或物件，空间线全部服从它。
- 前后景翻面：背景折到前景，角色像被纸层包住；翻面边缘可成为转场。
- 人物内部取景：轮廓、瞳孔、口腔、影子、衣物纹理成为第二场景入口。
- 图层速度分裂：人物、前景、背景和图形层以不同时间密度移动。
- 画框变形：屏幕边缘、漫画格、门框或字幕直接挤压、裁切或放逐人物。
- 视点实体化：摄影机属于物件、影子、文字、动物、群体或环境，而非中立观察者。

### 8.2 动画镜头路径

```text
当前状态需要观众站在哪里
-> 哪个图形/身体/物件取得观看权限
-> 投影怎样随其改变
-> 运动由谁的动作提供力
-> 何处改变信息或权力
-> 落到什么可继承画面
```

无动机推拉摇移、环绕、鱼眼和快速切换仍然是空镜头语言。摄影机必须被人物动作、世界法则、声音或证据变化驱动。

### 8.3 常规镜头的正确位置

- 基准：让观众知道现实人体、空间和站位。
- 对照：越界前后用同构构图比较变化。
- 判决：客观大全景夺回比例和后果。
- 落地：归模后确认人物、物件和空间状态。

常规正反打可承担这些任务，但不能自动获得整段所有权。

## 9. 时间作为可塑材料

### 9.1 主观时间

- 一个眼神可以保持数秒，而环境在同一保持中完成多轮变化。
- 台词尾音可以被拉长成图形路径，人物动作在尾音内加速或冻结。
- 情绪峰值可短时一拍一，现实社交层仍保持一拍三，形成帧密度权力差。

### 9.2 重复时间

```text
第一次完整建立日常动作
-> 第二次省略中段，只改变物件状态
-> 第三次从错误步骤开始，角色已经适应异常
-> 第四次让后果先出现，再补回触发
```

适合把数天、数次霸凌、家庭关系恶化或愿望结果压缩成可比较的图形过程。

### 9.3 并行时间

- 现在人物继续说话，过去的影子在墙上完成另一套动作。
- 一侧画面实时，另一侧以更快帧密度展示可能后果。
- 同一动作在多个时间版本中同时落下，最终只保留一个现实结果。

### 9.4 预演与后果前置

角色想象的动作可先以简笔/图形完成，现实动作稍后走向不同落点。后果也可先作为环境痕迹出现，再回看触发。必须标明谁拥有预演、现实何时修正、哪项证据证明最终版本。

## 10. 空间作为心理和关系装置

空间不只提供站位，还可直接执行关系：

- 距离：一句话让两人之间增加空白、复制桌椅或拉长台阶。
- 高低：高处者保持不动，低处者的地面却逐级下沉。
- 通路：门、桌椅、人群和文字闭合成不能穿越的社会边界。
- 内外：角色身体、影子、房间和画框形成多层归属。
- 尺度：弱者缩小、权威不变；环境变大、人物不变；意义不同。
- 拓扑：直走廊变环形、同一门反复出现、共享房间翻成互不相通的两面。
- 负空间：空白可像实体一样增长、吞掉细节、隔开人物或保留缺席者形状。

每次空间变化都要迫使人物改变支点、路线、可达性、视线或身体高度，否则只是背景美术。

## 11. 物理法则与材质表演

动画可以让情绪选择性改写物理，但必须可读：

### 11.1 可改写物理

- 重力所有权：只有某人、某物或某种颜色受另一方向重力。
- 惯性差：公开笑容已经停，身体仍沿原弧线继续；或身体走了，影子留在原地。
- 弹性权：可爱角色高度弹性，客观现实物件保持沉重，制造解释冲突。
- 材质传染：一句话让墙、衣物、人体依次纸化、液化、结晶或颗粒化。
- 体积权限：角色被语言压扁、吹胀、折叠，但通过支点和回收保持身份。
- 接触延迟：触碰先发生，形变沿身体或环境晚半拍传播，显示力的路径。

### 11.2 物理因果锁

```text
谁施力 -> 接触点 -> 哪种材质先响应 -> 传播速度
-> 人物如何适应 -> 峰值 -> 回收/破损 -> 残留
```

“情绪爆发，周围碎裂”没有力源、路径和材质差，属于装饰爆破。

## 12. 人物形象与角色设计参加叙事

人物设定不是必须永远保持不动的模型表。可调用：

- 轮廓：圆、尖、扁、长、松散、紧闭改变关系姿态。
- 比例：头身比、手脚尺度、脖颈长度、身体高度在主观峰值越界。
- 发型/耳朵/衣褶：充当方向箭头、遮挡帘、情绪波形、转场边界或独立反应层。
- 服装图案：变成画格、地图、回忆入口、群体标签或空间纹理。
- 影子：先行动、拒绝同步、保留过去动作、成为另一角色。
- 分身/残影：表示选择、社会版本、时间版本或动作犹豫，而非单纯速度。
- 细节权限：主观层删除污渍和重量，客观层逐项归还。
- 角色与画框关系：人物可撑开、撕破、被挤出、藏进或停留在画格边界。

离模峰值必须保留身份锚点：发型轮廓、服装色块、主物件、声音、动作方向或归模接触。

## 13. 环境、群体、物件、文字和声音共同造场

### 13.1 环境不是布景

为环境选择一个动词：压、拉、拒绝、复制、遮、吞、呼吸、剥落、见证、遗忘。环境动作应改变人物选择或观众信息。

### 13.2 群体不是背景演员

群体可以是一个图形系统：

- 目光线组成闭环。
- 课桌通道逐轮关闭。
- NPC细节被统一删减，中心人物拥有更高绘制密度。
- 笑声与口型波形在画面中复制，但身体仍按不同感知路径反应。
- 人群前景每次遮挡后只改变一个关系变量，完成长期孤立转移。

### 13.3 物件不是象征插镜

物件必须执行动作：改变所有权、牵引视线、改写空间、触发记忆、承担转场、留下后果。只切一只裂开的杯子表示关系破裂，属于真人覆盖式符号；让杯沿裂纹逐段成为两人之间的空间边界，才进入动画场景法则。

### 13.4 文字不是字幕层

- 台词可以先于嘴出现，推、压、遮或拖拽人物。
- 写在桌面的字可沿木纹生长成通路、笼子或回忆裂缝。
- 同一词在不同角色视角具有不同字体、重量和运动方向。
- 文字可被角色擦掉、吞回、踩住、说错或留在环境中。

### 13.5 声音不是后期装饰

声音可决定画面何时绘制、擦除、换层、重复和归还。台词重音、门响、铃声、脚步、呼吸和环境底噪都可成为世界法则的时钟。

## 14. 动画化对话的十种场景架构

对话先选场景架构，再排台词和口型。

### 14.1 空间被语言改写

每句话改变距离、台阶、出口、房间面积、门路或人物可达性。适合压迫和关系破裂。

### 14.2 双重画面所有权争夺

说话者的自我叙述与听者看到的现实轮流改写人物材质、比例和环境细节。适合误读、否认和悬疑揭示。

### 14.3 物件成为世界引擎

杯、笔、门、包带、照片、食物或屏幕从现实任务出发，连续改写形体、空间和转场。适合稳定AIGC执行。

### 14.4 回忆在现在内部重建

现在人物和站位保持，墙面、影子、反射、物件或声音逐层重建过去的决定性动作。适合解释动机而不停止当前冲突。

### 14.5 人物形象承担权力变化

比例、轮廓、细节、影子、衣物和画框关系直接变化。适合喜剧、恐惧、羞耻和身份冲突。

### 14.6 群体拓扑说话

主台词保持克制，背景朝向、通道、物件传递和人物细节逐步改指新目标。适合校园与制度压迫。

### 14.7 声音和文字接管画面

重音生成物理层，文字排版切割空间，拟声字先后遮挡人物。适合强节奏、说明和喜剧。

### 14.8 时间循环微改

相同对话姿势或动作重复，每轮只改一项物件、表情权限、空间和声音，迅速跨越多天或多次冲突。

### 14.9 错误类型片/媒介误会

某角色把对话理解为怪兽片、法庭、游戏、舞台或儿童画，现实声音和物件在尾部拆台。适合天真角色与黑色幽默。

### 14.10 克制单构图压迫

人物不离模、空间不大变，但绘制密度、移动层、画面边界、环境循环、留白和声音权限持续变化。适合不宜炫技的严重段落。

克制架构示例：两人保持一个大全景，施压者始终一拍二正常说话；女主逐渐失去眨眼、发丝、衣褶和颜色运动，最后只剩包带因呼吸轻动；环境人流继续。这里没有常规反打，但动画时间和绘制权限在叙事。

## 15. 转场是叙事动作

转场回答“前一个状态如何造成后一个状态”，不是镜头之间的标点。

可用接力棒：

- 动作：挥手、跳跃、摔倒、转身、开门、落笔。
- 形状：眼、门、星、裂纹、圆管、嘴、杯沿、阴影。
- 材质：纸、墨、水、玻璃、布、头发、灰尘。
- 声音：铃、门、脚步、笑声、重音、呼吸、环境底。
- 权限：主观者、群体、证物、环境夺取画面。
- 物理：同一重力、惯性、风向、折叠或破裂继续。

转场落地后必须改变人物所处状态、信息、关系或时间。漂亮遮挡后什么都没变，只是包装。

## 16. 高密度与克制的统一

高密度不是平均堆效果，克制也不是回到真人正反打。二者共享同一原则：画面状态持续变化。

### 高密度

- `1-3`秒一次意义刷新。
- 允许形体、空间、媒介、文字和转场接力。
- 一条主法则贯穿，不同时建立多个世界。

### 克制

- 允许长保持和固定构图。
- 通过选择性运动、绘制细节增减、图层速度、环境循环、声音权限和留白改变状态。
- 一次只让观众意识到一个缺失或错位。

判断标准不是效果数量，而是删掉摄影机描述后，动画仍是否拥有独立的时间、绘制和世界组织方式。

## 17. AIGC分层执行

动画导演最优版先完成，再进行模型稳定拆分。

### 17.1 稳定层

进入BASE：人物身份、服装、现实空间结构、基础站位、主物件、轴线、动机光、客观物理基准。

### 17.2 可变层

进入A节拍：当前世界法则、画面所有者、激活轴、入口、发展、人物适应、环境/物件接力、现实证据、归还和残留。

### 17.3 拆分规则

- 同一A节拍只允许一个主世界轴达到峰值。
- 第二轴必须继承第一轴的形状、方向、材质、节奏或权限。
- 同一秒发生身份变化、空间重建、复杂口型和摄影机大运动时，顺序拆开。
- 先稳定现实锚点，再让模型生成越界；先落回现实，再进入下一套法则。

稳定翻译不是删掉动画，而是把同时发生改成先后发生。

## 18. 正式规划模板

### 18.1 段级动画场景规划

```text
导演事实锁：剧情因果 / 信息权限 / 现实空间 / 站位轴线 / 物件 / 时长 / 必须尾态
动画视觉命题：一句动词句
世界可变性扫描：时间 / 空间 / 物理 / 人物形象 / 绘画媒介 / 投影镜头 / 环境材质 / 物件符号 / 群体拓扑 / 声音文字 / 光色 / 转场剪辑
激活世界轴：主轴 / 次轴 / 辅轴 / 未激活轴基准
场景架构候选：至少三套完整架构与淘汰理由
动画场景规划：主世界法则 / 反法则 / 接力棒 / 现实锚点 / 法则升级 / 归还权限 / 现实残留
视觉状态图：S0 -> S1 -> S2 -> S3 -> S4 -> S5
动画镜头策略：观看位置 / 投影变化 / 常规镜头只承担的基准或落地任务
AIGC分层：BASE稳定项 / A节拍峰值顺序 / 拆分点
```

### 18.2 状态行

```text
状态与时长：
当前世界法则：
画面所有者：
激活世界轴与差量：
构图/投影/图层：
人物形象/身体/支点：

现实锚点：
归还/残留/尾帧：
```

具体景别、焦段、机位和摄影运动在状态图成立后与导演技能共同确定。动画状态不能被镜头表重新压回普通覆盖。

## 19. 反真人覆盖验收

### 19.1 覆盖剥离测试

删掉所有“中景、近景、过肩、反打、推镜、特写、空镜”后，检查还剩什么：

- 若只剩“两人说话、杯子放在中间、关系破裂”，这是可拍的真人场面，不是完整动画规划。
- 若仍能读到时间怎样错拍、空间怎样改写、人体怎样适应、绘画层怎样换权、群体怎样变形、声音怎样生成画面，动画场景成立。

### 19.2 台词归属测试

连续镜头若主要由“谁正在说话”决定，判为说话者覆盖。台词应拥有触发权，不自动拥有摄影机。

### 19.3 道具象征测试

裂杯、枯花、关门、背影、空椅可用于真人和动画。只有当它们改变运动、空间、绘制、时间、画面权限或转场，才成为动画场景机制。

### 19.4 世界轴测试

- 是否扫描全部十二轴？
- 是否只激活`2-4`轴并说明其余基准？
- 是否有一条主世界法则贯穿？
- 人物是否被迫适应世界变化？
- 相邻状态是否改变世界法则或信息，而非只换角度？
- 结尾是否由现实、人物、环境或证物重新取得权限并留下后果？

### 19.5 判废条件

- 先写镜头表，再给每镜贴动画效果。
- 两人一来一回正反打，偶尔插入象征性道具。
- 所谓动画化只发生在脸、颜色滤镜、粒子和冲击帧。
- 场景可以完整替换为真人演员加普通剪辑，画面意义几乎不变。
- 十二轴从未扫描，方案永远只想到摄影机、表情和道具。
- 时间、空间、物理、人物形象和绘画系统始终被假定不可改变。
- 每镜单独有创意，但段落没有主世界法则和状态累积。
- 为了“动画感”同时修改所有轴，人物身份、空间和因果无法追踪。

通过标准：这段不仅“拍得好”，而且只能以动画这种可以重新规定世界存在方式的媒介，最准确、最高效地表达当前戏剧任务。
