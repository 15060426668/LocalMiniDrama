# 全画面逐拍运动台账

> 运行状态：完整模板档案。普通任务使用 `animation-runtime-core.md` 的一行式台账；仅在需要展开完整制片表、字段映射或旧产物诊断时读取本文件。

这是动画正式分镜和 SD 承接之间的同步接口。它把训练库要求的“主体动作优先”落实为一条可检查的时间线，防止镜头设计、特效、表情、背景和声音各写各的。

## 1. 使用规则

- 普通日常节拍也使用台账；强度只改变动作幅度和字段密度，不改变是否检查。
- 每行只记录一个连续时间窗口。窗口可以用帧、整数秒或 `0-4帧`、`第2-3秒` 表示，但同一镜头内必须统一单位。
- 一行只有一个主动作所有者；其他层写成因果响应、独立低幅任务或有意保持。
- 每行的“结果”必须能成为下一行的“继承状态”；最后一行必须写恢复、尾帧和残留。
- 台账不替代镜头表。镜头号、景别、机位和焦点仍由导演分镜字段拥有；台账记录它们何时响应主体或信息权限。

## 2. 标准表

| 时间窗口 | 主体任务与动作链 | 脸/视线/呼吸 | 重心/肩脊髋/手脚 | 次级运动与材质 | 对手/听者/NPC | 道具与接触证明 | 环境力/背景任务 | 声音与声画触发 | 光影/色彩/线条 | 镜头/画层响应 | 结果与下一拍继承 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 0-4帧 | 支点、意图、预备 | 感知对象与最小泄露 | 哪只脚承重、哪只手准备 | 当前惯性或保持 | 谁知道、谁继续任务 | 持有者、阻力、接触前状态 | 一个主环境力及方向 | 声源、距离、吸气/静音 | 现实基准与注意力 | 起始构图与信息 owner | 预备完成，继承受力方向 |
| 4-8帧 | 发力顺序与主路径 | 视线是否先于头/身体 | 肩肘腕、腰胯、膝脚传力 | 衣发/道具延迟 | 第一反应者及幅度 | 接触、压缩、摩擦或重量 | 近处先响应，远处后响应 | 摩擦/风/声源换权 | 局部改变而非全屏装饰 | 只做服务主动作的运镜/突变 | 力开始释放，继承方向/节奏 |
| 8-12帧 | 峰值、命中或笑点 | 表情峰值、口型/呼吸 | 支点是否锁定、是否过冲 | smear/残影/弹性/碎片 | 第二波反应或低反应反差 | 伤痕、裂纹、形变、掉落 | 范围递进、背景权力变化 | 重音、静音、延迟后的可见反应 | 冲击对比、线条/媒介主变量 | hold、焦点或画面所有权转移 | 峰值完成，继承后果与尾音 |
| 12-16帧 | 收势、回弹、恢复 | 眼神回收、呼吸恢复 | 肩膝手脚回位，保留余震 | 头发/布料/碎片晚停 | 反应落定或仍误读 | 道具回到新状态 | 环境继续或接管余波 | 尾音/脚步/背景声桥 | 归还变量但保留残留 | 落到下一信息 owner | 明确尾帧、残留、下一拍起点 |

窗口数量按复杂度增减；表中四行是最小示范，不要求每个镜头固定四行。若一行同时含两个独立主体目标、两条主镜头路径、两次媒介越界或两次转场，顺序拆行。

## 3. 动作链字段最低覆盖

### 3.0 真人底片中的2D主体扩展

当表演主体是2D角色、背景或周围人物是真人底片时，每行在标准字段中并行锁定：

```text
底片状态：摄影机、真人NPC、真实道具的可见运动
2D状态：主体姿势、表情、线条、填色和曝光节奏
深度状态：前中后景和真人/实物的遮挡交换
接触状态：支点、投影、反射、视差和真实材质后果
差异状态：仍证明角色为手绘2D的粗线、线沸腾或选择性分拍
双层继承：底片尾态与2D尾态分别交给下一行的状态
```

这些项不是表外备注：底片动作进入环境/NPC列，2D状态进入主体/表情/次级运动列，遮挡与接触进入道具/环境/镜头列，双层继承进入最后一列。接触节点必须同时出现在主体手脚、真实物件、声音/光影和结果列。

### 3.1 普通日常/对话

```text
任务循环 -> 可见刺激 -> 最小视线/表情/呼吸变化
-> 手或物件的微动作 -> 听者/NPC独立任务
-> 环境反节拍 -> 说完后的支点/任务变化
```

普通节拍允许“现实绘画与运动基准保持”，但台账仍需写 Moving Hold、道具所有权、背景行为、声音位置和尾帧。口型只是并行轨，不是主体表演的全部。

### 3.2 动作/战斗/追逐

```text
预备/反向蓄力 -> 支点与重心转移 -> 肩脊髋/手脚发力顺序
-> 路径、弧线、加速 -> 接触/阻力 -> 冲击 hold 或速度峰值
-> 对手/环境后果 -> 过冲/回弹 -> 收势与残留
```

写清先动和后动：主体先于衣发，接触先于碎片，声画触发可提前或延迟，远处环境晚于近处接触。速度线、气流和残影必须沿主体路径出现并消退。

### 3.3 表现机制接管

```text
现实基准 -> 触发 -> 第一处可见越界 -> 发展/扩散
-> 主体与关系层参与 -> 峰值换权 -> 接触/声音/视线归还
-> 新现实状态 -> 至少一项残留
```

表达机制字段必须指出：画面所有者、主变量、身体后果、现实锚点、归还权和继承给下一拍的方向/形状/节奏/材质/证据。

### 3.4 复合摄影机连续路径证明

环绕、越顶、贴地跟拍后拉升、俯冲、穿遮挡物、连续景别变化或身体化 POV 出现时，导演提供的运镜意图必须在台账中展开为：

```text
开始机位：高度 / 距主体方位 / 初始景别
世界锚：地平线 / 消失点 / 门窗道路等固定几何
主体锚：身体朝向 / 支点 / 目标 / 当前运动方向
摄影机路径：围绕对象还是随对象移动，经过哪些高度、方位和遮挡
双重运动：摄影机和主体各自的速度、角度与转向，禁止用角色自转冒充环绕
遮挡连续：进入和离开遮挡前后的尺度、屏幕方向、速度、视差与焦点
落点：最终机位 / 景别 / 画面所有者 / 主体与影子的尾态
```

复合路径可以有意越轴。越轴过程可追踪，或在正俯视、POV、共同目标、遮挡节点后明确重建屏幕方向，即为连续；只写“镜头环绕、旋转、俯冲，很炫”而无世界锚、空间路径和落点，判为假旋转。

## 4. 同步完整度审计

逐行检查：

- 主体是否至少有任务、触发、姿势/支点变化、结果四项？
- 需要表情时，脸和视线是否与身体意图同步，且有可解释的提前/延迟？
- 手脚是否在承重、持物、发力、接触或落定时可读？
- 次级运动是否有来源、延迟和停止顺序？
- 对手/NPC 是否有知情差、独立幅度和继续任务？
- 道具/环境是否证明动作发生、改变路线或保留后果？
- 声音是否有声源、时序和一个可见反应？
- 光影/线条/媒介是否改变注意力或证明力，而非装饰？
- 镜头/画层是否由主体、声音、信息权限或环境接力触发？
- 复合运镜是否分别写了摄影机与主体路径，并锁定方向锚、遮挡连续和最终落点？
- 结果是否给出下一拍的姿势、支点、视线、物件、声音或残留？

## 5. 向 SD 的字段映射

```text
BASE LOCK：跨行稳定身份、空间方向、服装/身体基准、常态光色与声音床
A·镜头与构图：台账的起始构图、信息 owner、主体位置、复合路径证明与镜头落点
A·主体动作与表演：主体任务、脸/视线、重心手脚、动作路径、接触、峰值、恢复
A·关系/物件/环境反馈：次级运动、道具接触、对手/听者/NPC、环境力、延迟、沉降
A·声光与转场触发：镜头局部线条、媒介、光色、材质差量、声源、时序、静音/重音、可见反应、尾音桥，以及前态末端进入后态的形状、方向、遮挡或声音过程
A·尾帧与连续性：最后一行结果、残留和2-4个脆弱继承锚点
```

主体字段的预算高于其他字段。若需要压缩，删去不变背景和重复形容词，保留逐步动作、面部、支点、接触、反应、声音触发和尾帧；无法同时容纳时拆成连续 A 节拍。

## 6. 反例与修复

| 反例 | 丢失的因果 | 修复 |
|---|---|---|
| “女生快速跑过去” | 无任务、支点、速度阶段、脚步、落点 | 写看见目标、吸气、后脚蹬地、步频变化、手臂摆、气流、减速、停步与尾帧 |
| “拔刀很帅，风吹起衣服” | 无阻力、腰胯、刀路、命中和声音延迟 | 写推镡、蓄力、释放、刀路切开空气、对手晚反应、纳刀残心 |
| “大家都惊恐地看向主体” | 群体同步、无距离差、无任务和拥堵 | 写近中远三波、不同个体动作、物件掉落、环境先到、逃跑路线冲突 |
| “她犹豫地说话” | 无 Moving Hold、手指、呼吸、听者和环境 | 写视线躲闪、肩呼吸、捏衣角、吸气、听者等待、风/远声、说后松开 |
| “画面变成漫画风” | 无触发、所有权、媒介路径和归还 | 写声音/触碰触发、线条接管、身体参与、共同地面、回落和残留折痕 |
