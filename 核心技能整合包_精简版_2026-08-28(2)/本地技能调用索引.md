## 分流

- 已有成片证据：`video-story-analysis` -> `director-storyboard-integrated`
- 场景图资产前置：`scene-asset-decomposition` -> `live-action-spatial-previs` -> `director-storyboard-integrated`

## 标准流程

```text
story-framework 项目锁
-> script-writing 场景与行动节拍
-> script-roundtable 诊断并回传阻断项
-> dialogue-doctor 台词与口型时间锁
-> director-storyboard-integrated 场景闸门、方案池与正式分镜
   + animation-suspense-performance 动画表现深化
-> 用户批准正式分镜
-> dream-suspense-sd 纯文本无损转换
-> 生成结果QA与回修
```

流程锁定：

- 方案讨论时先给机制不同的候选，不提前锁死单一方案。
- 每轮只输出用户当前要求的一个阶段；未收到进入命令不跨到下一阶段。
- 正式分镜使用完整字段、21:9默认画幅和整秒时间。
- 固定机位1-4秒内必须有信息刷新；长运镜通过内部节拍持续刷新。
- 单段支持4-30秒；16-30秒默认使用一份正式分镜、一条SD文本和一个BASE，不在15秒重启。
- 动画内部按2-4秒自然动作拍组织，12-18秒附近必须有因果状态刷新。
- SD输出只使用正向、可见、可听、可执行事实。
- 分镜是SD唯一源表；梦导SD不得改剧情、台词、镜头任务或删减构图、动作、关系、物件、环境、声光、转场和尾帧。
- 用户侧SD只有纯文本 `BASE LOCK + 五字段A拍`；E索引、数值混音和JSON只允许用于内部验证或独立制作附件，JSON永不作为SD交付。
- 项目设定只在当前任务明确点名该项目时加载。
