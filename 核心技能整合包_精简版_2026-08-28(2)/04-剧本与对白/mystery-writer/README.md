# 悬疑编剧技能 (Mystery Writer Skill)

专业悬疑/犯罪/推理/惊悚编剧技能，基于三大经典编剧理论+悬疑类型专业方法论。

## 理论基础

1. **通用编剧基础**：《故事》《救猫咪》《编剧步步为营》三本书的结构、人物、场景理论
2. **悬疑类型专业方法**：希区柯克炸弹理论、信息差控制、叙述性诡计、公平游戏原则
3. **经典悬疑片实践**：《唐人街》《七宗罪》《非常嫌疑犯》《消失的爱人》《看不见的客人》等经典案例分析

## 能写什么

- 👮 犯罪悬疑/警匪追凶
- 🧠 心理惊悚/人格分裂
- 👨‍👩‍👧 家庭悬疑/亲密危险

- 📱 反转短剧/抖音快手3分钟悬疑

## 核心能力

### 结构
- 悬疑片专属15节拍表
- 3分钟反转短剧结构
- 连续剧"一答一问"集钩子设计
- 两条时间线设计法（真相时间线vs叙事时间线）

### 诡计
- 十大经典诡计类型（不在场证明/密室/身份/叙述性诡计等）
- 双义线索设计
- 红鲱鱼误导设计
- 三层反转结构
- 伏笔三原则

### 人物
- 公开面孔+隐藏事实的悬疑人物模板
- 每个角色都有秘密/欲望/恐惧/谎言
- 主角必须有私人代价
- 真凶必须有可理解的动机

### 场景与对话
- 询问场景攻防战写法
- 对峙场景鸿沟设计
- 六种悬疑对话技巧（回避/反问/半真话/错位回答/说漏嘴/重复）
- 信息差控制表

### 诊断
- 悬疑专属25项诊断清单
- 常见问题诊断与药方
- 公平性检查
- 节奏检查

## 悬疑九铁律

1. 悬疑不是藏信息，是控制信息差
2. 真相必须公平，至少3个伏笔
3. 反转必须改写因果，不能加新事实
4. 线索必须双义，初看假答案回看真答案
5. 误导必须有独立逻辑，不是硬骗
6. 每个人都有秘密、欲望、恐惧、谎言
7. 每场戏必须推进：案件/真相/危险/关系/选择
8. 不靠失忆/梦境/机械降神解决问题
9. 结尾必须改变人物、关系、主题的理解

> **桌子底下有炸弹，两个人在聊天——这才是悬疑。**
