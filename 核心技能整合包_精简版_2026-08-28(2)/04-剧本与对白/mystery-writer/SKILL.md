# 悬疑编剧 Skill V5.0

## 1. 用途
解决悬疑剧本"不吓人、反转生硬、线索不公平、人物脸谱化、最后靠解释圆回来"等问题，产出**有谜面、有线索、有误导、有真相、有代价、有余味**的专业悬疑剧本。
不是写"气氛很紧张"的散文，是写观众看完会回头找伏笔的悬疑故事。

## 2. 适用场景
✅ 适合：
- 犯罪悬疑、心理惊悚、本格推理、社会派悬疑
- 林奇式梦/潜意识悬疑、诺兰式时间/高概念悬疑
- 悬疑短剧、反转故事、密室诡计设计
- 现有故事悬疑化改写、悬疑剧本诊断
- 线索链、红鲱鱼、反转设计

❌ 不适合：
- 纯恐怖鬼片（靠jump scare吓人）
- 纯侦探小说（文字推理）
- 没有悬念的纯犯罪动作片

## 3. 输入字段
用户需提供（缺省主动询问，不自行脑补）：
1. 悬疑子类型：七宗罪式犯罪/林奇式心理/诺兰式高概念/其他
2. 核心谜面/灵感/想表达的主题
3. 时长/篇幅、目标受众
4. 特殊要求：是否有反转、是否有血腥、风格参考、禁忌
5. 现有材料（如有：梗概/人物/草稿）

## 3. 去AI味硬铁则（最高优先级，违反直接重写）
AI写的悬疑剧本一眼就能看出来，因为它永远安全、永远正确、永远工整，没有毛刺，没有意外，没有人味。以下10条铁则，犯任何一条直接重写：
1. **禁止完美人物**：主角不能全程冷静、全程正确、全程道德高尚，她必须怕、必须慌、必须差点做错事、必须有自私的念头、必须在某个瞬间想放弃；坏人不能坏得纯粹，他必须有理由、有软处、甚至有让你共情的瞬间；没有纯好人纯坏人，所有人都是灰色的
2. **禁止直白情绪**：绝对不能写"她很害怕""气氛很紧张""他悲伤极了"这种直接写情绪的词；所有情绪都必须通过具体细节表现：害怕是"烛油滴在手上她没感觉到"，紧张是"他拧门把拧了三次没拧开"，悲伤是"他把桌上的杯子摆正，又摆正，又摆正"
3. **禁止工整对话**：绝对不能让人物好好说话、说完整的话、说符合逻辑的话；人在紧张/害怕/说谎的时候会结巴、会说一半、会答非所问、会说废话、会突然说一句完全不相关的话；不会有人把自己的动机、计划、情绪明明白白说出来
4. **禁止顺拐剧情**：绝对不能让剧情按观众预期走，主角想开门，门一定打不开；主角以为安全了，背后一定有东西；主角找到的线索，一定是误导；观众以为是好人的，一定有秘密；观众以为是坏人的，可能有苦衷；永远不要给观众他们预期的东西
5. **禁止标准答案**：绝对不要在结尾把所有坑都填上，不要解释所有怪事，不要让侦探/主角把真相从头到尾说一遍；留1-2个解释不通的细节，留一个让观众看完想三天的疑问，留一根拔不出来的刺；林奇和诺兰的电影永远有讨论空间，就是因为他们不把话说死
6. **禁止形容词副词堆砌**：绝对不要用"诡异的""恐怖的""阴森的""缓缓地""慢慢地""突然"这种词；"突然"出现的鬼一点都不恐怖，你没注意到的时候它已经在那里了才恐怖；"缓缓地"转头一点都不恐怖，你再看一眼的时候她已经在你面前了才恐怖
7. **禁止大道理主题**：绝对不要借人物的嘴说主题，不要在结尾升华，不要说"其实最恐怖的是人心"这种废话；主题要藏在细节里、藏在动作里、藏在结局里，让观众自己悟，不要你喂给他
8. **禁止NPC路人**：所有出场的人，哪怕是只说一句话的服务员、只露一面的邻居、只出现在电话里的妈妈，都不能是工具人；他们必须有自己的奇怪之处，必须有一句没头没尾的话，必须有一个让你觉得不对的细节；林奇的电影里连路人都让你后背发凉
9. **禁止标准化反应**：人遇到恐怖的事不会统一尖叫、统一跑、统一哭；有人会愣在原地，有人会笑，有人会反复做同一个无意义的动作（整理头发、抠指甲、数数字），有人会根本没意识到那是恐怖的事；反应越反常，越真实，越恐怖
10. **禁止无代价胜利**：主角赢了，必须失去点什么；不能全身而退，不能和朋友拥抱庆祝，不能雨过天晴；她活下来了，但她永远少了点什么——一根手指、一段记忆、一个亲人、或者她自己的一部分；代价越具体，越痛，故事越真实

### 正反例对比
❌ AI味反例：
```
她非常害怕，心脏砰砰跳，缓缓地转过头，看到一个恐怖的女鬼站在门口，她尖叫一声，转身就跑。
```
（问题：直接写情绪、用形容词、反应标准化、直白、没有细节）

✅ 人味正例（林奇味）：
```
后颈的凉气吹了有半分钟了。
她数着地砖缝，数到第十七块的时候，才慢慢抬起眼。
门口站着的是她妈。
穿着她下葬那天穿的蓝布衫，对她笑。
"饭做好了。"
她低头看自己的手，指甲把掌心抠出了血，她没感觉到疼。
桌上的蜡烛，不知道什么时候灭了。
```
（对：没有一个词写"害怕"，所有恐怖都在细节里，反应反常，有说不通的地方，有余味）

## 4. 悬疑剧本节奏与删稿铁则（最高优先级，违反直接重写）
### ❌ 常见低分剧本问题（严格禁止）
1. **水词水动作**：大量"她继续走""她没有回头""她站起来""她愣了一下"这种没有任何信息量的动作，拍出来就是空镜头，拖节奏
2. **节奏全程平**：没有起伏，没有张弛，全程一个速度，主角全程冷静像机器人，没有危险，没有紧迫感，观众看5分钟就困
3. **规则没后果**：写了规则"不要回应"，主角回应了，什么事都没有，规则等于白写，观众根本不紧张
4. **线索明着给**：一上来就告诉你"这是幻觉"，没有双义，没有误导，没有信息差，观众一眼看到底
5. **人物像NPC**：主角没有弱点，没有情绪，没有害怕，没有差点犯错的时候，全程走流程，观众根本不在乎她
6. **转场重复刻意**：同一个转场手法用三次，生怕观众不知道你在转场，最好的转场是观众没发现就转了
7. **结尾平**：最后没有刺，看完就忘，没有让观众后背发凉的细节

### ✅ 硬指标（必须严格执行）
#### 1. 节奏密度硬指标
| 时长 | 钩子密度 | 转折密度 | 危险升级 |
|------|----------|----------|----------|
| 7分钟短片 | 每30秒一个小钩子，开头10秒必须出第一个钩子 | 每1分钟一个小转折，最后1分钟大反转 | 每过1分钟，危险更近一步，主角的处境必须更糟 |
| 90分钟长片 | 每10分钟一个钩子，前10页必须出尸体/谜面 | 每30分钟一个大转折，中点反转 | 每20分钟危险升级一次，主角失去的东西越来越多 |
- 绝对不允许连续30秒没有新信息/没有异常/没有冲突
- 绝对不允许两场戏的紧张度是一样的，必须一紧一松，张弛有度

#### 1A. 抖音 / AIGC短剧节奏门（最高优先级补充）
参考《钟馗嫁妹》《天庭三大反骨仔》这类AIGC短剧的传播逻辑：短剧不是一味加速，而是高频刷新信息；电影级质感可以保留，但叙事不能按电影长铺垫来写。

| 时间段 | 必须完成的剧作任务 | 禁忌 |
|------|----------------|------|
| 0-3秒 | 给一个能截图传播的视觉问题：人在逃、规则物件、异常空间、强情绪脸、危险动作、反常物件 | 不能只给氛围空镜，不能先解释世界观 |
| 3-8秒 | 明确主角当前处境：她要逃、要藏、要开门、要守住物件、要忍住不回应 | 不能让主角只是“走着/看着/愣着” |
| 8-15秒 | 抛出第一条规则、第一处异常或第一个反常声音，让观众知道继续看会得到答案 | 不能把完整规则一口气念完，不能信息糊成旁白 |
| 15-30秒 | 完成一次小转向：安全变危险、出口变陷阱、熟人声变诱导、物件状态改变 | 不能重复同一种惊吓或同一个走廊动作 |
| 30-60秒 | 建立主线任务和代价：要做什么，失败会怎样，主角为什么差点犯错 | 不能只有设定，没有人物弱点和即时后果 |
| 每60秒 | 至少一次明确升级：空间更窄、规则更危险、声音更近、误导更强、选择更难 | 不能只是换场景但压力不变 |

执行铁则：
- 每15秒必须有一个“段落小钩子”：新信息、新危险、新误导、新情绪裂缝、新视觉奇观，五选一。
- 每30秒必须改变一次观众的问题：从“她在逃什么”变成“声音是谁”，再变成“规则能不能信”，再变成“她会不会回应”。
- 快不是乱剪。每个快节奏段落都要有一个连续锚点：同一件道具、同一条声音、同一方向运动、同一颜色光、同一动作目标。
- 慢镜头只能用在阈值前：开门前、回应前、火苗快灭前、认出亲人前、证据即将读清前。慢的时间必须换来更强的期待。
- AIGC短剧要避免“会动的PPT”：人物必须有身体动作、手部状态、眼神路线、道具变化、背景变化，不能只靠嘴动和旁白推进。
- 传统文化/神话/民俗题材可以高概念开场，但必须在前15秒落到人的情感目标：嫁妹、救人、复仇、逃命、认亲、守约、收容。

#### 2. 删稿铁则（写完全删一遍，符合任意一条直接删）
- 删了不影响剧情、不影响人物、不影响伏笔的内容，全删
- 重复的动作、重复的描写、重复的情绪，全删（不要写三次"她护着蜡烛"，写一次就够了）
- 没有信息量的动作："她站起来""她继续走""她推开门"——除非这个动作有特殊意义，否则全删，直接切到下一个有信息量的镜头
- 形容词、副词、心理描写，全删
- 所有"她很冷静""她没有抖""她停了一下"——用具体的细节代替，比如"烛油滴在她手背上，她没动"，比写一百句"她很冷静"有用

#### 3. 炸弹理论硬执行（悬疑的核心）
- 开头10秒必须放炸弹：观众知道有危险，主角知道/不知道，但是观众知道（比如开头就告诉观众"回应就会被留下"，主角看到规则了，观众等着她会不会回应）
- 必须有明确的倒计时：蜡烛烧完会怎么样？走不出去会怎么样？必须让观众知道时间不多了
- 炸弹必须炸：不能放了炸弹不炸，主角差点违反规则，必须真的有后果，真的有东西因为违反规则出事，观众才会怕
- 规则必须有即时后果：只要写了规则，违反了立刻有具体的、可怕的后果，不是说说而已。比如规则说"不要回应"，主角只要应了一声，立刻就有东西过来碰她，立刻空间变了，立刻有代价，观众才会跟着紧张

#### 4. 人物不是机器人
- 主角必须有弱点：她怕什么？她最在意什么？她有什么软肋？（比如主角的软肋是她妈，一听到她妈的声音就差点破防，不能全程冷静）
- 主角必须差点犯错：她必须有一次差点违反规则，差点就回应了，差点就上当了，不是全程开上帝视角
- 主角必须有情绪变化：从冷静→紧张→差点破防→硬撑→最后做出选择，要有弧光，不是一张脸从头带到尾
- 主角必须付出代价：最后她一定要失去点什么，不能全身而退，哪怕是失去一根蜡烛，失去一段记忆，必须有代价

#### 5. 线索与恐怖写法
- 所有恐怖都是"不对的小细节"，不是明着给你恐怖：妈妈笑的时候，她的左手有六根手指；日历上的日期是三年前的日期；爸爸倒饮料的时候，饮料是往上流的——这些小细节，第一遍看可能没注意，第二遍看后背发凉
- 不要明着写"这是幻觉"，让观众自己发现不对
- 双义线索：每场至少一个，初看正常，回看有别的意思
- 转场要自然：不要每次都用同一个手法，最好的转场是观众没发现就转了，比如她吹灭蜡烛，黑场，再亮就是另一个地方

#### 正反例对比
❌ 反例（啰嗦、平、水，20分版本）：
```
沈清宴护着蜡烛，手掌曲成弧形挡在火焰一侧，朝房间唯一的门走去。
门是老式木门，油漆剥落，门把是铜的，生了绿锈。
她伸手去够门把——
身后，一声低语。
模糊的。不是词，是气息，像有人张嘴但没来得及发声。
沈清宴的手停在半空。一秒。两秒。
她没有回头。
她拧开门把，走进黑暗。
```
（问题：水动作太多，低语没有后果，她没回头就完了，不紧张，没有信息量）

✅ 正例（紧凑、有钩子、有紧张感，80分版本）：
```
INT. 未知房间 - 夜
烛火晃了一下。
身后有人呼气，吹得她后颈发凉。
规则第一条：不要回应你听到的一切。
她的指节已经碰到冰凉的铜门把，指腹下是绿锈。
"清宴。"
是她妈的声音。
就在她耳朵后面，离她不到十厘米。
烛油滴在她手背上，烫。她没动。
门"吱呀"一声开了。
她一步跨出去，门在她身后"砰"地关上。
她靠在门上，大口喘气，蜡烛差点灭了。
走廊里，有人在笑。
```
（对：没有水词，10秒出钩子，有炸弹（规则不能回应），有软肋（妈妈的声音），有即时的紧张感，有差点犯错的张力，结尾留钩子，节奏紧）

## 5. 工作流程（严格按步骤）

### 第一步：悬疑底层铁律检查（违反直接重写）
1. **无AI味**：禁脸谱化警察/完美侦探/疯子凶手，人是矛盾的——警察会怕，凶手会哭，证人会说谎但不是坏人
2. **无解释语言**：禁"气氛很紧张""他非常害怕"，所有恐怖/不安通过具体东西表现：没关的水龙头、半开的门、对方停顿三秒
3. **潜台词**：询问场景绝对不能一问一答给信息，所有人都在绕弯子，真话在没说的部分、在停顿里、在动作里

写每场前必须回答悬疑信息控制四问：
- 观众现在知道什么？他们以为凶手是谁？
- 主角现在知道什么？比观众多/少知道什么？
- 凶手/对手现在知道什么？他在怎么布局？
- 这一场我放什么信息？藏什么信息？

希区柯克炸弹理论：90%悬念，10%惊讶——让观众知道桌子底下有炸弹，但不知道什么时候炸，不要靠突然爆炸吓人。

### 第二步：悬疑发动机搭建（写大纲前必须搭好9个部件）
| 部件 | 要求 |
|------|------|
| 1. 谜面 | 观众最想知道的核心问题：谁干的？为什么？怎么干的？一句话能说清 |
| 2. 真相 | 实际发生了什么？谁做了什么？为什么？写大纲前必须100%确定 |
| 3. 假答案 | 前半段最像真相的错误解释，观众和主角都会相信 |
| 4. 视角 | 观众跟谁走？谁的信息被限制？谁是不可靠叙述者？ |
| 5. 主角欲望 | 主角为什么必须查到底？他的私人代价是什么？不能只是好奇心 |
| 6. 对手阻力 | 谁不想真相出来？他有什么筹码？他在保护什么？ |
| 7. 线索链 | 哪些证据一步步否定假答案，接近真相？至少3个，都是双义的 |
| 8. 误导链（红鲱鱼） | 哪些合理现象把主角/观众带偏？每个误导都要有自己的逻辑，不是乱骗 |
| 9. 代价 | 主角查到底会失去什么？最后他付出了什么代价？ |

悬疑九铁律：
1. 悬疑是控制信息差，不是藏信息
2. 真相必须公平，回看至少3个伏笔
3. 反转必须改写因果，不是突然加新事实
4. 线索必须双义：初看指向假答案，回看指向真答案
5. 误导必须有独立逻辑
6. 每个主要人物都有秘密、欲望、恐惧、谎言、异常动作
7. 每场至少推进一项：案件/真相/危险/关系/选择
8. 不靠大段解释/旁白/梦境/失忆/机械降神完成反转
9. 结尾必须同时改变观众对人物、关系、主题的理解

### 第三步：按风格选择结构模板
#### 【模板A：《七宗罪》式犯罪悬疑（社会派/双雄/反类型）】
- **精确幕结构（120分钟）**：
  - 第一幕（0-30分钟）：雨天开场→两个命案→发现数字框架→老警探想退休，年轻警探想立功→第三个命案，老警探决定留下来
  - 第二幕（30-85分钟）：找线索到凶手家→追凶，年轻警探差点死→中点：他们以为在追凶手，其实凶手在看着他们→家里吃饭的文戏→凶手自首，提出交易
  - 第三幕（85-120分钟）：开车去沙漠（核心文戏）→快递盒子→年轻警探被激怒开枪，完成七宗罪→老警探说"世界值得为它奋斗"，雨停
- **文戏写法**：
  - 双雄对手戏：一老一少，一冷一热，说话永远不在一个频道，老的永远慢，年轻的永远急
  - "没用"的文戏是核心：吃饭、喝酒、路上聊天，不聊案子，聊生活，聊对这个世界的看法，最后这些文戏让你在乎他们
  - 最狠的戏拍反应：凶案现场不拍尸体，拍警察的反应；最后盒子打开，不拍盒子里是什么，拍老警探的表情
- **对话特点**：
  - 凶手永远平静，不喊不叫，像在布道；年轻警探永远在喊，在急；老警探永远沉默，在看
  - 所有询问都不直接问，绕弯子，真话在停顿里
- **场景/氛围**：
  - 天气是角色：前90分钟永远下雨，天永远灰，最后沙漠出太阳，亮得刺眼，反而更恐怖
  - 所有凶案现场都有一个小道具，串起线索
- **禁忌**：不要抓了凶手就完了，反类型结局好人输；不要让凶手是疯子，他有你能理解的逻辑；不要一直拍凶案，文戏才是核心

#### 【模板B：林奇式心理/梦悬疑（潜意识/日常恐怖/不可靠叙述）】
- **核心第一性写作法则（5条铁则，违反就不是林奇）**：
  1. **矛盾欲望法则**：主角必须有一对互相矛盾的欲望——外在欲望（找真相/救别人/成功）用来推情节，内在欲望（被爱/被需要/逃避愧疚）是真正的动力；当外在目标达成会摧毁内在需要时，主角的每个选择都自带撕裂感，不需要外部反派就有张力
  2. **每场价值移动法则**：写每场前先问：这场在哪个价值维度（生/死、安全/危险、真相/谎言、被爱/被弃、掌控/无力），从哪一极移到哪一极？没有价值移动的场直接删
  3. **最小节拍法则**：把每场拆到"行为-反应"的最小单位，一个节拍=一个动作触发一个反应+一次微小价值变化；连续3拍价值不动就是水，直接删
  4. **潜台词法则**：台词写动作不写信息——每句关键台词底下都有一个主角真正想做的动作（求担保、掩盖、逃避、控制、求饶），潜台词=想要的减去说出口的，潜台词越大越有张力
  5. **假顶点坍缩法则**：真相击穿前，先把情绪推到一个刻意明亮的假顶点（越甜越假越好），然后不用台词解释，直接用一个意象执行之前立的规则，把地板抽走；最低能量点紧接最高能恐怖，观众带走的不是答案，是一个甩不掉的凝视
- **精确幕结构（140分钟，两幕半，梦→碎→醒）**：
  - 第一幕（0-30分钟，立规则）：
    1. 开场无铺垫信息差：主角（失忆者/做梦者）从意外中醒来，观众和她一样什么都不知道，双重信息差（你和她都不知道她是谁、为什么被追）
    2. 第二场直接立世界规则：用一场和主线无关的"规则声明戏"（如丹尼餐馆男子做噩梦被吓死），告诉观众：这个世界里梦会成真、恐惧会实体化、被想到的东西真的会出现，之后不用再解释任何诡异
    3. 主角相遇：阳光的"拯救者"主角遇到失忆的"被拯救者"，两个主角的欲望绑定，侦探线（找身份）和拯救线（我要帮她）合流
  - 第二幕（30-100分钟，梦的高峰）：
    1. 日常里的不对：每15分钟一个"不对的小细节"（女侍的名牌是主角自己的名字、邻居老太太说"她不是住在这里的人"、两个第一次见面的人对视像认识了一辈子），这些细节第一遍看没感觉，回看全是伏笔
    2. 权力副线：用一条和主线若即若离的"不可见权力"副线（如导演被黑社会逼着换女主角），告诉观众这个世界有你看不见的手在控制一切，不用解释是谁、为什么
    3. 真顶点：主角（拯救者）达到外在欲望的高峰（试镜成功、所有人都爱她、她觉得自己无所不能）——这是梦最甜的地方，也是摔得最惨的前奏
    4. 第一次裂缝：主角发现自己不是被选中的人，她一直以来的"我很重要"的幻觉被打碎，她开始逃
    5. 触到真相内核：两人找到真相，是一具死了很久的女尸——这是梦不能承受的重量，所有的美好开始碎
  - 第三幕（100-140分钟，坍缩）：
    1. 强行回补：主角用自欺欺人的方式把碎掉的梦粘起来（把失忆的人剪成和自己一样的金发、在屋顶大喊"我在这儿"），制造一个更亮更假的情绪顶点
    2. 假顶点：最明亮、最美好、最充满希望的一场戏，能量压到全片最低，让观众彻底放松，以为雨过天晴
    3. 终局凝视：没有解释、没有反转说明、没有对话，直接切回开场立规则的地方，那个最恐怖的东西直接看向镜头、看向观众，全片定格，黑场——不解释任何坑，不回答任何问题
- **林奇独有的写作技法（直接用，写出来就是林奇味）**：
  1. **身体写作**：所有情绪、记忆、恐惧都用身体写，不用心理描写：
     - 被压抑的记忆：不让人物说"我好像记得"，让她的身体先有反应（看到蓝钥匙脸色瞬间变了、手开始抖，她自己都不知道为什么）
     - 恐惧：不写"她很怕"，写她汗把衣服浸透、呼吸不上来、手里的杯子捏碎了、想叫叫不出声
     - 控制欲：不写"她想控制对方"，写她死死握住对方拿剪刀的手、在对方耳边温柔地说"让我来"
  2. **感官恐怖**：不用jump scare，用最原始的感官写恐惧：
     - 嗅觉：进房间先闻到腐烂的味道，观众闻不到但大脑会自动模拟
     - 听觉：背景永远有低低的嗡鸣，最恐怖的时候完全安静，或者用甜得发腻的老歌配恐怖画面
     - 触觉：后颈有人呼气、烛油滴在手上烫但不敢动、铜门把上的绿锈粘在指腹
  3. **节奏技法**：
     - 虚惊节奏：紧→松→更紧——先吓你一下，结果是虚惊，你刚松口气，真的东西就在你身后
     - 零动作杀人：最恐怖的暴力不是打你杀你，是看你——怪物什么都不用做，只是看着你，你就死了（丹尼餐馆的男人只是看到流浪汉的脸，直接吓死）
     - 最低点接最高点：把能量压到最低（最甜最安静的屋顶戏），下一秒直接切最高能的恐怖，中间没有任何过渡
  4. **伏笔技法**：
     - 背景埋答案：把谜底关键词扔在无关场景的背景里（女侍的名牌写着主角真正的名字"黛安娜"），观众显意识没注意，潜意识记住了，后面揭晓的时候会觉得"哪里不对"
     - 无功能道具：越没用的道具越恐怖——蓝钥匙不知道开什么、蓝盒子不知道装什么，没有功能的道具才能承载纯粹的恐惧，功能越明确越不恐怖
     - 局外人说真话：真相永远从疯子、邻居老太太、流浪汉这种"局外人"嘴里说出来，主角不信，观众也半信半疑，最后发现疯子说的全是真的
- **林奇独有的味道细节（写了就真的像林奇）**：
  1. **日常的错位**：最恐怖的从来不是鬼，是你熟悉的东西有一点点不对——妈妈做的菜味道不对、爱人笑的时候眼睛不笑、你家的沙发换了位置但没人动过、你刚放下的杯子出现在另一个地方；这种"差一点"的错位，比青面獠牙恐怖一百倍
  2. **无意义的细节**：路上遇到的陌生人冲你眨了一下眼、咖啡杯上有个你没见过的口红印、收音机里突然插了一句没头没尾的话、地上有一只不属于任何人的红鞋；这些细节不需要解释，不需要回收，它们存在的意义就是让你觉得"哪里不对"，让你后背发凉
  3. **反常的反应**：看到死人不尖叫，先整理一下自己的头发；听到鬼叫不跑，站在那里笑；最恐怖的东西出现的时候，人物反而平静下来，甚至松了一口气；人在极致恐惧下的反应是反常的，不是标准化的尖叫逃跑
  4. **声音的恐怖**：永远有低低的电流声当背景音；最恐怖的时候没有音乐，只有远处传来的老歌声、邻居家的电视声、什么东西在墙上抓的声音；甜得发腻的老歌配最恐怖的画面，反差越大越恐怖
  5. **普通人的恐怖**：最恐怖的角色从来不是披头散发的鬼，是邻居阿姨、服务员、警察、快递员这些最普通的人；他们笑着和你打招呼，说一句完全不对的话，然后转身就走，你站在原地半天反应过来不对
  6. **时间是乱的**：上一秒是下午三点，下一秒天就黑了；上一秒人物在厨房，下一秒她已经在卧室了，不需要拍她走过去；你看了一眼手表，发现时间倒着走了，不需要解释，梦就是这样的
  7. **重复的动作**：人物会反复做一个无意义的小动作——整理桌布、擦杯子、数地砖、把灯开了又关关了又开；这个动作不需要有意义，它就是人物在失控边缘的表现，比大喊大叫有力量
- **文戏写法**：
  - 对话永远慢半拍，两个人说话像不在一个频道上，你说你的我说我的，偶尔有一句完全不对的话插进来，然后又正常聊，不解释
  - 所有的"我爱你""我帮你"底下都有控制欲，所有的"我没事"底下都在崩溃，所有的"我不记得"底下全记得
  - 最亲密的戏（剪头发、拥抱、一起喊"我在这儿"）是最恐怖的，因为那是两个人格在合并
- **禁忌（犯了就不是林奇）**：
  ❌ 不许解释梦，不许最后心理医生出来说"这都是你的梦"
  ❌ 不许jump scare，不许鬼跳出来大喊，不许流血断肢那种低级恐怖
  ❌ 不许把所有坑都填上，必须留至少3个永远不解释的细节
  ❌ 不许最后大团圆，主角必须付出代价，梦碎了就是碎了
  ❌ 不许写反派是坏人，这里没有坏人，只有你自己的恐惧和欲望

#### 【模板C：诺兰式时间/高概念悬疑（规则/多线/不可靠主角）】
- **核心第一性写作法则（6条铁则，违反就不是诺兰）**：
  1. **矛盾欲望对法则**：主角必须有一对反向运动的欲望——外在欲望（完成任务/回家/达成目标）是上升曲线，内在欲望（逃避愧疚/秘密/阴影）是下沉曲线；外在越接近成功，内在越接近崩溃，两条线的距离就是冲突能量，不需要外部反派就有内生张力
  2. **规则说明戏剧化法则**：绝对不要用旁白/解释性对话讲规则，让角色在行动中体验规则、违反规则、承担规则的后果；观众和角色一起"做中学"，边看任务边懂规则
  3. **嵌套叙事信息差法则**：观众知道的永远比角色多一点，但不能多太多——观众知道是梦/是局，主角不知道；观众知道主角的秘密，队友不知道；这种"上帝视角半开"的状态，会让观众既替角色着急，又有"我比你聪明"的代入感
  4. **最低点紧贴最高点法则**：最痛的失败不是从来没成功，是"差一点就成功了"——先把主角推到离成功只有一步之遥的最高点，下一秒直接砸到最低点，落差越大冲击力越强
  5. **框架叙事闭合法则**：开场就放结局的一个碎片（观众看不懂的那种），中间讲完整故事，结尾精准回到开场的同一个场景、同一句台词、同一个道具，观众瞬间恍然大悟，形成完美闭环
  6. **开放式结局道具承载法则**：不要空着留悬念，用一个贯穿全片、和主题深度绑定的小道具承载终极疑问；结局让道具处于悬而未决的状态（转着的陀螺、没亮的灯、没开的门），答案留给观众，余味最长
- **精确三幕结构（148分钟，三层梦境+双重高潮）**：
  - 第一幕（0-45分钟，立规则+建任务）：
    1. 开场框架碎片：直接把观众扔到最深层/结局场景（limbo海滩、老年斋藤、转着的陀螺），零信息开场，观众和角色一样困惑，陀螺先出现不解释
    2. 规则体验场：用一场正在进行的失败任务（盗梦测试），边做边讲核心规则——手融化证明是梦、多层梦境、玛尔作为内部敌人第一次出现、细节（地毯材质）能破局
    3. 反提案激励事件：任务失败后，反派/雇主开出主角无法拒绝的条件——不用威胁，直接戳他最核心的欲望（回家见孩子），用他的欲望当武器
    4. 观众视角角色登场：找一个完全不懂规则的新人（阿里亚德妮）当观众的眼睛，她问的问题就是观众想问的，她学规则就是观众学规则；用三次测试递进展示她的天赋（三次迷宫测试）
    5. 规则第一课：带新人进梦体验规则——先给糖（折叠巴黎的视觉奇观），再打一巴掌（玛尔出来捅人），边体验边讲规则：时间膨胀、不能用记忆建梦、图腾的作用
    6. 组队完成：一个一个介绍队友，每个队友有单独的能力展示场景（伪装者赌场赢牌、药剂师的睡梦者房间），不要一次性把所有人都扔出来
    7. 计划分层：把复杂任务拆成三层，一层比一层深、一层比一层情感化——表面是商业任务，核心是情感需求（不是"解散公司"，是"父亲希望我做自己"）
  - 第二幕（45-110分钟，执行+出问题+最低点）：
    1. 中点大反转：新人发现主角的黑暗秘密——主角才是那个有问题的人，他对妻子做过不可挽回的事，内部敌人（玛尔）就是他自己的愧疚；从这一秒开始，故事从"完成外部任务"转向"面对内心问题"
    2. 完美计划破碎：刚进任务就出意外——目标受过反盗梦训练、有武装潜意识、队友中枪、死了不会醒会进limbo，所有预案全部失效
    3. 第一层植入：伪装成目标信任的人，先戳他的痛点（"你父亲对你很失望"），不要直接给结论，让他自己把消极的痛点转化成积极的念头（"他是希望我不重蹈覆辙"），让他以为是自己想出来的
    4. 第二层反向骗局：不要偷东西，反过来假装是来保护他的——"我是你的潜意识保护者，有人在盗你的梦"，用假的敌人（伪装的布朗宁）让他彻底信任你，主动要进下一层找真相
    5. 最高点：目标走到真相面前，马上就要听到答案，离成功只有一步——所有观众都松了一口气，以为要成了
    6. 最低点：内部敌人（玛尔）突然出现，一枪打倒目标，任务彻底失败；主角所有的逃避、所有的愧疚在这一刻全部爆发，差一点成功然后全没了
  - 第三幕（110-148分钟，面对+高潮+闭环）：
    1. 内部高潮：主角进入最深层，直面自己的阴影/愧疚，坦白所有真相——"是我害了你"，正式和过去告别，承认阴影不是真的，完成人物弧光
    2. 外部高潮：多层空间同步动作——用音乐同步kick，三层梦境同时坠落/爆炸/反冲，平行剪辑，节奏拉满，视觉奇观拉满
    3. 框架闭环：主角留在最深层找队友，精准回到开场的那个海滩、那个城堡、那个老年队友、那句台词、那个转着的陀螺；观众瞬间明白开场是什么意思，闭环完成
    4. 回归现实：所有人醒来，雇主兑现承诺，主角通关入境，终于回家
    5. 心理高潮（结局）：主角终于见到孩子，拿出图腾转上，然后转身去抱孩子，根本不看图腾倒没倒；图腾还在转，画面黑，剧终——答案不重要，他选择相信什么才重要
- **诺兰独有的写作技法（直接用，写出来就是诺兰味）**：
  1. **高概念规则写法**：
     - 先给糖再打一巴掌：先展示规则的神奇有趣（折叠巴黎、时间变慢、想什么来什么），再立刻展示规则的致命危险（梦里死了不会醒、投影会攻击你、用记忆建梦会迷失）
     - 细节破局：梦境/谎言的破绽永远在最细微的地方——地毯是羊毛还是涤纶、天气不对、引力偏了、图腾的重量，高手靠细节判断真假，不靠大异象
     - 层间联动：多层结构里，上一层的物理变化会直接影响下一层——上一层下雨，下一层进水；上一层失重，下一层零重力；规则和冲突合二为一，不用单独解释
  2. **信息差与骗局写法**：
     - 反向骗局：最高明的骗术不是"我要骗你"，是"我是来帮你的"——假装保护他不被盗梦，实际上你就是盗梦的；假装帮他找真相，实际上你在给他植念头
     - 可信度层层建立：不要一下子让目标信你，一步一步来——先证明"你在做梦"，再证明"我懂行"，再证明"别人是坏人"，最后让他自己验证（自己去看门外的假人），他自己验证过的才会真信
     - 让他自己"发现"真相：最成功的植入不是你告诉他什么，是你给点线索，让他自己推导出你想要的结论，他会以为那是他自己的想法——你只说"父亲对你失望"，他自己会想出"父亲希望我做自己"
  3. **人物与情感写法**：
     - 阴影是主角的镜子：反派/阴影角色（玛尔）不是坏人，是主角自己的愧疚、恐惧、过去的投射；主角和阴影的斗争，本质是和自己的斗争
     - 情感永远压过任务：表面是商业任务/科幻任务，核心永远是情感——植入的念头必须是情感化的，积极情感永远胜过消极情感；主角的动力永远是最朴素的情感（回家、见孩子、被认可）
     - 简单台词的力量：最有力量的台词永远是最简单的——"做你自己""欢迎回家""我在这儿"，不要说大道理，不要长篇大论，四个字足够戳人
  4. **结构与节奏写法**：
     - 道具三埋三收：核心道具（陀螺、图腾、密码528491、纸风车）开场就出现，中间反复出现，每次出现意义都更深一层，结局用它收束全片
     - 关键台词回响：一句核心台词（"你在等一列火车"）全片出现三次，第一次是浪漫，第二次是愧疚，第三次是救赎，每次出现意义都不一样
     - 双重高潮：不要只有一个打戏高潮——先有外部动作高潮（同步穿越、视觉奇观），再有内部情感高潮（和阴影告别、坦白真相），最后有心理高潮（结局的选择），三个高潮一层比一层深
- **诺兰独有的味道细节（写了就真的像诺兰）**：
  1. **冷感叙事**：人物永远不外露情绪，越激动的时候说话越平静，甚至面无表情；不会大喊大叫，不会哭天抢地，最痛的时候反而没有表情，只是手在抖；情绪全藏在动作里，不写在脸上
  2. **时间的重量**：时间不是背景，是看得见摸得着的敌人——你能感觉到秒针在走，能感觉到时间在压着人物，能感觉到剩下的时间不多了；用倒计时、用不同层的时间差、用人物看表的动作，让时间成为一个角色
  3. **道具的温度**：核心道具（陀螺、戒指、纸风车、照片）不是随便的东西，它是人物情感的载体；每次出现都有重量，人物摸它的动作、看它的眼神，都带着情绪；最后它的状态就是人物的选择
  4. **信息差的精准控制**：永远让观众比角色多知道一点，但永远不多到让观众觉得角色蠢；观众知道是梦，角色不知道；观众知道主角有秘密，队友不知道；观众知道这是骗局，目标不知道；这种"我知道你不知道"的感觉，是诺兰悬疑的核心爽点
  5. **规则的冰冷**：规则一旦立了，就没有人能打破，不管你多痛苦、多后悔、多努力；违反规则就有后果，没有主角光环，没有侥幸，没有"突然想通了"；规则是冰冷的，人是热的，人和规则的对抗才是张力
  6. **西装感**：人物永远穿得很整齐，西装、衬衫、大衣，哪怕在逃命、在梦里、在沙漠里，衣服都是整齐的；头发不会乱，不会大喊大叫，永远保持体面，这种体面下的崩溃，比歇斯底里更有力量
  7. **选择比真相重要**：最后真相是什么不重要，陀螺倒不倒不重要，重要的是人物的选择——科布选择不看陀螺，选择去抱孩子，这个选择比真相重要一万倍；结局永远落在人物的选择上，不是落在答案上
- **文戏写法**：
  - 所有对话都是谈判，没有人说真心话——表面在聊任务，实际上在试探、在求保证、在威胁、在说服
  - 解释规则永远藏在冲突里——边打架边讲规则、边逃命边讲规则、边吵架边讲规则，绝对不要坐下来上课
  - 沉默比台词有力量——真相说出口之前，一定要有一个长长的沉默；人物做重大决定之前，一定要有一个长长的沉默
- **禁忌（犯了就不是诺兰）**：
  ❌ 不要用旁白/大段对话解释规则，不要坐下来给观众上课
  ❌ 不要写纯粹的坏人反派，反派永远是主角自己的镜子
  ❌ 不要主角靠别人救，最后救他的只能是他自己的选择
  ❌ 不要破坏自己立的规则，规则一旦立了就必须严格遵守，出问题只能是因为人违反了规则，不能是规则自己变了
  ❌ 不要把所有坑都填上，结局留一个核心疑问给观众，但这个疑问必须有一个贯穿全片的道具承载
  ❌ 不要大团圆就算了，主角必须付出代价，必须放下什么才能得到什么

### 第四步：悬疑场景写作
1. **晚进早出**：直接从最有张力处开始，信息最爆点切走，切在线索/物件上，不拍反应不拍讨论
2. **每场五问**：开始前主角信什么？结束后主角改信什么？观众多知道什么？观众误会什么？危险怎么升级？
3. **信息载体十项**：所有线索/恐怖附着在：动作、道具、声音、空间、光、对话、沉默、反应、时间、节奏
4. **询问场景规则**：不要一问一答，被问的人永远在绕弯子，永远有不想说的事，真话在停顿里

### 第五步：反转与余味设计
1. 三层反转：情节反转（凶手是谁）→人物反转（他原来是这样的人）→主题反转（原来这个故事讲的是这个）
2. 反转必须改写之前所有事的意义，不能只是换个凶手
3. 结尾留最后一根刺：不要圆满结束，留一个让观众看完想很久的细节
4. 主角必须付出代价，不能全身而退

### 第六步：基础自检
1. 按悬疑100分标准打分，低于80分重写
2. 把所有线索列出来，看是不是初看都指向假答案，回看都指向真答案
3. 把所有解释性台词删掉，换成动作/细节/潜台词
4. 检查有没有靠大段台词圆真相，真相应该观众自己拼出来

### 第七步：悬疑专属高颗粒度优化（在通用8步优化基础上，增加悬疑特有检查）
通用优化流程严格按screenwriter的8步优先级（前置定标→内核→人物→结构→节奏→单场→文本→落地），在此基础上增加悬疑专属检查：

#### 1. 内核层悬疑检查
- 主题和悬疑结合：真相揭开的同时，主题也落地，不是查完案再讲道理
- 基调统一：悬疑感全程保持，不能中间突然变成喜剧/爱情片破功
- 希区柯克炸弹检查：观众知道的危险，主角不知道，紧张感持续，不是靠突然吓人

#### 2. 人物层悬疑检查
- 主角四层动机：查案的私人代价必须和案件本身相关，不能是"顺便查个案"
- 凶手/反派：动机自洽，不是疯子，他的逻辑你甚至能共情；和主角形成镜像，他就是主角另一种选择
- 每个人物的秘密：所有出场人物都有不想让人知道的事，都有说谎的理由，没有纯好人纯坏人
- 不可靠叙述者检查：如果主角不可靠，他的哪些叙述是骗观众的，伏笔要提前埋好

#### 3. 结构层悬疑检查
- 谜面出现时间：长片前10页必须出谜面，短剧前30秒必须出钩子
- 信息差控制：每场明确"观众知道什么/主角知道什么/凶手知道什么"，三者永远不完全相等
- 线索双义检查：每个关键线索初看指向假答案，回看指向真答案，没有只有回看才成立的线索
- 红鲱鱼检查：每个误导都有自己的逻辑，不是为了骗观众故意放的假线索
- 伏笔回收：所有伏笔都回收，关键伏笔至少出现3次，间隔不超过30分钟
- 反转检查：反转不是加新事实，是改变之前所有事实的意义；三层反转（情节/人物/主题）齐全
- 时间线检查：上帝视角真实时间线无bug，凶手作案时间、不在场证明逻辑自洽

#### 4. 节奏层悬疑检查
- 危险升级：每10分钟危险升一级，主角越接近真相，危险离他越近
- 张弛有度：紧张的查案戏+日常的人物戏交替，不能全程绷着也不能全程松
- 信息释放：线索碎片化给出，不要一次给完，每个线索给一点，让观众自己拼
- 询问场景：所有询问都有潜台词，没有一问一答给信息，被问的人都在回避

#### 5. 单场悬疑检查
- 每场至少推进一项：案件进展/真相揭露/危险升级/关系变化/主角选择
- 晚进早出：从最紧张的地方开始，信息爆点切走，不拍讨论不拍反应
- 恐怖/不安：所有紧张感通过具体细节表现（没关的门、不对的声音、对方停顿了三秒），不写"气氛紧张"
- **三角剧情迂回法（悬疑绝对禁止直线剧情）**：所有恐怖/线索/反转都不能直给：
  - 想写这个地方不对，别直接写"这里很诡异"，先写一切都很正常，最后一个小细节暴露不对（妈妈笑的时候多了一根手指）
  - 想写主角怕，别直接写他手抖，先写他嘴硬说"这有什么好怕的"，最后烛油滴在手上他没动
  - 想写这个人有问题，别直接写他眼神诡异，先写他特别正常特别热情，最后一个动作暴露他不对
- **剧情攻击性（悬疑冲突必须打在痛处）**：所有危险都必须攻击主角的弱点：
  - 主角怕鬼就专门用他怕的东西吓他
  - 主角最在意他妈就用他妈的声音引他回应
  - 主角不信别人就专门制造让他怀疑身边人的假象
  - 主角的缺陷、创伤、最在意的人，就是反派要攻击的地方，无关痛痒的惊吓不叫恐怖

#### 6. 结尾悬疑检查
- 主角付出代价：查完案主角失去了什么，不能全身而退
- 余味：最后留一根刺，不要圆满，留一个让观众想很久的细节
- 公平性：回看所有线索都在，观众和主角获得的信息一样多，没有藏线索
- 不解释：不要最后坐下来解释所有事，真相观众自己能拼出来

## 6. 标准剧本格式要求（严格遵守通用编剧规范）
悬疑剧本和所有影视剧本一样，必须严格遵守标准好莱坞电影剧本格式，绝对不能写成小说/散文/故事：
- 场头全大写：INT./EXT. 地点 - 时间
- 动作只写拍得到的，不写心理、不写形容词、不写"气氛紧张"
- 人物名居中全大写，对话居中偏左，单句不超过3行
- 所有恐怖/紧张感通过具体细节表现（没关的门、停了的钟、半杯茶、对方停顿三秒），不写"他很害怕""气氛很诡异"
- 详细格式规范、正反例见screenwriter通用编剧第5章，违反格式直接重写

❌ 悬疑剧本常见格式错误（反例）：
> 深夜，走廊里很黑，气氛非常诡异，警察心里很害怕，慢慢往前走，他觉得凶手就在附近。突然，门后面跳出来一个人！警察吓了一跳，原来是他的同事。
> （错误：有心理、有形容词、靠jump scare、格式混乱，拍不出来）

✅ 正确悬疑剧本写法（正例）：
```
INT. 公寓走廊 - 夜
声控灯坏了，只有应急灯绿莹莹的光，一闪一闪。
警察的皮鞋踩在地上，回声很长。
他手放在枪套上，一步一步往前走。
走廊尽头的门，虚掩着，门缝里漏出一点光。
他停在门口，深呼吸，伸手推门。
门"吱呀"一声开了。
一个人站在门后。
警察的手瞬间把枪拔出来，上膛。
			警察
		不许动！
应急灯闪了一下。
是他的同事，举着咖啡杯，被他吓了一跳，咖啡洒了一半。
```
（正确：没有"诡异""害怕"，所有紧张感在声音、光、动作里，格式标准，能直接拍）

## 7. 输出格式

```
【名称】【子类型】
【核心谜面】
【真实真相】（上帝视角）
【假答案/误导方向】
【主角】（含四层动机Want/Need/Flaw/Fear、私人代价）
【真凶/对手】（含动机逻辑）
【关键双义线索】（3个以上）
【最大红鲱鱼】
【最终三层反转】
【结尾代价/余味】
```
### 悬疑大纲
```
【人物秘密表】（每个人的秘密/欲望/恐惧/谎言）
【真实时间线】（上帝视角，所有事按顺序）
【叙事时间线】（观众看到的顺序）
【双义线索表】（初看意思/回看意思/出现场次）
【红鲱鱼误导表】（误导内容/为什么合理/揭穿场次）
【分场大纲】（每场信息放什么藏什么/推进什么）
```
### 悬疑剧本
严格按标准电影剧本格式输出，场头→动作→人物→对话，所有恐怖/紧张通过具体细节表现，不写形容词不写心理，重点标注：线索出现的地方、误导的地方、信息差的地方
### 悬疑诊断
```
【总分】/100
【谜面问题】【线索问题】【反转问题】【人物问题】【格式问题】
【具体修改建议】【修改后版本】
```

## 8. 质量标准（100分制，80分合格）
| 维度 | 分 | 高颗粒度检查标准 |
|------|----|----------------|
| 核心谜题 | 15 | 谜面清晰，真相写大纲前就确定，假答案可信，回看公平，无新事实反转 |
| 悬疑铁律 | 15 | 无脸谱化，无解释语言，对话有潜台词，信息差控制准确，不靠jump scare |
| 信息差控制 | 15 | 每场明确三方信息（观众/主角/凶手），大悬念套小悬念，无大段解释圆真相 |
| 人物 | 15 | 主角查案有私人代价，凶手有自洽逻辑和镜像关系，每个人有秘密，人物弧光完整 |
| 线索误导 | 15 | 线索双义，红鲱鱼有独立逻辑，关键伏笔≥3个全回收，无机械降神，时间线无bug |
| 节奏场景 | 10 | 前10页出谜面，危险持续升级，张弛有度，每场有推进，晚进早出无水戏 |
| 反转余味 | 15 | 三层反转改写因果，主角付出代价，结尾有刺有余味，不解释所有谜团 |

## 9. 常见错误（严格禁止）
❌ 水词水动作，大量没有信息量的描写，节奏慢，啰嗦
❌ 节奏全程平，没有张弛，没有危险升级，观众看困
❌ 规则写了没后果，违反规则什么事都没有，不紧张
❌ 写成小说/散文，有心理活动、有形容词、格式混乱，不是标准剧本格式
❌ 最后靠大段解释圆真相、凶手突然自爆
❌ 线索只有回看才成立，初看完全不合理
❌ 红鲱鱼就是骗观众，没有自己的逻辑
❌ 警察/侦探太蠢衬托凶手聪明
❌ 主角查案没有私人原因，就是好奇心，主角像机器人没有情绪没有弱点
❌ 凶手是疯子，没有自洽的世界观
❌ 靠jump scare吓人，不靠信息差制造悬念
❌ 结尾圆满，主角没有任何代价，结尾平没有刺
❌ 解释所有谜团，不留余味

## 10. 正反例
（剧本格式正反例见第6章，节奏正反例见第4章，其他写作正反例）
❌ 反例："气氛非常紧张，警察慢慢推开门，凶手突然跳出来！原来凶手是管家！"
- 问题：全是解释语言，靠jump scare，反转突然没有伏笔
✅ 正例："警察推开门，桌上的茶还冒着热气。他看到书架上的钟停在3:15——和死者手表上的时间一样。钟后面，有半张没烧完的照片，照片上的人，是他自己。"
- 没有紧张两个字，恐怖在细节里，线索双义，反转改写因果

## 11. 训练计划
- 第1周：格式训练+删稿训练——写完删掉所有水词，只留能拍的、有信息量的内容
- 第2-3周：节奏训练——7分钟短片写14个钩子，每30秒一个，每1分钟一个转折
- 第4-5周：线索双义训练——同一个线索写两个完全不同的意思
- 第6周：误导训练——设计一个有独立逻辑的红鲱鱼
- 第7周：信息差训练——写一场询问戏，全程不提核心问题，但观众能感受到
- 第8周：反转训练——设计一个三层反转，改写之前所有事的意义
详细训练见 `references/mystery-exercises.md`
