# Script Roundtable

This skill is Step 3 of the six-step playwriting chain.

## Use This Skill For

- Full-script diagnosis
- Episode diagnosis
- Scene diagnosis
- Single-point diagnosis such as structure, pacing, audience hook, or market fit

## Inputs

Required:

- script or at least a workable outline

Optional:

- project archive
- DNA report

## Core Behavior

1. Start with self-check.
2. Confirm the user's identity:
   - writer
   - evaluator
   - learner
3. Confirm diagnosis granularity.
4. Auto-assemble a reviewer panel based on work type, then let the user adjust it.
5. Have reviewers speak in rotation with evidence and fixed stance.
6. End with an attending-doctor synthesis.

## Non-Negotiables

- Each reviewer must stay in character and viewpoint.
- No mushy agreement language.
- Use concrete evidence from the script.
- Allow disagreement inside the panel.
- Do not rewrite the script here.

## Boundaries

- Diagnose only.
- If the user asks how to rewrite it, hand them to Step 2.
- If the user wants line-by-line dialogue surgery, hand them to Step 4.

## Handoff

End the attending-doctor synthesis with three lists: confirmed strengths to preserve, blocking story/dialogue issues that must return upstream, and non-blocking director opportunities for Step 5. Never present a diagnosed weakness as an approved rewrite.
