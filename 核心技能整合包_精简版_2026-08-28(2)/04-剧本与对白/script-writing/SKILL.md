# Script Writing

This skill is Step 2 of the six-step playwriting chain.

## Use This Skill For

- Writing the actual script after Step 1 is complete
- Switching between standard screenplay mode and novelized script mode
- Matching the draft to a target pacing style such as short drama, series, short video, anthology, microfilm, or feature film
- Writing in episodic packaging when the project needs per-episode structure

## Required Inputs

- Project archive
- Outline

Optional:

- DNA report from benchmark analysis

## Core Behavior

1. Start with a short self-check.
2. Confirm or infer:
   - writing mode
   - pacing mode
   - whether episodic packaging is on
3. If the trigger is vague, ask the minimum necessary clarifying question instead of guessing recklessly.
4. Follow the nine-step writing workflow in the reference.
5. For long outputs, split into batches and explicitly preserve continuity.

## Mode System

- `M1` standard screenplay: stronger for scene-based production output
- `M2` novelized script: stronger for emotional readability and prose flow
- episodic packaging: a wrapper layer for serial work, not a peer mode

## Pacing System

- `R1` short drama
- `R2` long-form series
- `R3` short video
- `R4` anthology / unit drama
- `R5` microfilm
- `R6` feature film

## Output Contract

- Preserve hard constraints from the archive.
- Do not silently rewrite the project's core identity.
- End every substantial output with `创作笔记`.
- Stay candid; do not fake confidence about weak sections.

## Boundaries

- This skill writes the script.
- It does not replace Step 3 roundtable diagnosis, Step 4 dialogue surgery, Step 5 storyboard design, or Step 6 prompt translation.

## Storyboard Handoff

When a scene or episode is ready for downstream diagnosis and eventual Step 5, preserve a compact scene packet. Steps 3 and 4 may diagnose or lock dialogue, but they must retain this packet:

- target platform, scene/segment duration and pacing mode
- scene function and entry state
- character objective, obstacle and current tactic
- visible trigger and causal beat chain; each beat records cause -> visible action -> feedback -> state change
- mid-scene turn, exit delta and next-scene debt
- character/audience knowledge permissions
- prop ownership, location continuity and required physical actions
- dialogue draft status: provisional or locked

Do not prescribe camera moves or SD wording in this packet.
