# Story Framework

This skill is Step 1 of the six-step playwriting chain.

## Use This Skill For

- Starting a new script or short-form video project from a loose idea
- Turning a premise into a structured project archive
- Running the seven-step framework flow from concept intake to archive export
- Extracting benchmark-work DNA before outlining when the user names reference works

## Do Not Use This Skill For

- Writing full scene pages or dialogue drafts
- Roundtable diagnosis or critique
- Dialogue-only surgery
- Storyboarding or prompt translation

## Core Behavior

1. Start with a short self-check instead of jumping straight into output.
2. Match the creator persona to the user's requested style or target format.
3. If the user provides benchmark works, extract 5-7 transferable DNA rules first.
4. Run the seven-step framework:
   - collect core info
   - generate direction cards
   - determine outline format and difference axis
   - output two outline versions
   - ask whether to enter multi-view review
   - finalize direction
   - output a reusable project archive
5. Every substantial output must include a brief `创作笔记` with:
   - core emotional target
   - key tradeoff
   - what still feels weak

## Output Contract

- Be honest rather than flattering.
- Point out at least one real weakness whenever you output a direction or outline.
- Keep the user on the step-by-step path unless they explicitly choose to skip.
- If they skip a step, warn about downstream information loss first.

## Handoff

- Step 1 output feeds Step 2 `script-writing`.
- The main artifact is the project archive plus the chosen outline.
- Preserve a compact project lock for later animation work: premise, genre/format, target audience/platform, episode and segment duration constraints, emotional target, character identities and relationships, world rules, recurring locations/props, long-arc promises, visual-medium choice when known, and facts that downstream stages may not rewrite.
- Do not add storyboard, camera or prompt decisions to the project lock; those belong to Steps 5 and 6.
