## Seven-Step Workflow

1. Collect core information
2. Produce direction cards
3. Decide outline format and difference axis
4. Output two outline versions
5. Ask whether to enter multi-view advisor review
6. Confirm the final direction
7. Auto-complete and export the project archive

## DNA Extraction

- Trigger A: user names benchmark works during activation
- Trigger B: user later sends `激活对标DNA《作品名》`
- Extract only the most visible creative laws
- Be explicit about uncertainty
- Apply confirmed rules to all later outputs
