# Qidu Cinematic Charter Reference

Source: `F:\剧本创作四步骤\提示词画风\AIGC提示词手册·七渡(1).html`

## Base Visual Identity

```text
诺兰《星际穿越》电影质感，霍特玛掌镜，IMAX 65mm 胶片拍摄，柯达 Vision3 5219，有机胶片颗粒，高光自然晕染，柔和对比度，自然光与实用光主导，球面镜头浅景深，胶片化学调色，无数字锐化，电影剧照级画面。
```

English:

```text
Interstellar (2014) cinematic aesthetic, Hoyte van Hoytema cinematography, shot on IMAX 65mm Kodak Vision3 5219 film, organic film grain, natural halation on highlights, soft contrast curve with lifted blacks, naturalistic available light and practical lights, spherical lenses, shallow depth of field, photochemical color grading, no digital sharpening, cinematic still frame.
```

## Three Color Systems

### Earth / Dusty Warmth

```text
暖琥珀色调，怀旧褪色，沙尘弥散，自然光主导，柯达褪色感（faded Kodachrome），泛黄高光，中性偏暖的肤色，低饱和绿色，颗粒明显，大气尘雾，黄金时刻农田，Terrence Malick 式怀旧。
```

### Spaceship Interior / Industrial Teal Gray

```text
工业冷青灰色调（teal-gray），实用光源（practical lights）暖色点缀，高对比度，深黑背景，金属质感冷峻，人物面部用暖色实用光打亮，背景压暗，NASA 写实风，低饱和，低调打光（low-key lighting）。
```

### Space / Black Hole / Minimal Black White

```text
近乎黑白，深邃黑色，纯净冷白，零色彩干扰，卡冈图亚黑洞：暖橙色吸积盘 vs 纯黑虚空 = 极端反差，极简主义色彩，沉默的宏大，渺小感与神圣感并存。
```

## Human Realism

Skin:

```text
真实皮肤质感，自然肤色不均，毛孔克制可见但不堆砌，轻微油光与汗渍，无美颜磨皮，无塑料感，皮肤上有环境痕迹（沙尘/汗/泪/红润），胶片柔光下的皮肤通透感。
```

Hair:

```text
头发有真实重量感和分股，几缕被风吹乱，不完美的发型，自然油光，没有 CG 完美感，胶片柔焦下的发丝光晕。
```

Eyes:

```text
眼睛有湿润的真实反光，瞳孔清晰但不锐利，眼白有自然血丝（不夸张），眼神聚焦在画面外某点（不是直视镜头），睫毛根部细节自然，眼角有轻微泪光 / 疲惫感。
```

## Motion

```text
捕捉于动作中段，非摆拍，自然身体重心，微动态模糊（仅手部/发丝/衣角），身体有重量感，呼吸可见（胸腔/肩膀微起伏），肌肉有自然张力，不僵硬。
```

English:

```text
caught mid-motion, candid not posed, natural body weight distribution, subtle motion blur on hands/hair/clothing edges only, visible breathing (chest/shoulder rise), natural muscle tension, never stiff.
```

## Emotion

General base:

```text
克制的情绪表达，情绪藏在眼睛和呼吸里，不夸张的面部肌肉，微表情主导，诺兰式情感克制，库珀式压抑，安静的力量感。
```

Sadness:

```text
强忍泪水，眼眶发红但泪未落，下颌肌肉绷紧，呼吸短促，喉结上下滑动，嘴角微下沉但不哭出声，眼神聚焦于一点不敢移开。
```

Joy / Reunion:

```text
眼睛先于嘴角先笑，泪光闪现，颤抖的笑容，难以置信的呼吸停顿，伸手又缩回的迟疑。
```

Awe:

```text
张开的嘴但没有声音，瞳孔放大，呼吸暂停，身体僵在原地，眼睛反射着光源，渺小感和神圣感同时存在。
```

Fear:

```text
瞳孔急速收缩，颈部血管浮起，肩膀僵硬上抬，手指不自觉抓紧，呼吸急促但克制不出声。
```

Resolve:

```text
平静到反常的脸，眼神坚定无波澜，深呼吸一次，下巴微抬，嘴唇抿成直线，不是悲壮而是接受。
```

Longing:

```text
长久的远眺，眼神空洞但不悲伤，习惯性的等待姿态，手指无意识摩挲一个旧物，脸上有岁月的疲惫但保留着希望。
```

## Ready-Made Templates

### Close-Up Emotion Shot

```text
[人物描述] 的特写镜头，[情绪描述]。
人物质感：真实皮肤纹理，自然肤色不均，眼睛有湿润反光，睫毛细节自然，发丝有重量感，几缕被风吹乱。
动态：捕捉于动作中段，呼吸可见，身体微微张力，克制的情绪表达，情绪藏在眼睛里。
画面质感：诺兰《星际穿越》电影质感，霍特玛掌镜，IMAX 65mm 柯达 Vision3 5219 胶片，有机颗粒，高光晕染，柔对比度，自然光主导，浅景深，电影剧照感。
```

### Medium / Wide Shot

```text
[场景描述]，[人物在做什么]，[情绪基调]。
人物：真实身体重心，自然站姿/动作，衣物有重量与褶皱，[插入具体动作关键词]。
光线：自然光 + 实用光源，光线在皮肤上不均匀包裹，背景压暗，人物通过光被分离出来。
画面质感：诺兰《星际穿越》电影质感，霍特玛掌镜，IMAX 65mm 柯达 Vision3 5219 胶片，有机颗粒，高光晕染，柔对比度，球面镜头浅景深，胶片化学调色，无数字锐化，电影剧照感。
```

### Two-Person Scene

```text
[人物 A] 和 [人物 B] 在 [场景]，[关系 / 情绪]。
两人之间的距离感：[紧密拥抱 / 隔着东西对望 / 一前一后]，彼此的肢体语言相互呼应，A 的眼神看向 [B / 别处]，B 的眼神看向 […]。
情绪克制，靠肢体距离和眼神传递，不靠夸张表情。
画面质感：诺兰《星际穿越》电影质感，霍特玛掌镜，IMAX 65mm 柯达 Vision3 5219 胶片，有机颗粒，高光晕染，柔对比度，自然光与实用光主导，浅景深，电影剧照感。
```

### One-Line Universal Template

```text
[人物] 在 [场景] [做什么]，[一个具体情绪 + 一个具体微动作]。
拍摄风格：诺兰《星际穿越》，霍特玛 IMAX 65mm 胶片，柯达 5219 颗粒，自然光，胶片柔光，克制对比，浅景深，真实皮肤质感，眼神聚焦画面外，情绪藏在呼吸里，电影剧照感，非数字锐化，非摆拍。
```
