📋 LocalMiniDrama 分镜 Excel 导入模板

使用说明：

  1. 数据结构：每个对象代表一个视频编号块（如"01-01"、"01-02"等）
  2. 总时长计算：系统会自动根据所有镜头的秒数之和取整作为该分镜的时长
  3. 自动关联：场景和角色名称需与已存在的素材库中完全匹配
  4. 格式要求：
    • durationSec：镜头时长，单位秒（如 3.4、6.4）
    • shotType：景别（全景、中景、近景、特写等）
    • cameraPos：机位角度（高机位、低机位、平视、侧拍、肩后等）
    • cameraMove：运镜方式（缓慢推近、快速横移、静态浅焦、横移跟拍等）

前端使用示例：

  
// 1. 创建 Excel 文件或转换为 JSON
const excelData = [
  {
    videoId: "01-01",
    totalDuration: "13.6s",
    scene: "SC01 中和宫庭院大树下",
    characters: ["林君雪·浅朱庭院宫装", "丹珍", "巧心", "谷雨"],
    scenarioDesc: "白日近黄昏...",
    lighting: "LG01 庭院斜阳：斜阳 5200K...",
    logicLock: "先交代浅坑...",
    shots: [
      {
        shotNo: 1,
        durationSec: 3.4,
        shotType: "全景",
        cameraPos: "高机位",
        cameraMove: "缓慢推近",
        visualDesc: "←承上...",
        remarks: ""
      },
      // ...更多镜头
    ]
  }
];

// 2. 发送到后端
const response = await fetch('/api/v1/storyboards/import-excel', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    episode_id: 8,  // 剧集 ID
    data: excelData  // 上面定义的 JSON 数组
  })
});

const result = await response.json();
console.log(result);
// { success: true, message: "成功导入 X 个分镜", imported: X, failed: Y }
