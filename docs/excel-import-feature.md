# 📥 Excel 分镜导入功能使用说明

## 功能概述

支持从 Excel 或文本直接导入格式化的分镜数据，自动创建分镜并关联角色、场景素材。

---

## 前置条件

1. **已有角色、场景素材**：确保已在系统中录入相关角色图片/视频和场景图片
2. **选择剧集**：在分镜页面选择要导入的剧集（episode_id）
3. **准备分镜数据**：按照下面的格式准备 Excel 或文本内容

---

## 分镜数据格式

### 基础格式

每行一个分镜块，以分隔符 `====【视频编号】====` 开头：

```
====【视频编号 01-01】====总时长（秒）、场景、人物
镜头 XX(X.Xs) 画面描述
台词："XXX"（可选）
运镜：景别 + 机位 + 运动（可选）
备注：XXX（可选）
===

====【视频编号 02-02】====总时长、场景、人物
镜头 XX(X.Xs) 画面描述
...
```

### 详细示例

```text
====【视频编号 01-01】====30、书房、张三
镜头 01(3.5s) 坐在书桌前翻阅文件
台词："这份报告终于完成了..."
运镜：特写，固定镜头
备注：体现疲惫感

镜头 02(6.4s) 站起来走到窗边眺望远方
台词："接下来的挑战..."
运镜：中景，缓慢推镜头
备注：窗外夜景

镜头 03(3.8s) 回头看向书桌上的照片
台词："一定会努力 overcome 的"
运镜：全景，摇镜头到照片
===

====【视频编号 02-02】====45、公园、李四、王五
镜头 01(5.4s) 两人在长椅上交谈
台词："听说项目通过了？"
运镜：近景，轻微晃动模拟手持
===

镜头 02(2.6s) 点头微笑
台词："是啊，不容易啊"
运镜：特写
===

镜头 03(5.8s) 看向远处的孩子玩耍
台词："看到新一代成长真好"
运镜：远景，缓慢拉远
```

### 解析规则

| 字段 | 识别方式 | 要求 |
|------|----------|------|
| **视频编号** | `====【XX-XX】====` | 必需，用于排序和标识 |
| **总时长** | `第 2 个====后的数字` | 会自动计算验证 |
| **场景名** | `,第 1 个逗号后的文本` | 会从 scenes 表匹配 |
| **人物** | `,后续逗号分割` | 会从 characters 表匹配 |
| **镜头** | `镜头 XX(X.Xs)` | 必需，X 可以是中文或英文括号 |
| **画面描述** | 镜头行后面的非空行 | 必选，构成 prompt 核心 |
| **台词** | `台词："..."` | 可选 |
| **运镜** | `运镜：xxx` | 提取景别 ['大特写','特写','全景','中近景','中景','近景','远景']、机位、运动 |
| **备注** | `备注：xxx` | 可选 |

## 使用步骤

### 1️⃣ 进入分镜页面

打开剧集编辑页，找到"批量生成分镜视频"按钮旁边的 **"📥 从 Excel 导入分镜"** 按钮

### 2️⃣ 选择导入方式

对话框有两个标签页：

#### 方式 A：粘贴文本
- 直接从 Excel 复制分镜数据（Ctrl+C）
- 粘贴到文本区域
- 点击确认导入

#### 方式 B：上传 JSON
- 如果数据已导出为 JSON 格式，可直接拖拽上传
- 支持 `.json`, `.xlsx`, `.xls` 扩展名

### 3️⃣ 确认导入

系统会：
1. ✅ 自动解析每行分镜块
2. ✅ 提取镜头数量与时长
3. ✅ 自动关联场景中素材（按名称匹配）
4. ✅ 自动关联角色素材（按名称匹配）
5. ✅ 生成 frame_prompts（镜头详情）
6. ✅ 累计总时长取整（如 13.6s → 14s）
7. ✅ 导入到 storyboards 表

### 4️⃣ 查看结果

- 成功后自动刷新分镜列表
- 可以看到新导入的分镜缩略图
- 可以检查角色、场景关联是否正确

## 注意事项

### ⚠️ 必填字段

- 视频编号格式必须正确：`====【XX-XX】====`
- 至少有一个镜头，否则无法保存
- 每个镜头必须有画面描述（不能为空）

### ⚠️ 匹配规则

- **场景匹配**：严格匹配 `scenes.name`，不完全一致则跳过关联
- **角色匹配**：严格匹配 `characters.name`，多个人物用逗号或顿号分隔
- 未匹配的素材会被忽略，但仍会保存分镜

### ⚠️ 时长计算

- 系统会自动累加所有镜头秒数
- 最终取整（`Math.round()`），向上或向下取决于小数部分
- 示例：`3.5 + 6.4 + 3.8 = 13.7` → `14 秒`

### ⚠️ 失败处理

- 如果单个分镜解析失败，其他正常分镜仍会导入
- 失败原因会提示在消息区
- 建议先小规模测试再大批量导入

## API 接口

### POST `/api/v1/storyboards/import-excel`

**请求体**：
```json
{
  "episode_id": 123,
  "data": [
    "====【01-01】====30、书房、张三\n镜头 01(3.5s)...",
    "====【02-02】====45、公园、李四\n镜头 01(5.4s)..."
  ]
}
```

**响应**：
```json
{
  "success": true,
  "count": 2,
  "data": [...],
  "errors": [] // 如果有失败记录
}
```

## 常见问题

**Q: 为什么我的分镜没关联上角色？**  
A: 检查角色名称是否完全一致，注意空格和中英文字符。可以在系统中查找角色名称复制使用。

**Q: 总分镜显示时长不对？**  
A: 这是正常的，系统会自动重新计算并取整。原手动输入的时长会被替换为新计算的总时长。

**Q: 能不能一次导入 100 条以上？**  
A: 可以，但建议分批测试。首次建议先试 5-10 条，确认格式无误后再批量导入。

**Q: 如何回滚导入错误？**  
A: 在分镜列表中选择错误的分镜，点击删除按钮即可删除。
