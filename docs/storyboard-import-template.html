🔍 字段详解

🎬 分镜标题
格式：====【XX-XX】====总时长（秒）、场景名、人物 1、人物 2...
说明：
  • 视频编号 用双中括号，如【01-01】代表第 1 集第 1 个分镜
  • 总时长 单位秒，系统会自动验证并取整
  • 场景名 必须与系统中已存在的场景名称完全一致
  • 人物 多个角色用逗号或顿号分隔，需与角色库匹配
🎞️ 镜头信息
格式：镜头 XX(X.Xs) 画面开头
说明：
  • 数字顺序不要跳号，可以中断补上（如 01, 02, 03...）
  • 时长必须带 s 后缀，保留一位小数
  • 支持中文括号 ( ) 或英文括号 ()
📝 画面描述
说明：这是最重要的字段，将作为 AI 生成图像的核心提示词。
建议：
  • 明确主体动作（"张三坐在书桌前翻阅红色封面文件"）
  • 描述环境细节（"暖黄色台灯下，窗外细雨"）
  • 提及光影效果（"逆光剪影"、"柔和侧光"）
  • 避免空泛词汇（"漂亮的场景"应改为具体描述）
🎵 台词
格式：台词："XXX"（注意使用英文引号）
说明：角色的对白内容，如果有多个人物同时说话，可以用不同镜头分别表述。
📷 运镜
格式：运镜：景别，机位，运动
景别选项：大特写特写近景中景全景远景
机位选项：固定镜头 / 仰拍 / 俯拍 / 平视 / 主观视角
运动选项：推镜头 / 拉镜头 / 摇镜头 / 移镜头 / 跟拍 / 环绕
💭 备注
补充说明特殊要求，如情感表达、氛围、材质细节等。

📖 使用步骤

  1. 下载模板 - 点击上方按钮下载 storyboard-import-template.xlsx
  2. 准备数据 - 在 Excel 中按上述格式填写分镜内容
  3. 保存为 JSON - 每行一个完整的分镜块（从 ====【 开始到下一个 ====【 或文件结束）
  4. 上传导入 - 在分镜页面选择"上传 JSON"标签页，拖拽文件到此处
  5. 确认导入 - 系统会验证格式并创建分镜
✓
准备工作：确保已在系统中录入对应的角色素材（图片/视频）和场景素材，否则无法自动关联。
✓
测试建议：首次导入建议先试 5-10 条，确认格式无误后再批量导入大量分镜。
✓
时长计算：系统会自动累加所有镜头秒数，最终取整（如 13.6s → 14s），手动输入的时长会被替换。

❓ 常见问题

问题 解决方案
为什么我的分镜没关联上角色/场景？ 检查名称是否完全一致（包括空格、中英文字符）。可以在系统中查找对应素材的名称复制使用。
总分镜显示时长与实际不符？ 这是正常的，系统会自动重新计算并取整。如需调整，可在导入后手动修改单个镜头时长。
如何导出已导入的分镜？ 目前只支持导入功能，导出功能正在开发中。可暂时通过截图或复制文本方式备份。
一次最多能导入多少条？ 理论上没有上限，但建议分批导入（每次不超过 50 条）以便及时发现错误。

⚠️ 注意事项

!
分隔符必须准确：每行的 ====【XX-XX】==== 必须完全一致，不能用其他符号代替。
!
必须至少有一个镜头：没有镜头的分镜无法保存。
!
画面描述不能为空：每个镜头必须有画面描述，否则会导致 AI 生成失败。
!
场景和人物名称要完全匹配：区分大小写和空格，建议直接从系统中复制名称。
