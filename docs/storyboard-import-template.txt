📥 LocalMiniDrama 分镜 Excel 导入模板说明

使用方法：
========
1. 将此文件的内容复制粘贴到 Excel 中
2. 每行填写一个完整的分镜块（从====开始到下一个===或文件结束）
3. 保存为 .xlsx 或 .csv 格式
4. 在分镜页面点击"📥 从 Excel 导入分镜"上传此文件


数据格式规范：
============
====【视频编号】====总时长（秒）、场景名、人物 1、人物 2...
镜头 XX(X.Xs) 画面描述
台词："角色对白内容"
运镜：景别 + 机位 + 运动（可选）
备注：特殊要求（可选）


详细规则：
========
1. 分隔符必须准确：每行的"====【XX-XX】===="必须完全一致
2. 视频编号格式：【集数 - 分镜序号】，如【01-01】表示第 1 集第 1 个分镜
3. 镜头序号不要跳号，可以中断补上（如 01, 02, 03...）
4. 场景和人物名称必须与系统中已存在的素材名称完全一致（包括空格、中英文字符）
5. 支持中文括号 ( ) 或英文括号 ()
6. 每个镜头必须有画面描述（不能为空）


字段详解：
========
【视频编号】
   格式：【XX-YY】其中 XX=集数，YY=分镜序号在同一集内的序号
   示例：【01-01】、【02-03】、【05-12】

【总时长】
   单位：秒，整数或小数均可
   注意：系统会自动累加所有镜头时长并取整

【场景名】
   必填项，必须与系统中的场景名称完全匹配
   提示：建议直接从系统中复制场景名称

【人物】
   多个角色用逗号或顿号分隔
   必须与系统中的角色名称完全匹配
   示例：张三、李四、王五


镜头信息格式：
=============
格式：镜头 XX(X.Xs) 画面开头

示例 1: 镜头 01(3.5s) 坐在书桌前翻阅文件
示例 2: 镜头 02(6.4s) 站起来走到窗边眺望远方
示例 3: 镜头 03(3.8s) 回头看向书桌上的照片


完整示例：
========
====【01-01】====30、书房、张三
镜头 01(3.5s) 坐在书桌前翻阅文件
台词："这份报告终于完成了..."
运镜：特写，固定镜头
备注：体现疲惫感

镜头 02(6.4s) 站起来走到窗边眺望远方
台词："接下来的挑战..."
运镜：中景，缓慢推镜头
备注：窗外夜景

镜头 03(3.8s) 回头看向书桌上的照片
台词："一定会努力 overcome 的"
运镜：全景，摇镜头到照片

====

====【02-02】====45、公园、李四、王五
镜头 01(5.4s) 两人在长椅上交谈，秋日午后阳光洒在脸上
台词："听说项目通过了？"
运镜：近景，轻微晃动模拟手持

镜头 02(2.6s) 点头微笑
台词："是啊，不容易啊"
运镜：特写，自然光

镜头 03(5.8s) 看向远处的孩子玩耍
台词："看到新一代成长真好"
运镜：远景，缓慢拉远

===


注意事项：
========
⚠️ 分隔符必须准确
   "====【XX-XX】===="中的等号数量不能少，括号必须是中文全角

⚠️ 场景和人物名称要完全匹配
   区分大小写和空格，建议直接从系统中复制名称

⚠️ 至少需要有一个镜头
   没有镜头的分镜无法保存

⚠️ 画面描述不能为空
   每个镜头必须有画面描述，否则会导致 AI 生成失败

⚠️ 首次测试建议小规模
   先试 5-10 条，确认格式无误后再批量导入大量分镜


常见问题：
========
Q: 为什么我的分镜没关联上角色/场景？
A: 检查名称是否完全一致（包括空格、中英文字符）。可以在系统中查找对应素材的名称复制使用。

Q: 总分镜显示时长与实际不符？
A: 这是正常的，系统会自动重新计算并取整。如需调整，可在导入后手动修改单个镜头时长。

Q: 一次最多能导入多少条？
A: 理论上没有上限，但建议分批导入（每次不超过 50 条）以便及时发现错误。


技术细节：
========
时长计算：Math.round(sum(镜头时长))，即 13.6s → 14s
括号兼容：支持 [（(]XX[）)] 的全角半角混合写法
分隔识别：按 "^==+\s*\[" 正则表达式分割分镜块


导出说明：
========
目前仅支持导入功能，导出一份 JSON 格式用于备份：
{
  "episode_id": 123,
  "data": [
    "====【01-01】====30、书房、张三\n镜头 01(3.5s)...",
    "====【02-02】====45、公园、李四\n镜头 01(5.4s)..."
  ]
}
